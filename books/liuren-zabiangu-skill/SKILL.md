# 六壬杂编边界：什么算六壬，什么只是邻居

六壬书堆里常混着几类"不是六壬、但必须认识"的书。认不出它们，就会出现三种错误：把星命当六壬断、把奇门套六壬、把日本六壬当中国六壬。本技能只做分界与著录，不做断法。

## 一、先把整个"阴阳家"的分科摆出来（十三门）

这一套分科出自近人《雷公式简述》（無塵／葉楓撰），是少见的把术数各科一次说清的分类，可作为判断"某书属哪一门"的坐标系：

- **三式**：太乙、奇门、六壬。
- **二算**：高弧、勾股、推步（天文测算，非占）。
- **五占**：日月、星辰、云气、风角、四时（观象之占）。
- **四相**：相都城、相宅墓、相人形、相字画。
- **三造**：干支衰旺、丛辰煞曜、七政四余、斗首元辰（择日与造命）。
- **三命**：五星四柱、暗藏纳音。
- **四卜**：灼龟、揲蓍、纳甲、演禽。
- **二诊**：三指深沉（脉）、一针补泻（针）。

> 作者按语："阴阳之学甚多且杂，**贵专忌散**"——引汉刘歆语。这句话是读杂编的正当态度：知道邻居是谁，但不要串门断事。

## 二、雷公式：曾经与六壬并列为"式"的第四家

### 制度上的证据（这条最硬）
- 《唐六典》卷十四《太卜》："凡式占，辨三式之异同。"注："**一曰雷公式，二曰太乙式，并禁私家畜；三曰六壬式，士庶通用之。**"
- 《唐律·职制律》（贞观律卷三第二十条）："诸玄象器物、天文、图书、谶书、兵书、《七曜历》、太一、**雷公式**，私家不得有，违者徒二年；私习天文者亦同。"
- 后周广顺三年敕："今后所有玄象器物、天文图书、谶书、七曜历、太一、雷公式，私家不得有及衷私传习，如有者，并须禁毁。"
- 书目著录：《新唐志·子部》有《雷公式经》一卷；《宋史·艺文志》有《雷公式局》一卷、《雷公印法》三卷、《雷公摄杀律》一卷；《日本国见在目录》五行家类下并列"咒禁、符箓、五行、六壬、雷公、太一、易、遁甲、式、相、仙术"。

> 由制度可见：**唐人心目中的"式"是雷公、太乙、六壬三家并列，奇门尚未入"三式"之列**；"三式＝太乙、奇门、六壬"是宋代（仁宗命杨维德等撰《景祐》诸经）以后才定型的说法。这一条对读唐宋以前的壬书极重要。

### "雷公即太乙"之说不可信
《壬学琐记》开篇称："唐时功令，以奇门、雷公、六壬为三式，雷公即太乙，所谓太乙雷公式是也。"作者直斥其非，理由是雷公式自有其歌诀体系，与太乙（十六神、九宫、主客算）不是一回事。本技能采其立场：**雷公式非太乙，亦非六壬**。

### 《异玄入室歌》（雷公式歌诀残篇，可辨部分）
此歌是判断"雷公式究竟是什么"的关键证据——它用的是**九宫＋十二位尊星＋七政星曜**：

- 结构："只在**雷霆四局**中，雷霆合气动天地""一守位行九宫转，传音直符于此同"——**以九宫为盘、以雷局为用**。
- 断序："一论年，二论月，三论日时真妙诀，四论生命细推详""仍看何姓属何宫"——**年→月→日时→生命，四层叠加，并配姓氏宫位**（与后世"五音配姓"同一思路）。
- 星曜名目：太阳（"作君喜气浓，资财驴马便亨通"）、月孛（"烧野火，克除新妇手槌胸"）、金水星（"居位吉，居官便得公侯职"）、天罡金星（"巳酉丑年多快乐，西方财马自来迎，印信文书终不错"）、土褥（"损户头，肿病瘟瘗家衰落"）、奇罗（"吉星，白衣变作绿衣人"，但"又忧燥火烧厨屋"）、丙乙凶星（"临到八千方半吉，支惟传主损阴娘"）、水位凶星（"兴灾起祸""合家长幼皆不利，资财耗散病来侵"）。
- 杂煞：将军、太岁、官符、七杀、金神、血刃、台将上星。
- 末署"辛丑年庚子月于吾师家中"。

> 结论：**雷公式＝以九宫雷霆局配七政星曜（太阳、月孛、金水、天罡、土褥、奇罗、丙乙……）的一套星占式法**，与六壬的干支四课三传、太乙的十六神主客算，都是不同系统。它亡佚最彻底，今日只见零篇歌诀。**凡见"雷公式"三字，不可当六壬读**。

## 三、其余四类杂编（著录与分界）

### 1. 《星平会海》——星命合参，不是六壬
- 性质：**七政四余（星）＋子平（平）合参**的命书，主推人命，不排四课三传。
- 分界：凡书中出现"命宫、十二宫、行限、五星、四余、度主"者，属星命；六壬书里出现这些是借用，不可反客为主。
- 素材：本册仅著录，**未取正文**。

### 2. 《遁甲穿壬讲义》——奇门与六壬合参
- 性质：以奇门九宫为盘、六壬课传为用，讲两套如何对接（穿＝穿透、贯通）。
- 分界：此类书最易误导——**它讲的"六壬"是为奇门服务的六壬**，取象偏重九宫方位与门星神，与六壬本系的四课三传主线不同。
- 素材：本册仅著录，**未取正文**。研习时须先有 `liuren-jichu` 与 `liuren-kejing` 的底子，否则会被带偏。

### 3. 吴师青《六壬存验》与手抄《大六壬灵觉经》
- 《六壬存验》：民国术家课验集性质（以存验为主，理论从简）。**未取正文**。
- 其手抄《大六壬灵觉经》：已并入 `liuren-kejing`（课经一组的素材之一），此处只记其版本来源为吴师青手抄本，**影印质量直接影响该组素材可信度**。
- 分界：课验集的价值在"案"，不在"法"；引用其断语须标明是某家之验，不可当经文。

### 4. 阿部泰山两本——日本六壬（天文易）
- 《六壬神课吉凶正断》（另有"〔基础〕"同书重份）、《六壬天文易秘传百法》（另有同书异名重份）。
- 性质：日本传六壬，称"**天文易**"，其特色是把六壬与日本本土的天文、历法、密教修法相合，断法偏重"秘传百法"式的条目化口诀。
- 分界：可参照、可比较（尤其可见中国六壬东传后的变形），但**不可与中国六壬的判据混引**；其"秘传"名目多为日方自创，中国古本无对应。
- 素材：两本均**未取正文**，故本技能不述其具体断法。

## 四、使用边界与素材缺陷

1. 本技能**唯一的实质素材**是《雷公式简述》（無塵／葉楓撰，约 1.6 万字节，含阴阳家十三门分类、唐至宋的雷公式制度史料、《异玄入室歌》全篇）。其余四类（星平会海、遁甲穿壬、吴师青存验、阿部泰山两本）**均只作著录与分界，未取正文**——凡涉及它们的断法、口诀、案例，本技能一概不提供，须回检原书。
2. **《异玄入室歌》文本有讹脱**：OCR 中"出将人相"（应为入相）、"肿病瘟瘗"（瘗／疫之讹）、"白衣变作绿衣人"等字有误；且歌中星曜名（土褥、奇罗、丙乙）与今日通行的七政四余名目不完全对应，**说明雷公式自成一系，不可用七政四余的规则去套它**。引用时须声明"雷公式佚文，名义待考"。
3. **"三式"的定义随时代变动**：唐以雷公、太乙、六壬为式占三家（《唐六典》），宋以后定型为太乙、奇门、六壬。今人一律说"三式＝太乙奇门六壬"，是把宋以后的说法上推到唐。本技能如实并置两说，**不裁断**，但凡引唐宋史料时须用唐说。
4. 本篇作者对《壬学琐记》"雷公即太乙"的驳论，属**一家之言**；《壬学琐记》亦为近代有一定影响的笔记。两说并存，本技能取"雷公非太乙"为工作假设（因其歌诀体系确实不同），但**不代表学界定论**。
5. **本技能不提供任何断法**。它不是"第六个六壬流派"，而是一张"邻居门牌表"。要断事请看：`liuren-jichu`（入门）、`liuren-kejing`（课经）、`liuren-bifa`（毕法）、`liuren-duanan`（断案成案）；要现代路数看 `liuren-liukele`、`liuren-jianhong`、`liuren-beihai-gaoji`、`liuren-qinruisheng`、`liuren-linzheng`。
6. 台账提示：本组尚有**星平会海、雷公式（正文已佚）、遁甲穿壬、吴师青存验、阿部泰山吉凶正断与秘传百法**等书未完成正文蒸馏，其中阿部泰山两本与星平会海均为大体积扫描件，重 OCR 成本高，列为本轮"已知缺口"。
