# 术语表 — 《开元占经-唐-瞿昙悉达》

| 术语 | 上下文线索（OCR） |
|---|---|
| 石氏曰 | 石氏曰：“日再出，为渗光，其国君死，有兵起。”《春秋汉含孳》曰：“日复中，支庶起。”京氏曰：“日再中，帝王穷。”（按《帝王郊祭志》文帝时新垣平上言曰：日再中居顷之日却复中，乃更以十七年为元年。） |
| 郗萌曰 | 《河图帝览嬉》曰：“月犯尾，君臣不和。”郗萌曰：“月犯尾，贵戚有诛者，其国有军将死。”又曰：“在尾宿有变，后宫不安，妃后争人君，子孙不吉，在宫中矣。” |
| 荆州占 | 郗萌占曰：“月初生盛，女主持政。”京氏《易飞候》曰：“月之光如张芒，所宿之国立君；三齐所宿之国，立将军，上卿。”《荆州占》曰：“月上弦巳后盛，君无戕德，臣执权柄，人背君，尊其臣。” |
| 又曰 | 石氏曰：“气在日上，名为戴。”又曰：戴之色青赤。”王朔曰：“日戴者，形如直状，其上微起，在日上为戴。戴者，德也，国有喜也。”如淳曰：“气在日上为戴。”《高宗占》曰：“重戴，天子有喜，得地，若有所立。” |
| 甘氏曰 | 甘氏曰：“有青气，横在日上下者，为格也；格者，格斗之象也。” |
| 黄帝占 | 《河图帝览嬉》曰：“月犯张，有飧客。”郗萌曰：“月犯张，将相死，其国有忧。”《黄帝占》曰：“月蚀张，贵臣失势，皇后有忧，期七十日。”陈卓曰：“月宿张而雾，天子恶之。” |
| 巫咸曰 | 巫咸曰：“岁星守梗河，国有谋兵，四夷兵起，来侵中国，边境有忧。” |
| 海中占 | 《荆州占》曰：“月初生小，而形广大者，月有水灾。”《海中占》曰：“月大而体小者，旱；有气色非常，皆为皇后阴谋事。” |
| 又占曰 | 《河图帝览嬉》曰：“月犯虚，空邑复起。”郗萌曰：“月犯虚，天下乱政，天下大虚，其国有忧，军将死，有哭泣之事；又占曰：月变于虚，有土功事；又曰在外军大饥。” |
| 兵起 | 《洪范传》曰：“天忽变色，是谓易常。天裂见人，兵起国亡。天鸣有声，至尊忧且惊。皆乱国之所由生也。”《天镜》曰：“天忽变色，四夷来侵，不出八年有兵。” |
| 一曰 | 《河图帝览嬉》曰：“月犯须女，天下多女患。”陈卓曰：“月犯须女，将军死，其国有忧。”《郗萌占》曰：“月变于须女，有兵不战而降；又曰有嫁女娶女之事。”陈卓曰：“月宿须女，雾，大人死；一曰蛰虫死。” |
| 春秋纬 | 《春秋纬汉含孳》曰：“日当出不出，懦下，当入不入（阙）。” |
| 陈卓曰 | 《河图帝览嬉》曰：“月犯须女，天下多女患。”陈卓曰：“月犯须女，将军死，其国有忧。”《郗萌占》曰：“月变于须女，有兵不战而降；又曰有嫁女娶女之事。”陈卓曰：“月宿须女，雾，大人死；一曰蛰虫死。” |
| 郄萌曰 | 郄萌曰：“客星入天枪，天下有饥兵。”《荆州占》曰：“客星入天枪，有大战。”石氏曰：“客星出天枪，边外有急，机枪用，有兵起，大将出，期一年。” |
| 兵大起 | 《圣洽符》曰：“岁星犯招摇，边兵大起，敌人为寇；若守之，敌人败，敌人死：期不出二年。”《荆州占》曰：“岁星入招摇，兵起，马多死。” |
| 天文志 | 《天文志》曰：“二星合，有小兵，小人愁，人君忧。”《海中占》曰：“二星相近者，其殃大，相远者，其殃小，无伤。”《荆州占》曰：“二星若合，其国有兵，改立侯王，有德者兴，无德者亡。” |
| 京氏曰 | 石氏曰：“日再出，为渗光，其国君死，有兵起。”《春秋汉含孳》曰：“日复中，支庶起。”京氏曰：“日再中，帝王穷。”（按《帝王郊祭志》文帝时新垣平上言曰：日再中居顷之日却复中，乃更以十七年为元年。） |
| 京房曰 | 甘氏曰：“茀星出东南，本有星，末类茀，所当之国，是受其殃。”京房曰：“茀星三角，三年消；五角，五年消；七角，七年消；九角，九年消。” |
| 有兵 | 《洪范传》曰：“天忽变色，是谓易常。天裂见人，兵起国亡。天鸣有声，至尊忧且惊。皆乱国之所由生也。”《天镜》曰：“天忽变色，四夷来侵，不出八年有兵。” |
| 期三年 | 石氏曰：“辰星犯五诸侯，若守之，兵大起，将士出，诸侯有忧，若有死者。”巫咸曰：“辰星入五诸侯，伺其出之日而数之，二十日兵起发；伺始入处之率，一日军罢。”石氏曰：“守犯乘守五诸侯，诸侯兵死，期三年。” |
| 古今同 | 氐四星，十五度，距西南星，去极九十四度，宋分。古今同。 |
| 河图 | 京氏曰：“日出于午，天子失国。”京氏曰：“日出于巳，天子失明，令不行。”《河图》曰：“日出西方，以母制。” |
| 期一年 | 《海中占》曰：“岁星犯摄提，臣谋其君，若主出走，有兵起。期一年。” |
| 地镜 | 《地镜》曰：“地中哅哅有声，人君好兴兵相致。”《潜潭巴》曰：“地鸣有声，天子不知国，政任妇人。”“地中有声洞洞者，邑亡。”京房《易候》曰：“地中讻讻，若嗷嗷，为凶祥，所爱子死，邦有殃。” |
| 十日 | 《京房占》曰：“月当出而不出，有阴谋，有死王，天下乱。”《郗萌占》曰：“月生七日见者，天下有兵；十日见者，有大兵；十二日至十六日而后见者，天下有灭国。”《海中占》曰：“月出复没，天下乱。” |
| 宋书天文 | 《宋书天文志》曰：“宋孝武孝建元年十月乙丑，荧惑犯进贤星，时吏部尚书谢庄表解职。” |
| 不出其年 | 《黄帝占》曰：“岁星守织女，天下有女忧，有兵起，不出其年。” |
| 期二年 | 石氏曰：“岁星犯阁道绝汉者，为九州异政，各主其王，天下有兵，期二年。” |
| 帝览嬉 | 《河图帝览嬉》曰：“月犯尾，君臣不和。”郗萌曰：“月犯尾，贵戚有诛者，其国有军将死。”又曰：“在尾宿有变，后宫不安，妃后争人君，子孙不吉，在宫中矣。” |
| 京房 | 《地镜》曰：“地中哅哅有声，人君好兴兵相致。”《潜潭巴》曰：“地鸣有声，天子不知国，政任妇人。”“地中有声洞洞者，邑亡。”京房《易候》曰：“地中讻讻，若嗷嗷，为凶祥，所爱子死，邦有殃。” |
| 天官书 | 《天官书》曰：“客星入天鸡，西北之夷且来下降。”郄萌曰：“客星守天鸡，鸡夜鸣，天下尽有惊。”《荆州占》曰：“客星守天鸡，山摧，若大水。” |
