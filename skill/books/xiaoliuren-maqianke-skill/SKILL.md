# 小六壬 / 马前课

## 它是什么

最简的一套速占法：不用工具，随手取数，掐指几秒出结果。传统路径是"以月定起点、以日推次、以时定终"，落在一个六神上，按六神断吉凶。

**核心机制一句话**：把任意三个数（月日时，或任意报数）依次在六个固定位置上数，第三个落点即结果。

## 一、六神定义表

|---|---|---|---|---|---|
| 大安 | 木 / 青龙 | 东 | 一、五、七 | 身不动，静止、心安、平稳 | 吉 |
| 留连 | 水 / 玄武 | 北 | 二、八、十 | 暗昧不明、延迟、纠缠、漫长 | 凶 |
| 速喜 | 火 / 朱雀 | 南 | 三、六、九 | 快速、喜庆、时机已到 | 吉 |
| 赤口 | 金 / 白虎 | 西 | 四、七、十 | 惊恐、口舌是非、血光 | 凶 |
| 小吉 | ⚠️见下 / 六合或螣蛇 | 木作东、水作北 | 一、五、七 | 和合、吉利、介于大安与速喜之间 | 吉 |
| 空亡 | 土 / 勾陈 | 中央 | 三、六、九 | 无结果、忧虑、晦气 | 凶 |

### ⚠️ 一个必须先说清的版本冲突

库内两份材料对小吉的定性不一致：

- **《小六壬预测.txt》**：小吉"五行属木，临六合"，方位未明指，主和合吉利
- **《六壬高级教程.doc》**：小吉"五行：螣蛇水，方位：北方，后天象卦：乾天（西北属金），人物：老男"

其余五神两版一致。**这不是笔误，是流派差异**（一版按"六合和合"取义，一版按"螣蛇=水"入五行生克链）。实操时：
- 只取吉凶含义 → 用哪个版本结论相同（都作吉）
- 要做五行生克、天干化气推演 → 必须先声明用哪一版，不可混用

小吉的人物对应也有差异：一版本作"阴人报喜"，另一版作"老男"。同一个位置，断"来人是男是女"会得到相反答案——这也是流派分歧，如实告知即可。

### 六神掌诀位置（左掌，顺时针固定顺序）

顺序永远是：大安 → 留连 → 速喜 → 赤口 → 小吉 → 空亡。

位置（左手）：大安食指根、留连食指指尖、速喜中指指尖、赤口无名指指尖、小吉无名指根、空亡中指根。

**顺序固定不变，位置不可调换**——这是整套方法唯一的硬约束。

## 二、掐算方法：月 → 日 → 时

三步曲，每步都在六个位置上数，落点作为下一步的起点。

1. **定月**：不管第几个月，一律从"大安"起正月，顺时针数到所求月份
   - 例：十一月 = 大安(1) 留连(2) 速喜(3) 赤口(4) 小吉(5) 空亡(6) 大安(7) 留连(8) 速喜(9) 赤口(10) **小吉(11)**
2. **定日**：以月份落点为初一起，数到所求日
   - 例：十一月落小吉，则小吉为初一、空亡初二、大安初三……初十落**留连**
3. **定时**：以日落点为子时起，数到所求时辰

**落点即结果。**

## 三、随机取数法（本书最强调的一点）

月日时法有个致命限制：同一时辰多人同时求测，结果全一样。所以要用取数法。

**三种取数**：
1. **月日时法**（正统）
2. **变通取数法**：任意报三个数字、写三个汉字（按笔画数）、抽三张扑克
3. **随机取数法**：个数不受限——1 个、2 个、10 个都行（如电话号码、座位号、房间号、生肖数、年龄、门牌、页码、随手抓的东西）

**取数唯一原则：第一反应。** 想用整个号码就用整个，第一反应是后三位就用后三位，不能犹豫、不能人为设定。原文对此说得极重：

> "带有先入为主、人为的设定、刻意的思维都会影响预测的准确性。"

⚠️ 这一条必须如实说明它的性质：**方法的有效性完全建立在"取数不能有主观选择"上，而"第一反应"本身无法被外部验证**。所以这套体系在方法学上是自证循环的——这不是缺陷描述，而是使用时必须知道的边界。

## 四、用神取法（进阶的关键）

不同事类，**起课起点不同**：

| 所问 | 用神（起课起点） | 说明 |
|---|---|---|
| 婚姻、杂事、去官府 | 大安 | 从大安起月，月上起日，日上起时 |
| 求财、经商 | 留连 | 从留连起月…… |
| 疾厄、病苦 | 速喜 | 从速喜起月…… |
| 官司、诉讼 | 赤口 | 从赤口起月…… |
| 外出、旅行 | 小吉 | 从小吉起月…… |
| 死亡、神灵 | 空亡 | 空亡无用神 |
| 天气 | 四季（不用小吉） | — |
| 男女问事 | 小吉 / 留连 | — |

**月、日、时的分工**（断事归属）：
- **月** = 父母、长辈、上级、领导、官员
- **日** = 自身、配偶、亲属、家内
- **时** = 子孙、晚辈、下级、物品、六畜、财产、方位

**用神受冲克或逢空亡 → 事情虚假，吉凶变动不定，寻人望事有变。**

## 五、用神喜忌（判断主轴）

| 组合 | 结果 |
|---|---|
| 用神 + 吉神 相冲克 | 吉事不吉，办事无成，喜事成空 |
| 用神 + 凶神 相冲克 | 凶事不凶，凶中有吉，化险为夷 |
| 用神 + 吉神 相生 | 吉事更吉，喜上加喜 |
| 用神 + 凶神 相生 | 凶事更凶，雪上加霜 |

## 六、应期推法

1. **月日时相合即应期**：课内月、日、时与当年的某月某日相合，就是事情发生的时点
2. **日与月合 = 正合**：婚姻美满、求事有成、家事兴隆
3. **日与时合 = 内合**：家庭和睦、求财可得，但办事迟缓
4. **月与时合 = 外合**：在外顺利，求官、就业、升学、升职
5. **六神相合**：
   - 大安 + 留连 = 阴合 → 阴私事、牵连、拖延，与女人有关
   - 大安 + 小吉 = 阳合 → 喜庆吉事，婚姻可成，交易有成
   - 赤口 + 空亡 = 空合 → 凶事不凶，或吉凶未定
   - 速喜 = 自合（喜合）→ 喜庆迅速，占事不出月
6. **天干相合**：甲己近合（时间不长、距离不远）、丁壬远合（远方、拖延）、丙辛自合（迅速，"远在天边近在眼前"）、乙庚与戊癸空合（事情虚假）

## 七、大运 / 流年 / 岁运

- **大运**：从月上起，一运十年。例：月落大安 → 大安10–20岁、留连20–30、速喜30–40、赤口40–50、小吉50–60、空亡60–70
- **流年**：从该运起点起，顺序排下（一运大安则大安11、留连12、速喜13……）
- **岁运**：从日上起，一运管一年

**判法**：看六神在大运、流年、岁运中的相互作用，对用神的影响——凶以凶断，吉以吉断。

另有一套"大运对命宫"的强弱规则：大运对命宫起好作用时，从增力年起连续几年应吉（凶亦小凶）；起坏作用时反之。⚠️ 这段是**八字预测法**，不是小六壬原生内容，属教程作者混编，引用时要区分。

## 九、分事断语（原文歌诀压缩）

**占病**
- 大安：不用慌，上天佑你保健康
- 留连：多忧愁，绵绵缠缠病不离
- 速喜：病来急，急速医治别务期
- 赤口：是重衰，忍受痛苦度病关
- 小吉：为吉利，不用慌忙病有安
- 空亡：为无病，有病可能是癔病

**占官司**
- 大安不顺，要找人疏通｜留连拖延，耐心等｜速喜见分晓，黑白自分明｜小吉要答礼，舍财保平安｜赤口输定｜空亡虚惊一场

**占财**
- 大安：不动财，动则损伤｜留连：无财，真想求财去远方｜速喜：九分财，余一分要贵人帮｜赤口：一口财，辛苦才赚到｜小吉：流动财，有去有来｜空亡：意外财，要逢天时好运

**占出行**
- 大安不宜远｜留连远行但忧心拖延｜速喜走得慌，匆匆忙忙｜赤口有凶险，按兵不动是真招｜小吉最顺当｜空亡最不欢，有矢无中

**占婚**
- 大安：青梅竹马｜留连：两家犹豫不欢｜速喜：一见钟情｜赤口：棒打鸳鸯｜小吉：桃花婚｜空亡：喜无音

## 十、五行旺相（进阶推演用）

口诀：**当生者旺，生我者相，我生者休，克我者囚，我克者死。**
四季：木旺于春、火旺于夏、金旺于秋、水旺于冬。

课内五行偏旺的取象（摘用）：
- **土旺**：人厚道热心，性格坚决不服人；家多居高岗或近坟地；多孤寡或凶伤车祸
- **金旺**：好斗脾气暴，或军官军人刀枪剑；见木伤六畜，见火克金必有凶伤；见水为吉
- **水旺**：漂流不实、风流聪明；多迁居、工作调动、无主见；出贼人；家临水或低洼
- **木旺**：好争强有进取，仁义讲信义；木多主家贫、官司纠缠、兄弟不睦；住处有树林大树
- **火旺**：性急做事不稳、急于求成；主盗贼谋害或火光伤人；家多住楼上或高岗

## 使用流程

1. 问清所测何事 → 定用神（起课起点）
2. 取数（第一反应，不犹豫）
3. 三步推：起点月 → 月上日 → 日上时
4. 得六神落点
5. 看用神与落点六神的生克（喜忌表）
6. 推应期（日月时相合 / 干合）
7. 按事类套断语
8. 若涉时间跨度，参大运流年
