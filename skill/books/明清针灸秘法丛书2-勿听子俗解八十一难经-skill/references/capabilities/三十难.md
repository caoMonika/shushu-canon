# [三十难]

## I — 方法论骨架 (Interpretation)

本节主要探讨荣气和卫气的运行规律，以及它们在人体中的作用。荣气和卫气是中医理论中重要的概念，分别代表气血的精华部分和保护功能。荣气行于脉内，卫气行于脉外，两者相互依存，共同维持人体的健康。

## A1 — 应用示例 (Application Example)

假设患者出现头痛症状，根据荣卫相随的原则，可以通过针灸调节肝、肺、心等五脏六腑的功能，以达到治疗目的。例如，通过刺激特定穴位来调整肝气的沉降和肺气的浮升。

## A2 — 触发场景 (Future Trigger) ★

当患者出现身体不适，如头痛、失眠、食欲不振等症状时，应考虑荣卫失衡的可能性，并进行相应的针灸调理。

## E — 可执行步骤 (Execution)

1. **诊断**：通过望闻问切等方法，确定患者的症状和体质。
2. **定位穴位**：根据荣卫相随的原则，选择相应的穴位进行针灸。例如，头痛可能与肝气有关，可以针刺太冲穴（足大趾背侧）来调节肝气。
3. **操作手法**：使用温和的进针、提插和捻转手法，以促进气血流通。
4. **完成标准**：患者症状减轻或消失，体质恢复平衡。

## B — 边界 (Boundary) ★

- 针灸治疗应在专业医师指导下进行，避免自行操作导致不良后果。
- 患者在针灸过程中应保持放松，避免剧烈运动和情绪波动。
