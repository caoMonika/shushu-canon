# 术语表 — 《奇门遁甲秘笈大全-明-刘伯温》

| 术语 | 上下文线索（OCR） |
|---|---|
| 号曰 | 经曰：“出军疫疠传染，死者甚众，号曰军气，可于上风焚死人骷髅数枚，军气即能散”。 |
| 大吉 | 午（朱雀、胜光）丑（神天乙、将大吉） |
| 不利 | 万事从之无不利，能知玄妙得其灵，值符前三六合位，前二太阴须切记， |
| 为应 | 值丑时，主树倒伤人、有雷电大作，及风雨为应。作用后主七日内鷄生鹅卵、犬上房，百日内伤小口，白头老人作牙，进田产、大旺十年后主退败。 |
| 名曰 | 加辛名曰“朱雀入狱”，罪人释囚，官人失位。 |
| 大利 | 值亥时，主西方有钟声为应，山下人喊叫，作用后百日内，因救火得财大利。 |
| 六十日内 | 值卯时，主黄云四起、妇人拿把铁器前来、大蛇过路为应。作用后半月有征音人送财物来，六十日内女人被贼害破财，百日内得横财大发。 |
| 太阴 | “五假”之地各有吉凶，是杜、死、惊、伤、景合九地、太阴、（六合），乙、丙、丁、己、癸而致也。如六戊不测之术，六甲阴符之妙，此乃心悟，难以言传，有志于卫国安民，出将入相者，不可不知也。 |
| 朱雀 | 朱雀在门，遇生色物，远闻鼓声，文书无阻。 |
| 六合 | “五假”之地各有吉凶，是杜、死、惊、伤、景合九地、太阴、（六合），乙、丙、丁、己、癸而致也。如六戊不测之术，六甲阴符之妙，此乃心悟，难以言传，有志于卫国安民，出将入相者，不可不知也。 |
| 作用后六 | 值未时，主童子赶马牛至，鹭鸶自北方飞来，女人着红衣至为应，作用后六十日内贼入屋，劫掠财物凶败。 |
| 论值符 | 科试先须论值符，逢生合旺可进图，朱白生身名高擢，勾蛇刑害卷胡涂，年命日元九天位，皇都得意唱传胪。 |
| 白虎 | 白虎在门，见死闻悲，官事惊迫，途逢兵革。 |
| 值符 | 认取九宫分九星，八门又逐九宫行，九宫逢甲为值符，八门值使自分明， |
| 下临地盘 | 天假：景门合乙丙丁三奇，下临地盘九天宫者，名曰“天假”。乙为天德，丙为天威，丁为太阴，凡三奇之灵，宜陈事、利便、进谒、干求之事，大吉。 |
| 九地 | “五假”之地各有吉凶，是杜、死、惊、伤、景合九地、太阴、（六合），乙、丙、丁、己、癸而致也。如六戊不测之术，六甲阴符之妙，此乃心悟，难以言传，有志于卫国安民，出将入相者，不可不知也。 |
| 勾陈 | 勾陈在门，路逢鬪打，作事勾留，谋为参差。 |
| 元武 | 问曰：休门属水，无物不杀，霜雪之寒，纯阴之气，元武之精，三光不照，鬼邪所居之宫，何以言吉？ |
| 主胜 | 六乙到干名曰“玉兔入天门”，吉。天冲、天辅加六宫，在季夏、秋月或庚辛酉申日，有白色气来助，主胜。一名“玉兔入林”。 |
| 螣蛇 | 螣蛇在门，虚惊怪异，半途而回，风雨相阻，若有鸦鸣，有人追捕。 |
| 失令 | 一，得令，才名双美；失令，风流荡子。 |
| 军行出门 | 乙奇同白虎、心星临死门，号曰“五虎临门”。宜出巳宫坐午宫，正将大胜，得城池、首级、车马、财帛，军行出门有紫色云气，行三里有黄伞人至，大吉。 |
| 客胜 | 六丙到干名为“天成天权”，凶。有白云气从西北或西方来助，主胜。天英加六宫，在夏秋月有赤色云气来助，客胜。一名“光明不全”。 |
| 余仿此 | 旺于正二休四五，其余仿此自研穷，急则从神缓从门，三五反复天道亨， |
| 咒曰 | 凡出兵左足向前踏去，咒曰：“禹步相催登阳明，一气混沌灌我形，天回地转步七星，蹑罡履斗觉通灵，恶逆催伏妖魔群，众星助我斩妖精，我得长生游太清”。左右足一步一句念去，切勿回头。 |
| 九天 | 值符前三六合位，太阴之神在前二，后一宫中为九天，后二之神为九地， |
| 名为 | 加乙名为“墓神不明”，地户蓬星，宜遁迹隐形为利逸。 |
| 吉格 | 加癸为“青龙华盖”吉格者吉，招福，门凶多乖。 |
| 大凶 | 大凶蓬芮不堪使，小凶英柱不精明，小凶无气变为吉，大凶无气却平平， |
| 加死 | 加死：主官司惊忧，先忧后喜。 |
| 论干支 | 假如，甲子日出行，甲与子皆九数，二九得一十八数，或卯时六数，共得二十四数，课吉。或午时九数，共得一十七数，课凶；余仿此。日论干支，时祇论地支，不论天干。 |
| 论十干 | （见正文） |
| 得令 | 开门有奇应，是文职。伤门得令，定系虎臣。生门得奇，石崇富足。景门合局，丹天文明。惊门入式，好辩之人。干宫为开，白头出仕。死门得奇，职在司刑。分布八门、星、神、奇、仪合局者，豪富豪贵；失局者，下等平人。 |
| 来助 | 九星旺方能取胜，休囚失地忌兴师；悖格飞伏皆难许，最羡吉宿得奇门；天上风雷来助武，上下左右魁与魒；蹑罡履斗丁甲使，疑神疑鬼壮军威。 |
| 青龙 | 青龙在门，喜兆则马路逢官吏，锦衣、奇花。 |
| 年月日时 | 加壬之时为上格，又嫌年月日时逢，更有一般奇格者，六庚谨勿加三奇， |
