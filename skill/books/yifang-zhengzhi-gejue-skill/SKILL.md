# 医方证治汇编歌诀 · 蒸馏技能

**来源**：《医方证治汇编歌诀》，清·王泰林（字旭高，号退思居士）
**体例**：歌诀内嵌括号注——药量、出处（《金匮》《伤寒》《局方》《丹溪心法》等）与方义按语；开篇即**通治方**门

## 一、读法与总戒

1. **「虽云通治，亦当细切病情，不得笼统施用」**——全书方法论第一句
2. 歌诀中括号 = 活按语：出处、药量、加减别名、旭高按
3. 旭高典型思路：**引经文 → 辨病机真假（如消渴饮一溲一）→ 定君药（附子 vs 茯苓）→ 指出俗医滥用**

## 二、肾系通治谱（六味—八味—肾气）

```
金匮肾气丸（桂附八味）
    ├─ 减桂附 → 六味地黄（钱仲阳，平补足三阴）
    │     ├─ +杜仲牛膝 → 腰膝酸痛
    │     ├─ 去泽泻+益智 → 小便频数
    │     ├─ +麦冬五味 → 都气丸
    │     └─ +知柏等 → 滋阴降火支线
    ├─ 全方 → 转胞、消渴饮一溲一、虚劳腰痛少腹拘急小便不利
    └─ +牛膝车前 → 济生肾气：阳虚蛊胀、喘满痰鸣脉沉细
```

### 关键按语（可执行判断）

| 证 | 选用 | 病机要点（旭高） |
|---|---|---|
| 饮一溲一消渴 | 肾气丸 | 肾阳虚、邪水反胜，蒸动肾阳驱水——非单纯火消 |
| 妇人转胞 | 肾气丸 | 胞中气不顺；饮食如故而烦热倚息溺不利 |
| 虚劳腰痛+少腹拘急+小便不利 | 肾气丸 | 专利小便：水去阴不伤、扶阳火不升 |
| 阳衰水盛蛊胀喘痰 | 济生肾气 | 争议君药：严用附子为君开关闭，薛己重茯苓——关闭不开则车前无功 |
| 肝肾阴亏火浮 | 六味 | 平补三阴；非天下病统方 |

**滥用警告（书中反复）**：把肾气/六味当作万能补药 = "大失此方之义"。

## 三、精血虚劳方阵速查

| 方 | 主干药意 | 主治锚点 |
|---|---|---|
| 七宝美髯丹 | 首乌为主 + 归茯牛菟杞故纸 | 补精血 |
| 黑地黄丸 | 苍术熟地炒黑 + 五味干姜 | 脾肾两顾：燥脾滋肾；上咳下利、脱血脾寒 |
| 还少丹 / 打老儿丸 | 地药苁蓉杜仲膝杞等 + 菖蒲 | 脾肾虚寒；加续断或苓易茯神为变方 |
| 滋阴大补丸 | 还少去楮实 | 阴阳平补 |
| 虎潜丸 | 知柏地膝等 | **脏热生痿**、骨蒸；非外邪痰湿痿 |
| 龙虎济阴丹 | 虎潜 + 龙骨 | 兼涩精 |
| 补益丸 | 虎潜 + 紫河车苓术姜甘菟味 | 阴虚湿热痿 |
| 三才 + 封髓 | 天地人 + 砂仁黄柏 | 补三焦精气神；柏砂制苦寒呆滞 |
| 大造丸 / 补天 | 河车为主，晋三加减 | 上滋金水、下肾肝、潜阳固阴 |
| 人参固本丸 | 二地二冬人参 | 肺肾阴亏；可加介类潜阳或阿胶熄风 |
| 天王补心丹（《道藏》本） | 按魂魄意智精志配伍 | 心血不足、神用不安 |
| 孔圣枕中丹 | 龙骨龟板远志菖蒲 | 善忘：镇肝补肾通心窍 |
| 大补阴丸 | 知柏地龟猪脊 | 相火；肾肝虚呃用参术汤送——崇土制龙雷 |
| 通关丸（滋肾丸） | 知柏桂 | **关阴**小便不通、口不渴（下焦血分热）；非气分口渴之淡渗证 |

### 通关 vs 淡渗（鉴别）

- **口渴 + 小便不通**：上焦气分热 → 清肺淡渗
- **不渴 + 小便不通**：下焦血分热壅 → 通关丸（知柏+少桂寒因热用）
- 膀胱阳虚阴无以化 → 反用肾气丸

## 五、脾胃四君支线（书中后半常见）

```
四君子 → 异功（+陈皮）→ 六君子（+半夏）→ 香砂六君
         → 归脾（脾血）
```

调用时：气虚痰痞用六君轴；夹食滞香砂；心脾两虚归脾——与补肾谱勿混层。
