| 金匮 | 《金匮》曰：卯酉之位，日月所从；子午之辰，阴阳所起；皆幽暗，谓之私门。若四仲加四仲，是门户相通，阴阳交媾，私奸聚党，而中末又兼之，故名三交，太阴六合皆主阴私蔽匿，更见此二神加之，愈是三交。 |

| 时占 | 又曰：八专之日是无淫，有克比并涉害深，无克须当涉害数，阴日还阴逆数寻，阳日便从阳起顺，顺逆三位用为真，中末传归日干上，依此用之是为精。有时顺到日辰上，三传飞散莫重临。正月己未酉时占，酉作三传独脚名。 |

| 旺相 | 元首课是贵人、岁君、将相，旺相生合行年神，来意是见大贵人，有生彩之庆。若是反吟等凶破，主暗昧，伸诉之事。 |
| 假如正月 | 假如正月辛卯日午时占事，太冲为用，临辛为斫轮课，当有印绶除官之职。 |
| 断曰 | 断曰：知一是如何，用神今日比，婚姻失和谐，事缘同类起。逃走不远去，失物邻人取，论讼和允好，为事尚狐疑。 |
| 天乙顺行 | 诗曰：天乙顺行用旺相，日辰干上加旬头，传末生初或生日，用传环顾乙不相仇，四三人年有吉将，此课六仪百不忧，解祸求凶皆顺遂，加官进禄事王侯，所为百事皆顺遂，是凶化吉无祸由。 |
| 又诗曰 | 又诗曰：三合之课是杂神，二姓公婆及议人，凡事干谋宜托人，不然带众事縈心。 |
| 将得天后 | 如正月癸酉日寅时占，胜光为用，将得天后，正月天马在午，中传见太冲，将得朱雀，谓之轩车。末传神后，将得青龙，谓之华盖。合此乘轩，要见龙常方主禄位。青龙主文官，太常主武官。文武方得高盖乘轩之贵，余官不得。 |
| 欲动不动 | 孔明曰：“别责课主荡泆、奸盗、不正之事。凡举不备，求谋不遂，欲动不动，留连之课。以支干皆取合神，故男妇皆有私合。” |

| 之神 | 又曰：阴阳上下无相克，其中择取遥相贼，贼日之神为用初，课名蒿矢似无力。如无神遥于今日，日有克神是弹射。有如日遥克于神，后有两神亦克日。用比用涉是为良，依此课之情不失。 |
