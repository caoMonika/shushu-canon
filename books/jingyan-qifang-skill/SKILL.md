# 经验奇方 · 蒸馏技能

**来源**：《经验奇方》二卷，题刘一明辑（清光绪二十四年海坛林贤庆序刊）
**性质**：民间验方集成，以"通治丹丸"为特色——一方多治，便于居家预备
**使用边界**：古籍文献参考。书中含砒、汞、雄黄、巴豆等剧毒药物及"符咒"色彩内容（如"仙传""乩传"），不可照方抓药，不可作为医疗依据。

---

## 一、核心方法论：通治成药速查

本书最大特点是**一丹治多病**。遇到急症先判断类别，再选"通治丹"，最后按症状细分用法。

### 1. 第一灵宝丹（搐鼻/抹眼角用）

- **组成**：辰砂二两、雄精五钱、蟾酥、闹阳花各一钱，麝香、冰片、老姜粉各三分
- **通治**：中寒暑（搐鼻取嚏）、气闭血滞（抹两太阳穴）、疫疠（抹眼角出汗）、无名肿毒（醋调敷）、火眼（抹眼角）
- **禁忌**：孕妇忌服（搐鼻抹眼角不忌）；常带身上可避疫气（原书说法）

### 2. 万应十宝丹（内服急救主丹）

- **通治**：中寒中暑痧胀、感冒头痛、痰气厥昏迷、痈疽疔毒、虫咬、小儿急惊、臌胀水肿、吐血衄血、跌打至死（有微气者）、疟痢、时疫、经闭、疝气上冲
- **标志性用法**：昏迷牙关紧闭者，研末**吹鼻取嚏**；泄泻痢疾开水送服二十一丸
- **经水不调**：当归、生地、白芍、川芎各一钱煎汤送服二十一丸；**经闭**：红花一钱煎汤送服十九丸，连服三次

### 3. 紫金锭（解暑毒万能）

- **主治**：食物中毒、瘴气、痈疽发背、阴症伤寒、瘟疫喉痹、气痛、泄泻痢疾霍乱、中风、自缢溺水（心头温者）、疟、经闭、小儿惊风疳痢、头风、腹鼓胀、汤火伤、蛇犬咬
- **组方要点**：山慈菇、五倍子、千金子、红芽大戟（即局方紫金锭法）
- **送服汤引口诀**：痢→薄荷汤；疟→桃枝汤；经闭→红花酒；惊风→薄荷汤（慢惊忌）

### 4. 辟瘟回生丸（时疫主药）

- **主治**：伤风伤寒、时疫、瘟疫瘴疠（老鼠瘟结核）、湿毒流注脚肿、风火喉痹、毒痢斑疹、心经疔
- **服法**：每证研一丸开水冲服，暖睡取汗

### 5. 仙果散（食积气滞通治，嚼服）

- **主治**：泄泻、红白痢、诸疟、胃停食积（舌苔黄厚）、胃气痛晨吐、霍乱、喉蛾、痰嗽、中风不语、气胀、水胀、妇女经闭肚胀（蜘蛛胀）
- **服法**：日嚼二三钱；忌生冷瓜果、虾蟹、油炸、面食、芋艿等发物
- **鉴别要点**：气胀由胸腹胀起延及四肢；水胀由两足背胀起渐至上身——治法同，均以胀消为度

## 二、外科膏散速查（卷上）

| 方名 | 主治 | 要点/禁忌 |
|---|---|---|
| 仙传三妙膏 | 痈疽发背、疔疮、无名肿毒、瘰疬、乳疽 | 阴阳症并治；麻油浸药七日再熬 |
| 万应膏 | 跌打损伤青肿（皮破出血忌）、疯痛、肝胃气痛 | 松香水煎三次去毒 |
| 黄蜡膏 | 新旧臁疮 | 忌酒糟发物；切忌水洗 |
| 猪胆膏 | 无名肿毒肉色白淡者 | 阴疽忌用 |
| 如意丹 | 痈疽大毒、去腐生肌 | 先拭净腐脓再糁 |
| 三仙丹 | 拔陈疮管肉 | 火硝、皂矾、水银升炼 |
| 玉华丹 | 眼外障红肿翳膜 | 炉甘石黄连童便淬七次 |
| 白降丹 | 拔老疮管 | 丹成白藕丝色为上品，色黄太老 |
| 珍珠散 | 下疳肿痛破烂 | 米泔水洗后糁 |
| 铁扇散 | 一切破伤 | 敷后扇之立愈，不必包裹 |
| 白附散（玉真散） | 跌坠刀箭伤，止血止痛不忌风 | 白附子十二两为主 |
| 金花散 | 发背对口、红肿痈毒 | 生猪板油调敷 |
| 降痈活命饮 | 一切肿毒阴阳症 | 上部加川芎、中部加桔梗、下部加牛膝；阴疽加桂心炮姜 |
| 紫袍散/万应吹喉散 | 咽喉十八症、喉痈喉痧乳蛾 | 吹喉用 |
| 消痔千金散 | 痔疮肿痛 | 清茶调敷 |
| 光明散 | 时眼红肿羞明 | 点大小眦 |

**外科通则**（书中反复强调）：
- 肿毒初起看**阴阳**：红肿热痛为阳，漫肿肉白色淡为阴（阴疽用阳和丸：瑶桂心一两、麻黄姜炭各五钱）
- 溃后处理顺序：拭净腐脓 → 提毒去腐（如意丹/三仙丹）→ 生肌（珍珠散类）
- 忌：水洗疮口、发物（酒糟、虾蟹、冬笋、香菇、煎炸）

## 三、中毒急救（卷下，原书"急救"门精华）

| 中毒 | 解法 |
|---|---|
| 鸦片毒 | 生南瓜（金瓜）捣露一小茶杯服下，不必取吐 |
| 砒毒 | 防风一两研末，水调灌之；吐再灌 |
| 盐卤毒 | 生豆腐浆冷服二三碗；或以黄豆搅粉冲冷水去渣服 |
| 压死/跌死（假死） | 扶起盘脚坐地，提发，生半夏末吹两鼻，姜汁灌之——只要心头微温可救 |
| 服毒通用 | 巴豆仁一粒、矾红少许、冷饭数粒捣烂为丸如龙眼核大服下 |

## 四、妇科速查（卷下）

- **难产**：木茯神方（连服头煎二三四帖，服至产为度；产后忌服，接服生化汤）
- **产后血崩**三法：加参生化汤（形脱气促汗多）、升举大补汤（日久不止）、生脉散（保肺清心）
- **产后心腹痛**：加味生化汤（伤肉食加砂仁）
- **行经腹痛**：制香附、当归尾各二钱，延胡、赤芍、丹皮、川芎各一钱五分——临痛时服，愈后永忌生冷
- **妇人乳核**：生地泽兰各四钱加王不留行、蒲公英、大力子

## 五、慢惊风辨证（卷下，与《幼科切要》互参）

**总纲**：慢惊多因吐泻伤脾，**补土即所以敌木**。庸医误指为食为热，投清火去积凉药立毙。

**辨证十四条**（符合数条即急救）：
吐泻（脾胃虚寒）、身冷（阳抑不出）、鼻煽（真阴失守虚火烁肺）、面色青黄白（气血两虚）、二便清白（肾与大肠无火）、昏睡露睛（神气不足）、手足抽掣（血不行于四肢）、角弓反张（血虚筋急）、乍热乍冷（阴阳错乱）、汗出如洗（阳虚表不固）、囟门下陷（虚极）、口唇焦裂不喜凉饮、所吐所泻不消化。

**三主方**：
1. 逐寒荡惊汤：瑶桂心（研，不可经火）、炮姜、胡椒、丁香各一钱，灶心土水澄清煎，频频灌
2. 加味理中地黄汤：熟地、当归、枸杞、枣仁、党参、白术、炮姜、肉桂、故纸等，浓煎频服
3. 温中补脾汤：西党参、炙芪、于术、干姜、白蔻砂仁，水煎浓汁一酒杯频灌

## 六、杂病速查（卷下精选）

- **一切疟疾**：白胡椒粉一钱合第一灵宝丹三分，不拘何疟取药一分
- **癫狗咬伤**：真纹党、红柴胡、前胡、羌独活、茯苓、生甘草各三钱——急则七日发作缓则七七，畏风畏锣声即毒发欲死之兆
- **毒蛇咬**：田鸡草嚼融敷伤处，立能止痛消肿
- **脱骨疽**（手足指）：生甘草末麻油调敷 + 金银花、元参各三两，当归二两，生甘草一两水煎服，连服十帖
- **红丝疔**：疔边红丝循臂而上，急灸红丝尽头处
- **各种胀病**四型鉴别：气胀（胸腹胀起）、水胀（足背胀起）、臌胀/蜘蛛胀（经闭肚胀四肢细）、脾虚胀（久泻转胀）——各型调治后**忌食生冷发气物四个月**
- **黄胖病**：黑枣煮熟去皮一斤，青矾、米醋炼丸
- **大麻风**：汤药方（陈皮白芷苦参天麻秦艽等）+ 丸药方（大小胡麻、白蒺藜、苦参等加枫子膏），**百日内忌房事、食盐**

## 七、使用要点（蒸馏者注）

1. **先分阴阳虚实**再选方，是全书暗线；外科先看肿色，内科先看二便神色
2. 通治丹丸的"汤引送服"是第二决策层：同丹不同引，主治随引变
3. 急救首重**吹鼻取嚏**与**探吐**两法，为"关窍不通"总钥匙
4. 本书与《钱氏秘传产科方》《济生集》方意多互见（生化汤、逐寒荡惊汤同出傅青主一系），交叉引用可判源流
