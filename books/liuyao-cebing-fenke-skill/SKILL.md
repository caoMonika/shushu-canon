# 六爻测病分科详解（王虎应体系）

取材：《王虎应-六爻测病分科详解》上下册（时轮造化有限公司出版，作者王虎应）。作者自述早年欲考中医研究生未果，1986 年起以六爻研究疾病，处女作《六爻预测疾病新探》奠定六亲、六神、爻位测病含义，本书为其修订深化版，全部卦例为作者实测验证。

## 一、断病总则：24 条病爻定位

古人测病以官鬼为病，应验率低。**正解是一切围绕用神喜忌，病在"受伤之处"，不一定在官鬼**。24 条法则（可多条并用，一卦常以多种组合表现病症）：

1. 用神受伤，以用神为病
2. 忌神动来克用，以忌神为病
3. 仇神动来克元神，以仇神为病
4. 元神受伤，以元神为病
5. 用神空而不受元神生，以用神为病
6. 元神空而不能生用，以元神为病
7. 元神被合（贪合忘生）不能生用，以元神为病
8. 用神月破，以用神或月建为病
9. 元神月破，以元神或月建为病
10. 用神见病地，以用神或病地为病
11. 元神见病地，以元神或病地为病
12. 动爻化出官鬼，以动爻或化出之鬼为病
13. 动爻化出忌神，以动爻为病
14. 官鬼为忌神，旺而为病
15. 日月克用，与其相同五行入卦者为病
16. 用神入墓，以墓库之爻或用神为病
17. 官鬼爻墓库为病
18. 忌神墓库为病
19. 独发卦，独发之爻表示病症（兼表病因）
20. 元神化空、化破、化退，以元神为病
21. 用神伏藏，以压伏的飞爻为病，或以伏神为病
22. 官鬼不上卦，以飞神为判断依据
23. 个别卦以主卦卦宫属性为病
24. 用神或元神过旺无克泄，也是病

**要点**：多条法则同时命中时，命中最多的爻就是焦点（卦的中心）。日合之鬼旺可冲开再克——合绊本身也是信息（间歇性发作）。

## 二、取用神与元神

- 自测病：以**世爻**为用神
- 测子女小孩：以**子孙爻**为用
- 测父母长辈：以**父母爻**为用
- 测妻：以**妻财爻**为用；测夫：以**官鬼爻**为用
- 测兄弟朋友：以**兄弟爻**为用
- 测病遇两现：取合日、发动、或应位者为用
- **元神主思维、头脑、内心**：元神受伤/入墓/化死地/被合，多应智力、思维、神经、脑部病症
- 财在测病中的延伸：饮食、呼吸、血液、月经、痰、尿、屎（兄化财=强行饮食/强行行经；财入墓=经闭/饮食不进）
- 子孙延伸：五官、呼吸道、食道、器官、通道；父母延伸：头、骨、胸、衣服；兄弟延伸：手脚、腿、肛门、消化、牙

## 三、病位三层定位

三层叠加取交集，锁定病种与部位。

### 爻位
| 爻位 | 部位 |
|---|---|
| 初爻 | 脚、幼年、出生 |
| 二爻 | 腿、生殖器、子宫、宅、肝胆（寅为胆，空为囊） |
| 三爻 | 床、腰、腹、大腿、子宫 |
| 四爻 | 胸、脖子、胸口 |
| 五爻 | 五官、喉咙、口腔、脸面、鼻子 |
| 六爻 | 头、脑、手、体表、老年 |

### 卦宫
乾=头；坎=耳、智慧、水、肾；艮=鼻、皮肤、背、胸口；巽=风、气管、神经、眼；离=眼、心；坤=腹、脾胃、皮肤；兑=口、说、喉咙、肺；震=肝、足、声音。

### 五行
金=肺、骨、耳、牙、声；木=肝、发、神经、痒、风寒；水=肾、血、智、尿、湿；火=心、眼、血、热；土=脾胃、皮肤、肉、鼻、肿胀。

## 四、六神病象与六亲病象

### 六神定病性
| 六神 | 病象 |
|---|---|
| 青龙 | 痛、痒、饮食、酒色（酒精肝）、生育/中毒 |
| 朱雀 | 炎症、发烧、声音、语言 |
| 勾陈 | 肿瘤、肿胀、增厚、迟钝、愚昧、肥胖、浮肿 |
| 腾蛇 | 疱、病菌、疤痕、带状/连续、怪异、梦、萎缩、少 |
| 白虎 | 疾病、手术、出血、血、急症 |
| 玄武 | 溃烂、潮湿、昏暗、内向、夜、眩晕、近视 |

### 身体卦兼断要点
一卦多断时先定吉凶，再取病象；从非测病卦中看出疾病信息是常态（求财、考学、风水卦皆含身体信息）。兼断时休囚不影响吉凶结论（问事不问病则休囚无妨）。

## 五、呼吸系统

- **感冒**：巽宫（巽为风）；木、水五行（木主风、水主寒）；玄武（风寒）；兄弟爻为风；朱雀主发烧。
- **咳嗽/哮喘**：乾、兑宫（金主肺）；金五行；五爻、四爻（胸、呼吸道）；勾陈主憋胀、腾蛇主紧缩；子孙爻为呼吸道、财爻为气；墓库、逢合=气上不来。
- **支气管炎/肺炎**：参考哮喘组合，加朱雀（炎症）。
- **肺结核**：参考肺炎，兼玄武（结核）。
- **肺癌**：参考肺炎组合 + 用神休囚 + 用神/元神/忌神临勾陈 + 用神元神见死墓绝。

## 六、消化系统

- **呕吐**：财动（饮食出来）、土在外卦动主吐。
- **胃炎**：艮、坤、兑宫；财爻、兄弟爻（财为饮食、兄弟主消化）；三四五爻；朱雀、青龙。六神分性：青龙痛、朱雀炎、勾陈胀/癌、腾蛇萎缩/下垂、白虎出血、玄武湿/暗。
- **胃溃疡/十二指肠溃疡**：参考胃炎 + 白虎（出血）。
- **胃癌**：参考胃炎 + 勾陈 + 用神休囚死墓绝。
- **食道炎/食道癌**：五爻（喉咙通道）、子孙（食道）；癌加勾陈。
- **肝炎**：震、巽宫；木（卯、寅）；二三爻；**财库为肝**（肝藏血），财库临白虎最验；青龙=酒精肝、朱雀=肝炎、勾陈=肝肿大。
- **肝硬化/肝癌**：肝组合 + 严重者用神休囚、死墓绝、勾陈。
- **胆囊炎/胆结石**：二爻寅木（阳木为胆，空为囊）；朱雀=炎症、勾陈=结石肿胀。
- **胰腺炎、阑尾**：三爻腹位、勾陈肿胀。
- **便秘**：乾、兑、离、坎宫（肠、泄）；金、木、火（金木为肠、火为干燥）；财爻（屎尿）入墓/被合/克合用神/不上卦；**兄弟在内卦化财=强行大便**；伏吟主停留；勾陈主迟缓、腾蛇主次数少；二三爻（肛门）。
- **痢疾/腹泻/肠炎/肠梗阻**：二三爻、财爻（排泄）、水火（湿热）；梗阻见合绊、墓库。

## 七、儿科

- **弱智/脑瘫**：乾宫（头）、坎宫（智）；六爻（头脑）；水（智）；勾陈（愚昧迟钝）；爻变见墓库、绝地、死地、逢合、衰地；初爻六爻空亡或逢合=手脚不灵活。先天性多见初爻/胎位信息。
- **尿床**：二爻（生殖器）、三爻（床）；水（尿）；财（尿）；腾蛇（梦中不觉）。与卦宫关系不大。
- **小儿高烧**：朱雀（发烧）；火克子孙或与火爻相合；入墓=昏迷。
- **小儿夜啼**：金、朱雀（声音）；反吟、伏吟（啼哭反复）；三爻（床）；玄武（夜）。
- **自闭症**：六爻（头）、初爻（心事）；元神（思维）；玄武（内向）、腾蛇（古怪）、白虎（多动暴怒）；**墓库=封闭**是核心标志。
- **口吃**：父母爻、朱雀（语言）；反吟、伏吟（重复）。
- **哑巴/耳聋哑**：兑宫（口）、金（声音）、朱雀；金入墓=不出声。
- **小儿积食**：青龙（饮食）；乾、坤、艮宫（脾胃）；财不上卦/空亡/逢合/入墓。

## 八、皮肤科

总纲：**土主皮肤**，土临白虎、青龙为皮肤病标志；坤、艮宫（土）；六神分症：青龙痛痒、朱雀炎症红斑、勾陈疹子增厚、腾蛇疱/菌/疤痕、白虎出血、玄武溃烂湿。

- **荨麻疹**：坤艮宫；土临白虎青龙；土空或用神空不受土生；土爻发动/被冲/动合他爻/临驿马（移动、此起彼伏）；多在外卦三爻。
- **皮炎**：同荨麻疹，按六神分症。
- **湿疹**：水 + 玄武（潮湿）；合（对称分布）；水空被克=水疱。
- **带状疱疹**：腾蛇（连续、带状）；二三爻（腰）；合（连接）。
- **白癜风**：皮肤组合（土被木克），无特异标志。
- **痱子**：腾蛇（心情不畅）+ 元神土临白虎在外卦空 + 勾陈（疙瘩）。
- **脚气**：初爻（脚）；青龙（痒）、木（痒）；土（皮肤）、水（湿）；**月破=蜕皮破裂、空亡=水疱**；玄武=溃烂湿气。年运卦中初爻动化鬼克世即作脚气断。
- **脱发**：乾宫、六爻（头）；木（发）、金克木（发绝）；腾蛇（细长、少）；财爻（头发）。空=没有了。
- **淋巴结核**：四五爻（颈、腋下）；勾陈（肿瘤）、玄武（结核）。

## 九、五官科

- **耳鸣/耳聋**：坎宫（耳）；五六爻；金、水；**金空则鸣**、土空不能生金；金入墓、逢合=耳聋；朱雀（声音）。左耳水右耳金之说不验。
- **鼻炎**：艮宫（鼻）；土（鼻）、金（呼吸系统）；五六爻；朱雀（炎）、青龙（痒→打喷嚏）。
- **鼻癌**：鼻炎组合 + 用神休囚 + 勾陈 + 死墓绝。
- **咽喉炎**：乾、兑宫；五爻（喉咙）；水（喉咙）；子孙、财（饮食呼吸）；青龙痛、朱雀炎、勾陈肿、腾蛇干哑。
- **喉癌/失音**：咽喉组合 + 勾陈（癌）；失音看兑宫 + 五爻 + 金 + 朱雀，腾蛇克之=声音被绊住。
- **牙周病**：兑、乾宫；**火雷噬嗑、山雷颐卦尤验**（饮食卦）；五爻（口腔）；金（骨骼=牙）；财（饮食）、兄弟（咬碎食物）；青龙牙痛、朱雀牙龈炎、勾陈牙床肿、腾蛇虫牙、白虎出血、玄武腐烂；**金入墓于丑=牙包在肉里（牙床）**；金临白虎空=牙已拔。
- **眼睛诸病**：离、巽宫；火（眼睛）；五六爻（脸）；子孙（五官）；朱雀炎、青龙痛、勾陈肿、腾蛇异样遮挡、白虎出血充血、玄武昏暗（近视）。入墓=戴眼镜（遮盖）。
- **飞蚊症**：五六爻；火；**腾蛇（飘荡飞舞）**；**戌土（火库=眼前有遮挡物）**。
- **白内障**：同飞蚊症更重；戌土遮挡 + 腾蛇。
- **青光眼**：近白内障 + 白虎。
- **口腔溃疡**：兑宫；五爻；玄武（溃疡）；财（饮食营养，缺维生素）。
- **舌癌**：参考口腔溃疡 + 勾陈。

## 十、疑难杂症

- **肥胖症**：勾陈主胖。测减肥成败看世爻：世旺可减成，被克/回头克/空=减不成（与兼断胖瘦相反，勿以旺相为胖）。复卦=反复减胖。空临勾陈=懒、不运动。财空=节食挨饿。
- **甲状腺疾病/癌**：土五行（戌、未、丑）；四五爻（喉咙、胸口）；艮宫；财、子孙（饮食、呼吸、食道）；勾陈主肿胀（轻则扁桃腺，重则甲状腺）。兄弟化财=强行饮食、吞咽困难。癌：勾陈 + 用神弱。
- **美尼尔氏综合症**：四组合并断——六爻（头）逢冲入墓临玄武=眩晕；金空/土空不生金/金被合=耳鸣；入墓四五爻临勾陈=胸闷；财动=呕吐。
- **鬼交**：官鬼持世 + 腾蛇（怪异、梦）+ 三爻（床）+ 沐浴（裸体）；二爻官鬼在宅动=家宅阴气。卦例少，慎断。
- **中邪（癔病/神经官能症）**：卦例极少，参考鬼交与自闭组合。

## 十一、辅助技法

- **移神辨爻法**：日辰、月建未入卦时，以卦中同五行之爻替代定位（如日为丑土，卦中无丑则以未土代入五爻看）；六亲相同者可互借六神（初爻父母可借六爻父母之六神）。
- **辨爻法**：把日月移到卦里看其落于何爻位，取该爻位之象（日冲世为父母，父母伏二爻临腾蛇=紧身衣）。
- **太极裂变法**：从一卦演变出他人之卦（如测官运之卦裂变出妻子身体卦），裂变卦看吉凶身体一律以世爻为用，等于对方自己摇卦。
- **独发**：独发之爻表示原因兼病症；问事之卦兼断病时独发即焦点。
- **理象并存**：月破休囚之爻仍以"破"的状态克世（象=蜕皮），旺克则为大病。理（力量）与象（状态）并存，既矛盾又统一。
- **反推法**：卦中眼镜之象（火库、入墓）反推眼睛有病。

## 十二、应期

- 空亡应**实空之年**（卯空 → 己卯年）
- 月破应实破、逢合之期（财破逢合=手术应期）
- 冲开合绊、冲实用神之时为转机（日冲元神暗动生用=当下开始好转）
- 化出之爻所值之年暗藏应期（化戌土防戌年）

## 使用流程

1. 明确求测对象与用神（自病/子女/父母/夫妻/兄弟）
2. 列出日月、动变、旬空、月破、入墓、合冲
3. 套 24 条法则找"病爻"，命中最多的爻为焦点
4. 用爻位 + 卦宫 + 五行三层定位病的部位
5. 用六神定病的性质（炎/肿瘤/溃烂/痒/出血/湿）
6. 对照分科组合判病种（多病并存是常态，一卦常断出数病）
7. 断应期：实空、实破、冲合、填实
8. 非测病卦兼断时，先定所问之事吉凶，再取身体信息

## 边界

- **不构成医疗建议**。卦象推演仅供术数研究，诊断治疗以医生为准。
- 书中部分化解方法（猫毛灰加生姜汁治脱发、土豆片敷湿疹、梨+香菜+生姜+绿豆退烧、西红柿汁治口腔溃疡）为作者经验方，未验证，勿据此指导用药。
- 上册理论 + 呼吸/消化系统完整；下册本次取材起自第九章（儿科），其前（疑为心血管、神经、泌尿、妇科等）未在本次取材范围内；下册某些卦例标注"具体分析请看有关章节"，所指章节未全见。
- OCR 残缺：卦表多处乱码（"图5-97"式图注混入正文、卦画散排、个别字错讹如"背龙"即青龙、"脾气"即脚气），卦例排盘以纳甲常识复核后使用，个别爻位存疑。
- 鬼交、口吃、哑巴、白癜风、淋巴结核等病种卦例少，作者明言"有待进一步研究"，规律弱，慎用。
- 本体系为王虎应传统派（用神喜忌+象法），与董元辰新派（合神定旺弱）底层不兼容，勿混用；应期与《增删卜易》应期总注可互参。
- 测病以用神受伤为核心，勿退回"官鬼旺即病"的旧套；但官鬼旺而克用时仍以鬼为病（第 14 条）。
