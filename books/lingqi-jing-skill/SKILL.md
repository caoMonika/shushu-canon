# 灵棋经

题汉东方朔；实为棋占专书。文献参考。

## 起卦

- 十二棋：上、中、下各四枚（或四棋分掷三次）。
- 每层得 **1～4**；全卦记为「×上×中×下」。
- 共 \(4^3=64\) 象（源本约 125 条象/诗；常用按上中下组合检索）。

**操作**：诚意提问 → 分上中下三掷（或分堆）→ 得三数 → 查对应卦名／象曰／诗曰。

## 盘式结构（每条）

1. **标号**：如「一上一中一下」
2. **卦名 + 象题**：如「大通卦 · 升腾之象」
3. **阴阳方位备注**：如「纯阳得令 · 乾天西北」
4. **象曰**：散文断
5. **诗曰**：七言/五言诗断

## 断法次序

1. 先读**象题**（升腾／待时／小危等）定基调。
2. 象曰定事理；诗曰作修辞补充。
3. 看阴阳：纯阳／阴极／阴盛克阳等，判进退宜忌。
4. 人事类推：出行、求财、家宅、防仆从——以象题关键词为准，勿外加神煞。

## 检索提示

源 TXT 按「一上…」顺序排满。查法：先定三数 → 在文本中搜「N上N中N下」。若只有象曰无诗，以象为准。

## 边界

棋占与易卦同属符号系统；不可用于医疗、刑讼、投资实操。
