# 六爻取象：多重取象法

## 它是什么

前几层技能解决"成不成、什么时候"，这一层解决"是什么、在哪里、什么人、因何而起"。

方法论核心是一句话：**理推象，不是背断语。** 先掌握五行生克之理，再从理的基础上延伸出象；通晓一"理"，自然能推出很多象，不必死记任何断语（任何断语都有使用条件）。

取象的基本操作是**对应关系**：找出尽可能多的"对应点"，每一个对应点落实到一个卦爻上，对应点找得越多越准，断得越细。

## 二、爻位细分法

### 同位爻与贵贱位

- 一与四、二与五、三与六为同位之爻
- 上卦人爻在五爻，下卦人爻在二爻；整体六爻卦论，**五爻为天位主高贵，二爻为地位主低下卑贱**（"乾高贵五，坤卑贱二"）
- 测升迁得五爻官鬼生合世 → 得高位者重用。**但必须符合社会常理**：一个普通干部得五爻生世，不能说"国家首脑提拔"，只能说本单位本辖区首脑重用

### 阴阳位

一三五为阳位，二四六为阴位。阳爻居阳位、阴爻居阴位为**得位（位正）**；反之失位。

- 位正 → 所处环境、才能与职位待遇相当；人光明正大、德高
- 位不正 → 不相当，或阴险狡诈、行事不端
- 官爻位正 → 当官与才能德行相配；位不正 → 不相配
- **官旺世衰 → 人无能力却做高官；世旺官衰 → 能力强却做小官**，都是位不正

### 六爻各位对应的具体人事物

| 爻位 | 地理（国家区域） | 企业人事 | 国政 | 家庭 | 家宅 | 人体 |
|---|---|---|---|---|---|---|
| 上爻 | 远地、外省、外国 | 股东、合作者 | 人大、政协、总理 | 祖父母 | 屋顶、瓦梁、天棚 | 头 |
| 五爻 | 首都 | 董事 | 国家元首、主席 | 丈夫、父亲、长子长女 | 入口、过道、走廊 | 胸部、心脏 |
| 四爻 | 省级市 | 上层领导（处长级） | 部长级 | 妻子、妇女 | 门户、大门、院门 | 腹部、腰部 |
| 三爻 | 地级市 | 中层领导（科长级，实际管事） | 地方政府首脑 | 丈夫、兄弟 | 内门、房门、墙壁、床、灶 | 腰、小腹、肚、臀 |
| 二爻 | 县城 | 职员、小组长 | 基层领导、乡镇级 | 妻子、女孩 | 宅、灶、屋内空间 | 大腿、小腿 |
| 初爻 | 乡村、乡镇、本地 | 临时工、最低层劳动者 | 百姓、村长 | 子孙、晚辈 | 地面、地基、水井 | 腿、脚 |

里表：五、六爻为身体外表皮肉；三、四爻为内脏。

> 一卦六爻代表无穷物象，取哪一部分，看测什么事，**必须取与所测之事有关联、符合常理的那一部分**。事有多大卦就包含多大，事有多小卦就有多小。

### 三才（天人地）

- **五、六爻 = 天爻**：高处、远处、外来、外面、外地外国外省、京都、高贵高层次、首脑地位；天象、天意、天灾、天时、人命不可违之事；人体上部头颈
- **三、四爻 = 人爻**：不远不近、中等距离（本市县区镇）、中间的、中等的、中间人、中介；人事、人祸、人事纠纷、人为因素；人体胸腰之间
- **初、二爻 = 地爻**：本地、近地、家里、低处、下边；地位低贱、官位卑微；农村乡里、矿山地质、地下暗地、地面；人体下身腿足

用法举例：
- 测生意，天爻临财发动生合世 → 得外地之财、天时之财（受节令天气影响）、天意之财（中奖）
- 测调动，天爻为用神旺相生世 → 进京到外地工作之喜
- 测行人，父母爻在天爻发动临螣蛇青龙驿马 → 乘飞机
- 测官职，官鬼在天爻 → 官位高；在地爻 → 官级低
- 测出行，父母临地爻 → 乘车（地面交通工具）
- 测求财，土爻金爻临财居地爻 → 土财、矿产之财、本地内地之财

## 三、卦位与八卦类象

### 卦位

- **上卦**：上面、高处、远处、外面、表面、外层、外界、顶端、外来、领导者、统治者、高贵、高档次
- **下卦**：心里、内里、深层次、近处、低处、下面、内部、内含、低层次、位置低下、被压迫者、被统治者

注意变通：测雨，上卦坎下卦艮，不能说"上面有雨下面不下"，应断外地有雨本地无雨。

### 八卦类象（按爻形推导，不是背表）

- **乾**：三个阳爻，主实、主外、阳性。天、圆（易滚动）→ 主动、金、金属物、硬物、实心体、宁折不弯。主白、冷凉
- **坤**：三个阴爻，主虚、空 → 柔软、可塑性、承载性、容纳性。地、母、土、柔物、布匹、粮食、土中之物；中虚断裂又有小人多、人多之象；天圆地方 → 方形之物，主静
- **震**（仰盂，口朝上）：振动、动而不稳；为足（脚管行走）；为雷为声响 → 一切有声音振动性质的物体，如电话、手机、飞机。上两阴主柔虚空、下一阳主硬实
- **巽**（下断，上实下虚）：抽象床、矮桌、有垫脚的箱柜；木、草生之物、果园、鸡；为股（上实下两阴如两腿叉开）；为风，捉摸不定、无形无影、反复不定
- **坎**（中实，阴包阳）：水、流动、向下 → 下流、不正、盗贼；中男；雨、水中生物；车（爻象如车俯视图）；**有核之物**（如桃杏李，阴包阳）
- **离**（中虚）：外硬中空、两头硬中间空软；火、光明 → 文明、文化、文章、书籍；中女（阳包阴）
- **艮**（覆碗，上实下虚）：桌、床、门坎、倒扣的碗；坟墓（上阳主实圆，下阴主空方）；山、静、不动、阻碍、阻隔、止；狗（山有外实中空如山洞，戌为库为山洞，戌为狗）
- **兑**（上缺）：残缺、空、虚、不实；口 → 说、歌曲、一切靠口表现求生的行业（翻译、教师、预测师、演说家、歌唱者、音乐师）；少女

**同一物体可以由不同卦代表，因为取象角度不同**——按质地取、按形状取、按性质取。例：瓷缶口朝上旋转有震象，口朝下有艮象；按质地坚硬有口则取兑象。

## 四、卦名卦象

卦象卦名往往揭示**整个事体轮廓**，但**不一定决定吉凶**。原则是"辩证看，不要一看卦名卦象就直断"。

举几个代表例（原始素材为缩写版，只详述了部分卦）：

- **乾为天**：爻全阳，刚硬之象；政府机关、公安检察法院等刚正之象
- **天风姤**：乾上巽下，一阴五阳，有一女五夫之象；占婚主女人不正；卦名有交媾、约会之意，易有外情暧昧
- **天山遁**：逃亡、逃跑、退避、隐遁；两阴在内阳在外，小人欲制君子而君子退隐；占行人主逃避某事而出走
- **天地否**：三阴居内三阳居外，小人主内政；闭塞黑暗，小人得势；家庭论主夫妻不和、分居分离；测心性外强中柔
- **山地剥**：阴盛阳衰，小人得势；测官运多剥官降职降薪
- **火地晋**：太阳普照、万物依附；晋升、晋级、进见
- **火天大有**：大的富有；与人协同方能大有
- **坎为水**：重重险阻；也主心中实在、说话办事有诚信（吉取吉象，凶用负面）
- **水火既济**：三阴三阳全得位，形象完美；**预测遇之多难成功完美，因物极必反，必以反论**
- **泽火革**：改革、革新、革命；主改行换业、变革换新
- **地火明夷**：受伤流血之象；主受伤、得病开刀
- **地水师**：一阳居二爻，众阴环绕，主多人参与、势不可挡
- **艮为山**：重重阻碍、止住停顿
- **火山贲**：墙内亮丽 → 装饰、化妆、粉饰、打扮、遮掩、装修、涂抹、包装；占住宅多有装修之象

用法：卦名卦象**只在用神信息不明或需补细节时参看**，且必须与用神吉凶一致时才引用其含义。

## 五、卦宫信息（大环境）

卦宫是一个场：环境、处所、状态。由上下两个单卦组成，两个单卦处在共同的场态中。

- **卦宫 = 大气候、大环境、宏观调控**（世界风云、国情、地区形势、天气、自然规律）
- **单卦 = 小气场、小环境**，直接影响其管辖的卦爻
- 卦宫对单卦影响力大小，取决于卦宫得日月生扶的程度
- **单卦可影响卦爻，卦爻无权影响单卦**

用法：测工作，世所在单卦（工作单位）受卦宫克 → 单位受政策、市场形势制约；单卦虽临日月旺相，只是眼下效益好，受大气候限制难有更大发展。

## 六、空亡的信息象

总体含义为"空"与"实"相对：不实、虚伪、心里没底、没有、不存在、不在、发挥不出来、躲避。

按事类延伸：
1. **合伙生意**：世应哪方逢空 → 该方不实、没诚意、心里没底
2. **行人**：用神空 → 无音迹
3. **婚姻**：用神空 → 一没配偶；二与配偶分居（空有无象）
4. **讨债**：应空 → 对方躲避不在家或不实；世空 → 自己心里没底。世在未出空期间去讨 → 竹篮打水一场空
5. **求财**：财爻真空 → 无财可求；旺相逢空 → 有钱一时拿不到手
6. **怀孕**：世或子孙或胎爻空 → 没有怀孕
7. **交易**：财空 → 难成或钱财虚假，防假钞假货
8. **工作**：官空 → 无固定工作或工作没落实；已有工作官空 → 无官位、权力被架空、职位空缺。找工作父空 → 单位没落实或徒有虚名
9. **出行**：上爻（天）父空 → **可以是坐飞机之象**（空中意），但不能死搬（距离短或无航线就不能这么断）
10. **音讯**：父空不一定无音信，可能是手机、广播、电讯等"空中"信息传递
11. **介绍对象**：间爻（媒人）临父旺相逢空 → 无媒人，或"空中鹊桥"为媒（电台、电视、网络）
12. **风水**：父（建筑物）临五六爻（天爻、高处）逢空 → 可能架空的（立交桥、天桥）；地爻（初二）逢空 → 地洞、地窖、井、口洞

## 七、墓库的信息象

本意：收藏、收敛、收容、装载、躲避。**既限制又保护**入库之爻。

- 休囚之爻逢墓 = 入墓（死墓）；旺相之爻入墓 = 入库（可进可出，有保护功能）
- 入库期间不受它爻克，也不克它爻
- 延伸物象：公共汽车、车辆、飞机（可容人装载人）；监狱、收容所、医院（收容限制人）；仓库、容器、盒子、包装箱；袋子、衣兜、杯子、抽屉；水库、水井、池塘、水缸（水墓库）；银行、储蓄所、保险柜（金钱墓库）

取象要问"这个墓是哪一类的墓"：墓爻临官鬼 → 官方、国家的（如火车）；临螣蛇 → 细而长（火车、绳索）；在五、六爻（天爻）临螣蛇青龙动 → 可能坐飞机。

## 八、六神信息（只作辅助，不主吉凶）

> 六神本身并不主吉凶，**切不可单独使用**，必须配合六亲、爻位、卦象、爻象并结合实际综合推断。六神的作用只是辅助提取具体信息。

（六神本义素材较杂，此处只列实用取象）

- 青龙：端正、高大挺直、喜庆、酒色、正义、法律文书
- 朱雀：口、说、念叨、口舌、是非、文书材料、通讯信件、面赤有麻痣、麻雀唧唧喳喳
- 勾陈：旧、陈旧、慢、田土、房产、契约、熟识、团伙、土特产；个矮面黄
- 螣蛇：细而长、绳索、缠绕、怪异、虚惊、虚病、缠绕不清；体瘦高弓曲
- 白虎：凶、风波、孝服、血光、病伤、开刀手术、跌打损伤、体胖面白
- 玄武：暗、不明不白、私下、暧昧、盗、风流、赌博、机灵；面黑

**关键用法：六神必须挂在有生克关系的爻上才有意义。** 如"世临白虎"单独看无意义，须是世临白虎**又被克**才主病灾血光；不受克则不主灾。

## 九、六亲外延（同一亲在具体场景下的延伸义）

### 父母爻

- 测求财经营：父母为**耗财爻** → 投资费用、消耗、路费盘缠。父旺动 → 经营费用大、开销多；也代表管理、事物头绪，父旺动 → 头绪多而乱、管理不善、漏洞多、财物流失
- 测子女：父为孙爻的忌神（相当于官鬼性质）→ 灾难、祸患
- 测婚姻：嫁妆、婚期
- 父母为辛苦劳碌之神，父持世 → 辛苦劳碌、心事多、烦恼、杂事多
- 测官司：状子、证据。父空 → 还没起诉状子；已打官司父空 → 证据不足、没头绪

### 兄弟爻

- 测生意：劫财、破财、阻力、竞争、口舌争斗争执。兄动无子孙同动通关 → 阻力大、破财；兄临朱雀动 → 伴口舌是非；**兄与子孙同动 → 兄弟反成财的渊源，得朋友同行帮助而财源广进**
- 男测婚：阻隔之神。兄动 → 婚姻有阻、有人作梗；兄持世求婚 → 成婚心切
- 兄克财 → 花费、投资；也主竞争、求财心切、占有欲强。兄持世主将本求财（有本钱投入），可能有合作者参与；兄持世又动 → 有争财、有合伙者来分财
- 测官司：兄持世主打官司耗破钱财，发动破得更多；兄在间爻（证人）→ 证人有勒索钱财迹象；兄弟爻克哪方则对哪方不利

### 子孙爻

- 子孙代表技艺：孙持世 → 靠技艺求财或靠嘴求财；孙动 → 有来财的路、有挣钱的地方
- 测官司：**讲和的说客**（孙克官，使官方不再插手）。孙旺动 → 说客口才好、道理讲得透，双方能和解
- 测战事：舆论、和平
- 测养殖：养殖物，其旺衰代表健康状况成长速度
- 测种植：种植物，其旺衰代表生长状况

### 妻财爻

- 财动 → 意味要动用钱财资金
- 测人事：财动克世 → 有妻或女人制约自己，或女人从中作梗使坏，或受钱财物制约限制
- 测生意：财临日建 → 可天天见财（卖店、卖菜，天天有顾客）；财不上卦 → 不是天天见财，是时出时没；养殖种植则先不断投资，一定时期出售才见钱

### 官鬼爻

- 测求财：官鬼**盗泄财**，代表要支出的费用（税收、各种收费、租金）。官旺动 → 支出大、有人从中捣鬼、或有财物丢失
- 测经营：官旺动而财休囚 → 因上述原因不赚钱。**兄官同动、财旺相 → 官起护财作用**（制约兄弟劫财），说明利润与官方或内部管理、保卫措施得力有关
- 测流年：官动克世 → 来自官方的灾祸（官司、罚款、处罚、警告）、小人兴风作浪、盗贼、疾病伤灾；官生世 → 官方支持、贵人扶助

> **总原则：六亲本身中性，都有吉凶两面。提取信息象看此六亲是向着世爻用神（取吉的信息）还是背着（取凶的信息）。**

## 十、六亲通变取象（揭示本质关系）

以辩证思维，把所测的具体人事物作为坐标原点（立太极点），按"克我者官鬼、我克者妻财、生我者父母、我生者子孙、比和者兄弟"重新审视原卦六亲，产生**新的六亲复合之象**。

**关键限定：**

> 测人事关系取用神时，仍以卦中原来六亲取用。**六亲通变只用来看此人对卦主的实质关系（向背），不用来改用神。**

例：
- 看朋友有无助益：以原卦兄弟为用。兄克世 → 这朋友实质是官鬼性质，不是真朋友，明一套暗一套（小人、危害）。兄生世 → 实质是父母性质，对世有爱护保护生养功能
- 测领导如何：以官鬼为用。官生世 → 对世体现父母性质（信任、爱护、教育）；官世比和 → 性质相当兄弟（关系如朋友，但在利益钱财面前又具竞争纷争）
- 测买房是否有利：以父母为用。父克世 → 体现官鬼性质（危害、克制、阻碍），不再体现保护功能
- 测考驾照是否有益：父生世 → 父性不变，有利；父世比和 → 性质转为兄弟，也有帮助功能（但不是保护）

**未知小人的真面目**（不以官鬼为用，以冲克世爻的五行为用）：
- 兄克世 → 同事、朋友、兄弟姐妹、竞争对象所为
- 官克世 → 上级领导、仇人、丈夫等人所为
- 财克世 → 女人、管钱财之人、妻子、下属、曾被自己打击控制之人
- 孙克世 → 晚辈、游手好闲之人、下属、士卒、好歌唱跳、运动、有手艺、好说笑之人
- 父克世 → 父母长辈、有文化之人、开车之人、文书秘书工作之人

危害程度看该爻力量与动静：旺相发动 → 危害明显且大；动而弱 → 危害轻；暗动 → 暗地使诈、背后危害；不发动 → 只有想法未行动，说说而已。

**六亲通变的一个重要推论**：克世之子孙，就不是"医药"而是"病"。所以测病时，若子孙克世，子孙爻即病神，此时能制子孙的父母爻才是医生药物。

## 十一、两象定一象

取象最实用的技巧：**两个以上的象指向同一结论时，才能定案。**

例：断胃病——卦中辰土在三爻受克，三爻为腹部也代表肠胃位置，且辰为脾胃，**两个象**合一定为胃病，可直接断。

反例（必须避免）：只凭一个象就断。如只凭"用神在日月休囚+临白虎"就断血光之灾，不看卦中内部组合——这是取象最常见的失误。

## 十二、信息拓扑（形象思维）

拓扑本义：几何图形任意变形而基本特性不变。用在六爻上，就是把卦象、爻象、卦位**正看、反看、变形看、形象看**，再结合易理与社会，提取信息象。

具体手法：
- **字形思维**：如"申"字可看成轴承套与轴的组合俯视图、两头细长中间粗的器物；测人外貌，用神临申即申字形脸
- **符号思维**：动爻的"○"可看成张开的**口**（主说话）；也可看成绳套（配合螣蛇的绳索象）
- **串联思维**：把零散信息合情合理组成一组象。例：官鬼寅木临螣蛇（绳索）+"○"（绳套）+ 寅戌合（捆绑缠绕）→ 树上挂绳索的套 → 上吊而死
- **外应思维**：此时空、地点、事物暗示测事状态（如母亲跨门槛问卦，把下卦艮（门坎、止）翻转为震（动），震木生上卦离火 → 口红）

## 十三、一卦多断的原则与技巧

### 原则

1. 多数卦可一卦多断，能断出多少取决于**测事牵涉面的大小**和预测师对测事的了解程度。测"妻子下班何时回来"这类牵扯面很窄的事，就难多断
2. 一卦多断**不是一卦断万事**，而是围绕所测之事尽量提取有关信息，绝不可提取与测事毫无关联的信息（信息定向锁定原理）
3. **一卦多断 ≠ 一卦兼断**。多断是围绕测事展开；兼断是用一卦提取与测事无关的其它事象，这不符合理与辩证法，偶尔碰准可以，不能作为定律推广

### 技巧

1. **丰富的社会阅历**——你了解的事物越多，越能把现实中的人和事对应到卦里
2. **在卦中标注对应点**——初学者可在主卦旁标注与测事有关的对应关系，直观看出信息
3. **联想思维 + 两象定一象**——把零碎信息合情合理地串起来

## 使用流程

1. **先定吉凶**：先用前几层技能判成败。取象只在吉凶已定之后做，不能反过来用象改吉凶
2. **列出对应点清单**：按现实条件列出涉及的每一个人、事、物
3. **逐个定位到卦爻**：六亲 → 再配爻位 → 再配三才/卦位 → 再配六神
4. **两象定一象**：至少两个象一致才定案
5. **六亲通变校核**：看此人此物对世爻的**实质关系**（是保护还是危害），而不是名分
6. **串成叙事**：按时间或因果把象连起来，形成可读的叙述
7. **标注置信度**：哪几条是两象以上互相印证的，哪几条只是单象推测，明确区分

## 边界

1. **这是传统术数体系，不是可验证的预测方法。** 象的延伸没有边界，因此取象最容易滑向"怎么说都对"。**必须坚持两象定一象，单象不作结论**；并如实告知求测者哪部分是强信息、哪部分只是可能。
2. **取象不能改变吉凶判断。** 若吉凶已定为"不成"，不可因为找到一堆象说得通就改判"成"。取象只解释"是什么、在哪里、因何"，不解释"成不成"。
3. **健康、法律、投资类取象风险最高**：
   - 断病部位、病名属传统对应，**不构成医学判断**，不可据此延误就医
   - 断"贼的相貌、方位"、断"官司起因"属传统套话，**不构成对具体人的指控**，不可用于指认现实中的人
   - 断"上吊而死""车祸""牢狱"一类具体死因灾祸的象，是六爻中最容易造成心理伤害的部分。**遇到此类取象，应明确说明这是传统象数推演、不是事实判断，并避免对具体人的生死下断言**
4. **素材与损坏说明**：
   - 《六爻多重取象》为**缩写版**，目录列 16 章，正文实际覆盖第 1–14 章及第 15、16 章；其中"旺衰信息""动静信息""变爻信息""飞伏神信息""生克冲合信息"等章正文有但较简，本技能只取可核对的部分
   - 64 卦名象在素材中只详述了约二十卦，本技能只列代表例，**未作补全**
   - 六神本义的素材（《多重取象》第六章）字库有讹误（"螣蛇"处多处显示为乱码），本技能只取可用部分
   - 爻位细分、三才、卦位八卦类象取自《六爻基础入门（2019修订版）》
5. **流派分歧**：真假六亲、六亲通变、临界状态属李顺祥一系特有方法，传统派（野鹤一系）不用。用哪一派须先声明，不可混用同一次判断。
6. 若求测者因取象结果产生焦虑或恐惧，应直接说明其非事实判断的性质，并把话题拉回可操作的部分。
