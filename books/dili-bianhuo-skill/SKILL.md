# 地理辨惑（马泰清百问）

## 作者与成书（决定了这本的分量）

马泰清，陕西人，道光丁未（1847）在京师遇乐亭李振宇，执弟子礼，从游年余，"尽得其传"，此后覆验旧茔数百年者"断之无不吻合"。同治甲子（1864）应老友张蓉溪之请，把平日问答笔录成书。

**为什么值得看**：作者自述先学过五行三合、拨砂辅星，前后十六年"日夜不懈"，读遍《地理原真》《天机会元》《地理大成》《地理纲目》《人子须知》《山洋指迷》《罗经解》等，登山引证书籍"非不至详且备"，但"考其人家之事迹，殊大不然"——**他是从反方走过来的人**，所以他的辨伪不是门户之见。

## 一、最核心的一句：形势为体，理气为用

> "先以形势为体，理气为用，形势一错，则体非其体，用非其用，无往而不错矣。"

推论出四条分工，这是全书骨架：

| 问题 | 由什么决定 |
|---|---|
| 出什么样的人（温厚/强悍、端庄/卑鄙） | **形势**（山川平坦则人温厚，粗雄则人强悍） |
| 什么时候发、发多久 | **理气**（元运） |
| 人丁、寿考 | 坐山主星庄重、水法团聚，且在旺运 |
| 科甲 | 要看乡会试之年文昌、魁星是否会于坐山/水口/文峰/向中三堂之水 |

**四种反常组合的解释**（很实用）：
- 贱而富 → 远坟非地，新坟得地
- 贵而贫 → 山龙得运，向水失运
- 富贵而夭绝 → 旺运已尽，煞运管事
- 贫贱而丁寿 → 地本非地，但向水得令

## 二、为什么三合被判定为"死格局"

三合的用法：某龙来、某水去、立某向，合生旺墓库 → 主富主贵。

马泰清的驳论只有一句但很硬：

> 前数十百年遇此等地如此用法，后数十百年遇此等地也如此用法，而吉凶大相悬殊。或一样之地，前为人用而发，后为人用而败；或一山之上，前为人用而吉，后为人用而凶。

→ **三合是"一定之死格局"，缺少时间变量。** 真气运"以三元为始终"，循环往来。

配套结论：**形势虽美、元运不合，应当弃之**。"若勉强用之，其凶立至。"

## 三、伪书与伪师鉴别清单（本节最可直接使用）

### 被明确点名的

| 书/人 | 判语 |
|---|---|
| 叶九升《地理大成》 | "略闻斯道，信之不专，杂收伪书，不辨鱼鲁" |
| 尹一勺《地理十二种》 | 同上 |
| 《乾坤法窍》《风水一书》《增注地理辨正疏》 | "俱是未得真传，私心悬揣，拟造挨星图，去道逾远" |
| 咸丰元年京师所刻《地理正宗》 | "穿凿不经，尤堪齿冷" |
| 范宜宾《挨星图》 | "似是而非，徒足以乱真"；其四十八局"与生旺墓库、游年翻卦死板格局有何分别" |
| 章仲山《地理辨正直解》《天元五歌阐义》 | 承认"尤为明晰"，但**评其人"熟于理气而昧于形势"**，"不曾与人葬得好坟"（引广陵人语） |
| 张九仪二十八宿拨砂法 | "日月之八宿最不经"（把心危毕张四月宿指为火，与天文书不合） |
| 《海角经》《青鸟经》 | 托名最古，"其书即伪之尤者"——证据：《海角经》号称黄帝时九天玄女语却"酷似唐以后之言"；《青鸟经》题樗里子（秦惠王弟，周时王侯），而文中出现"沙堤"（唐时拜相之礼）、"宰相"（秦以后才有的极贵之官） |
| 各种"自创挨星""伪造元空秘本" | "愈出愈奇，辨惑之作正为此辈" |

### 被认可的

- **形势书**：杨筠松《撼龙经》《疑龙经》、吴景鸾《望龙经》、廖金精《拨砂经》、沈六圃《地学》
- **理气书**：蒋大鸿《地理辨正》《天元五歌》——"足称千古不传之绝学"
- **峦头书通判**："凡系峦头之书，不过大同小异，尚属有凭有据，尽皆可看；至理气，则东牵西就"

### 三条通用的识伪方法（比清单更有用）

1. **看证据链**：真师"覆验旧茔，虽数百年者断之无不吻合"；伪师"枯骨无言，纳棺入土即受谢而去"，祸发要十数年才见，"则夸其地力当在三五十以欺罔"
2. **看是否可证伪**：伪书多"朝成诵而夕行道"，词无奥义；真诀"引经据典，语奥义深"，且"必遇其人始授"
3. **看是否造形状名目**：见一地即造一名（狮象虎凤猪犬龟鱼罗汉将军美女、玉屏牙笏文笔三台贵人天马旗鼓）——"不问有龙无龙，有穴无穴，勉强扦葬"

### 一条识别"改碑改向"骗术的判据

**阳宅能改，阴宅不能。** 阳宅门路通阳气出入，改门改路可化凶为吉；阴宅"以水口为门、以元辰水为路"，土冢上立碑"非门非路"，改碑换向毫无作用。唯一例外：平阳以路为水、有小沟渠立局的，可以改就旺方（同阳宅改门路）。

## 四、房分公位排序法（书上少见的可操作细节）

诸家说法不一，作者实测后只认这一套：

**从坐山左侧往右排，不拘多少房，各占一位。**

| 房数 | 排法 |
|---|---|
| 1 房 | 四面均归之 |
| 2 房 | 一居左，一居右 |
| 3 房 | 孟左、仲向、季右 |
| 7 房 | 左为长，往右排二三四（第四房正在向上），续往右五六，第七房居右之末 |
| 9 房 | 长居首、九居末，第五房正在向上 |
| 10 房 | 五在向之左，六在向之右 |

**两条补充规则**（古书无，作者自述"屡试不爽"）：
1. 葬时若长房已死，则次子居长位，长房位上的吉凶由代长者承当
2. 多子已死数人者，以**葬坟之日现存几子**为准排位

⚠️ 作者自己承认："余初亦用此考验多次，均不合法，惟孟左仲向季右之说尚是。"即七房以上是推演所得，把握不如三房。

## 五、元运年限表（本书独有的说法）

| 运 | 该地可管年数 | 理由 |
|---|---|---|
| 一白 | 160 年 | 一与九相对，九紫当运时一白之地才败 |
| 二黑 | 140 年 | 二与八相对，八白管运即败 |
| 三碧 | 120 年 | 三与七相对，交七赤管运始败 |
| 四绿 | 50 年 | 中五前十年属巽，三碧运内已可用 |
| 六白 | 50 年 | 中五后十年属乾，七赤运内尚有余气 |
| 七赤 / 八白 / 九紫 | 各 60 年 | — |

配套：五黄运前十年寄巽、后十年寄乾（作者指出这与"俗收二八两宫"及奇寄宫之说不同，是"得诀后覆验古坟所得"）。

**"三元不败"的真相**：不是一坟管三元，而是百余年间人非一代，上元有上元老坟、中元又遇中元吉坟、下元再接葬下元新坟——"非积善之家有大福德之人不能"。

## 六、平阳 / 平原 / 平洋点穴法

**核心尺度："高一寸为山，低一寸为水。"**

平阳看气之法：于绵渺一片处细察地气"隐隐隆隆，如人肉上之筋、皮中之脉，若有若无"——有帐盖、有迎送、有过峡、有入首，到结穴处或以水、或以路、或以低浅之地缠绕交护，穴形同样分窝钳乳突。

**平原四种结穴位置**：
- 原边 → 下临崖岸，必左右有沟渠插入交汇，于交汇气聚处立穴
- 原角 → 如大小转弯处，形象圆净、理气清纯处立穴
- 原尽头 → 原势渐低，有枝脚作龙虎拱卫，与高山干流结穴相类
- 原之中 → 四望不见边岸，有沟渠就沟渠，有路水就路水

**江浙水田的特殊判据**：田必高处是有龙有砂，田必低处是界水，田必低窄处是过峡，田必横宽处是开帐；结穴之田"高不过砂，低不侵水"。

**窝钳乳突与晕法（点穴的最后一关）**：
- 小窝钳乳突 = 少阴少阳 → 直接点
- 窝钳宽大 = 老阳，不可用 → 于老阳中觅少阴（窝钳中求乳突）
- 乳突肥厚 = 老阴，不可用 → 于老阴中觅少阳（乳突上求窝钳）
- 大窝钳中无乳突、大乳突上无窝钳 → 求晕
  - **窝钳之晕**：如人心坎中跳起处略有一点高影，一阴初动，似有似无
  - **乳突之晕**：如小儿囟门上吸动处略有一点低靥，一阳初动，若隐若现

**穴中土色判据**：山垄平冈，穴中必有"似石非石、似土非土"之土，搓之如粉、见风日即坚硬如石，极佳者成太极晕；平原平阳多为淡黄细土或红黄青紫，佳者亦有太极晕；平洋池塘水侧，好土"干而不燥、润而不湿、捻之如面、不夹砂石污泥"。夹砂石又潮湿者为无气之穴——"只可为厝，不可为坟"。

## 七、阴阳宅比重

- 阴宅 70–80%，阳宅 20–30%
- 比喻：**阴宅是土壤，阳宅是雨露**。根植肥壤，纵雨露愆期，终久滋荣；根植瘠区，纵雨露调匀，暂时繁华终必枯槁

## 八、南北葬法的工程差异（这部分有实际参考价值）

| | 北方 | 南方 |
|---|---|---|
| 穴深 | 丈余，浅亦六七尺（土厚） | 五六尺，或结盘培土成坟（土薄） |
| 主要威胁 | 土潮湿 → 棺败毁如泥（但无白蚁） | 白蚁、树根、水气渗入 |
| 应对 | 少雨，堆土践踏即成 | 坚筑石灰隔水蚁，炭末隔树根 |
| 好穴表征 | 干暖、土有油润、见风即干、棺骨如初、有温暖之气甚至"气出如蒸" | 同 |

**树根**：松柏根伸不远，也须在二丈以外；最不宜乌桕、夜合、枫、栗——"其根能串行满山，虽数十丈外亦不可留"。
**一个可操作的改良**：棺底先坚筑石灰一层，再纳棺，与四围及顶坚筑为一，则虱蚁树根无隙可入（因棺足入土最浅，蚁根常由棺足而进）。

## 九、选择（择日）的地位

作者把择日压得很低：**阳宅之力不敌阴地之半，择日又其末**。理由：世家巨族高碑大冢"选择非不慎重讲求"，何以葬非其地补救无灵。实用态度：避太岁三煞、岁月时空破、化命祭主刑冲克害即足，不必拘各种不经神煞。

## 十、《地理十不葬》（附批判说明）

原文十条：不孝弟者、积世怙恶者、身为不善者、心术不测者、出身下贱者、古坟旧墓者、私用公山者、来历不明者、信任不专者、接待无礼者。

⚠️ **整理时必须标注的三点**：
1. 这是一份**行业伦理规约**，主体精神是"不予助恶"（不帮土豪讼棍、不破人古冢、不占公山、不谋夺民地），在当时是约束从业者的道德条款。书中有实例：李师为亲王看生茔，王欲扩界占民地，李师怒而登车径去。
2. **第五条"出身下贱者不葬"（厮仆、隶卒、娼优）是明确的身份歧视**，反映清代等级观念，与现代价值观直接冲突。引用时应指出其时代局限，不可作为行为准则传承。
3. **"信任不专者""接待无礼者"两条，实质是门派对客户的要求**，背后是秘传体系的商业逻辑，不宜当作道德标准。

## 使用流程（把百问压成可执行顺序）

1. 定形势：认龙（起伏摆折、屏幛、枝脚）→ 认穴（砂环水绕、窝钳乳突）→ 认砂水
2. 定元运：这块地属何元何运可用，现下是否当运
3. 定穴法：山垄 / 冈原 / 平阳 / 平洋 / 平原 / 水乡，六样形势各有看法，理气用法相同
4. 定深浅：看土色与燥湿（干而不燥、润而不湿为佳）
5. 排房分：按坐山左→右排位，有亡故者以葬日现存子数排
6. 算应期：大运（二十年）→ 年运 → 月运，看文昌魁星、生旺气是否临山向砂水
7. 择日：只避刑冲克害与三煞，不深求

## 边界

1. **本书是内部论战文本，不是中立综述**。马泰清站在蒋大鸿—李振宇一脉，对三合、拨砂、翻卦、范宜宾、章仲山、叶九升、尹一勺的评价都带强烈门派立场。引用时须标明"此为玄空派立场"，不要当作业界共识。
2. **正版《地理辨正》与本书对"分金坐度"的态度一致：判为伪法**。若用户资料含《二十四山罗经图》一类分金断语，结论会冲突，见 `ershisi-shan-fenjin-skill` 的冲突说明。
3. **书中"灵验"叙述（覆验古坟、断某房某事）属作者自述，无法验证**。可作为文本理解与传统知识整理，不构成对现实吉凶的预测承诺，也不应据以判断具体人的命运。
4. **南北葬法中的工程建议（石灰、炭末、隔树根、穴深）在当年是防潮防蚁的实用技术**，但现代殡葬须依《殡葬管理条例》及地方规定，不得私占公山、耕地、林地建坟。
5. 文本完整性：本库所收为百问全本 + 十不葬 + 结语，未见缺章；个别字有 OCR 讹误（如"干"多为"乾"、"绿"多为"禄"、"颂门"应为"囟门"），引用时不擅改。
