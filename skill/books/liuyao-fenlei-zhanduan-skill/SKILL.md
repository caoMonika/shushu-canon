# 六爻分类占断

## 它是什么

分类占断是把六爻的基础判据（旺衰、生克权、空破墓绝、动变）落到具体问事上。**同一个卦测不同的事，断法不一样**——不是判据变了，是取用和对应点变了。

## 零、三条前置方法论（比条文更重要）

### 1. 断卦前先联系实际

起出卦后先别急着看卦。先在脑中过一遍：**现实中要办成这件事，需要哪些条件、经过哪些环节、涉及哪些人事物？** 然后把这些人事物一一对应到卦爻上（这就是取用），再看哪些条件具备、哪些不具备、能否补救。有补救，逢补救之时即是应期；无补救则事不成。

求测者多数是来求指点迷津的，不是来考你的——不清楚就直接问：这件事现在到哪一步了、需要经过什么环节、期限多长。

### 2. 卦的内因与外因

- **内因** = 主卦、变卦（含变爻）的内部组合
- **外因** = 年、月、日、时，以及进行时的日月

判据链：
> **内因决定成败，外因只是成败的引发点（应期）。外因只能通过内因起作用。**

所以：
- 日月全克用神，但**卦中无动爻克用神** → 只是眼下不顺、处于低谷，不会有大灾
- 日月生扶用神，但**卦中有动爻克用神且无通关** → 现在风光，等克神旺相之日必应灾
- 判断顺序永远是：先看卦内有没有伤用神的隐患，再看日月何时引发

### 3. 卦象信息定向锁定

所求之事确定后，**卦中各爻的信息就锁定在"与此事有关"这一范围内，不再具有其它含义。**

反例（必须避免）：测"父亲能否回来"，见世爻入墓、又逢三合局冲克，就断"求测者本人有牢狱之灾"——这是画蛇添足。此卦里世爻只代表"自己的心愿"，官鬼也不代表官方，它是父母爻的原神。

推论：
- **测具体事项（测父母、测工作、测官运等定向预测），不可以一卦多断。** 偶尔兼断碰准是巧合
- 只有测运程、流年、终身这类范围广的卦，才可以一卦多断，但也必须围绕"运气"这一主题
- 所以父母爻受克无生，在测文书时**只主文书不成**，不代表父母有灾、房子有损

## 一、求财

### 先分类（不同求财方式，判据不同）

**（1）长期求财**（开店、办厂、长期经营）
必须满足：财、世两旺 **且** 财爻持世或生合世爻，方可得财。财爻冲克世爻时，需有通关才行。
道理：长期生意靠关系，财与世必须是相生相合关系。

**（2）短期求财**（一次性交易、当日之财）
只要财世两旺，**无论财爻与世爻是冲、克、生、合，只要有某种联系，即可得财**。兄弟持世也照样可得财。
道理：一次买卖不需凭关系。

**（3）生意求财**（有资金投入）
- 世爻 = 求测者，其旺衰 = 担财能力
- 应爻 = 客户及求财环境
- 财爻旺衰 = 挣钱多少
- **父母爻、官鬼爻 = 耗财因素**（管理费、税收、租金、各种收费）
- 财爻休囚 + 官或父动而耗泄财 → 管理不善、费用过大、税收租金多，不挣钱
- 兄弟爻旺动劫财 → 不但不挣还要赔
- 兄弟与子孙同动、子孙旺 → 财源广、来得快、源源不断
- 子孙爻不上卦 = 无财源（顾客少、只是偶尔出现）

**（4）空手求财**（靠信息、中介、技艺、体力）
靠技艺挣钱，关键看**官鬼爻旺衰**（官鬼代表名气，名气大财路才广），兼顾财、世旺衰。

**（5）合伙求财**
世为自己、应为对方。一看世应关系，二看财爻旺衰，三看**财爻向着世还是应**。财生应而不生世 = 自己之财流入对方手中。

**（6）讨债**
① 对方（应爻）想不想还 ② 对方有没有钱（财爻旺衰）③ 世爻有无担财之力。
判据同长期求财：必须财爻生合世爻才行。财爻克世、应爻旬空、外卦无财 → 讨不回来。

### 得财之象的部位

- 财爻在**五、六爻（天位）** → 得天财：不劳而获之财、摸奖、运气财、股票、远方之财、空中之财；在五爻还主动中之财、路上之财
- 财爻在**日、月建上** → 主外面、远方之财、外省外国之财
- 财爻在**三、四爻（门户、人爻）** → 不远不近之财、人事上之财
- 财爻在**初、二爻（地位）** → 近地之财、土产、地面、土建之财

### 求财方位三法（以本人居住地为原点）

1. **以财爻地支论方位**：子北、丑寅东北、卯东、辰巳东南、午南、未申西南、酉西、戌亥西北
2. **以世爻为基点**：以世爻所克的方位为求财方向（我克者为财）。如世为丑土，所克为水，水主北 → 北方之财
3. **以财爻所在卦论**：乾西北、坤西南、震东、巽东南、坎北、离南、艮东北、兑西

三法综合：两种或三种一致 → 取该方向；三法各不相同 → 此人求财无定向、流动性大。

### 财的数目

可用财爻地支数和主卦+变卦之数配合求测者的规模估。属经验法，只作量级参考，不是判据。

### 求财应期的一个反直觉点

> **财爻太旺，应期不在生财日、财值日，往往在财被合之日或入墓之日。**

## 二、婚姻

### 先分已婚未婚（判据完全不同）

**（1）未婚（未确立关系）**
主看**世应**，兼看财（男）官（女）。
- 世 = 自己，应 = 对方。世旺 = 自身条件好、信心强；应旺意义相同
- 宜世应相生：应生世 → 对方喜欢自己；世生应 → 自己喜欢对方；世应相合 → 相互爱慕
- 世应相冲相克 → 不成。世应皆阴爻 → 关系慢慢冷淡；世应皆阳爻发动相克 → 一谈即崩
- 世或应与他爻/日月有合 → 另有选择（世逢合自己另有选择，应逢合对方另有选择）
- **男测世宜阳、女测世宜阴**为阴阳得位，否则不顺。阴阳反错（男阴持世、女阳持世），除非倒插门或女方掌家权，才能成
- 世动生合应 → 相处中自己主动；应动生合世 → 对方主动
- 世动化回头克/化墓/化空 → 因自己而败事；世化退 → 自己有退悔之意。应爻同理，反映在对方
- 世空 → 自己心里没底、不实；应空 → 对方如此；世应皆空 → 双方都无诚意

**（2）已婚（关系已确立）**
主看世与财（男）、世与官（女）。
- 男测世与财相生相合为好；女测世与官相生相合为好
- **忌财官两现**，主二婚或外遇之象
- 忌世与财官相冲相克，主婚不顺，有生死别离之兆
- **无论已婚未婚，最忌六冲卦，主不出三年必有分离**（婚姻为合和之事，逢冲必散）
- **男测最忌兄弟持世**：未婚主不成，已婚主夫妻失和、有生死别离之忧
- **女测最忌子孙持世**：同上
- 男测兄弟持世临白虎发动 → 男方对妻子凶，常动手
- 女测子孙临白虎持世发动 → 自己先动手与丈夫撕打

### 情敌

- 男测：官鬼为情敌（官鬼持世主位正，无妨）。官临勾陈 → 妻有旧情人；财动与官合 → 妻主动在外找情人；官动合财 → 有男人勾引妻
- 女测：妻财为情敌。财临勾陈 → 夫有旧情人；财临玄武 → 夫与其他女人有暧昧

### 六神定性格与态度

- 兄弟临朱雀 → 双方争吵不休
- 男测财临朱雀冲克世 → 妻唠叨好骂夫、爱挑毛病；若生合世则不为此象，反主言语多、感情交流多
- 男测财临玄武 → 妻风流、不正、好赌；财临青龙 → 妻正派
- 男测官鬼持世、女测财爻持世为**位正**，吉；男财持世、女官持世为**位不正**，须世爻休囚才好，旺则婚上不顺，或须对方说了算

### 双方家庭条件

以世爻所在卦为自己家庭、应爻所在卦为对方家庭。卦旺 → 家庭条件好。
世旺而世所在卦休囚 → 本人素质好但家庭条件一般。

### 对方相貌

未婚看应爻与财爻，已婚看财（男）官（女）：
- 临子午卯酉 → 俊俏端正
- 临木 → 高挺；休囚 → 中等身材、发秀
- 子为单眼皮，亥为双眼皮
- 临辰戌丑未 → 敦厚朴实，但长相较丑
- 临寅申巳亥 → 聪明，长相一般
- **值日月建 → 不论何支都主长得好或能力强**
- 配六神：青龙端正、朱雀面红有麻或痣、勾陈丑、螣蛇瘦高、白虎体胖面白、玄武面黑但机灵

### 距离远近

- 男财持世、女官持世 → 近地之妻/夫
- 财（官）与世同在一卦 → 近地
- 一在上卦一在下卦 → 远地
- 被日月动爻变爻**隔断** → 外市外省
- 财（官）不上卦 → 远方之人
- 财在二爻（宅爻）→ 邻里之人

### 年龄差距

- 以八卦论长幼：乾老男、坤老妇、兑少女、艮少年、离中女、坎中男、震长男、巽长女
- 以世与用神（财官）地支纳甲排六十甲子，序数之差为年龄差
- 阳爻主年龄大、阴爻主年龄小；老阳（○）比静阳更大，老阴（×）比静阴更小
- 世应或世与财官皆阳/皆阴 → 年龄相仿（发动一方年龄略大/略小）

### 排行（传统法，现代已基本失效，仅作参考）

财官临辰戌丑未 → 长；临子午卯酉 → 中；临寅申巳亥 → 幼。再配卦：乾兑艮坤 → 最小；坎离 → 居中；震巽 → 最大。卦与支一致则确定，不一致则取中。

## 三、失物

### 分类取用

六畜走失取子孙；文书证件取父母；**贵重之物无论何物一律以财爻为主**。

### 失物可寻之象（8 条）

1. 用神在内卦本宫，无伤无劫 → 未出家门
2. 用神旺相安静，持世或生合世 → 可寻
3. 用神宜静不宜动——动则地点有变，静则不动易找
4. 官鬼不上卦，或官鬼落空、衰、墓、绝且不动 → 非人偷，易寻
5. 世应相生相合 → 物不失、非人偷；应生世尤为可寻
6. 官鬼临日月建 → 无人偷，是自己丢的
7. 卦遇**游魂** → 多属忘记，不是丢失
8. 用临应或伏于应下 → 借给别人了，借给谁看应爻六亲

### 失物难寻之象（7 条）

1. 用神无故旬空，或动而化空
2. 财/用在外卦外宫旺相发动 → 在外转移不定
3. 用爻动（动则难寻）；或衰绝墓空无气、旺而受制无生克权
4. 鬼爻发动，或变爻为鬼 → 被人偷
5. 内卦用神无气
6. 用动化鬼
7. 用爻伏而休囚

### 在何处（三套坐标）

**按宫位**（用神所在卦 → 方位与场所）：
乾西北（寺庙、楼房、观宇、城墙）；坤西南（坟墓、荒郊、野外、粮食、车辆）；震东（加工厂、森林、木材、有声之处）；巽东南（市场、庄园、果园）；坎北（水边、车辆、酒店）；艮东北（山林、坟地、山边、路边、门坎、床边）；离南（冶炼、砖窑、窗户、闹市）；兑西（酒店、歌舞厅、戏院）。

**按伏神**：
伏子孙下 → 寺院或禽畜处、门院、小辈僧道处
伏父母下 → 屋中、尊长处、衣服书箱中、厨房
伏兄弟下 → 兄弟姐妹处（三四爻兄弟下则门边墙下）
伏财下 → 与妇人有关，或粮食仓库、厨房
伏鬼下 → 与军役人有关，或厅堂、病人处、神案

**按爻位**：
上爻 → 屋顶、天棚、梁柱间（本宫）；远地庙宇亭间（他宫）
五爻 → 箱柜桌边、人常走动处（本宫）；路边（他宫），发动则更远
四爻 → 门前、不远处、卫生间（本宫）；屋外不高不低处
三爻 → 房中（本宫）；屋外门边腰脐高低处
二爻 → 与灶上下相齐处（本宫）；地上（他宫）
初爻 → 屋内地面被物掩盖（被何物掩盖看初爻六亲五行）

### 其它定位信息

- 用神入墓、化墓、伏墓下 → 在某物体中或固定地方
- 用神持墓爻 → 在器物边，看墓爻为何五行六亲之墓
- 用持鬼墓 → 在神庙处；无气在坟内；值螣蛇在神图像佛有关处
- 用爻发动被日辰合住 → 必有物遮掩
- 用化子孙、子孙化用 → 在禽畜处或动物巢穴洞中

### 自己丢的还是被偷的

卦无官鬼，或官鬼空亡而世爻发动 → 自己遗失。因何失落看世爻六神：
青龙 → 酒店饭店或喜庆之事；白虎 → 因病探病、医院丧事、跌倒；勾陈 → 起落走路、工作干活、与朋友熟人聚会；螣蛇或与应相冲克 → 打架打闹；朱雀 → 口舌竞争歌唱吵闹；**玄武 → 被人偷**。
用伏而逢日辰动爻暗冲，鬼爻安静 → 有人把物移走收起来了，何人所移看日辰及相冲之爻的六亲。

### 谁拾到

兄弟、官鬼在**外卦**动 → 外人得；在**内卦**动 → 家人或熟人。

### 知情人

以子孙爻为知情人，**必须子孙发动**才有知情人，不动则无或找不到。子孙临地支可推此人形象：子（黑衣、秃顶、打鱼、属鼠）、丑（农民、放牧、上坟、属牛）、寅（小孩、木有关、属虎）、卯（青衣、妇女、属兔、种菜种花）、辰（黄衣、男子、肩挑手提、属龙、有宗教信仰、水库边）、巳（红衣女子、闲人、小玩童、玩蛇、属蛇、好说话）、午（红衣男子、骑马牵马、属马）、未（土有关、土字部姓、放羊、属羊、种花菜）、申（白衣男子、军警、属猴、铺路修路开车）、酉（白衣女子、针工织衣、酒店、医务、买卖、属鸡、养鸡）、戌（狱官、犯过法、与狗有关、属狗、烧窑、信佛烧香、会五术）、亥（黑衣人女子、水有关、养猪、属猪）。

### 贼或拾者

- 年龄：官鬼或兄弟旺相 → 青年；休囚 → 老年；临胎养长生 → 小孩
- 方位：看兄鬼在何卦发动（乾西北、坤西南、兑西、离南、震东、巽东南、坎北、艮东北）
- 远近：本宫内卦动 → 家贼亲邻；本宫外卦动 → 本地之贼；外宫外卦 → 外地人。另一法：五六爻动 → 远方；三四爻动 → 未出市县；初二爻动 → 本地邻里家人
- 相貌：水黑、金白、土黄、木青灰、火红（肤色）；地支定脸型（子圆略凸、丑长、寅短圆、卯上宽下窄、辰方、巳上尖下阔、午上宽下尖、未长方圆、申上宽下尖、酉长方、戌方、亥圆）；六神定身型（青龙高大挺直、朱雀面赤有麻中等身材、勾陈矮面黄、螣蛇瘦高弓曲、白虎体胖面凶色白、玄武体圆面黑）

## 四、疾病

### 一条重要的修正（与传统说法不同）

传统"官鬼为病症、子孙为医药，鬼旺病重鬼弱病轻"——**实际不成立**。

- 官鬼持世、休囚，自测病，被子孙旺克 → 不但不好，反有生命之灾
- 父母持世，官鬼为原神，官鬼被子孙克 → 病难治，还会加重

修正后的用法：
> 官鬼为忌神、闲神、仇神时**不代表病症**，一般只代表**病的部位**（官在五爻胸部、六爻头部、四爻胸腑、三爻腹部、二爻腿部、初爻脚）。只有当官爻为原神或为世爻（自测）而被克时，才表示病症。

### 主要方法：把整个卦当一个人体

阴阳失衡、五行失衡是致病主因。所以：
1. 看卦中**过旺**之五行与**不及**之五行
2. **最旺五行**及**被最旺五行所克之五行**，就是病症所在
3. 结合爻位与五行对应的身体部位，推出是什么病
4. **动爻及被日月冲之爻位，往往也是病位**

不用专看官鬼爻。

### 实病与虚病

- **实病**：阴阳失衡、某五行太旺或受克太弱；多是世、用神原神受克或休囚无气。医院仪器能查出病灶
- **虚病**：用神不受克，往往是**世、用爻临螣蛇或玄武**。仪器查不出，人却觉得不适

### 病能否治愈

看用神旺衰 + 原神救应程度 + 忌神力量大小。这部分与其它门类同法。

### 一个经验

初爻动卯变辰、辰变卯（卯辰相加）→ 主腰脚刑狱之灾。

## 五、出行与行人

### 先分清问的是什么（最容易错的地方）

- 问**能否走得成** → 世爻被合、入墓、休囚、旬空都是走不成之象
- 问**是否平安** → 用神受克才断有凶险
- 问**行人何时回** → 用神休囚受克是不能回来之象，不是"人在外有灾"

**一念之差天壤之别。** 问"何日可走"与问"能否走成"断法不同；把"能否走成"断成"有灾"是典型错误。

### 预测外出

- 世 = 求测者，应 = 目的地。应空、应休囚 → 去的地方衰败冷落，去了也不顺；应旺 → 地方大、热闹
- **父母爻 = 行李包裹**：休囚带得少，旺相带得多；旺相逢空 = 带了很多不值钱的东西；被刑冲克害 = 带的为旧物
- **间爻 = 伴侣**：间爻旬空 → 无伴侣，独自出门；间爻安静 → 往来平安；间爻发动 → 必有阻碍
- 父母持世 → 路上辛苦劳累颠簸
- 世爻安静不动 → 行期未定；世发动 → 行期已定；应爻同时发动 → 对方来信来电催促
- 官鬼持世 → 出行顾虑重重
- 世静被日辰或动爻冲起 → 是给别人办事
- 世动逢日辰或动爻合住 → 绊住不能出行，或出行不顺
- 世爻旬空 → 去不成；硬要去终不顺
- 玄武并官鬼冲克世，或兄弟临朱雀发动 → 有口舌争斗；兄弟临玄武发动 → 有失盗
- 兄弟临白虎，或官鬼临白虎冲克世 → 有跌打损伤及风波
- 财爻发动克世且世休囚无气 → 因钱财或女人招灾
- 子孙持世最好，但宜旺不宜被冲克
- **测能否走得脱，最怕日月动变合住用神** → 必因事走不了

### 出行时的一个特例（重要）

> 测出行，用神**无论动静、无论旺衰、无论生合克合、无论合化成功与否**，都作"被合住"之象。

因何事绊住？看主合之爻的六亲：被父母爻合住 → 父母、车辆、文书之事；被财爻合住 → 钱财之事。

### 应期

世爻静 → 待冲日月；世入墓 → 待出墓；旬空 → 待填实逢冲之日。

## 六、官司诉讼

### 胜负判据（与传统说法不同）

> **不看世克应还是应克世，只看世与应哪方力量大，力量大的胜。不论世应临何六亲都如此。**

- 世克应不一定是我胜，可能是"我欺人"之象；应克世也不一定他胜，是"他欺我"
- 世临鬼旺相，照样胜官司；父母持世动化鬼回头生世，官司对我有利
- 太岁临官鬼 → 官司必升级。日月为贵人（日为小贵人、月为大贵人），世得月或日生 → 有贵人帮忙
- 世爻发动 → 我方想方设法出点子；化回头克 → 聪明反被聪明误，出了馊主意反害自己
- **财爻主理**：财持世 → 我有理；财临应 → 对方有理。若鬼来克世，虽有理而官不听
- 兄弟爻动 → 不容自己辩解
- 世空 → 我心不实、有撤诉之意；应空同论
- **子孙爻旺动 → 有人调和，有和解之象**
- 应生世 → 他欲求和；世生应 → 我想和解。若官鬼发动，想和解官方不让
- 父母爻主诉状：休囚或无父母 → 证据不足，不能立案；财动克父 → 官司打不起来；父空无气 → 未起诉、没写诉状
- 官鬼两重 → 事有反复、重告之象；两官权不一 → 经反复方能结案
- 原告被告看父爻：父持世 → 我告他；应临父母 → 他告我
- **间爻为证人**：间空 → 无人作证；间动克谁则证词不利谁，生谁则利谁；兄弟在间爻 → 牵连众人极多，动冲克世 → 证人向我索钱，冲克应 → 向对方索钱
- 卦无官鬼 → 无官主事，官司难告成；鬼休囚逢空同理，官方不想管
- 兄弟爻代表耗财：兄临世 → 我耗财；兄临应 → 他耗财
- **六冲卦 → 冲之必散，官司了结快**（输赢仍看双方旺衰）；**六合卦 → 拖拉不易了结**
- 世应旺衰接近时 → 看官爻向着哪方：生哪方哪方胜，克哪方哪方败
- 世应相生相合、世应比和 → 有和解之象。世动化官临空 → 假和；世空/应空 → 对方假议和。但若官动，官方不让议和，不想打也得打

### 官司起因（三条主线索）

第一是某六亲临朱雀发动；第二是某六亲发动变官鬼爻；第三是官鬼爻临某六神发动且去冲克刑害世或应。

前两条等价，按六亲分类：
- **兄弟**动临朱雀/动变鬼 → 朋友、同事、伴侣、中保中介、打架斗殴、经济纠纷、赌博、竞争、意气之争
- **妻财** → 女人、妻子、下属、佣人、买卖、经济问题、租借、财物
- **子孙** → 吃喝玩乐、暗娼嫖宿、男女情事、牲口畜类、信誉名声、为人担保、市场买卖、投资、讨说法、公安、医院、产权版权受侵
- **父母** → 父母尊长、领导上级、单位厂家、文书合同、房屋车辆地产墓地、考试应聘、工作调动

第三条按六神分类（鬼临某神发动且冲克刑害世或应）：
- **青龙** → 婚姻、酒色、喜事庆典、盈利分红、乔迁
- **玄武** → 水产水利、奸淫、失盗、男女情事、第三者、婚外恋、贪污受贿、营私舞弊、走私贩毒
- **勾陈** → 房屋、田地、产权、契约、团伙争斗、熟人相害、无故侵害
- **螣蛇** → 积怨结恨、株连造发、无理取闹
- **白虎** → 丧事、病伤、屠宰、捕猎、谋害争斗
- **朱雀** → 口舌传话、声音干扰、文书材料、通讯信件、火灾电力、名誉受侵、违法宣传
- 鬼不上卦但被日辰冲之暗动克世/应 → 因他人牵连引发，起因看飞神六亲

范围：本宫发动 → 家中亲属间；外宫 → 邻里单位同事朋友间；内卦非本宫 → 近邻熟人；外卦外宫 → 远方人。

## 七、竞争、比赛

- 世 = 自己/我方，应 = 对方。**看哪方力量大，力量大者胜出**，不以谁克谁论
- 短期行为，**时辰很重要**，一般不看太岁
- **月令 = 天时，日辰 = 地利，时辰 = 人和**。得月生 → 得天时；得日生 → 得地利；得时辰生助 → 得人和。日月冲克哪方，哪方就在条件上欠佳（如客场、时差、气候）
- **间爻 = 观众**，生哪方则观众利哪方
- **父母爻 = 教练**：生世 → 指挥有利；动冲克世 → 指导有误；静 → 影响力小；发动暗动 → 影响力大
- 世爻旺衰 = 自身竞争力、实力、自信心，是最关键的决定性因素
- 世应均动 → 双方都积极，竞争激烈，胜负要看日月动变对双方的利弊
- 一静一动：除动爻化回头克外，**动爻层次高于静爻**，谁临动爻谁有主动权
- 差距越大，成绩差距越大

## 八、流年

### 三块内容

1. **平安**（首选）：身体有无病伤、危及生命之事
2. **事业财运**：公职看官位、人事升迁；无公职看财运，哪月好哪月差
3. **六亲**：六亲是否平安、有无灾祸

### 起手看什么

一卦排出，**先看世爻有无生克权**。
- 世有生克权 → 一年中能主动做事，具备成事条件
- 世无生克权 → 一年平平，不能成事，与财官无缘，得益不大
- 原神、忌神、财官兄父皆同此理：**原卦中有生克权为"有用之爻"，逢流月出现时吉凶能兑现；无生克权为无用之爻，逢流月也无法兑现**

主卦各爻当下的旺衰就是"底"，一年的利弊都从这个底上评断；变卦变爻是趋势。

### 逐月推法

按流月推各爻旺衰的升降：升高则吉，降低则凶。

### 常用条文

1. 兄爻发动，破财难免，尤其克世
2. 兄临勾陈克世 → 熟人相害，因朋友兄弟姐妹破财
3. 兄临玄武动克世 → 易受骗、犯小人、防盗贼；赌博必大输
4. 兄带朱雀动克世 → 招口舌官非破财
5. 兄生世 → 得朋友相助，有益无害
6. 官爻发动：生世者吉，克世者凶
7. 官生世 → 得贵人、官方扶持，求事易成
8. 官动克世 → 官非、口舌、疾病等忧愁
9. 官临青龙动克世 → 官方法律惩罚（因自己有违法行为）
10. 官临勾陈动克世 → 拘留、审查
11. 官临白虎克世 → 开刀、手术、血光
12. 官临玄武克世 → 身体损伤或财物被盗劫
13. 某六亲冲世（以发动为准）→ 一年中与此六亲关系失和有纠纷
14. 世爻逢空 → 未出空前做事不成；**流年卦出空以月为单位推，不能以日推**
15. 世在日月都受克、卦中无其它爻克世 → 一年平淡无大灾也无多少收获；若另有爻冲克世 → 必有灾，无论世旺否
16. 世爻入墓 → 全年运气不好难有作为；再有爻冲克世 → 易有凶灾
17. 官鬼爻、忌神为病伤之灾，发动克世 → 有病伤或口舌官非；不克世则无

## 九、测来意

四条线索，几乎所有信息都逃不出这四条：**一看世爻，二看动爻变爻，三看应爻，四看六神。**

- 世爻 = 求测者本人，其旺衰、临何六神、动静变化直接反映处境、状态、心思、行为
- 动爻 = 卦的中心点（"卦不妄成，爻不妄动，天机尽泄于动变之间"），往往揭示发生了何事
- 变爻 = 往往表示事情的**起因**
- 应爻 = 所求之事的**环境**
- 六神 = 辅助区分事物类别与性质

另须结合社会常理：七八十岁老人求测，不太可能是为自己的婚姻、财运、官运，往往是平安、病灾、为子女小辈之事。测来意一般是近期发生或近期要办之事，所以抓住主卦变卦原象（代表现在时）。世旺得生扶多为吉事，世休囚被克多有忧心不顺之事。

**没有性别年龄等已知条件，很难完全测准来意。**

## 十、断应期的现实校验（极易被忽略）

应期大致两类：
1. 可推出具体日月时的
2. **不可用具体日月确定的**——预测结果本身就是应期（如"何时能忘记女友"这类无绝对应期之事，只能以年月为单位大致说）

必须做现实校验：
- 测出国定居，按国内惯例需几个月。若理论应期落在近几天，不符合现实 → **这种"超前"往往主办不成**
- 测有时间限制之事，理论应期超出办事时效 → **同样主办不成**
- 这类应期超前或落后于时限的情况，**无论卦的组合多好，都主事不成**

## 使用流程

1. **问清条件**：测什么、为谁测、关系角度、期限、事情现在到哪一步
2. **定向锁定**：把卦中各爻锁定到"与此事有关的条件"上，列表对应
3. **分内外因**：先看卦内有无伤用神的隐患，再看日月如何引发
4. **按门类取用**：对照本技能对应门类，取准用神（含真假六亲、用神转换）
5. **判生克权旺衰**：转 `liuyao-duangua-jifa-skill` 的四层次与生克权标准
6. **套本门类判据**：本技能各门类的具体条文
7. **定成败**：内因为主
8. **定应期**：按应期总注 + 层次转换 + 现实验证（时限是否够）
9. **补细节**：六神、爻位、卦名卦象、六亲外延（转 `liuyao-xiangyi-quxiang-skill`）

## 边界

1. **这是传统术数体系，不是可验证的预测方法。** 起卦依赖意念，结论无法对照检验。可作体系整理与文献研究，**不能作为对现实事件的预测承诺**。
2. **门类边界尤为要紧**：
   - **疾病门**：卦象不能诊断任何疾病，也不能替代就医。任何"何病、何时好、是否凶"的表述都是传统套话，不构成医学判断。若求测者据此延误就医，是本技能最需要防范的风险——遇到健康类求测，必须直接说明这一点并建议就医
   - **官司门**：不构成法律意见。涉及诉讼、合同、证据的，应建议咨询律师
   - **求财门**：不构成投资建议。原文自己也写"给人预测时要慎重，一句不负责任的话，有时会导致对方损失惨重"
   - **婚姻门**：不构成对具体人的品行、忠贞、寿命的判断
3. **原文缺项须如实说明**：本技能素材为《六爻基础入门（2019修订版）》与李顺祥一系（目录含测求财、测婚姻、测失物、测病、测出行、官司诉讼、测竞争比赛、断流年八节，均已获取正文）。**测来意与断应期两章正文仅部分获取**，本技能只给出框架，未作条文推测补全。**第十二章"六亲通变"正文未获取**，相关方法见 `liuyao-xiangyi-quxiang-skill` 的六亲外延与通变部分。

   - 官司胜负：本技能主"看双方力量大小"，传统派多主"世克应则我胜"
   - 疾病：本技能主"看五行过旺与受克定病位"，传统派主"官鬼为病症"
