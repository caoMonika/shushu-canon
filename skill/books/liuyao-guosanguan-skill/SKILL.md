# 六爻过三关：理法吉凶判定体系（姜效龙）

取材：《六爻过三关》（姜效龙著，网络手打版）。全书以《周易》三易为纲分三关：**不易＝第一关理法吉凶关**（固定规律判大象吉凶，断语不模棱两可）、**变易＝第二关灵活取象关**（吉凶既定后取象，不颠覆大象）、**简易＝第三关理象应期关**（应期核心是"对称反向"——应期在该爻目前状态的对称相反方向）。大量卦例取自《增删卜易》，本书价值在其理法条文本身。

分工：六亲六神取象基础见 liuyao-xiangyi-quxiang-skill；用神旺衰基础见 liuyao-zengshan-buyi-skill；爻层次与生克权见 liuyao-duangua-jifa-skill。本技能专收**判定"有用无用"与"吉凶归属"**的理法。

## 一、月日关系总纲（第一关第一章）

### 1. 月日同功同权

宇宙星体运行无先后，故月日对卦爻**权力等同，无谁大谁小**。以下皆为**平局**：月克日生、日克月生、月克日扶、日克月扶、月冲日合、日冲月合、月冲日值。

**冲合同功**：冲、合、值三者力量等同，皆最高层次，可互抵互补——
- 月破之爻，日辰能合补；月破之爻值日则不为破
- 月建合住之爻，日辰能冲开；月建克合之爻值日也不受伤
- 月冲日合＝先冲后合（先有挫折后有转机）；月合日冲＝先合后冲（先合作后分开）
- 例：财爻月破日合为平局，本不破财，但卦内三合兄弟局再增克 → 仍低价卖车。
- 例：财星先被月合后被日冲，月日互抵持平；但月合本护住财不受变爻回头克，日冲开反破坏这个吉象 → 仍破财。

**生克同权**：月克日生/日克月生/月克日扶/日克月扶皆平局；月建克得住的爻日辰生得起，反之亦然。月建不能生克日辰，日辰也不能生克月建。平局之爻**吉凶由卦内动爻决定**（再多一个动克即失衡为凶，多一个动生即有用）。

**生合克合的加权**：普通生克为一个层级，生中带合、克中带合力量更大。月克日生但日为生合 → 旺于平局；月日一克一生其中带合，按"合的层次"论强弱。

### 2. 月日各自为政（五对关系）

- **月纲日宰**：月建是万卦提纲（大政方针、政策、官员），日辰是六爻主宰（执行细节、主管官员）。月建冲爻就是破、没有余地；日辰冲爻有冲动与冲破之别。月建月内至高、出月过期无效；日辰月内不与月建争锋、出月后时效更长。例：军校招生——月建临世（政策允许花钱上），日辰官星克世（主管录取的官不同意）→ 不成。
- **月先日后**：分析思路先月后日（不是力量先后）。例：月建财合世（先得财）→ 日辰冲动官鬼克世（得财后马上有官非）。
- **月破日动**：月冲为破，无转化通关余地，刚猛直接；日冲可由动爻通关化泄。日冲带克＝克力＋推力；日冲不克＝只有推力；月建冲爻不分推力克力一律论破。**静爻月破即真破**（日合、值日除外），月破日生也是无用。
- **月短日长**（时限）、**月往日来**（月建为以往/现状信息，日辰为将来信息）。例：月建克财＝此前一直破财；日辰冲破财星＝以后也没财运。
- **天时地利人和**：月建＝天时，日辰＝地利，卦象（动变组合）＝人和。

## 二、有用值判定（第一关第二章，本书最硬核）

核心思路：先判外因（月日）给爻的基准状态，再看内因（动变）加减。**卦内动爻是失衡/补平的砝码**。

### 静爻有用值

| 月日状态 | 结论 | 备注 |
|---|---|---|
| 一克一生（含一克一扶） | 平局，**看卦内动爻**：有动生/动化吉→有用；有动克→无用 | 生中带合则旺于平局 |
| 一处休囚，另一处当值/受生/逢合 | 有用 | 生合>普通克 |
| 一处休囚，另一处被克/合中带克或带泄（盗合） | 无用 | 亥水被寅木合中带泄＝盗泄无用 |
| 月日双生/双扶/双值 | 有用 | 但有动爻克之则无用 |
| 月日双克/双休/一克一休 | 无用 | 有动爻生则可救为有用 |
| 月日双冲 | 真破无用 | |
| 月破＋日生（或日克日休） | **彻底无用** | 静爻月破多为真破 |
| 月破＋临日 | 有用 | 冲值互抵 |
| 月克＋日冲 | 日破无用 | 若有动爻转化相生（动爻把月克力转化过去）→ 暗动 |

暗动判定要点：日冲之爻须**本身在月日不受伤**才暗动；月克日冲之爻须有动爻通关转化才能暗动。日月与卦爻作用顺序：**先动后静，先生后克，无生则克**。

### 动爻有用值

1. 月日一克一生／一克一临 → 有用（前提是**不化坏**）。生中带合则生力大于克力。
2. 月日双生、双扶、双值 → 有用；**但化坏也不吉**（世临日辰而自动化回头克，久后必患——内因动变是长久趋势，月日只是暂时力量）。
3. 月日双克 → **看变爻**：化回头生（化吉）→ 有用；化弃权或化坏 → 无用。
4. 化吉、化弃权情况下，月日双休或一克一休 → 仍有用（衰爻冲静爻还能暗动间接起好作用）。
5. 月日双冲＋变爻弃权 → 无用。
6. 动化进神：即使动变双破仍**有用**（自身力量不断增强，月日之破只是外因暂时不配合）。应期：动而逢合之月。

**化坏**＝化回头克、化退神：力量减弱趋于无用，临月日旺相尚可苟延，衰弱或再被动克则当时作废。**变爻伏吟**＝力量转移中凝固，无明显吉凶；动爻旺相者冲开合起后还有用，休囚逢冲即断凶。**变爻反吟**：回头冲而不克→与弃权同论；回头冲中带克→按化坏论。

### 变爻弃权（本书独有概念）

变爻对动爻**不生不克**（如申化卯、午化未）＝"弃权"：力量流动到此为止，事情终局在变爻。此时动爻的有用值**完全由月日原状决定**。弃权之变爻本身的状态很关键——变爻健康则动爻保持原力；变爻真破＝动爻给自己造出"流失能量的伤口"（例：申金化卯木，卯在酉月真破 → 要工资一分也要不回）。变爻与主卦他爻的合象只用于人际关系/心理取象，不主吉凶。

**判大象吉凶只论生克冲合，空墓合绊之说是取象和断应期时用的**（例：巳火化戌土，断吉凶时不看化墓）。

## 三、三合局六态（第一关第三章）

**成局条件**：合局当令、或得月日之生；参与三爻都未受伤；**中爻必须在主卦或临月日**（申子辰子水为中爻）；成局后以**中爻五行的作用方向**论吉凶；两个辅爻因合化失去原五行属性。

- **成局**：中爻临月建、辅爻不伤。力量走向看合局五行流通到谁——例：应爻与日辰成水局 → 生寅木 → 生官鬼午火 → 生世，**流通终止处受益者为世爻**（马英九胜）。先动后静原则在合局成功时让位：辅爻失性，动爻改向。
- **破局**：中爻被冲破／化破／自变化坏／化退、辅爻被冲破。破后**破爻无用，未破之爻恢复原五行属性**。例：官父与应爻合局倾向对方，日辰冲破中爻 → 应爻化破＝对方自动放弃，辅爻官鬼恢复本性转生世 → 我方得。合伙事业合局被冲破＝散伙之象（实破之月散伙）。
- **虚局**：有爻旬空、或月日克制中爻 → 待时（填实/出空）才发力。例：合局未土逢空，未月填实才破财。
- **绊局**：中爻不在主卦和月日、而在变卦，力量回不了主卦，两辅爻也被绊住。**绊局可因绊住忌神而间接为吉**（例：申子辰合局中爻在变卦，把忌神申金绊住，世爻得月旺日冲＝冲旺冲动，升迁）。
- **喜局**：合成用神局、合局生世生用。例：亥卯未财局生世官，未月出空应吉。合局中爻临日辰克世但先先生变爻转生世 → 化险为夷（中爻临日辰则先生变爻）。
- **凶局**：合局克世克用、绊住世用、冲世冲用、间接坏作用。例：寅午戌局生应克世，且用神被合走失原性加入克世阵营＝"出现无情"。**暗动之爻也可参与合局**。

## 四、吉凶判定四大法（第一关第四章）

总纲：外因（月日）是条件，内因（动变组合）是根据。静卦静爻受外因主导大（如无行动能力之人被左右）；动卦动爻自身有运动能力，内因主导。

1. **外因主导／内因主导**：静卦看月日；有动变则动变组合是长久吉凶大趋势，月日只是暂时。
2. **直读断吉凶**：动化喜忌直读（动爻化出用神/元神为喜，化出忌神/鬼为忌）、化鬼化忌直读、用忌独发直读、用忌持世直读。
3. **链接有情**（关键框架）：
   - **二元卦**：须双方参与才能定成败——求官、求学、求工、求名、求财、借贷、婚姻、情感、官司、比赛、买卖、投资、合作、官非、丢失、求助、牢狱、风水吉凶。要求**用神和世（主）爻都是有用之爻，且五行气势能链接**，缺一不可。
   - **一元卦**：单用神即定吉凶——自身安危、病情（自己/他人）、寿命、产品质量、不明物、伤灾、行人回归、宠物六畜、天气、出行、产育等。只看用神有用无用，世爻可忽略，不必链接。
   - **有情链接**：用神生/合/持世、动爻化用生世、世生合用、世化用（世爻化出的用神即使不能回头生克，因同位且动变是因果，也算链接）。**无情**：世用相互冲克。用神冲世是离心排斥，气势无法链接。
   - **代占**：主爻（如代占兄弟看兄弟爻）是最后承受者，用神与主爻都要有用且链接。
   - 二元卦一元无用／一点化坏 → 可舍用神直接断凶。
   - **三个"用克世也算链接"的特例**：用神克世人即回、财来克世财必得、子孙克世病必愈。前提是**用神和世爻都旺、力量相当、世能承受克力**；财旺世衰则财反成克世之鬼（破财、工伤赔钱例）。
4. **流通及受阻**：生克方向是力量流向，**流通终止处的爻是最终受益人**（世爻可能只是中转）。多爻同动看链条是否受阻。

**特殊卦象**：伏藏卦、反吟伏吟卦、入墓库、空破各有判法（见下）。

## 五、取象要点（第二关精选，均不颠覆大象）

- **动静取象**：动爻主变化之端；静爻为现状/被动；暗动为暗中进行、突发；独发以一爻为事之焦点；独静以唯一静爻为归宿。
- **动变因果**：动为因、变为果。化回头生＝事情反过来帮自己；化回头克＝自找麻烦、结果伤自己；**介化取象**：变化经某动爻中介而成（官化兄、兄化财＝要靠中间人/朋友转手才能从对方手里要到钱）。
- **六亲墓库象**（入墓＝受困、收藏、放弃信心）：官弱/为忌时官库＝医院、牢房、有病；官旺/为喜时官库＝办公场所、开会。财旺/为喜＝银行、富户、厨房；财弱或临桃花＝色情场所。子库＝学校、科研、演艺、歌舞、洗手间。兄库＝同学聚会、监狱、犯罪团伙窝点。父库＝学校、科研基地、父母住院、单位。
- **入墓判凶的前提是受克**：用神先受月克再入日墓＝已在狱中；若月建不克只入日墓受生＝在外躲藏且有人照顾。**旺者入墓＝休息**（放假），不为凶；世弱入墓才主纠纷官非。世旺入墓力量发挥不出＝被迫放弃（工程款要不回例）。入墓也代表放弃、失去信心。月建入墓＝前运不顺（月主以往），日辰生世＝将来转好。
- **刑害只做取象，吉凶依生克**：三刑是间接、侧面的摩擦不和，最终吉凶以五行旺衰生克决断（月建丑土刑世，只是受摩擦批评，并不立案；胜负看世应力量对比）。六害＝互相不配合、暗中仇视、私下破坏（源于冲合牵连：子午冲破坏子丑合，故丑嫉午）。例：世应相害＋财官不能相生相合＝夫妻不同房离婚。
- **变爻与主卦他爻关系**只用于人际关系、心理活动取象（财贴近官而远世＝妻暗恋他人；变爻与他爻合象＝藕断丝连）。

## 六、应期（第三关仅存目录，正文缺失）

据前言与目录，第三关应期体系为：
- **总原理：对称反向**——应期在该爻目前状态的对称相反方向（依理或依象）。
- 坐标兼顾原理；测月内事"日动月静"（月心原则）；测长期事"月动日静"（日心原则）；测多年事"流动卦静"（卦心原则）；测当日事"时动日静"（时动原则）。
- 规律：动爻定应期（动而逢值逢合）、变爻定应期、进退、反吟（逢冲）、伏吟（冲开）、静而逢值逢冲、暗动逢值逢合；直读定应期（动爻化用/化鬼）；特殊规律（旬空实破实空、破爻补破、入墓冲墓、伏藏引拔出伏）；应期范围客观灵活运用。

## 七、使用边界与素材缺陷

1. 素材为论坛手打繁体转简体版，OCR/手误：「孙子爻」即子孙爻、「父父」即父母、「句空」即旬空、「月心原则」括注残缺、个别卦例排盘（如大畜卦例）只列六爻不完整。卦例多取《增删卜易》，与原书对照时以原书为准。
2. 本书与传统派（增删卜易系）同源同法，无门派冲突；其"有用值判定表"比一般教材精细，但结论（如"月破日生之静爻无用"）与野鹤原文"月破为无用之爻"一致，不矛盾。
3. 与 liuyao-duangua-jifa-skill 的爻层次分工：李顺祥按爻的层次（日月第一……）排生克权优先级，姜效龙按"外因基准＋内因加减"判有用无用——两套可并用，先用本书定"这个爻还有没有用"，再用层次法排作用顺序。
4. "变爻弃权"是本书术语，其他流派或称"化泄/化耗/不生不克"，使用时注意语境。
5. 第一关例 13（渐卦复职）本书对野鹤原断提出批评（"官临应爻就是别人的官"是大错，真正原因是世爻月日双休无用）——属于作者独立见解，引用时注明出处。
