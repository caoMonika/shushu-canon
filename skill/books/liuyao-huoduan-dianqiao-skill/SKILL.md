# 六爻活断点窍（张成达）

讲义＋函授体教材，分基础篇（装卦）、断卦篇（总纲）、分类解断 13 门、趋避篇。核心主张：功夫在背诵与总纲（《黄金策总断千金赋》），"卦要活起活断"。

## 一、装卦要点（基础篇）

- 画卦记背不记字；重(○)交(×)为动。
- 装世应：背熟京房八宫六十四卦是"笨法"也是真功夫。歌诀："八卦之首世六当，以下初爻轮上场，游魂八卦四爻位，归魂八卦三爻详。"世在变爻的爻位上。
- 装地支：记"相冲"定位——乾震子午、坎寅申、艮辰戌、巽丑未、离卯酉、坤未丑、兑巳亥；阳四宫（乾坎艮震）隔一位顺数，阴四宫（巽离坤兑）隔一位逆数。
- 装六亲：以"我＝兄弟"（卦宫五行为我）为轴心；卦中兄弟不现仍按寻宫记心中。
- 卦身两种：月卦身（"阴世从午起，阳世从子生，从初数至世"，卦中无此支则身不入卦）；世身（"子午持世身居初……巳亥持世身居六"）——**作者不用世身**（从《卜筮正宗》"辟《卜筮全书》世身之谬"）。
- 装变爻：按变出之卦装地支，**按本卦属性装六亲**（不变宫）。
- 邵伟华"一爻动则全动、变卦也安世应"之说：作者持古法（神机尽现于动），仅作多方位参考。

## 二、断卦总纲（生克四原则）

1. 月日可生克卦爻，爻不能生克月日（"日伤爻真罹其祸，爻伤日徒受其名"）。
2. 动爻（含暗动）可生克静爻与同层次动爻，静不能克动。
3. 变爻回头生克本位动爻；**变通**：变爻与本位动爻无生克合冲关系时，可作用旁爻。
4. 旺相爻能生克衰弱爻，反之不能。

**用神通变**（本书最实用处）：卖衣服看财不看父；测衣服丢失看财（失的是钱）、衣服质量看父；卖房求财取财（财旺月日价高），测拆迁看父被刑冲克破；外出找工作——求官看官、糊口看应爻兼财。
**用神两现**：按阴阳取（父占阳爻、母占阴爻）；按内外卦取（在家内卦、在外外卦；求官外卦为升、内卦为降）；两现同看（内外两财＝本地与外地财，比较旺衰）。
**伏神**："伏克飞神为除暴，飞来克伏反伤身，伏去生飞名泄气，飞来生伏得长生。"
**反吟伏吟**：卦反吟（乾巽/坎离/震兑/坤艮互变）与爻反吟（动变冲克）主反复；伏吟（卦变而地支不变，注意乾震同支）主呻吟，内卦内不适、外卦外不顺。
**进退神**：寅化卯等为进（地支顺行），卯化寅等为退；吉神宜进、凶神宜退。
**合的条件**：六合成化须两爻皆动（或动与本位变爻）且日月为化神无克；日月合爻皆论"合而不化"；动爻逢日月合＝绊住暂失生克权；静爻逢日月合、旺相时为"合起"（克合不论）。三合局分实合与"虚一待用"（待用之爻多为应期）。
**冲的层次**（全书最细）：日月冲变爻可冲散冲脱；月冲旺动爻为冲脱、休囚为冲散（永无生克权）；月建冲动爻皆月破（旺者值日/逢合/出月可用）；**日冲旺静爻＝暗动；日冲休囚静爻分只冲不克与连冲带克——前者介于暗动与日破的临界状态，看卦中动变爻向背**（生扶则暗动，克泄耗则日破）；月冲静爻分彻底破（休囚）、月内破（旺者合/值日/出月解）、月建冲值日之爻反为暗动。**合冲互解互破顺序**：变解主、日月解变、日解月、进行时日月解日。

## 三、分类解断（要点＋歌诀，摘核心）

- **身命**：世为身；世旺有福、世衰夭贫；入墓痴呆、居空无成；六合通达六冲有始无终。官动持世难为兄弟、兄动持世克妻、财动持世刑父、父动持世子难兴、子动持世损官运。
- **求财**：财旺福旺终如意，世去克财反难寻；"卦无子孙财无根"（开饭店子孙＝顾客，伏而受克＝没顾客，纵三传生世也赔——内因外因论：年月日是外因，卦爻是内因）。买卖看世应："世空己有悔，应空他不实"；兄动临玄武主官非。炒股：财旺升财衰跌，只测趋势不测点数（点名批"测开盘指数"为异想天开，《股谎》之说得之）。
- **婚姻**：男财女官为用；男占两财再娶、女占两官再婚；财伏鬼下有男人；八纯游魂闹离婚，咸恒节泰吉、睽革坎离分；间爻逢空媒人虚；兄多争财婚难成。相貌用五行＋六神"不要硬去对号"。
- **疾病**：官鬼为病（五行配五脏），子孙为医药，财为饮食；近病逢冲愈、久病逢冲死（六冲变六冲最凶）；爻位病图（上头五心四胁三腰二腿初足）。**真六亲假六亲**（《易隐》）：本宫六亲为真、他宫为假；内六亲外六亲之分——占母应取真六亲（伏神），假六亲现而真六亲伏藏＝"没了"之象；"鬼伏空亡防不测"；还可按飞宫转换取用。
- **行人**："动而克世人速回，静而生身归来晚"；用伏官下官司阻、伏兄下口舌阻、伏父下长辈留、伏财下钱财女色缠、伏子下游玩；方向看用神五行/卦象/变爻/独发，远近看本宫他宫内外卦与世爻距离；应期奇诀：亲人逢墓日归、人动墓冲墓归、人世墓值墓日归；**"用神无故动入空亡必死"**屡验。
- **失物**：财为用、官为盗、子孙为捕贼人；方向：鬼爻五行定来方、变爻为贼去向、外卦八卦定方位、财爻入墓定藏处（金物在丑、水土在辰、木在未、火在戌）；**六亲转换**（太极点）：财持世则克财之兄即"官鬼"（盗贼），制兄之官即"子孙"（捕贼人）。
- **官讼**：世应强弱定输赢，官爻向背定胜负（生谁谁胜）；父为状子（空破不能立案）、财为理、子孙为贵人、间爻为证人；世临鬼旺应衰照样赢、父母持世化鬼是回头生不能断丧命。
- **子女**：有无子女专看子孙（不看胎爻）；受孕专看胎爻（《黄金策》按宫推法，不用邵伟华日干查法）；生男生女看子孙阴阳＋卦包＋动爻；生产取用三法中"财为产母、胎为胞胎、福为儿女"最合卦理。
- **阳宅**：爻位断（初基井、二灶厅、三门床、四房中门、五路人、六梁壁）＋六亲断＋世应断＋六神断（左青龙右白虎前朱雀后玄武实用）；合二爻为门、冲二爻为路——**作者自注"合为门冲为路屡占不验，有待检验"**。
- **阴宅**：世为坐山为穴、所冲之爻为穴向；应与朱雀为案山、间爻为明堂、勾陈为来龙、青龙白虎为左右砂、玄武为靠山、上爻为水口；未葬穴（世主山、二正穴、螣蛇旁穴）与已葬穴（官鬼为亡人、父母为棺）断法不同；迁坟：青龙外卦动宜迁、白虎外卦动不宜，内卦衰空宜迁、旺相不宜。
- **趋避**：官鬼为灾（五行定灾类：金刀兵、木木器、水江河、火雷电、土山崩），子孙为解灾吉神；鬼动内卦出外躲、鬼动外卦莫出疆；宜去生世子孙临方，**须按世爻转换**（子孙卯木克世则东方反为凶方）。

## 四、实战风范

- 外应优先：摇卦时铜钱落地两次→断事推迟；"无可奈何"状→走留两难。
- 一卦不断二事；多法混用（六爻＋梅花）难对上号，用什么法就以什么法为主。
- 厌胜化解（画符、白牛）属民俗操作，记录在案不作推荐。

## 使用边界与素材缺陷

1. 全书为教学讲义，歌诀多承《卜筮正宗》《增删卜易》，独到处在通变实例与冲的层次细分。
2. 对"八卦测股票精确点数"持明确否定态度，与 liuyao-caipiao-guping 中部分材料观点相反，两存并用时注意立场。
3. "合为门、冲为路"作者本人标注屡占不验；六神断相貌"不要硬对号"。
4. 符咒、镇宅属民俗信仰层，仅作文本记录。
5. 占子女一节公开批判古例"劝善得子"的道德劝诫与子息无关（引"曹孟德多奸诈子孙满堂"），立场鲜明。
