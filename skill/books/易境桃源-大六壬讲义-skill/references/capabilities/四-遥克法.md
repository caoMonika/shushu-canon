# 四、遥克法

## R — 原文 (Reading)

> 凡四课上下俱无相克，则取日干与其他三课上神相比较。先取遥克日干之神作

> 初传，若无，再取日干遥克之神作初传；若同时出现数者遥克日干，日干遥克之神，

> 则以阳日用阳神、阴日用阴神法则来取作初传，以初传递次求得中末传。

> 四课上下俱无相克战斗处，则观日干与其他三课上神来比较。今三四课未戌

> 两神俱遥克日干，壬为阳日，未为阴土，戌为阳土，阳日取阳神为用，所以取戌作

> 四课上下俱无相克处，则取庚与其他三课比较。三课悉无上神来克日干，则

## I — 方法论骨架 (Interpretation)

遥克法是六壬占课中的一种方法，用于处理四课上下均无相克的情况。具体步骤如下：

1. 首先，比较日干与其他三课上神的关系。
2. 如果有某个神遥克日干，则以该神为初传。
3. 若没有遥克日干的神，则取日干本身为初传。
4. 根据初传，依次求得中传和末传。

## A1 — 应用示例 (Application Example)

假设某日为壬辰日，巳时，申将。四课如下：

```

卯
未午巳辰
```

根据遥克法，首先比较日干“申”与其他三课上神的关系。发现“戌”遥克“申”，因此以“戌”为初传。

## A2 — 触发场景 (Future Trigger) ★

遥克法适用于四课上下均无相克的情况，例如：

- 四课中没有明显的克号。
- 日干与其他三课上神之间没有直接的克关系。

## E — 可执行步骤 (Execution)

1. **确定初传**：
   - 比较日干与其他三课上神的关系。
   - 如果有遥克日干的神，则以该神为初传。
   - 若没有遥克日干的神，则取日干本身为初传。

2. **求中传和末传**：
   - 根据初传，依次求得中传和末传。

完成标准：根据遥克法确定的三传（初传、中传、末传）应准确无误。

## B — 边界 (Boundary) ★

遥克法仅适用于四课上下均无相克的情况。在实际应用中，应注意以下几点：

- 确保四课关系的准确性。
- 避免将遥克法应用于有明显克号的情况，以免影响占课结果。
