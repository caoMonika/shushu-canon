| 初六 | 《象》曰：履霜坚冰，阴始凝也。驯致其道，至坚冰也。凝，鱼陵反。驯，似遵反。按，《魏志》作「初六，履霜」，今当从之。驯，顺习也。 |

| 六五 | 六五，童蒙，吉。柔中居尊，下应九二，纯一未发，以听于人，故其象为童蒙，而其占为如是，则吉也。 |
| 六三 | 六三，含章可贞，或从王事，无成有终。六阴三阳，内含章美，可贞以守。然居下之上，不终含藏，故或时出而从上之事，则始虽无成，而后必有终。爻有此象，故戒占者有此德，则如此占也。 |
| 初九 | 天造，犹言天运。草，杂乱。昧，晦冥也。阴阳交而雷雨作，杂乱晦冥，塞乎两间。天下未定，名分未明，宜立君以统治，而未可遽谓安宁之是也。不取初九爻义者，取义多端，姑举其一也。 |
| 上九 | 上九，亢龙有悔。亢，苦浪反。上者，最上一爻之名。亢者，过于上而不能下之意也。阳极于上，动必有悔，故其象占如此。 |
| 六四 | 六四，括囊，无咎，无誉。括，古活反。誉，音余，又音预。括囊，言结囊口而不出也。誉者，过实之名。谨密如是，则无咎而亦无誉矣。六四重阴不中，故其象占如此。盖或事当谨密，或时当隐遁也。 |

| 音悦 | 《彖》曰：履，柔履刚也。以二体释卦名义。说而应乎乾，是以「履虎尾，不咥人，亨」。说，音悦。以卦德释《彖辞》。刚中正，履帝位而不疚，光明也。又以卦体明之，指九五也。 |

| 故其占为 | 六四，乘马班如，求婚媾，往吉，无不利。阴柔居屯，不能上进，故为乘马班如之象。然初九守正居下，以应于己，故其占为下求婚媾则吉也。 |
