# 《图解六壬大全》白话图解三部教程

现代图解本（华龄出版社《四库全书白话图解》丛书），以《四库全书》文渊阁足本十二卷《六壬大全》（明·郭载骐字御青辑）为底本，分三部重编：第一部占法及神煞、第二部吉凶占断、第三部毕法赋。编辑三层体例：**【原文】**（点校分段）+**【白话提要】**（现代译解）+**【白话图解】**（数百图表）。本技能为入门教程与查表索引；核心判据与《六壬大全》古本同源（见 liuren-daquan/zhinan/bifa），不重复蒸馏，仅收本版**独有整理**与学习路径。

## 一、全书结构（三部十二卷映射）

### 第一部：占法及神煞（卷一入手法、卷二神将释）
- **导读×2**：认识大六壬（式盘模型：天盘地盘太阳二十八宿年月日时四季纳于一盘，生克为正制化为变）+ 基本方法。

  2. 总钤：六壬 720 课（12 时×60 甲子）全表。
  3. **神煞**（本版独有整理）：岁神煞（太岁岁君）、太岁神煞系统、十天干神煞、十二地支神煞、**内天罡行十二经络**（气血运行十二经络规律）、**星煞总表**、逐月神煞（月煞系统）。
  4. **德煞八种**：德神（福祐）/合神（和顺）/鬼煞（贼害）/墓煞（伏没）/破煞（分散移易）/害煞（阻碍争斗）/刑煞（伤残）/冲煞（冲动）——每种一页图表释义。
  5. **课目**：六十四课口诀（六十四课对应六十四卦）+ 补论。
  6. 吉神凶神：先天贵神图（贵神昼夜运行）+ 十二天将简述。
- **卷二 神将释**四章：大神总论（十二支神总说）→ 十二神释（正月将登明亥、二月将河魁戌、三月将从魁酉、四月将传送申、五月将小吉未、六月将胜光午、七月将太乙巳、八月将天罡辰、九月将太冲卯、十月将功曹寅、十一月将大吉丑、十二月将神后子，各系页码条目）→ 天将总论 → 十二将释（贵人论/螣蛇论/朱雀论/六合论/勾陈论/青龙论/天空论/白虎论/太常论/玄武论/太阴论/天后论）。

## 二、本版独有贡献（相对古本与其他技能）

1. **神煞工程化整理**：岁/干/支/月四层神煞 + 星煞总表 + 内天罡行十二经络——古本神煞散见各卷，本版集中为可查表格，是全库**神煞总表最全的单一来源**。
2. **德煞八分法**：德合鬼墓破害刑冲八大"作用力"分类讲透，每类一页原理图——与 liuren-guanlu-shu"论破神/刑/冲/害/墓"互补（那边是断语条目，这边是体系原理）。
3. **六十四课口诀**：六十四课配六十四卦（课目对应卦象）——课体卦象化的入门记忆法。
4. **毕法一百法白话逐条**：liuren-bifa 为赋文+古注蒸馏，本版为逐法现代译解与图解，适合初学逐法对照。
5. **三部导航表**：章序号-主标题-书眉对照，跨部检索工具。

## 三、学习路径建议

1. 零基础：第一部卷一（起三传→总钤→神煞德煞→课目）→ 卷二（十二神将释义）。
2. 断课进阶：第二部卷三歌诀（日辰发用占病）→ 卷五～八课经逐课。
3. 精研：第三部毕法一百法逐条 + 与 liuren-bifa 对照古注。
4. 查表：神煞用第一部卷一第 3 章总表；类象用卷二十二神将释 + liuren-cuiyu-fu（贵人赋）。

## 四、使用边界与素材缺陷

- 本版是**现代编辑再加工本**：白话提要/图解为编者（许颐平、程子和）所加，非郭御青原文；编者自述"书中提要、图解皆作为阅读参考，其中注解有错误之处"——白话层偶有现代理解偏差，判据以【原文】层为准，与 liuren-daquan（古本蒸馏）互校。
- 底本书名题"郭载骐/郭载骅/郭御青"混用（同一人，字御青，明末清初怀庆府推官）；《四库提要》原文引录于每部卷首。
- OCR 情况：三部扫描各约 6.3–8 万字符（图解本大量图版不入文字），**文字层基本清通**，但图盘、表格、图注在 OCR 中散裂为图 alt 文本（如"太白星神氐星神五星之一…"混排），本技能不引图注细节；"秘籍网 www.miji8.com"水印行夹杂。
- 第一部目录页码（273–438 页）为原书页码，非本库页码；个别章节标题 OCR 讹字（"郭载骚/老人责/谈度"等为封面图版碎字）。
- 库中同一书多副本（图解六壬1/2/3、图解六壬大全（一）（二）（三）、带"郭御青"题名本），内容一致，蒸馏以三部全帙为准；《图解六壬大全（二）》副本仅 8.9MB 为残册，不采。
- 与兄弟技能分工：古本判据主干见 liuren-daquan；课体正法见 liuren-bifa；九宗门/神煞纲见 liuren-zhinan；十二天将临地断见 liuren-cuiyu-fu；身命空破墓见 liuren-guanlu-shu。本技能定位为**现代教程+神煞总表+毕法白话**索引层。
