# 天玉经（内传 + 外篇）

## 内传：三般卦与零正

| 卦 | 口诀 | 力 |
|---|---|---|
| 江东 | 八神四个一 | 管一卦 |
| 江西 | 八神四个二 | 兼二卦 |
| 南北 | 八神共一卦 | 含三卦最强 |

二十四龙管三卦。俗注地理切块否掉。

**倒排父母是真龙；顺排到子息人财退。**

| | 装 | 忌 |
|---|---|---|
| 正神 | 山上/向上 | 装水 |
| 零神 | 水上 | 装向 |

正神百步成龙，水短遭凶；零神不问长短。山上龙神不下水。

四隅阳顺、四正阴逆；甲庚丙壬顺，乙辛丁癸逆。北斗打劫：二七合离宫，向首即离宫。

## 外篇：四经与黄泉

阳金：干丙乙子寅辰；阳水：艮庚丁卯巳丑；阴木：坤壬辛午申戌；阴火：巽甲癸亥酉未。

折水公位：子寅辰+干丙乙长；午申戌+坤壬辛次；卯巳丑+艮庚丁三；酉亥未+巽甲癸四。

大黄泉忌坤巽艮干位；救贫黄泉来吉去凶（辛入干、癸归艮等）。

## 流程

格龙清纯 → 差错弃 → 三般同卦 → 零正 → 倒排父母 → 城门 → 四经折水黄泉 → 细排转辨正

## 边界

内传源加密；外篇后半疑掺撼龙，本技能不用；口诀未写全；术数非可验证因果。
