# 陆氏易解 · 陆绩注辑

**来源**：明姚士粦辑吴陆绩《周易》注残条（提要称凡一百五十条级，多抄《释文》《集解》，兼采京氏《易传注》）。
**性质**：汉魏象数易注辑佚速查——不是完整注疏，也不是占筮手册。
**文献边界**：原本久佚；本 skill 仅据现有 TXT 残条。缺卦（谦、蛊、无妄、艮、节、小过等标「阙」）不得凭记忆补写。不作现实预测。

---

## R — 原文 (Reading)

> 六爻发挥，旁通情也。乾六爻，发挥变动，旁通于坤。坤来入乾，以成六十四卦，故曰旁通情也。
>
> — 陆绩注，乾·文言段

> 分而为二以象两一营也。挂一以象三，二营也。揲之以四，以象四时，三营也。归奇于扐，以象闰四营也。
>
> — 陆绩注，系辞「四营而成易」

---

## I — 方法论骨架 (Interpretation)

陆绩注的可执行核不是「断吉凶口诀」，而是一套**象数读卦规程**：

1. **阴阳消息**：阳极则阴来、阴极则阳战；吉去凶生、否极泰来——用「盛极必反」读上爻与终卦。
2. **旁通成卦**：乾六爻变动旁通于坤（及反），由旁通生成六十四卦之情——读卦先问「与何卦旁通/往来」。
3. **卦象定位**：八卦方位与物象并用（乾西北、坎北、离火日、震雷、兑说等），象辞优先于空泛义理。
4. **君臣阴阳**：阴臣阳君、阳唱阴和——读三、四、五爻时先定君臣职分。
5. **京氏色**：六位时成、十二辰分六位升降消息——残注里夹京房时位语言，可与京氏对照，不可混作后世六爻世应术。
6. **系辞操作层**：四营成易、蓍以前民用、穷变通久——把「易」落实为蓍策与制器两件事。

## A1 — 应用示例 (Application Example)

### 示例 1: 读「亢龙有悔」
- **类型与来源**：原书注条（乾上九）
- **问题/输入**：上九亢龙，何以有悔？
- **方法论的使用**：用消息律——「阳极阴来，吉去凶生」。
- **结论**：不是道德训诫优先，而是阴阳度数已极。
- **结果**：原书仅给此象数句，未附占例。

### 示例 2: 读「同人九五先号咷后笑」
- **类型与来源**：原书注条
- **问题/输入**：九五何以先哭后笑？
- **方法论的使用**：「隔于阳位，不能决胜先克」→后获合方喜。
- **结论**：先看位隔与能否决胜，再断情绪时序。
- **结果**：原书止于象义，无应期推演。

### 示例 3: 合成演练——用旁通读乾之变
- **类型与来源**：原书未提供完整案例，以下为合成演练
- **问题/输入**：如何理解「六爻发挥旁通情」？
- **方法论的使用**：乾爻动 → 与坤旁通 → 生成具体别卦 → 以所通之卦情释本爻变动。
- **结论**：旁通是成卦机制说明，不是六爻装卦口诀。
- **结果**：演练结论；须回原文卦爻条核对。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 对比王弼义理派与汉魏象数派，要陆绩怎么说某爻。
2. 读到「旁通」「消息」「六位时成」，要出处与操作含义。
3. 做易注辑佚/京氏易对照，要一条条陆注原文锚点。
4. 解释「四营而成易」时要陆绩分步定义。

### 语言信号

- 「陆绩怎么注这句」
- 「旁通情是什么意思」
- 「陆氏易解里有没有某卦」
- 「阳极阴来」/「六位时成」
- 「京氏易和陆绩」

### 与相邻 skill 的区分

- 与 `jingshi-yizhuan-skill`：京氏是纳甲世应体系；陆氏是残注训诂+旁通消息，不能互相替代装卦。
- 与 `dayi-bushi-yuangui-skill`：元龟是筮法操作全书；陆氏无起卦流程，只有象义残条。
- 与 `huozhulin-skill`：火珠林是钱筮六亲；陆氏不讲六亲持世。

## E — 可执行步骤 (Execution)

**必需输入**：卦名 + 爻位/系辞句；或关键词（旁通、消息、四营等）。缺则先问要查哪一卦爻。
**交付物**：①原文注条（≤150字引用）②象数机制归类（消息/旁通/卦象/君臣/京氏时位/系辞操作）③文献边界声明 ④不可用处。

1. **定位条文**
   - 在乾→未济及系辞中检索对应卦爻；若原书标「阙」则如实报告无注。
   - 完成标准：给出可回溯的卦名+爻题。

2. **归类机制**
   - 判这条注主要用：消息 / 旁通 / 卦象方位 / 君臣阴阳 / 时位十二辰 / 训诂（字义）。
   - 完成标准：只标一类主机制，必要时加一类辅机制。

3. **压缩转述**
   - 用现代话重述陆注逻辑，禁止添入后世六爻世应、用神、装卦。
   - 完成标准：读者不读原文也能复述「他凭什么这么说」。

4. **对照边界**
   - 若用户要占事：导向 `dayi-bushi` / `huozhulin` / `wenwang-jinqianke`；本 skill 只提供陆氏象义。
   - 判停条件：问占断吉凶且不要文献 → 停用本 skill。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 要完整六十四卦陆注——书是辑佚残本。
- 要起卦、装卦、用神、应期——书中无此操作链。
- 要据「陆绩曰」做现代决策断言。

### 作者/辑者警告的失败模式

- 提要指出：朱彝尊所见异文（疚/疾、晢/逝等）此本或无——**传本异同，勿混引**。
- 卷数传说不一（十五卷/十三卷/三卷）——引用只标「姚辑残本」即可。

### 时代局限

- 吴人陆绩注经，夹京氏语言；不能代表先秦本义。
- 姚士粦明人辑佚，搜讨不及王应麟辑郑易之博（提要自评）。

### 容易混淆的邻近方法论

- 「旁通」≠ 虞翻旁通体系的全套条例（陆注只给乾坤旁通成卦的提纲）。
- 「六位时成」≠ 后世六爻世应装法。
