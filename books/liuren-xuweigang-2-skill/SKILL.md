# 徐伟刚心法·研究法·《指南》评注

## 一、这本书在讲什么

不是技法手册，是**方法论与实战反思**：怎么学、怎么研究、怎么判断自己处在什么层次、怎么读古书、怎么把《指南》的课例真正读懂。技法骨架见 liuren-xuweigang，本技能专管"路怎么走"。

## 二、学壬三步走

1. 跟古人学（入门）；
2. 跟现实学（结合当代人事）；
3. 形成个人风格（"学术结合个人特性，才能有真心得"）。

配套：**反对从死记硬背入手**。九宗门不必背诗诀，要理解"层层逻辑递进"，把九法归为三大类即可掌握。诗诀要"得其意可忘其句"，死背的结果是"得其句而失其意"。

## 三、占验的四种层次（自检标尺）

1. **垃圾课**：课式与所占之事根本对不上，断语牵强附会，纵然"应验"也无价值（滥占、戏占的产物）。
2. **俗课**：只断事成不成、走不走之类最初级问题；讲壬理滔滔不绝而无理致。多数爱好者停在这里。
3. **好课**：课式与事对得上，断法合乎壬法，有变通小技巧，断语合逻辑与常识，**应期准**。《指南》占例大多属于此层。
4. **神课**：课与事相合无间，方向、生肖、过程、应期、数量全部对上，断法灵动有新意。可遇不可求，是机缘与功力的合成。

用法：这不是给别人贴标签，是给自己定位——**先求脱离俗课，再求稳定的好课，神课自然会来**。判断别人水平也不必看其占例数量，看其高质量课有几则即可。

## 四、壬占五重关（想上层次必须逐关突破）

1. **干支关**：四课三传的形式特征要看到本质，不是背表面规律；
2. **年命关**：本命与行年之别、入式与不入式、年命与课传的关系（古书未讲透，是核心一关）；
3. **神煞关**：神煞是"克应"，决定课应不应、应在什么细节，取舍有深意；
4. **取象关**：象怎么取、取哪一个；
5. **运筹关**：断出来之后如何为人解决（趋避、调整、择时）。

## 五、壬占系统五法（断课的操作顺序）

1. **认格法**：从课中找出全部课式基本信息——干支关系、三传组合、盘面格局、课体名目。
2. **太岁代入法**：把四课三传之象与占课时的**太岁、月建、月将、正时**这些"动象"结合观察。动象才是壬占的真正着根处。
3. **点将法**：以天将定事之性质与最终方向。
4. **解构法**：把课拆成"人（干/年命）—事（支/类神）—过程（三传）—环境（太岁月建）"四层。
5. **断象法**：分**先天断象法**与**后天断象法**两大源头，是取象的根。

整个流程的要求是"一气呵成"：**"断"就是当机立断**，长考必出恶手；任何"让我再想想"的断法都不是上乘。

## 六、壬课格局论（八格）

仿八字命局分类，给壬课定"格"：

| 格 | 主要指标 |
|---|---|
| 贵课 | 贵人、太阳等主贵之象 |
| 富课 | 财爻、六合等主富之象 |
| 贫课 | 天空、空亡等主贫之象 |
| 贱课 | 太阴、蛇神等主贱之象 |
| 吉课 | 龙神、六合等主吉之象 |
| 凶课 | 白虎、蛇神等主凶之象 |
| 成课 | 龙神、马星等主事成之象 |
| 败课 | 天空、败神等主事败之象 |

实际课中吉凶混杂，**先定主象要素**，再归入某格，即得大致方向。格是"指标式分类研究"，与古课经不是一回事（课经看形态，格局看气象）。

## 七、象类与类象

- 古书只讲"类神"或"象"，"类象"一词是徐氏早期著作造出来的，后又自我修正：应作**"象类"**——**先有象，才有类；象先行，类方生；无象不成类**。
- 实践含义：不要先想"这事属于哪一类"，而要先看课中现了什么象，再由象归类。顺序一颠倒，就成了套类神。

## 八、年命四则（与技法本互见，此处为原始表述）

1. 本命重于行年；
2. 年命本身重于年命上神；
3. 年命与其上神可直接进入四课三传议论；
4. 占日天干与年命是"体用"关系。

补充：不知年命则不论——"天意让你不知其年命，你自可顺天行事，就课传去断"，不影响准确。占六亲最好知六亲年命，不知亦不必强求。

## 九、课命法与命课合参

- **课命**＝以时课占人一生。古法有之，但徐氏实践发现：**并非任何一课都能课出一生**。
- 于是提出"课命法"＝**工具选择法**：或用时课、或用八字、或两者参看。有时时课极准而八字不明，有时反之。
- 原则："课不离命，命不离课；无命不立课，无课不成命。"
- 引申：一个术者应"课、命、相、风水"四门皆通，只通一门难以从业。

## 十、运筹与调整（断之后的功夫）

徐氏把"为人解决问题"视为操术者的本职，方法六类：

1. 以生肖、姓氏、体态定"人"的吉凶关系（择人不当即坏运之始）；
2. 以数理定作事之宜忌方位与空间；
3. 行业分类归属（如忌木者不宜涉林、纸、木业及对应部门）；
4. 人生价值观与心理调整（婚姻类问题多在此）；
5. 数理专业调整（风水、命理、壬占三块）；
6. **神话、民俗、历史意象综合调整**——以"故事"为信息源解灾，如"后羿射日"用于胎神空亡之求子。此为徐氏特色，须以"意象"视之，不可当迷信推销。

择吉另成系统：**壬课择日**（把壬课特质与择日学沟通）、**节日择日**（国庆、中秋等节日自带象类，可高于一般择日原理）。

## 十一、读书法

- **术数五经**（徐氏自定）：六壬——《六壬集应钤》《六壬直指》《壬归》《壬学琐记》《精抄历代壬占汇选》；八字——《渊海子评》《三命通会》《神峰通考》《子平真诠》《穷通宝鉴》；风水、相学各有五经。
- **对《六壬大全》的评断**：可作入门（神煞、十二神将、毕法有价值），但主体课经与歌赋"与真正的壬占技术基本不搭界"；毕法赋"完全对头的不超过四成"，至少十五条赋文无实占意义，个别条目（金日逢丁、水中逢丁）在实践中是错的。**结论：读它入门，不可奉为典要。**
- **对《六壬直指》的推重**：720课总解是"壬占断课的基本程式"，其中**"解曰""断曰"最有价值**，毕法部分大概看看即可。
- **《六壬集应钤》**：明成化三年（1467）黄宾廷编，六十卷，集《口鉴》《金匮经》《玉历钤》《毕法》《通神集》《正疑钤》《无惑钤》《玉连环》《中黄经》《观月经》《灵辖经》《心镜》《龙首经》等为一编，逐课加"象曰""义曰""真一山人云"，是理论型集大成。
- **《精抄历代六壬占验汇选》**：清程爱函类编，六卷按六旬分卷，共 651 古例，纯实例无理论，是"棋谱式"实战教本（各卷例数：91/120/126/102/97/115）。
- **读书三病**：好读书（不择书）、死读书（奉书为绝对）、书本依赖症（手不离书）。破法：多问"为什么"，明其原理与出处。
- **"口头禅"之病**：理论滚瓜烂熟而实战三缄其口，是术数第一瓶颈。
- **"散"之病**：理路不明、术语满天飞、把断课做成"打分评模范"。破法：以"理"串象，纲举目张。

## 十二、《指南》评注：陈公献壬占思想复原

**《大六壬指南》结构**（五卷，约七万字）：卷一注心印赋；卷二注九天玄女指掌赋（价值高于心印赋）；卷三六壬会纂（分事类七言赋，毕法与人事的融合）；卷四六壬占验（125课，全书精华）；卷五神煞全图（庄公远辨讹）。

**技术口径（评注的核心贡献）**：

1. **正时为主，不废活时**。125课中绝大多数用正时；活时只用报时、拈字等。徐氏立场：正时是纯客观，活时带主观（显"心象"而非"现象"），应主用正时。
2. **昼夜分界固定**：卯辰巳午未申为昼，酉戌亥子丑寅为夜，不考虑四季实际日出。
3. **贵人口诀**用"甲戊庚牛羊，乙己鼠猴乡，丙丁猪鸡位，壬癸蛇兔藏，六辛逢马虎"正统口诀。
4. **涉害取传重孟仲季**，不重地盘涉害深浅（例：辛卯日四课寅辛/寅午/未卯/寅未，取仲上神未为初传）。
5. **本于毕法而不拘毕法**；以十二神将为中心，**神煞用得极多极活**；重太岁、太阳、月建、年命这些"动态因素"。
6. **重行年上神，本命次之**（与邵彦和重本命不同，也与徐氏本人"本命重于行年"不同——三说并存，用时择一）。
7. 风格是**"易简精妙"**：一事一课一断，直指本质；但初学者易堕入"非成即败"的二分法。

**实战技法（可直接套用）**：

- **一课多占**：同一课可断多事，"彼问则我答，彼不问我则不答"；关键在**换类神、换层面，不换课**。例：一丙戌日课同时断考试（支上巳为旺禄、支戌河魁文明）、升迁（驿马申加丑墓，马入墓不能动）、女病（干丙上见子鬼作胎爻）、兵警（子巳贼符加干支）。
- **同课异断**：同一课式在不同时间、不同人、不同事上反复出现，断法可比对。如甲申日干上巳一式，可断天时（申为水母）、考试（申为月建旬首）、仕途（申乘青龙内战）；末传龙神加午，占天时取"龙主雨"，占官取"龙主腾达"。
- **应期定法**（例：驿马坐墓求出狱）：取**冲马之月＋冲墓之日＋冲马之时**；因月令力最大，故以月冲为主。忌取戌月——入墓之马须大气力冲动，且初传发用应速，不会拖到半年后。
- **四绝体三传递克**（占官必遭弹劾的强规律）：常见组合为巳申寅（丙戊日）、子未寅（丙甲日）、寅未子（丙戊日）、卯申丑（辛日）、未子巳。凡天地盘成四绝体而三传递克者，占事多凶。
- **太阳西坠/太阳入山**：天盘太阳加地盘酉为"西坠"，加戌为"入山"（戌为山岗，故"入山"更确）。皆主荣华将尽，占官、求财、考学、治病都不吉。
- **龙神克下、龙退化蛇**：占官主失意（革职、退休、被逮），《指南》中屡用屡验。
- **鬼临三四**：主他非退位、灾患从内部起。
- **空亡**：陈公献讲"填实"，徐氏讲"应空"，两说并存；空亡法在全部课断中占比可达三成，是实现"铁口直断"的硬指标之一。
- **来意四法**：①天盘正时（先锋门）所值六亲天将；②发用初传；③干上神；④三传三合局六亲象。**四法中有两法以上重合，来意必验**——这是最实用的一条"绝招"。
- **神煞按占类汇集**（《指南》全书用过的煞，等于是"最灵验煞表"）：天时（风伯、雷公、电母、水母、雨师）；婚姻（天喜、成神、会神、月破、月厌、桃花）；求财（天财、大耗、小耗、破碎、劫煞）；阳宅（月厌、生气、天目、火鬼、死气）；出行（驿马、天马、天车、天坑、大将军）；疾病（生气、死气、丧门、吊客、血支、血忌、天地医、丧车、飞魂、丧魄、病符）；考试（驿马、学堂、印绶、皇恩、皇书）；官禄（生气、驿马、德禄、天喜、丧吊）；词讼（关格、吏神、天赫、皇恩、关神）；盗贼（天目、游都、贼符）；战争（游都、鲁都、太岁、将星、羊刃、天鬼、大将军）；耕种（天转、地转、劫煞、破碎、生气、死气）；阴地（生气、死气、龙神、驿马、丁马、天鬼、飞廉）；谋望（德神、合神、成神、会神、天喜、岁破、月破）。
- **占官看禄马之分**：守土官重禄神，钦差官重驿马——同是官占，取神不同。
- **神煞可代正神**：占失马而用驿马代午马，反而更准，因驿马本是从真马习性归纳出来的煞。

## 十三、徐氏八条自述观点（研究坐标）

1. 六壬只是时占之学，不能代替八字等其他宗法；
2. 十二神将论是六壬核心，"将高于神""吉将永吉、凶将永凶"；
3. 壬占当以象占为主，分"象断""理断"两路；
4. 提出太岁代入法、认格法、解构法、断象法等系统法；
5. 年命用法："命重于年、年命直接入课传、年命本身重于上神"；
6. 点将法为初学权宜；
7. 快速起课法以合"袖传一课"之速；
8. 推荐古书：《大全》《指南》《壬归》《断案》《琐记》《集应钤》《口鉴》《直指》。

## 十四、使用边界与素材缺陷

- 本技能合成四书：《大六壬点窍论要》上（约 5 万字，全）、《点窍论要》下（与《揭秘》合卷，抽取至"占官禄"后即接《揭秘》正文，故下编后半篇目未全）、《六壬开悟录》（目录全，正文抽取完整度较高，第九章"百家讲壬"中《洞微赋》《五要权衡》《毕法赋》《金科玉律诀》《课命要点》等古法汇编多为目录级信息）、《六壬指南占验精选评注》（全，含 50 余则课例的完整评注）。
- 因此：五要权衡、毕法赋、课命要点的**具体条文**本技能不复制（各有专书，且与 liuren-qinruisheng、liuren-bifa 等重叠）；本技能只保留《指南》评注中确实读到的技法与判据。
- 《指南》课例的**课式盘面**在抽取文本中大量以字符块形式散落（天将名、地支图），本技能引用课例时只述其断法与结论，不复原盘面，避免讹误。
- 原书对邵彦和、陈公献、王牧夫、徐养浩等人的评价带有强烈个人褒贬（如斥王牧夫"平民气、格局上不去"），属门户之见，本技能只取其技术判断。
