# 六爻实操、应期与冷门门类（王虎应《自修宝典》）

取材：《六爻预测自修宝典》（王虎应著，31 章，内部资料网络版）。定位为入门到中级的系统教材，重实操。与本技能族分工：装卦基础与《增删卜易》体系重叠部分不重复收录（见 liuyao-zengshan-buyi-skill），本技能收该书独有的**方法窍门**（爻变寻宫诀、用神两现次序、飞伏四关系、进退神反常断法）、最系统的**应期十九法**，以及既有技能未覆盖的**天气、比赛、考试、买卖、工作**五门。

## 一、起卦：铜钱摇卦记录法

三枚铜钱：字面为阴、背面为阳；三枚象征天地人三才。摇卦只是提取卦象的形式，**来人摇或预测师代摇皆可**；但求测者当儿戏、无预测念头，卦象可能不反映信息。摇前不必焚香沐浴仪式——六爻与神灵无关，是潜意识活动，动念即可摇。

记录符号（点卦从下往上，第一次摇为初爻，第六次为上爻）：
- 一背二字 = 少阳，记「、」（单）
- 一字二背 = 少阴，记「、、」（拆）
- 三背 = 老阳，记「○」（重，阳动变阴）
- 三字 = 老阴，记「X」（交，阴动变阳）

老阳老阴为动爻，变出之爻为变爻；摇出的卦为主卦，变化后的卦为变卦（之卦）。无动爻则只有主卦。例：既济（四、五爻动）→ 之卦雷火丰。

## 二、装卦

### 1. 纳甲（装地支）

纳甲歌（每卦从初爻起纳，阳卦顺行纳阳支、阴卦逆行纳阴支，隔支不用）：

> 乾金甲子外壬午，坎水戊寅外戊申。
> 震木庚子外庚午，艮土丙辰外丙戌。
> 坤土乙未外癸丑，巽木辛丑外辛未。
> 离火己卯外己酉，兑金丁巳外丁亥。

内卦起第一支，外卦起第二句所标之支。例水风井：下巽阴逆行纳辛丑、辛亥、辛酉；上坎阳顺行纳戊申、戊戌、戊子。**天干不参与吉凶判断**（只取数字用），装卦可省天干只纳地支。

### 2. 爻变法安世应寻宫诀（本书独有，不用背六十四卦名）

> 寻世从初往上轮，阴爻变阳阳变阴。
> 变至内外相同卦，该爻即为世所临。
> 若到五爻卦仍异，转从四爻向下行。
> 若到初爻方为止，归魂世在三爻临。
> 内外相同勿须变，六爻安世为八纯。
> 既得内外相同卦，原卦即以此为宫。
> 若问应爻安何处，世隔两爻即为应。

操作：从初爻起逐爻翻阴阳，翻到内外卦相同的那一爻即世爻，原卦即属该相同卦之宫（翻出来的那个相同卦就是本宫）。变到五爻仍不同 → 从四爻往回翻（上爻宗庙永不变）；翻到初爻才相同 = 归魂卦，世在三爻。
- **归魂速判**：只翻第五爻，若内外即相同，必是归魂卦，世在三爻（例山风蛊）。
- **八纯**：内外本相同，世在第六爻。
- 例：水泽节翻初爻即得坎坎 → 世在初爻，坎宫。山水蒙翻到四爻得离离 → 世在四爻，离宫。风泽中孚翻五爻仍异、回翻四爻得艮艮 → 世在四爻，艮宫游魂卦。

### 3. 六亲装配

以**卦宫五行为我**：同我兄弟、生我父母、克我官鬼、我生子孙、我克妻财（简写兄/父/鬼或官/子/才）。**变卦六亲一律按主卦卦宫定**，不按变入之宫；变卦只标变爻即可（重变爻对本位动爻的生克）。

### 4. 六神装配

按**预测当日天干**从初爻起配：甲乙日初爻青龙、丙丁日初爻朱雀、戊日勾陈、己日螣蛇（呈蛇/元武为螣蛇玄武别写）、庚辛日白虎、壬癸日玄武，往上依次青龙→朱雀→勾陈→螣蛇→白虎→玄武轮排。六神**不参与吉凶**，只定原因、性质、特点、程度；相互之间无须看生克。简写：龙/雀/勾/蛇/虎/武。

六神含义速查（本书版本）：
- 青龙：高贵、财帛、喜庆、酒席、装饰、仁义、左侧、生育、好色、**痛痒**
- 朱雀：文书、言语、信息、口舌、官非、火灾、噪音、**炎症**、前方、教育
- 勾陈：官讼、衙门、政府、公务员、田产、房地产、室内、牵连、老实迟钝、中央、**肿胀突出、癌症**
- 螣蛇：虚伪少信、猜忌、棘手难缠、惊恐意外、绳索细长卷曲、侧面、**臃肿**
- 白虎：果断凶猛、刀枪、道路、伤亡丧事、血光、骨折车祸、手术医药、右边
- 玄武：暗昧、偷盗、诈骗、阴谋、赌徒投机、厕所、潮湿、风湿、后侧、羞耻

## 三、取用神进阶

### 用神两现取舍次序（本书的清晰版，按序取一为主，另一参考或兼断）

1. 一动一静 → 取**动爻**（动为事之发端）
2. 皆动或皆静 → 取临**旬空或月破**之爻
3. 都不空破 → 取**逢冲或逢合**之爻
4. 不逢冲合 → 取**临世或临应**之爻
5. 不临世应 → 取**离世应近**者
6. 地支完全相同 → 按**爻位或所临六神**取（测病临白虎者为病，如父病例取临白虎之父母未土断头部血管）

反常豁免：一空一破、或一动一空，**可两爻兼断**（测妻病例：亥水动而月破、子水静而旬空，合断午月愈——亥破出月不破、子空午月冲实）。

### 飞神伏神

用神不上卦 → 到本宫首卦找，本宫用神在第几爻即伏于第几爻；伏神所压之爻为飞神。飞伏四关系：
- **飞来生伏 = 得长生**，吉
- **伏去生飞 = 泄气**，不吉
- **伏克飞 = 出暴**，以吉论
- **飞克伏 = 伤身**，最凶

伏神得出（吉）：伏神旺相、得日月动爻飞爻生扶，或有日月动爻克冲飞神（注意：飞神是生伏神的六亲时不宜冲），或飞神休囚空破墓绝。伏神休囚受冲克、值月破旬空、无元神救助 → 凶：求财财不得、求官官不就、病难愈。飞神兼作**事因参考**（字画丢失例：父母子水伏初爻妻财未土下，飞克伏又财动克用 → 找不回）。

### 进神退神

同五行之爻动化出同五行，辨气进退（顺支序为进、逆为退）：
- 化进：亥化子、寅化卯、巳化午、申化酉、丑化辰、辰化未、未化戌、戌化丑
- 化退：子化亥、卯化寅、午化巳、酉化申、辰化丑、丑化戌、戌化未、未化辰

通则：用神元神宜化进，忌神仇神宜化退。用弱化进如春木渐壮；忌旺化退，危机暂时。**反常断法（重要）**：
- 测失物、走失、朋友分手：**用化退 = 去而复返，吉**；化进 = 物人远离，不吉
- 用神过休囚，忌神化退也不吉（得日月生比有"当令不退"之说）
- 旺相化进 = 乘势而进；休囚化进 = 待时而进；进神空破 → 填实之时而进
- 动爻变爻皆旺而化退：占近事旺而不退，占远事日后必退；休囚 = 及时而退；有一空破 → 填实之时而退

- 例（风水）：父母持世空亡入墓于日财 → 因房借债未清、房产证未办；五爻领导动生世但化退 → 对自己好的领导调走；应爻为妻位、初爻为脚在震宫 → 妻腿有病。

## 五、应期十九法（本书最系统的一章，逐条记）

应期分**过去应期**（断已发生的婚期、得病时间）与**未来应期**。远事以年月、近事以日时。以用神为中心定：

1. **用神安静**：应其所临地支之年月日时，或**冲**用神之时。（自测病用弱静忌神独发，死于冲用之日）
2. **用神发动**：应其所临地支，或**合**用神之时。（申金动空，申时人到）
3. **用神太旺**：断吉应**入墓**之时；断凶应**生用神**之时。忌神旺则相反——忌入墓受克为凶、受生反吉。（父病用旺无克，丁卯日死，应"过旺逢生而凶"；测寿命忌神重重，防忌入墓之年，子年测未年死）
4. **元神发动**：应元神所临或合元神之时；元神空破 → 实空实破、冲空合破。（书到：元神辰土月破空亡，甲辰日实破到）
5. **忌神发动**：应忌神所临或合忌神之时。（父病忌神值日死）
6. **用神休囚逢绝**：断吉应**长生**之时或元神所临；断凶应入墓、逢冲、受克；用神衰极逢长生反为凶。（夫休囚亥日长生而回；子孙休囚亥月生子）
7. **用神入墓**：应**冲墓**或冲用神之时。（用入墓于日与动爻，丑年卯月卒——应入墓之年、用逢冲之月；近病用入日墓，巳日冲用而愈）
8. **用神逢合**：应冲用神或冲合用神之支。（用动合变爻，丑日冲开办下证；用弱者取冲中不带克之日）
9. **元神逢合**：冲元神（或冲合元神之支）为应；**忌神逢合**：冲忌神为应。（忌神动合，丑日冲开合神、用入墓而死）
10. **用神月破**：合破之时、用神所临、或**下个月**。（断指年：取月破之官鬼戌土为用，甲戌年实破即应；子水月破亥月实破生子；用神月破而世空，庚子辛丑日到，应合破）
11. **空亡**（用/忌/元神）：应其所临地支或冲空之时。（久病用空，午月出空受忌神之克而死——"久病逢空则死"，避空之地暂不受克）
12. **用被忌克而卦吉**：应**忌神被克或冲去**之时。（财动生世但化回头克，次日变爻被合不克用、巳时冲墓出财；戌日冲去变爻又进财）
13. **化进神**：应进神（变爻）所临或合进神之支；合则冲开、空则实空冲空、破则合破实破。（忌化进，进神空亡次日出空即凶）
14. **化退神**：应退神（变爻）所临，或冲、合动爻之支；空破仿进神。（测岳母死：子孙解忧化退，卯月合住不退，卯月应；自占久病世化退，丑月冲退神而死）
15. **用神伏藏**：应用神所临、冲伏神、或**冲飞神**之时。（夫出走用伏三爻，亥日亥时回——伏藏应出现）
16. **独发**：应独发之爻所临或合它之时。（开煤窑独发，亥年辰月出煤）
17. **独静**：应独静之爻。（五动一静，女儿寅日愈）
18. **忌神持世动化出与用神相同之六亲**：应**世爻变爻**所临。（世动化父母亥月得房；忌神兄弟持世化财酉日得财；忌财持世化父亥日见父）
19. **用神动化空、化破**：应**变爻**所临。（财动化空，出空乙未日得财六千）

**按事项微调**：测婚姻有时以父母爻定应期；测生孩子以子孙的胎、养之地为应；测行人用神静而合日当日回、入墓于日也当日回。应期是最难点，须长期积累验证。

## 六、测天气（练手最快的门类）

方法：很少用六神，以六亲取象；**有动爻以动爻为中心，无动爻看世爻或旺相之爻**；摇卦时用意识指定某地某时的天气。每天测天气是短期提高水平的捷径（反馈快）。

- **父母**：雨/雪/冰雹（随季节），旺雨大休囚雨小；化进雨渐大、化退渐小；休囚空破静而被克 = 无雨；动而与日合 → 冲开时有雨；动而月破 → 按月破法则定雨时（月破支与日同常当日有雨）；空亡伏藏又被克 = 无雨（何时有雨按伏神应期）；父母临月建、化进、日为父母长生 → 可能进入梅雨/连阴季。
- **子孙**：日月星辰，主**晴**。动或三合局 = 晴；化进万里无云、化退晴而不久；父母化子孙 = 阴转晴、雨后彩虹、云中日出；动而月破空亡按破空应期。
- **妻财**：晴而非大晴，有少量云。父母休囚财动三合 = 晴；财化子孙 = 大晴无云；财化进晴、化退晴不久乌云增多；财化兄弟 = 晴转多云或有风；财化官鬼 = 晴转浓云/转阴；财被日合冲开时转晴；财伏冲出/冲开飞神/财出现时天晴；空破则实空实破、冲空合破时晴。
- **兄弟**：风也主云。动或三合 = 有风，旺风大休囚风小；化进风云渐大、化退渐小；**巽宫兄弟动而旺相 = 台风强风**，与父母同动 = 暴风雨。
- **官鬼**：雷电、雾、浓云。**震宫官动多有雷**，与父母同动 = 雷雨交加；官鬼独发随季节或有雨或只雷无雨或阴天；官财同动 = 晴转多云/转阴；官化父母 = 阴转雨，化子孙 = 阴转晴。

断雨停/转晴要点：子孙旺动 = 雨停信息；伏藏之子孙飞神被冲出之日转晴；世动化父母与世生合（合主缠绵）= 连阴不止。**舍动爻衰旺而断者，对少错多**——父母动但被月克、化绝、官空生不起 → 不雨；"金空则鸣"＋反吟 = 光打雷不下雨（实测：晴天午后聚云响雷，一滴未下）。

## 七、测比赛

- 双方对阵：**世为我方/所问一方，应为对方，旺者胜弱者败**，六亲次要。世应所受生克完全相同 → 平局。
- **过旺反败**：一方生扶太多为"刚而易折"；但日为世爻墓库时"太过者以墓库收藏"，旺得恰到好处反胜。
- 应爻得日冲暗动生世 = 对方自己失误给我方可乘之机。
- **多人/多组比赛**（问某人能否获胜/取名次）：不看世应，**以官鬼为用神**（官鬼为名次），旺则得名次、弱则榜上无名；官鬼克世生应 = 名次被他人所得；可参卦数断名次（卯主三数 → 进不了前三，实测得第四）。
- 高层次参考：官鬼=名次/裁判，父母=场地，子孙=主力队员，兄弟=阻力，妻财父母=点数。

## 八、测考试（含求职、职称考试）

用神：**官鬼为名次，父母为成绩与录取通知书**，二者旺相即考得好。

- 日月与官父同五行或生合之 → 必考好成绩。父母休囚但官鬼旺而发动 → 也有希望。父母持世动化官鬼 = 结果满意；官鬼化进 = 越考越好。官父成三合局 = 必通过。
- 青龙临官鬼动而生合世爻 = 升学之喜；**青龙白虎同时发动 = 可考第一名**。
- **子孙持世或发动 = 多落选**（子孙为剥官之神）；子孙妻财同动 = 考学有难度；妻财发动 = 掏钱上学或侥幸得名。
- 官鬼、父母、世爻皆忌月破空亡，空破休囚者落榜。**官鬼生应爻谓之无情**，旺相也难考上。
- 断分数可用卦数：主卦上下卦数相加（乾1兑2离3震4巽5坎6艮7坤8）断十分位（实测雷火丰=震4+离3 → 断七十分中）。
- 例：官鬼月破又有子孙动克 → 落榜；官鬼两现取月破者为用，父母合世但官破 → 自己考不上、有人帮忙上了（日辰合破）；官持世暗动但空亡、冲中带克 → 差一分落榜（火主二数，冲起一半）。

## 九、测买卖、生意、开店

用神：**妻财为利，兼看世应关系**（开店：世=经营者、应=雇员顾客；买货：世=买方应=卖方；卖货反此；谈生意应=对方；合伙：世=我应=伙伴）。

- 应生世合世 = 交易顺利；应冲克世 = 不顺、刁难、压价、欺诈，小心。
- 世空 = 自己拿不定主意易出纰漏、可能中途停止；应空 = 顾客少/雇员有二心/对方有诈；**世应皆空 = 买卖中途而废**，签约也可能取消。
- 财旺应生世 = 兴隆；财弱受克世又空破 = 萧条。
- **防骗防盗组合**：应为兄弟临玄武克世 → 防诈骗（开店防雇员贪污）；财休囚官鬼临玄武动 → 防失盗；官鬼临朱雀动 → 防官司或失火（父母临朱雀螣蛇动也防诉讼）；官鬼空亡动而合应 → 防中间人与对方合伙欺骗；官鬼兄弟在间爻动 → 中间人有负我方；进货应临玄武克世、或应临财玄武空而生世 → 防假货伪劣；父母动化兄弟 → 合约有陷阱；财临世而兄弟临白虎动 → 防抢夺钱财。
- 兄弟旺相发动 → 必亏损无利。官鬼在五爻动 → 防出门在外有灾（克世更凶，宜停止在外活动）。
- **进退货行动指南**：财化进/化回头生 → 货价将涨，宜大量进货；财化退/化回头克 → 即使现价不错也宜赶快出货；**财与月建相合 = 价格最佳期，全部卖出**。
- 六合卦买卖久长，六冲卦不顺或短暂；反吟伏吟 = 做做停停起落不定。开店不宜世爻和二爻发动（主店铺搬迁）；二爻为店，父母临之其意更强（父母休囚店面不大）；应临二爻（应入飞宅）= 有异姓人入店合伙之象；卦中申酉戌相连成方局 = 三人合伙且同单位（世临勾陈为办公室）。
- 测投标：父母为工程、妻财为利润，重点看财（财空被月克 → 难中标）。

## 十、测工作、官运、升职

用神：**官鬼为工作**，父母为单位/公司；问升迁、工作变动同看官鬼。

- 官鬼持世生合世 = 吉。**官临六神定工种**：青龙=公务员、高雅令人羡慕；朱雀=文书、教育、口才职业（书记秘书）；勾陈=坐办公室室内工作；螣蛇=技术工作；白虎=政法公安法律（警察保安部队）；玄武=投机方面工作。
- 日月为官鬼生合世 = 上级领导照顾；**测工作：月为上级领导，日为同事**。
- 官鬼在五爻 = 重要岗位或公司领导。官化进 = 节节高升；化退 = 渐不好、可能丢工作。官鬼克世 = 压力大、领导对自己不好。子孙临日月或发动 = 就职难、已就职防丢职。
- **地支定职位性质**：官临子午卯酉=正职，寅申巳亥=偏职，辰戌丑未=杂职。工作方位看官鬼所临地支；工作变动看世应（世=现环境，应=要去的地方）。
- 官鬼父母两现 = 多为**兼职**。父母旺单位大、休囚单位小；财弱而父母克世 = 单位不景气。妻财为工资，旺而生世工资高；兄弟发动防降薪。六冲卦工作不安定、六合卦安稳；游魂卦多为工作变动，官父发动也主变动。
- **官鬼为忧患之神可反转**：已升官者担心被撤，若子孙动化进克官鬼（官在此卦为忧虑），是"克去忧愁"，反而不会被撤职——取用须随问事角度转换（与 liuyao-duangua-jifa-skill 的用神转换互参）。
