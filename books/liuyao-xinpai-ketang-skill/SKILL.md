# 新派六爻：课堂方法论

## 它是什么

这是《新派六爻预测学》课堂笔记的蒸馏（授课语境常见署名**一瑞**，理论主干来自**董元辰**新派）。它与 `liuyao-xinpai-dongyuanchen-skill` **同宗**：年干合神定旺弱、世爻中心、喜忌辩证。差别在于课堂笔记更强调——

- 虚／实／虚实三种状态的取象语言
- **用神忌神分三套**（卦中、时空、合神）
- **对称论**、伏吟细则、虚实填实
- 内外因（时空 vs 伏主变）如何配合断流年

**禁止**与野鹤传统派的用神旺相法、日辰主宰法混判。用新派先声明。

## 一、课堂五行观（取象层）

### 虚实三分

- **水、火、土为实**；**金、木为虚**（表达变化过程）；土兼虚实
- 每一行又有：阴／阳／阴阳不分（可见／不可见／似见非见）

### 类象口诀（课堂常用）

| 行 | 类 |
|---|---|
| 水 | 被动资源（冷能） |
| 火 | 能动资源（热能） |
| 土 | 转化载体 |
| 金 | 无形变化（思维、过程） |
| 木 | 有形变化（外表、表演） |

断象时先问：载体／能动／被动／有形变／无形变各是谁——再落到六亲与世应。

### 地支作用（课堂压缩）

- 刑冲合绊晦 = 力度不同的"克类"表达；本系不用"害"
- **进退**：仅同位动变化同类论（寅→卯进，卯→寅退等）；异类仍生克
- **冲**：旺冲弱→弱伤；弱冲旺→旺更旺；同势→两伤；动冲静→静伤重
- **合**：六合＋半合共论增减力（谁增谁减按课堂表，不按传统合化气为主）
- **三合**：须三支能相互作用；成局力大，类比天干合神；时空本身不另造三合

四库（丑辰未戌）与火金水木的生晦脆绊，以课堂表为准（与董元辰技能一致处从简，冲突时课堂"最终作用关系"优先）。

## 二、起卦课堂要点

- 随意起卦优于过度凝神；时间／笔画／万物类象皆可
- 电脑程序起卦课堂不推荐（信息经程序改编）
- 梅花心易：课堂倾向**世为断卦人、应为求测者**（与自测不同）

## 三、世爻中心与卦爻作用

### 六亲（按世重排）

生世印、克世官杀、同世比劫、世生食伤、世克财。不见之六亲多参应爻。类象同新派主干技能。

### 作用论（课堂修订口径）

初级常说"隔不作用"；课堂补充：**在条件满足时，紧贴、隔空、内外天人地相对、世应、初上、动变飞伏等均可论作用**。时空干支与年干合神可作用卦中各爻。

硬纪律：

- **主卦不作用于变卦**（单向）
- 世爻与其它爻一样可主动作用（否定"世永不主动"旧说）
- 空亡：该作用不作用／方向相反；**空动**则正向作用它爻、它爻反作用空动（越制越增力）
- **轮空**：减力近零，出空后正常

## 四、旺衰：合神四卦型（课堂表述）

年干合神：**甲己土、乙庚金、丙辛水、丁壬木、戊癸火**。合神约一半权重；年支与月令共约一半。日辰不定旺弱。

| 卦型 | 条件（课堂版） |
|---|---|
| 世弱 | 合神泄制世；年支／月令至少一项生扶（否则易入从弱） |
| 从弱 | 合神不助；年支与月令都不助 |
| 世旺 | 合神帮扶；年支／月令至少一项泄制（否则易入从强） |
| 从强 | 合神帮扶且年支月令再帮扶 |

特殊：

1. 月令旬空或**两次受制** → 月令不参与定世旺衰（仍可参与分析作用）
2. 上述前提下年支生合世 → **世按减力论**
3. 空动世：帮扶越多可能越显从弱（课堂例）
4. 分析点以外的五行：合神生助为旺，克泄为弱；动爻不做极弱

最终仍强调：**试断校正**是最根本手段。

## 五、用神忌神：必须分三套

总原则：**看对世爻的最终作用关系**（不是只看直接生克）。

### 1. 卦中用忌

- 对世最终为好 → 用；为坏 → 忌
- 技巧：把该爻"拿到世前"看作用，再按远近变性（远离可反性）——课堂口诀，实战要谨慎复核
- 伏吟等特殊格局：喜制泄时，生世也可能定为忌
- 同一地支在伏／主／变位置，用忌可不同，**各论各的**

### 2. 时空用忌

- 时空干支直接作用卦中；对世最终好坏定用忌
- 时空空亡地支对卦中按反作用理解
- 年支永不为空；时空与卦是外／内两系统（直接作用但不算卦内紧贴）
- 时空力度可映射卦中同字力度；时空伏吟会阶段性改变卦中同字表现

### 3. 合神用忌

- 合神制约／帮扶哪一行，整盘旺衰与喜忌底板随之定
- 合神层用忌与卦中用忌可以不一致，要分层说

不变性与双面性：

- **不变性**：用受生应吉，忌受生应凶（基本）
- **双面性**：用受生、忌受制时，仍可能有对卦主不利的侧面——课堂要求两边都讲

## 六、对称论（课堂速断）

- 对世而言：用与忌同现，且同受制／同受生、差异不明显 → **对称成立**
- 不一定一对一，一对多也可
- 紧贴世的伏吟、应爻伏吟：可直接抓结果象（仍要核受力）
- 用忌不对称或不成立时，勿强行对称断

练习口径：对称成立≠事事应验；要看力度与空亡是否拆掉对称条件。

## 七、空亡谱系（课堂必分清）

| 类型 | 要点 |
|---|---|
| 八字空亡 | 出生日旬空字入卦；永不填实；被动受作用；用忌定性反转 |
| 先天旬空 | 起卦日旬空；永不填实；口径同上 |
| 后天轮空 | 出起卦旬后，新旬空字作轮空；减力，过后恢复 |
| 当值大运空 | 六甲大运旬（十年一换）之空 |
| 大运轮空 | 非当值大运时段的旬空映射 |
| 时空空亡 | 近先天空；在年位则可不空 |

课堂否认真空假空老说的滥用：**静空即空，动则可不空**（与传统"旺空假空"话术区分）。

## 八、伏吟（课堂条件）

成立要点（摘要）：

1. 参与字在同样外力下增减排向须一致
2. **唯一性**：多组伏吟等同没有；双伏吟相遇成生泄者，彼此正常、对外仍伏吟
3. 世空不能构成相互作用则不伏吟
4. 时空两字伏吟时：卦中同字可阶段性消失伏吟，或带伏吟特性
5. 旺伏吟遭弱冲 → 伏吟减力；阶段伏吟过期消失

伏吟改造吉凶时，回到世旺衰与喜忌：伏吟常喜制泄等（与主干技能一致处不重复展开）。

## 九、虚实论（流年填实）

- 世仅一字时常作虚看的参照；余字分实喜／实忌；不见之字（除四库）多为虚
- 虚字与卦中成**克合** → 以实论；仅生合／合生 → 仍虚
- 天干不作虚字游戏；虚局填实后方能成绊等

流年：虚喜神到位偏吉；实忌近世要谨慎；合绊会改变虚实身份——断流年时看**到位字对世最终作用**，不看口号。

## 十、内外因辩证

| 层 | 内容 |
|---|---|
| 外因 | 时空天干、地支、合神、位置表达 |
| 内因 | 伏卦（宫／旧事）、主卦（当前）、变卦（将来） |

- 外好内不好／内好外不好／内外协调 → 断"机会与结果是否匹配"
- 距离世远近辅助定远近人事；伏主变定时间层次

## 十一、大运小运流年（课堂）

- 新派大运：六甲自然旬（甲子／甲戌／甲申／甲午／甲辰／甲寅），约十年一换
- 当值大运与出旬大运特性不同；先天组合受制论：喜忌先天受制，流年到位或制神到位则应吉凶

## 十二、使用边界

- 与 `liuyao-xinpai-dongyuanchen-skill`：彼为体系总图，此为**课堂判据与练习口径**；细节冲突时，先核合神四卦型与"最终作用关系"
- 笔记含习题与卦例，技能不抄原文卦例全文
- 新派与传统派判据互斥场景：只选一套说完，再可另开传统派对照
