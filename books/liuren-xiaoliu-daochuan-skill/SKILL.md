# 道传小六壬（马前课）六卷——骨架与缺陷档案

"道传小六壬"是一套**六卷本**的民间传承，与通行的《小六壬预测法》（见 `liuren-xiaoliu-minjian`）同源而分科更细。它的价值不在六神掐算本身（那部分与通行本基本一致），而在于把一门掐指小术**拆成六种用途**。本技能只记录这个框架，以及能从残页中确证的部分。

## 一、六卷分工（本技能唯一可确证的贡献）

| 卷 | 所主 | 与其余五卷的关系 |
|---|---|---|
| **卜法** | 占问具体事之吉凶（行人在否、失物、讨债、官讼、天气、出行） | 主干，其余五卷皆自此展开 |
| **解法** | 课见凶象之后的解禳、趋避之法 | 与卜法配套，卜凶则解 |
| **命法** | 以六宫推人一生性情、格局、六亲 | 由"占事"转为"占人" |
| **香法** | 以香、供、礼拜一类的仪式取用（民间道门色彩最重） | 属仪式层，非推演层 |
| **癔法** | 占"邪祟、附体、精神异常、久病不愈"一类 | 民间"癔病"专断，**现代不宜沿用其病理判断** |
| **择法** | 择日、择方、择时出行用事 | 与卜法互为正反：卜问"会怎样"，择问"该何时" |

> 这个分科比通行本高明的地方在于：它承认**同一套六宫既能占事（卜）、也能占人（命）、也能择时（择）**，而不是把六神当成只能答"是/否"的签筒。

## 二、可确证的推算法与名目

- **起法**："**月上起日，日上起时**"——与通行本完全一致（以正月起大安，月上起日，日上起时，顺数六宫）。
- **六神**：大安、留连（残页作"流连"）、速喜、赤口、小吉、空亡。
- **配六兽**：残页反复出现"白虎""玄武""朱雀""勾陈"与六神同现，可确证该本**为六神各配一兽**（青龙配大安、玄武配留连、朱雀配速喜、白虎配赤口、勾陈配空亡一类），与通行本"六神所临"之说相合。
- **判语体例**：残页有"世人分四十八句""金口诀"之语，可推知该本为**每神各系若干成句判语**（四十八句之说疑为六神×八句），并按占类分列（行人、失物、官讼、病、求财、出行、婚姻等）。这正是它比通行本"六首诀"更繁处。
- **例课格式**：残页留有"例：七月……从大安上起正月……查到日子……落白虎，从白虎上起初一……查到辰时"的完整推演示例，说明其教学是"逐宫数给人看"的口传式。

## 三、六神的判语残句（可辨者，仅作样本）

残页中可辨的零句（因 OCR 断裂，多不成完整句，**不可当判语引用**，只用于说明其体例）：

- "失物去不远"（大安一路）／"失物流连……"（留连一路）
- "空亡……在他乡"／"空亡主……官无"
- "白虎东起……"／"小吉……中央"
- "今日之内有喜……七日之内有喜……"
- "行人……在路中"／"……有口角之"

可见其判语多为**方位＋时间＋一事一断**的短句，与通行本六首诀同一路数而更细。

## 四、使用边界与素材缺陷

1. **首要缺陷：六卷原书均系扫描件，OCR 完全不可用。** 已取回的《道传小六壬·卜法卷》提取结果中，正文被压成"失物失物去不远……"整行连续重复数十次、"四/四/四……""治/治/治……""闪人/闪人/闪人……"这类单字灌水，以及"秘籍网 www.miji8.com"水印串行；真正的判语只剩零散短语。这是**扫描 OCR 的死循环**，不是原文。
2. 因此本技能**不是一套可用的断法**，只能当"体系档案"读：知道有这六卷、各卷管什么、起法与通行本一致、判语按占类分列。**要真正掐算请用 `liuren-xiaoliu-minjian`**（该本为文字版，内容完整可用）。
3. **未取部分**：六卷中**只有卜法卷被取回**（且损坏）；解法卷、命法卷、香法卷、癔法卷、择法卷**均未取**。故本技能所列六卷分工，是据卜法卷残页中的卷名与零星互见推得的**框架**，各卷的具体断法一概不知。
4. **内容立场提示**：癔法卷一类以"邪祟、附体"解释精神异常与久病，属民间宗教病理观，**现代使用须明确排除**——不得据以替代医疗判断；本技能仅作民俗文献记录，不提供任何此类"诊断"。
5. 与兄弟技能的关系：通行民间本见 `liuren-xiaoliu-minjian`（六神释义、六首诀、变通取数、随机取数与实例皆在其中）；江氏一系（《江氏小六壬真传秘诀》《掐指小六壬》《小六壬》上下册）**本技能与本组其余技能均未取**，故"小六壬"三路（通行／道传／江氏）目前只有通行一路可用，另两路只能记名。
