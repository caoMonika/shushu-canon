# 六爻快速推断法（李鹏系）

## 它是什么

李鹏《六爻快速推断法》的主张是：**大道至简**——不堆断语，而把断卦收成一条链：

> **易简 → 体用／世爻中心 → 五行归阴阳 → 定强弱 → 取病药 → 行运成象定应期 → 策划解化**

三大法骨架是 **太极、阴阳、四象**。与野鹤传统派可并存参考，但本系有几条硬特色（尤其"自占代占尽取世爻为用神人"、病药中心、双原速扫），**不要与传统"事事换用神"混成一锅**；用本系时先声明。

源书极长、重复多、含股市与大量卦例。下面只蒸馏**可执行框架**。

## 一、操作总序（推荐流水线）

1. **起卦记时空**；心神未明或自占代占 → **先定世爻为人用神**（见第二节）
2. **易简扫盘**：全卦五行大势 → 体用两股势力 → 强弱对比
3. **双原速看**：世爻（体）的原神 + 原神之原；必要时再看药／病的双原
4. **定病药**：损神（病／致病点）与调神（药）
5. **成象**：卦名、卦象、爻象、六神、神煞（辅）挂到病药上
6. **行运顺序**：本→互→变；年月日時；送迎／值冲合空；定应期
7. **构思成文**：列点 → 立病药中心 → 联线（见 `liuyao-kuaisu-gousi-skill`）
8. **策划解化**：按药点调天时地利人和事泰（能调则调，不能调则言明）

口诀级总则：

> **谨察阴阳之所在而调之，以平为期；玄机尽在病药间。**  
> **天机尽泄于有病之间，断法总在医药之处。**

## 二、易简与取用

### 1. 易简

- 不求背尽断语；求捉住**阴阳体用互换的平衡与变化**
- **五行归阴阳**：五行走势收成敌我／体用两股势力再论
- 万汇之繁，只推病药这一处枢纽

### 2. 用神 = 阴阳体用的定点

用神是卦中代表人／事的**固定标志**（体用窗口）。取准用神，才谈生克与病药。

### 3. 本系硬规则：凡自占代占，尽可取世爻为用神人

适用动机：

- 代占身份含糊、一事两用、用神多现难取舍
- 来人话术模糊，预测者不愿被口语牵着走
- 心有恍惚、先求快速立极

操作：不问自占代占，**先取世爻为人中心**，再围绕世爻展开人事与病药追踪。  
注意：这是本教程的方法论选择，**不是否定传统分类取用**；传统事用神仍可在"事爻"层另立太极点并行。

## 三、太极 · 阴阳 · 体用

### 太极

- 处处可立极：世应、体用、病药、日月冲击处，皆可作小太极
- **六爻相杂，唯其时物**：断语必须落到具体时空物象
- 立极后联想成象（点点立意成象）

### 五行归阴阳体用

1. 先分体用（人核／事核或敌我两股）
2. 再论五行生克冲合刑害——它们都是阴阳消长的外衣
3. 强弱对比：增益体用者为一类，损害体用者为一类
4. 真正旺弱看：**本爻 + 同类 + 双原 + 双夹 + 卦爻组合**，不只看月令旺相表

### 双原解卦法（速断半壁）

- **原神** = 生该爻之神；**双原** = 原神 + 原神之原（源头之源头）
- 爻排出后，速看体／世的双原圆缺：有源则活，源阻则滞，无源易枯
- 突破口仍在病药：双原好坏最终要回答"哪里失衡、哪里可调"
- 可再以时断歌推流时：动旺逢合、静空逢冲填实等（作应期线索，不机械套死）

## 四、病药论（全书中心）

| 名 | 义 |
|---|---|
| 病／损神 | 对阴阳体用有损害处（可在爻、卦、六神、象、组合规律上） |
| 药／调神 | 能治该损害、使全局回平的五行／卦／支／六神／行运点 |
| 致病点 | 病的来源（寻煞破煞的靶心） |

取准步骤：

1. 药必须让**全卦体用受益**，离开体用的"药"无效
2. 先精确衡量强弱，再取药
3. 看清全局势，找准阴阳失衡点（病）
4. 用太极追踪扩病的来处、去处、结果
5. 对症下药：通关、制衡、调候（借命理思路，落在卦爻组合上）

> 有病方为贵；卦中如去病，吉利两相随。  
> **病药者随时变化**——同一卦在不同行运，病药可迁移。

病药同时是：吉凶枢纽、应期着眼点、策划解化把手。

## 五、策划与解化

断准只是初阶；**替人找到可执行的平衡**才是本系目标。精义：让阴阳势力旋转互换，四两拨千斤。

### 大法骨架

1. **通关／制衡／调候（病药）** —— 主法
2. **寻煞破煞** —— 对准致病点解除不利冲克刑害组合
3. **择时（天）** —— 药旺、病受制之时行事
4. **移方选位（地）** —— 方位、场所随药行
5. **与人相处／变心调心／做与不做（人）** —— 人事策略
6. **事泰** —— 合规、节奏、形相、置物、山医数食等辅法（书中罗列甚杂，用时仍须回扣病药，忌迷信堆砌）

有效性判据：调整是否真能改变卦中构成灾祸的生克冲合结构，并兼顾天时地利人和事泰；**不据病药的调解，收益通常不大**。

## 六、四象：成象与调平

在病药立住后，把信息做成可说的现实象：

- **卦名／卦象／爻象／六神／神煞** —— 神煞只补细节，不主吉凶
- **象的调平**落在四维：**天时、地利、人和、事泰**
- 大爻与小爻：主线人事与枝节信息分层，避免一锅粥

## 七、行运成象与应期

- 六爻以**时空架构**立身；应期是实际意义所在
- **行运 = 事物顺序**（生命／事态程序），不是装饰
- 顺序意识：本卦 → 互 → 变；静动；年月日時分；送迎
- 病药的行运成象：病何时发、药何时到位，即应期主线索
- 送迎成象：以时间看事态先后（来／去、合／冲、空／实、墓／库）
- 本变静卦与本变动卦：先辨最大一层"动"，再落细时应

断应期忌：不分人事大小长短、不分哪一层行运，一概而论。

## 八、快速构思（嵌入）

人事、来意速断用三步（详 `liuyao-kuaisu-gousi-skill`）：

1. 列信息点（全卦五行、体用双原、要点）
2. 立病药中心
3. 联点成线成文（来意、时间、解化、行运）

## 九、隔山打牛（分类取象原则）

核心不是秘法，而是：**近水知鱼性，隔山识鸟音**——先进入该预测域的特有结构与类象，再套病药／体用。

示例（航海专象，说明方法，非穷尽）：

- 父／巽／木 → 船；世 → 船主／出海人；亥子坎玄武 → 水域
- 初二启航，五爻航道，六爻／土 → 港岸目的地
- 父世生旺有气则吉；忌土水白虎恶杀叠克；反吟多见返航／反复故障

换领域时同理：先定该域"船／航道／港"式专象坐标，再走总序。

## 十、股市期货（只留方法骨架）

书中专章强调：行情要抓**精确时空走势与买卖时点**；波浪与六甲干支周期同参。实盘仍须金融风险自担；技能层只保留"时空应期优先于只报涨跌方向"这一条方法提醒。

## 十一、使用边界

- 与传统派冲突时：本系优先"世爻立人极 + 病药"，传统派优先"事类用神 + 生克权层次"；**同卦勿混判据**
- 源书重复、文风口语、含大量自述卦例；技能以框架为准，卦例仅作理解线索，禁止整段照抄
- 策划解化涉及行为建议时，保持可检验、可逆、不替代医疗／法律／投资专业意见
