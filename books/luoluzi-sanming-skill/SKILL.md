# 珞琭子三命消息赋（徐子平注）

源：本地 `珞琭子三命消息赋注-宋-徐子平.txt`（GBK全文）。子平事迹莫考，世称推八字为「子平」因之。四库从《永乐大典》辑上下卷。

## 一句话地基

> **以干为禄，向背定贫富；以支为命，详顺逆以循环。运行一辰十岁，折除三日为年。精休旺、穷通变；不可一途而取。**

四柱映射：元一气＝本命/祖；清浊分＝生月/父母；三才＝生日/身；四气＝生时/子孙。每宫有天元人元支元。

## 一、看命总流程（赋注操作版）

1. **定生日天元**为禄主：看干下支与支内人元——禄？印？财？官？  
2. **向背**：天元是否向其禄马；无则向财/寿限/旺相。例：甲秋生居申酉巳丑戌无丙丁＝向禄；夏生居四季＝向财。  
3. **支命**：年月时支内天元配生日——财官寿夭劫财，精休旺。  
4. **行运**：一辰十年；折除按节气深浅（气深迎运前发，气浅交后运方发）。顺阳运佳、逆则背。  
5. **气权**：将来者进、功成者退。当用之神旺相有庆、死囚休败则退（如金用火官：夏向官、七月气退官不迁）。  
6. **绝处建贵**：丁亥丙子庚寅甲申乙酉戊寅壬午癸巳己卯己亥等，天元绝地反成贵强。  
7. **抽丝**：先得「头绪」（内外天元三合冲刑库墓余气禄马）再解全盘——见不见之形。

## 二、核心对立公式

| 命题 | 条件纲 | 断 |
|---|---|---|
| **背禄逐马** | 如甲春夏+丙丁背禄；乙/亥卯未克逐己财 | 无官无财，守穷途 |
| **禄马同乡** | 如壬午下丁己；忌甲乙寅卯春夺土 | 不三台而八座（无争夺） |
| **夹禄** | 戊辰戊午、丁巳丁未、己未己巳、壬戌壬子、癸丑癸亥等两干夹本禄 | 禄位勿被岁月「占实」；占实则华而不实 |
| **劫财** | 五阳见五阴比劫 | 克妻败财；阴见阳败财不克妻 |
| **生月带禄** | 甲乙秋、丙丁冬、戊己春、庚辛夏、壬癸四季月 | 入仕赫奕（真官禄月，非正月建禄） |
| **建禄不富** | 六甲正月等仅建本禄、财绝 | 无祖财，名目轻 |
| **身旺鬼绝** | 如甲正生庚自然绝 | 虽破命而长年 |
| **鬼旺身衰** | 如甲秋生逢建禄仍遇旺金 | 逢建命而夭寿 |
| **财命有气 / 建禄不富** | 背禄而财旺 vs 建禄财绝 | 背禄不贫 / 建禄不富 |

## 三、官鬼·七杀·元辰

- 甲见庚/申：须分金木轻重——作官印还是官鬼。  
- 七杀地：丙逢亥、丁子、甲申、辛午、壬巳、戊寅、己卯、庚巳等；**当生元有杀，运再逢则重**；元无则轻（「宣父畏元辰」＝命中原有煞害之辰）。  
- 戊见甲、己见乙为杀；十月正月土死，虽有金救亦易夭（建禄而夭寿例）。

## 四、合与交差

- **正合**阴阳相合（甲己乙庚…）成贵；**交差**甲见庚、乙见辛等阴阳不合，或支合被刑破冲＝无福。  
- **偏合曰疾、正合曰道**。  
- **无合有合**：刑破逼禄飞走，三合就马——如寅刑巳、丑破巳逼出丙戊，再巳酉丑合成（后学难知）。得一分三：既得一位为用，即按三合展看。

## 五、根苗花实 · 运岁

- **根在苗先，实从花后**：根元有贵/财/灾，运临其地方发；元无则运到亦不发（「良田不种无收」）。  
- 年逢冠带尚有余灾；初入衰乡犹披鲜福（前运厚则衰运不骤败）。  
- **天元羸弱，宫吉不及为荣**；**中下兴隆，卦凶不能成咎**（禄虽绝而建贵）。  
- **尊凶卑吉，救疗无功；尊吉卑凶，逢灾自愈**。禄有三会、灾有五期。  
- **闻喜不喜**：官星临休败月（如甲用辛而正二五十一生）见金不成官。  
- **当忧不忧**：杀地有合救/身旺制（甲见庚有乙卯或春生丙丁）。

## 六、阴错阳差 · 冲伏 · 诸煞

- 与生地相逢（如庚辛运到申酉官财俱衰）宜退身避位。  
- 伏吟反吟、阴错阳差、天冲地击：岁运与命东南↔西北相冲，内冲外主动改。  
- 四煞（辰戌丑未叠）、五鬼（运干为鬼制财克官）、六害、七伤、天罗地网（戌亥/辰巳互见）、三元九宫——福臻成庆、祸并危疑；扶则速、抑则迟。  
- 历贵地而待时（贵而无时令则虚名）；遇比肩争竞（称意中失意）。人疲马劣犹托财旺之乡；财旺禄衰建马可避冲掩。

## 七、三奇·将星·贵神（赋内）

- 三奇歌：甲己六辛头，乙戊向庚求…（年月日时内外匹配禄马）。  
- 将星扶德（月将+德/六合）而本主休囚＝虚名汩没。  
- 勾陈得位（戊己临禄马乡）成仁；真武当权（壬癸坐禄马墓库）大才分瑞。

## 八、与《子平真诠》分工

| | 珞琭子/子平注 | 真诠 |
|---|---|---|
| 重心 | 禄马向背、气进退、根苗运岁、早期子平话术 | 月令格局成败救应 |
| 用神 | 多从日干禄财官印论向背 | **专求月令** |
