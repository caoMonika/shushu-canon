# 平洋立穴法（地理古镜歌）

## 一句话总纲

**平地没有龙脉可追，一切以水为准。** "水之所止，即是地脉所钟。"

山龙看"来脉"，平洋看"气结"。所以：
- 山上忌"后空"，平地**喜**后空、坐水
- 山上忌水冲，平地**赖**水界气
- 山上以砂为护，平地以水为界

蒋大鸿的原话："平洋之穴无水则四面皆风，有水则八风顿息。所谓气乘风则散，界水则止，古人之言，正为平洋而发也。"

⚠️ 把山龙法硬套到平地上，是本领域最常见的系统性错误，直接导致"坐实反无真龙，坐空反有真龙"的结论全部反过来。

## 核心判断表：二十八辨

### 一、穴星层

**辨穴星厚薄**：穴星在平洋不是山头，是"贴身水城"。看水抱处的地势——
| 地势 | 断 |
|---|---|
| 雄壮宽厚 | 出人壮、官职大、财力厚 |
| 卑靡浅薄 | 出人弱、财力薄、丁伶仃 |
| 威严赫烈 | 官员大 |
| 浅秀生动 | 文人 |

⚠️ 关键限定："秀色以生动有情为秀色，非以卑隘为秀色"；"顽皮"不是雄壮，顽皮只出顽丁武力。

**辨下穴浅深**：
- 形势宽大厚实 → 宜深葬
- 形势狭隘浅薄 → 宜浅葬，或堆土
- 通则：**葬深发得迟，葬浅发得速**，平洋大概多浅穴

**辨坐穴燥湿**（很实用的一条）：
- 四面微微低来 → 真龙栖息之所，吉
- 四面平平，到坐穴处突然低数尺 → **不是低蓄，是水塘（圆）或水槽（长）**，真气已绝
- 后果：腐棺朽骨，或病肿、腹胀、丁少
- 判词："纵格局非凡格，财气横加到底凶……劝君不必筑泥封"——财再多也不取

**辨收山定穴远近**：
- 大荡大河 → 宜**缓受**（离岸远些立穴）
- 小溪小涧 → 宜**急相迎**（贴近）
- 比例原则："十丈河形一丈衡"——河面宽十丈，穴距岸约一丈的视觉比例
- 反例：水口太大又逼近立穴 = "一口西江吸还尽" → 泛滥沉没，主凶死
- 反例：水口仅数丈，穴离岸数十丈 = "远水安坟死气侵"，如鱼涸仅得升斗之水，四面死气反来混杂

### 二、方位气运层

**辨前后左右高低**（操作性最强的口诀）：
- **生方（旺方）宜高**，高则气自高而下润入穴
- **煞方（零神方）宜低**，低则煞气不能自下而上，且低处能引动高处生气、界住高处生气
- 举例上元：西为煞方则西宜低，东为生方则东宜"昌拜"（气聚）
- ⚠️ "昌拜指气而言，非指水而言"

**辨空位忌流神**：立向时九星轮不到的那一位叫"空位"，最忌被支河汊港（斜来或横出）冲破——
- 冲阳位（如寅）→ 男不育
- 冲阴位（如丁）→ 女不生，或生不长大
- 冲单阴位 → 人丁减
- 冲双阴位（如癸、子同冲）→ 丁全无
- 断语："世之有财而无丁者，大抵然也"

**辨吉星照临**：水吉还要星吉。水在吉位但排星是煞星，福减半；水在凶位而排星是吉星，祸也减。**水与星要同时看**。

### 三、砂与建筑层

| 对象 | 规则 |
|---|---|
| **砂** | 零神之砂宜高（界煞迎生），正神之砂宜低（否则煞气回风、生气被压）。四面尖头射来 = 凶，不是"文峰" |
| **屋（峤星）** | 楼台殿宇在零神能荫穴，在正神成煞。**百步以内**气未变换、吉凶立应；百步以外所回之气已变，效缓。一脊射来主一代发，两脊两代 |
| **桥** | 比屋宇更"活"（人来人往），得时甚吉、失时甚凶。木桥不若石桥重 |
| **墩阜** | 高三尺即成星体。零神吉、正神凶。形宜土金，忌木火 |
| **路** | 路能界气亦能迎气，与水神同论。乙字湾环有情，直来直去无生意。田间小路直射 = "土箭"，主吐血心痛 |
| **埧（堤坝）** | 水轮处有坝则断生气 → 主病、哑、折脚驼腰。但滑流（急流）处有坝拦住反妙。六七个池塘节节相连中腰断 = "联珠格"，是大吉格，别误认作坝 |
| **井** | 井气冲天，按挨星论。在生方胜过文笔，在衰方穿心。百步内宜避 |
| **灰塘** | 同墩泡论。穴前穴后七高八低 = 破军，旺方也凶 |
| **牛池粪窖** | **只有凶没有吉，一见即避**，不必论生旺 |

### 四、水形层（凶格清单）

**反弓水**：与山上飞砂同论，凶莫甚。应验：僧道、客商漂流、妇女逃亡、盗贼欺凌、出仕者剥落遭公事。
**水轮处叉河**：丁前丁后都算，真气散。高岸尖尖乱射如"崇牙""斧柯"→ 手足伤残、小口夭、秃头盲瞽。
**直射**（宝照经，可与本歌互参）：
- 一水直朝 = 一枪
- 两水 = 插胁水
- 三水 = 三刑伤
- 四水 = 四杀；八水 = 八杀
- 直来反去 = 拖刀杀 → 徒流客死少年亡
**摆头水**：曲水本吉，但摆头斜去、如绳索样（或大或小、或疏或密）→ 吉而带凶，主淫邪、自缢
**裹头水**：一水裹头名"断城"，虽发不荣，久后房房绝。但若面前另有一枝水到，逼窄之气有发泄，反不为凶
**茶槽水**：穴前池塘水聚天心本名"荫龙水"，是吉局；但硬直深坑形似茶槽，不是佳格。明堂宽旷尚可，急葬则穴气大逼，有凶无吉
**割脚水**：水轮环抱虽贵，但隔河对岸低田之水隐隐相从（"送水归塘"），葬之生忧

### 五、分房断法

凶曜落在哪一位，就断哪一房、哪一体：
- 坎 = 先天坤 = 母；癸 = 阴位 = 妇人；壬 = 阳位 = 男子
- 艮 = 手；震 = 足；离 = 目（后天离即先天震，故坎震方有墩阜蔽塞或支河界割 → 断目疾）
- 左遇凶星长子亏，右遇凶星幼子害，中房看前后煞星
- ⚠️ 蒋注限定："公位之分，不可尽拘"

## 使用流程

1. 先判**平地还是山地**（本技能只适用平地/水乡，山地请用 `dili-xingshi-skill`）
2. 找水：主河在哪、支流在哪、水口在哪、去水还是来水
3. 定穴星：贴身水城抱处，看雄壮还是卑靡
4. 量远近：河宽与穴距按比例配，太近太远都凶
5. 查四面高低：生方高、煞方低是否成立
6. 扫凶格：反弓、直射、摆头、裹头、茶槽、割脚、土箭、叉河——命中任一即降等或弃
7. 扫人造物：屋、桥、墩、路、坝、井、灰塘、粪窖
8. 定深浅：宽厚深葬，狭薄浅葬
9. 验气运：零正是否倒置，排星是否相助

## 关于本书的性质（必须如实告知）

**《地理古镜歌》不是蒋大鸿亲著。** 书末嘉庆丙子（1816）杜薇之跋写得很清楚：

> "天元古镜歌上下二卷，辞句鄙俚，其为伪托大鸿先生无疑。"

所以：
- **歌诀正文**：托名之作，但内容与蒋氏《辨正》体系基本自洽，且实操性强
- **注文**：夹杂"星光按""一勺子"等后人批注，与蒋注不同源，个别处（如"三元气运解为妥"）是批注者的个人见解，不是蒋氏原意
- 引用时应说明"此为伪托蒋氏之作，但义理多可采"，不要当成蒋大鸿原话

另：原文有脱字与OCR错讹，如"辨二十四山逐位阴阳差错"一节第二句，通行本作"一宫亦有一法"，库中文本作"亦有一字法"；"琴瑟难调弦较□"通行本作"弦数易"。凡遇缺字，标注不补。
