# 幼科切要 · 蒸馏技能

**来源**：《幼科切要》，清·王锡鑫（亚拙山人）撰，道光二十七年刊
**定位**：儿科"哑科"的**认证索引**——"每证之下专变阴阳，诸方之中悉论虚实"
**总原则**："凡看小儿先观元气厚薄，手探口息寒热，次察唇舌润燥，再看关纹色气，问其饮食二便，方才酌方调治。"
**使用边界**：古籍文献参考。小儿病情变化急速，书中方药含附子、巴豆、蟾酥等烈药，现代儿童健康问题必须就医。

---

## 一、诊断体系（本书精华，先诊后方）

### 1. 面部五部配五脏
- 额属心、鼻属脾、左腮肝、右腮肺、颏属肾
- **顺逆色**：左腮青顺白逆；右腮白顺赤逆；额赤顺黑逆；鼻黄顺青逆；颏黑顺黄逆
- 五色主病：白气虚、黄有积、赤热、青寒

### 2. 虎口三关指纹（三岁以下）
- 男左女右，食指三节：第一节**风关**（病轻）、第二节**气关**（病重）、第三节**命关**（难治，射中通关命难全）
- **纹色**：紫热、红寒、青惊风、白疳病、黑中恶、黄脾困
- **浮沉**：浮邪在表（易治，疏解汗之）；沉邪入里（莫试风药，须宣阳明里证）
- **形态**：纹淡禀弱防攻伐；纹滞涩因积；纹入掌中腹痛；弯内风寒、外弯痰食热

### 3. 小儿脉法
- 七至八至为数热，四至五至为迟寒
- 浮主表、沉主里；浮而无力中虚宜培元；沉而有力痰积食，无力气滞
- 迟而有力乃为痛，迟而无力是虚寒；数而有力本实热，无力疮疡恐熬煎

### 4. 闻声与问诊
- 言厉声粗知病实，气衰体虚必微言；肝病怒声、心病笑、脾病如歌、肺病若哭、肾主呻吟
- 问七事：寒热、汗、头身胸前、饮食新久、二便渴烦、前服药寒热、痘麻先后
- 舌诊：红黄有火清即安；白滑里寒温中急；白涩里热黄滑寒；舌黑辨阴阳（气热便赤→下，气微便清肢冷→参 桂附；阴亏舌黑→滋阴润燥）

### 5. 危症识别（原文歌诀精选）
浑身热似火而手足如冰、黑掩口角太阴、黑如针垂眼下、目中黑色、水肿准头黑（肾气绝）、咳嗽白入眉（肺虚气绝）、目暗无光不转睛、呕吐不止止又吐、摇头咬齿、囟门或肿或深沉——"此是小儿危急症"

### 6. 变蒸考（勿误药）
- 生后三十二日一变蒸，三百六十五日满十变——发热吐泻与病无异，**误认为疾妄投药饵则蒸长之气全消**
- 变蒸特征：额多微汗、唇生泡、耳冷吐乳——宜惺惺散

## 二、惊风门（儿科最险）

### 急惊（痰火闭证，气体壮实者）
- 前兆：发烧、口鼻气热、大便结、小便臊、喉中热痰
- **祛风败毒散**：羌活、防风、独活、前胡、天麻、荆芥、桔梗、黄芩各一钱——大便不通加大黄，小便不通加木通，痰喘加苏子莱菔子
- **抱龙丸**（发搐吐痰）、**泻青丸**（木旺生风口眼歪斜；兼治内热火泻酱色）

### 慢惊（水侮土证，脾胃虚损）
- 成因：吐泻之后、久病之后、急惊过用攻降
- 症见：神昏气喘、乍寒乍热、面色淡白青黄、二便清白、四肢厥冷、喉内痰鸣、角弓反张
- **逐寒荡惊汤**：白胡椒、炒干姜、肉桂各一钱、丁香十粒，灶心土煎水澄清煎药，频灌——后接理中方
  - 使用口诀：探口中气息微冷、便清者速用如神；**火极似水者（眼眵干结、小便赤、口渴气壮）切勿服**
- **加味理中地黄汤**：熟地、当归、枸杞、枣仁、焦术、党参各二钱，枣皮、肉桂、故纸、炒干姜、炙草各一钱——助气补血却病回阳，"真有参天回元之功"
- **景岳胃关煎**（慢惊脾虚泄泻腹微痛）、**六味回阳饮**（四肢厥冷）

### 痫症（五痫分脏）
导痰汤为五痫初起通用方；肝痫柴胡清肝散、心痫朱砂安神丸、脾痫导痰汤加紫苏香附苍术、肺痫五味异功散、肾痫六味地黄汤。外治：耳后高骨紫青筋针挑破即醒；卒死痰迷：白矾百草霜等分开水灌。

## 三、伤寒五法（纲领性）

| 法 | 脉症要点 | 方属 |
|---|---|---|
| 发表 | 脉浮、发热恶寒、口不渴、二便如常 | 麻黄汤、桂枝汤、大小青龙 |
| 解肌 | 尺寸俱长、目痛鼻干、漱水不欲咽 | 葛根汤、升麻葛根 |
| 和解 | 脉不浮不沉、往来寒热、胁痛口苦 | 大小柴胡 |
| 攻里 | 脉沉有力、潮热谵语、咽干便秘 | 白虎、三承气 |
| 救里 | 脉沉无力、下利清谷、四肢厥冷 | 真武、白通、四逆 |

- 三承气选择法：**以手按自胸至腹有硬处手不可近 + 舌燥滑**，然后大承气（急下）、小承气（少与）、调胃承气（微和胃气）
- 六经定位：太阳表之表（行身背）、阳明表之里（行身前）、少阳半表半里（两胁旁）；过此入脏为里

## 四、常见病分治索引

### 发热（先辨面色）
- 面红气粗口渴尿赤→解表（黄芩紫苏薄荷防风柴胡方）
- 面白眼青神倦→温补（洋参白术茯苓半夏方）
- 面赤鼻扇汗多→肺火（牛蒡枳壳苏子方）
- 久热手足心热下午甚→阴虚（六味加减）
- 肌瘦便艰积热→疳积发热（郁金胆星熟军使君红曲末红糖调服）

### 霍乱与吐泻
- **先分寒热**：先泻后吐者虚寒（六君子→理中加藿香木瓜）；先吐后泻者热（五苓加藿香）
- 干霍乱（绞肠痧，上不得吐下不得泻）：**盐汤探吐**必待吐出宿食积痰然后用药；或针刺十指甲边、委中穴出血
- 吐泻通用：胃苓汤（寒食隔滞腹痛脾虚必服）；安胃醒脾汤随证加减（伤食加枳壳山楂、夹惊加胆星天麻、伤暑加香薷扁豆）

### 泄泻六型
水泻（湿，不痛→分水神丹：焦术七钱车前子三钱）／热泻（腹痛一阵泻一阵粪如酱→泻青丸、芍药汤）／痰泻（平胃散）／食积泻（泻后痛，神曲麦芽焦楂）／脾虚泻（四柱散、参苓白术散）／久泻（加味六君子、真人养脏汤）

### 痢疾
- 红者血热、白者寒积；红白者槐花干姜各二钱
- 切忌大汗大分大下；噤口痢→仓廪散（人参败毒加陈米）或人参石莲汤
- 石室神丹：当归、黄连各一钱，枳壳、白芍各二钱，莱菔子、木香、甘草

### 疳积（五脏分证）
- 总纲：积久成疳，体实以集圣五疳丸为主，**体虚者以补为消**（参苓白术散、肥儿丸）
- 心疳（切牙舌疮喜凉水）→集圣宁心丸；肝疳（面青目生白膜泻青粪）→集圣平肝丸；肺疳（鼻赤烂手足枯细）→集圣清肺丸；肾疳（耳疮鹤膝走马疳）→集圣补肾丸；脾疳（爱食泥土身面黄头大项小）→集圣醒脾丸
- 兼证化裁：食积成疳去芦荟灵脂加参 术苓等；疳泻加白术肉蔻诃子；疳疟加 柴胡鳖甲

### 咳嗽（按时辰与痰辨）
- 清晨咳属痰火、午前属胃火、午后属阴虚、黄昏火浮于肺、二更食积滞三焦
- 因痰而嗽者痰为重主治在脾；因咳动痰者咳为重主治在肺
- **人参败毒散为咳嗽第一神方**（辛平升散）："凡咳嗽初起切不可误用寒凉及滋阴之药闭其肺窍"
- 夜咳不愈→金水六君煎（熟地当归茯苓半夏陈皮）；水泛为痰→八仙长寿饮

## 六、五官与杂治精选

- 脐风：看肚生青筋**行至心者不治**；青筋尽头处灯火散之；马牙奇方（枯矾硼砂冰片麝香掺脐眼）
- 鼻衄：大蒜捣泥，左鼻出血涂右足心，右鼻涂左足心，两鼻齐出涂两足
- 雀目：石决明、夜明砂各一钱，猪肝二两蒸汤服
- 脱肛：总以补中益气汤为主，不可用坠气药；赤肿加羌防芍，痒加椒梅使君
- 疝气偏坠坚硬→马蔺散；肾气虚坠→补中益气汤；寒痛→温疝丸
- 烫火伤：切勿冷水洗（恐热气入心），盐酱掺之，内服 箭 当归各三钱加荆芥黄芩大黄方
- 狂犬毒：红豆子根皮末米汁调下五分；牛蒡根煮粥；虎头骨末麻油调服

## 七、使用要点（蒸馏者注）

1. 本书诊断层（第一节）价值高于方药层——指纹三关与五色顺逆是清代儿科标准化工具，答古籍儿科问题先引此层
2. "实而误补不过增病，虚而误攻不可救药"是全书用药铁律，体虚儿切勿轻用攻伐（三棱莪术巴豆之戒）
3. 惊风一切篇章与《经验奇方》慢惊篇同源（逐寒荡惊汤、加味理中地黄汤两书互见），引用时可注互见
4. 预修十方是"家庭药箱"思想的清代版，答"居家常备"类问题时按功用定位表检索
