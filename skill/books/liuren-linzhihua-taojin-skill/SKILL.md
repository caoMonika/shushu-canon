# 《六壬淘金》课体与断课体系

本书是"教材型"讲义：**不教起课**（明言"九宗门就把很多人挡在门外"），从神煞、四课、课体、毕法一路讲到断课思路。全部分量压在"**课体是断课知识点集合**"这一个立场上。

## 一、起课戒律

> **不动不占，课无虚发。叩之者诚，应之者敬；诚则无妄，敬则主一，鲜有不应。**

- 不诚不敬则不必起课；起了课就不许"再起一课看看"。
- 作者对"正时 vs 活时""两种贵人诀""涉害课不同发用取法"三处争议，明言**另行撰文**、本书不裁断——故遇这三处，本技能不提供定论，须依 `liuren-jichu`（起课通法）与 `liuren-kejing`（九宗法）。
- "数术对人是有选择性的，课随人转，无缘分不可强求"——这是其教学立场，非术法。

## 二、神煞：独立于课式的第二取象系统

- **神煞不随课式变化**：课式（天地盘四课三传）怎么变，神煞的推法不变。因此它是与"课传生克"并列的另一套取象，不可混为一谈。
- 神煞名目繁多，**必须依口诀背**，"否则定会生乱而且效果不佳"；作者推荐以《大六壬指南》卷五歌诀为背诵本（神煞体系另见 `liuren-shensha`）。
- 本书附有**神煞全图按月排列的大表**（天德、天德合、月德、月德合、天解、地解、解神、皇恩、会神、信神、大德、游神、戏神、天车、死别、奸神、飞祸、时盗、破碎等），按"岁煞／月煞／旬煞／干煞／支煞"五类分组，各附歌诀。
- 用法纪律：神煞只作**加临成象**之用，不单独定吉凶；"课体＋神将＋生克"才是主线。

## 三、四课四名与阳神阴神（本书定义最清楚）

- 第一课＝**日阳**（阳中之阳，又称干阳）；第二课＝**干阴**（阳中之阴）；第三课＝**支阳**（阴中之阳）；第四课＝**支阴**（阴中之阴）。
- **阳神**＝某神之上神（表、显现）；**阴神**＝上神之上神（里、隐藏）。例：甲日上神丑，丑为日干之阳神；丑上亥，则亥为甲之阴神。
- **乘**在天盘（某神乘某将）；**临／坐**在地盘（某神临某宫）。此三字全书用法严格，读旧书时注意别混。

## 四、两套旺衰（与通行说法有出入，须留意）

1. **时令旺**：春木、夏火、秋金、冬水、四季土。
2. **课内旺**：全课五行配比可改判。例：秋占本金旺，若课内水多而有木，则转为**水旺木相**。
3. 生克定位用"**以我为旺**"起算：我＝旺，我生者＝相，我克者＝死，生我者＝休，克我者＝囚。

> 注意：这里把"我克"定为**死**、"生我"定为**休**，与《大全》系"旺相休囚死"（当令者旺、我生者相、生我者休、克我者囚、我克者死）次序一致，但把"死"挂在"我克"上是**以占者为主体**的算法，与以月令为主体的算法会得出不同结论。同一课两法并用时须先声明用哪一套。

## 五、课体：64 课＝64 个断课知识点

本书对课体有三句定调，是它区别于其余各家的地方：

1. **课体表示大象，但不表示吉凶**。吉凶在生克、在神将、在其他元素。故"某人说六壬课体没用、毕法百分之四十是错的"，是"没看懂六壬书"。
2. **六壬 64 课不是 64 个发展方向或 64 个结局**，而是**64 个断课知识点**（李老师语）。且不同资料的课体结构与课名并不统一，不必强合。
3. **学课体不必死记**，只取其中的"剖析"（知识点）即可；与《六壬心镜》重合处以《心镜》歌诀记忆，另可参张官德《六壬辨疑》。
4. **毕法赋与课体高度对应**——学课体可省掉大半毕法；但毕法"也有错误、不准确之处"，作者拟另文论，本书未展开。

本书把 64 课按"吉／凶／杂"顺序逐一列名并给一句定义，可直接当查表用：

- 吉课类：三光、三阳、三奇、六仪、时泰、官爵、富贵、龙德、轩盖、铸印、引从、亨通、繁昌、荣华、德庆、合欢、和美。
- 阻隔与变局类：斩关、闭口、游子、三交、乱首、赘婿、冲破、淫泆、芜淫、孤寡、度厄、无禄绝嗣、迍福、侵害、刑伤。
- 凶课类：二烦、天祸、天狱、天寇、天网、魄化、三阴、龙战、死奇、灾厄、殃咎、九丑、鬼墓、励德。
- 结构与传法类：盘珠、全局、元胎、连珠、间传、六纯、杂状。
- 九宗门本体：元首、重审、知一、涉害、遥克、昴星、别责、八专、伏吟、反吟。

> 各课定义以一句话给出，与本技能 `liuren-kejing`（课经原文）互为详略：此处取"速查＋知识点"，细文与成案仍以课经为准。

## 六、射覆：刚日柔辰射覆基

本书把射覆作为"课经最后一课"，并直言其思路与常占不同——"**取象微观，相当于用显微镜来研究事物**"。法出《袁天罡先师射覆无移口鉴》：

- **取用**：阳干（刚日）看**日上神**，阴干（柔日）看**辰上神**；再兼**初传发用**之神合断。**不看中末二传**。
- **定物**：以用神五行＋日辰上神五行互推。
  - 用起**水**神：珠蚌浆汁、水晶流转、中实之物；日辰上见水→四足、好走、中实之物；见水（另一处）为轮转物；见金为生全物；见土为故土物。
  - 用起**火**神：经火炉冶、陶铸、尖斜中虚之物；日辰上见火为故破物；见水为半虚半实好行走物；见木为花果；见金为陶冶物。
  - 见火半虚半实、有头无尾者为**已坏物**。
- 练习纪律：射覆是校验"取象精度"的唯一硬指标，故本书将其置于课体章之末——先能射覆，才能谈断细象。

## 七、断课即翻译课：信、达、雅

作者转述其师语，这是全书最可操作的一段方法论：

1. **信**——把课**完整、正确地**翻译出来。翻错即错断，"接下来即使说得再精彩也没有意义"。
2. **达**——在断对的基础上**有所发挥**，把课理与现实联系起来。
3. **雅**——用艺术手法表达：邵彦和断得"内容详尽、有故事情节、跟小说一样"，陈公献"经常随口四言绝句"。

配套三条实操：

- **知识点必须背熟**："实战时你记忆深刻的知识点课里没出现，你没记住的知识点出现了"，故须练到"用到哪个信手拈来"。
- **无用信息不是废信息**：断课时把多个类象系统调起来，按自己对所问事项的理解挑出相关因素、剔除无关因素——"**这些没有用的信息，是留给同时辰占卜其他事情的人用的**"。这一句同时解释了"一课可多断"与"为什么不必强行用完所有象"。
- **六壬课像在跟一个很原始的古人对话**：表达方式与今人不同，只能靠反复交流去熟悉，"直到最后他一个眼神我们就心有灵犀"。故"六壬没有传说中的秘笈秘本，由老师引入门径之后，全在个人勤奋"。

## 八、不列分类占的理由（一条立场，供取舍时参考）

本书**仿《六壬大全》不设分类占章节**，理由有二：

- 类象神煞在不同占项里意思完全不同，且占农桑、占苗禾于今无意义；
- **占天时意义不大**："同样一支课在不同地方占，全国天气难道一样吗？"（例：冬至后巳加酉为雪，海南岛占哪来的雪？）占家宅则有专门的阴阳宅学。

> 这是与"十六门分类占"派（如 `liuren-jianhong` 所据《占测机理揭秘》）的明确分歧：一派认为分类占是必需的分科训练，一派认为分类占脱离地域与时代即为空谈。两说并列，不裁断。

## 九、使用边界与素材缺陷

1. 本技能据 `_src\taojin.md`（119K 字符，《六壬淘金（精简版）》word 全文）。**该书章节不全：仅有第一章（基础提要＋神煞指南）、第二章（课前补充）、第三章（课体，含毕法赋目录与 64 课）、第六章（断课思路提点）**；第四章、第五章在提取中缺失，其内容或为类象章、或为分类占章，无法确认。故本技能**不含类象系统与分类占断法**，涉类象须转 `liuren-beihai-gaoji`（九大类象系统）或 `liuren-qinruisheng`。
2. 书末附**李法玄解《黄帝阴符经疏》与《道德经》九篇**，属道家经解，与六壬无关，本技能不取。
3. **作者归属存疑**：书中通篇称"李老师""李法玄"，未自署作者；本技能沿用分组计划中"林志华"之著录，但**不能确认《六壬淘金》即林志华所著**。引用时请写"《六壬淘金》"，勿直署人名。同组另三本——林志华《六壬学（学习大六壬最合适教材）》、林志华《大六壬提高》、《六壬实战详解》——**本技能未取**。
4. 64 课的一句話定义在提取中有若干处与《六壬心镜》引文交叠（书中作"[六壬心镜]略……"），说明作者本意是"心镜详、本书略"。故**本技能的课体定义不得当《课经》原文引用**，需原文时用 `liuren-kejing`。
5. 旺衰"两套并用"的取舍（时令旺／课内旺）本书未给优先级，实际断课须先声明。此项属素材缺陷，不代作者补定。
6. 学派差异并列：淘金一系"**课体＝知识点、神煞独立、断课即翻译**"；北海"类象为核心、课体只是象之一"（`liuren-beihai-gaoji`）；刘科乐"理气象类＋易简"（`liuren-liukele`）；徐伟刚"将高于神、神煞极重"（`liuren-xuweigang`）；伍剑虹"重结构层次"（`liuren-jianhong`）。
