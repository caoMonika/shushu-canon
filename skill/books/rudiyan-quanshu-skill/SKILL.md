# 入地眼全书（静道）

## 派系警告

斥双山长生、用翻卦净阴净阳——常与蒋系相反。须标"入地眼说"vs"蒋氏说"。

五认：龙生死、穴有无、砂粗秀、水曲直、向纯疵。

## 龙

以少祖为主；喜单清。五龙难下：亥辛午巽卯。兼邻字多煞。震忌兼甲乙；巽忌兼辰巳等。

替代水法：阳来阳向、阴来阴向，或八卦夫妇配。

## 砂 / 水

砂：肥圆富、尖丽贵、斜肿贱；形方理气合参。  
水：形象第一。分合三层（小/次/大）定穴有无；后合蓄力最大。

## 向 / 阳宅

翻卦从向上起辅；阴向阴水、阳向阳水。  
东四西四；游年生天延吉；竹节贯井分动静变化宅。

## 流程

单清入首 → 分合验穴 → 砂开面 → 水形象 → 翻卦立向（声明派系）→ 阳宅游年贯井

## 边界

疑非完帙；与蒋杨玄空异；术数非可验证因果。
