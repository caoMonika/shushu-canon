# 六爻快速构思法

## 它是什么

李鹏把断卦最难的一步定成**构思**：不是先背断语，而是把卦中与中心相关的信息，按逻辑顺序或时空顺序挂到坐标上，再交合联想，快速形成来意、行运应期与策划解化的推理链。

整法走的是"无极→太极→两仪→四象"式展开：**由点到线，由线到面，由面到体**。它解决的是"看完卦却说不成话"，不是另起一套旺衰公式。

## 一、三步总流程（必须按序）

### 1. 列出信息点（厚积）

先整体扫一遍本卦、变卦的卦名卦象与十二爻，再聚焦：

1. **全卦五行**强弱大势
2. **体用**（常以世爻为体／人中心）及其**双原**（原神 + 原神之原）
3. 双原的再一层双原（必要时）
4. 其余爻与要点（四时送迎、动静、关键六神等）——**略看，不喧宾夺主**

原则：与中心相关的信息尽量多列，先"厚积"再"薄发"。信息少就选不出病药，也串不成文。

### 2. 确立中心（聚焦）

中心 = 本卦主要矛盾 = **病药点**：

| 概念 | 含义 |
|---|---|
| 病／致病点 | 对体用损害最大、最破败处 |
| 药／调神 | 最能致吉、能使全局回平处 |
| 切入 | 断卦先找病药，不先散断六亲 |

操作：看出最好爻与最弱爻；抓住致病点与药点各自的**天时、地利、人和、事泰**因系。一句纲领：

> **病药为先，纲举目张。天机尽泄于病药之处。**

测来意、断人事：专寻致病爻、病爻、药爻；时断要连地支逐一推，找最巧的平衡处，再展病药象数追踪。把五行收束到二行／阴阳体用，信息才"聚焦"。

### 3. 联点成线，联线成文（成文）

把已列出的病药信息点按**逻辑顺序**或**时空顺序**理顺，再交合联想：

- 理顺病药涉及的**时间、地点、人物、事件**（天时、地利、人和、事泰）
- 十二支逐一推；展开卦象、爻象、六神象的系列追踪
- 明确四块输出：**来意 → 时间／应期 → 策划解化 → 行运**

预测之妙在病药与病药顺序之间的联系：把象数联成现实情景（太极追踪），自然成一篇有经络的断文。卦爻是骨架；**病药与病药顺序是经络**。

## 二、与断卦实务的对接

| 选题 | 构思落点 |
|---|---|
| 破来意 | 病药中心 + 最显眼的失衡迹象 |
| 断应期 | 病药何时加重／何时得药（时空顺序） |
| 策划解化 | 药点对应的天时地利人和事泰可调处 |
| 立中心不偏题 | 始终围绕体用／世爻与双原，不散扫六亲 |

## 三、使用边界

- 本技能管**构思流程与选题顺序**；具体旺衰、冲合、生克权细则仍用对应断法技能。
- 与 `liuyao-kuaisu-duanfa-skill` 配套：彼为全书框架（易简、病药论、行运、解化），此为其中"快速构思"专篇的可执行压缩。
- 禁止把"列信息点"做成流水账：第三步必须收敛到病药顺序与四块输出。
