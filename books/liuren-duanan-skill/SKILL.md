# 六壬断案（邵彦和案例集）蒸馏

底本：《六壬断案》，干鼎斋陈镛朴辑(古歙槐塘程铨爱圅原辑本基础上整理)，宋·邵彦和先生(生于英宗治平二年乙巳，殁于高宗绍兴三年癸丑，浙江太末人)占验，及门诸子编录。陈氏汇五本残帙(梦醒头陀钞本、口鉴注、前知书引、方仰松武林购本、宋人原书己酉年残册)考订分类，共得**二百一十六例**：天时三、宅墓三十九、前程仕进五十八、终身十六、流年二、婚姻三、胎产子息七、财产十二、一课二事各断式三、交易二、出行访谒七、行人音信六、病症十七、六畜九、亡盗十四、官讼十二、杂占六。分元、亨、利、贞四集。每例体式：起课年月日时+月将+空亡落空+课体格局名 → 邵断 → 应验记录 → **先生析曰**(取象推理)。

## 一、断案方法论总纲

### 1. 课体定性先行
课体格局直接定事性：
- **铸印(巳戌卯)**占天时必大雨雪；春夏占冲，冬占必雪。
- **润下(申子辰)**冬占大雪、春占水涨；元临子作用更的。
- **赘婿**(支来就干为干所制)：宅来就人被人克，主家破；妻为主夫反少。
- **涉三渊**(间传一传远一传又入空)：主劳碌奔波、劳力无成；三传反流入他方主死于外州。
- **登三天**：至高至危之象，细微中出入却能显焕(反断)。
- **炎上局**：有头无尾，如火之炎暂时便止，合天后主因妇人坏事。
- **退茹**：不作阻断论，须看六仪三奇拱护(如甲戌旬戌为六仪加干为朝天)。
- **无禄课(四上克下)**：天动于上纯阳主动；久困在下者遇之而发，居家者出(蔡京占例)。
- **昴星**：朱雀临门主文字立至，子卯相刑主来速。
- **连茹**在不明(乘玄武)末虎作鬼，主盗案连累。
- **不备课取用纠正**：干支阴阳先据其位者不重取用，当以日遥克(弹射)为用——"传用已差，占何得应？皆由用术不精，反云六壬不灵"（第7例为取用正误的教科书案例，须精读）。

### 2. 数字应期（干支上下数、地支数）
邵断应期大量用数理，须记基础数：
- 亥四、申七 → 四七二十八(第45例中式名次、第164例寿数)
- 卯六 → 六年(第5例家破期)
- 丑(蛇)八数 → 八年(第6例开生地致不和)
- 戌加巳：上五下四共九 → 九年(第6例)
- 亥四子九 → 四九三十六、或亥为肾元武疝气取十三(第109例)
- 建将重逢为双胎；太岁主年内、月建主月、日时主近期
- **三合全逢定归期**：申辰缺子字→子日归(第158例行人)；以用神合处定末期，近用六合、远用三合
- 孟迟仲中季速；用神墓绝日归来(阳日墓所临之日、阴日绝所临之日)
- 发用克日主来就我；绝神克干行人必归(第158例亥作贵作绝加丁)

### 3. 三传分野
- 病占：**初传论上部、中传论中间、末传论下部**(第164例：初巳火上热、中寅木风气相击、末亥水下冷)。
- 盗占：**发用为偷即贼身、中传为赃、末传捕人**。
- 事占：初传事发端、中传事之过程、末传事之结局归宿(如初脱末生→先败后成)。

### 4. 干支彼我生脱
- 干支皆受上神来生、互受脱(干生支之长生、支生干之长生)：**先兴旺而后衰败**(第4例张九翁，亥四寅七十一年败)。
- 三传脱支生日干→人多屋少；三传生支脱干→屋旺人衰。
- 日去加辰夫脱妻(赘婿)；干加支子恋母、支临干儿生速。
- 财爻引归长生末传→破败后妻家起家晚年享福(第46例)；脱上逢脱必诗书荒废家道空虚(第45/46例对读：同课异断在年命月将)。

### 5. 类象落实(取象精微是邵断灵魂)
- 申：磨、僧(申为身，身入空门)、传送道路、金声名于西北(申为西北金到巳炉冶有声名)
- 亥：妇人、水、酒色、肾、天门
- 卯：门户、沙门(乙为沙门辛为僧舍)、六数
- 丑：墓、库(丑为库)、僧贤(第217例申为僧丑为贤上见贵→大和尚)
- 巳：鼎灶(炼丹)、店业(第46例巳为店业禄加之做酒起家)、朱姓(午未字像朱)
- 酉：酒、歌喉、门户、婢
- 天后为妇人、六合为媒/儿孙、太阴为老阴人/阴私、玄武为失脱/疝气/女耗、天空为奴/虚诈/空门、白虎为死丧/血光/催程、勾陈为争讼/官吏/滞神、朱雀为文书/口舌、青龙为财/夫/恩宠
- 摩压东门(申为磨卯为压东门)之类物象断，须据神将组合灵活成象，忌死套。

### 6. 空亡与神煞妙用
- **空亡是断层次的机关**：申酉空亡=兄已亡故娶兄妻(第6例)"若申不空，则不可乱断"；妻宫空亡主克妻(第48例)；初传空亡子息居阳刃鬼上难得子(第47例)。
- 落空(空亡落空)与暗鬼(通鬼)、丁神并见时逐项标注，断时逐层剥。
- 丧门吊客临干支行年→孝服(第45例爱圅补断)；月破+死神坐空+丧车→因产死(第47例注)。
- 贵人昼夜用事分吉凶：酉作贵登天门为夜贵用事主不明(第106例)。

### 7. 行年本命必入断
几乎每例皆以生年干支(如"戊午生五十一岁")+行年上神定事应：
- 行年上神伤玄武→发使追求早擒；行年上见吊客主孝服。
- 本命入传课即事应在己身：夜贵乘未闭口又是本命→得官不久即死(第45例)。
- 夫妇年上推男女(占胎)；年命冲克胎神不育。

### 8. 吉凶反断与"有救无救"
- 同课异断：第45/46例同得一课，因月将不同、年命有无，一中第一下第、一丧妻一妻家起家——**不可只凭课体套断，须合年命月将**。
- 先凶后吉的转机：末作解神/天喜乘龙→恩赦(第215例)；中末自刑喜见解神；勾陈作天空为官吏不认必入狱、认了无虑(第216例)。
- 处决凶格：日加辰作勾上下夹克、日辰皆自刑、末虎入墓→死不完尸(第214例)。

## 二、分类占断验例举要

- **天时(3例)**：铸印占雪"巳戌卯铸印，春夏秋夏冲，冬必雪"，三传顺行三雨、卯为雷雷过西方为虎所制主雪；润下元临子冬占大雪。火伏于下水升乎上不拘占雪占雨皆当日有。
- **宅墓(39例)**：干支互受生脱主先兴后败；太岁入宅克宅六年家破屋拆遂成墓地(第5例)；妻为主日加辰夫脱妻(第6例)；金日得水局三传皆子孙脱气，一生被子息作吵十二年后出怪(第8例)；伏尸旧冢掘得十四穴(第104例)。
- **前程仕进(58例)**：六仪扶护三奇拱秀小则郎官大则侍从(第44例，兼断阴德——"因有活人之功上天降福"，德行入断是邵断特色)；子孙生长生地脱日夺气为子得第之兆(第45例)；涉三渊劳力无成死于外州(第47例)；禄重于财为占前程通则(爱圅注)。
- **终身(16例)**：极阴课因酒色成痨(第105例亥四酉六四十六岁亡)；登三天细微中出入能显焕(第107例)；随身库只利书会(第108例)；堂上坟地丑加寅艮山、水陡泻西北主退耗(第109例)。
- **行人(贞集)**：绝神克干主归、行年上见生不归、三合缺字定日(第158例)；天罡加支望事立至(第161例榜至四十九名)；朱雀临门+子卯刑文字立至(第163例)。
- **疾病(17例)**：初末分部论寒热(第164例)；寄舍出家免灾类"关煞化解"断法(申为寺院空生为寄舍)。
- **官讼(12例)**：自刑乘虎临门户主徒罪，中末解神恩赦先凶后吉(第215例)；四上克下无禄课久困者发(第222例蔡京)。
- **杂占**：酉加子作天空"酉破子"主无酒(第221例)；僧道占住持以日为我支为住持，阳刃乘后加支因妇人受刑(第219例)；库中者丑为库(第220例)。

## 三、实占操作流程(据断案提炼)

1. 报占：来人生年+占事+起课时刻 → 推月将、四课三传、标注空亡/落空/暗鬼/丁神、课体格局名。
2. 定性：课体格局定事之性(成败/迟速/远近)，如赘婿主破家、铸印主雨雪印信、无禄久困者发。
3. 落实：以类象将神落实到人事物(谁/何物/何处/何疾)，干支分彼我，初中末分阶段/部位/赃贼。
4. 应期：取数(干支上下数、地支数)、三合缺字、墓绝日、孟仲季、太岁月建日时层级。
5. 合参：行年本命入断定应在己身何年；空亡神煞定层次(空则不成/先伤后续)；吉凶反断看有救无救(解神/天喜/子孙)。
6. 表述：先断吉凶结论，再"析曰"分层论证，验记附后——输出断语时给出可核验的时间/数量/人物特征。

## 使用边界与素材缺陷

1. **版本**：陈镛朴(干鼎斋)汇五本残帙考订分类本，非宋刻原本；原书已散逸，"原本渺不可得"，异文择理长者从之。书中多处"爱圅曰/爱圅析曰"为程铨按语，与邵断有别须分辨。陈氏整理后记署"乙酉年孟秋立秋日陈镛朴整理于塞外干鼎斋"等三次续修。
2. **秘籍网水印**：正文夹杂"三十万多本武、易、道、医、奇等类书籍尽在(秘籍网: www.miji8.com)"水印行，非原文；转换时已见多次，引用时剔除。
3. **课式图形损失**：每例天盘地盘课体图为文本表格转换，行列错位(如第3例表格破碎)，三传神将须据干支文字重排核验，不能直接信转换后的表格位次。
4. **断语遗失与存疑**：第3例"断语遗失"；第46例古本无应秀才课(爱圅辨异)；同类"某秀才/或占"式匿名例身份不可考。部分例末"(仔细研读)"(第7、217例)为辑者提示语。
5. **方法边界**：邵断以类象活用取胜，"不可乱断"(空亡条件)与"同课异断"(年命月将)是铁律——本技能提炼的是方法与先例，不是课体-断语对照表；具体占问须按流程重推，勿机械套例。九宗门课体基础另见 liuren-xinjing，分类断诀速查另见 liuren-zhinan，法赋条文另见 liuren-bifa。
6. **OCR 讹误**：个别字讹(如"妻宫/妻官""已/己/巳"混、"颎/颎"类生僻字)，数字大写小写混排；应期数字务必回核原文上下文。
