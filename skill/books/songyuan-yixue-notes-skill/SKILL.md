# 宋元易学笔记合参（songyuan-yixue-notes）

四短篇合成一张「概念导航图」：疑经→护邵→明象→义理笔记。调用时先定用户问的是**哪一层**。

## 一、分工一览

| 书 | 作者 | 本 skill 取用 |
|---|---|---|
| 易童子问 | 宋欧阳修 | 以《彖》质众辞；人事优先；卦不为一人设 |
| 易学辨惑 | 宋邵伯温 | 邵雍传授链；辟郑夬窃书冒邵 |
| 易学滥觞 | 元黄泽 | 明象以《序卦》为本；折中王弼忘象与汉儒烦象 |
| 了斋易说 | 宋陈瓘 | 义理札记口径（源本简略，作补充语气） |

## 二、欧阳修《易童子问》框架

### 1. 质诸圣＝质诸《彖》

- 「乾元亨利贞」四德说：欧阳修指《文言》乾四德出鲁穆姜（《左传》襄九），不以《文言》全归孔子。
- 凡彖象与卦辞似反：先分「众人／君子」时位（例：屯——众人勿往，君子动以经纶）。

### 2. 用九用六

- 《易》用变：乾用九、坤用六，释所以不用七八。
- 阳亢必变→见群龙无首；阴邪须戒→利永贞。

### 3. 人事急于天道

- 《谦》彖独具天道亏盈云云：可知者直言人情，不可知者推迹；修人事则与天地鬼神合。
- 汤武：师「毒天下」仅得无咎——兵非圣王所务；革称汤武是「适当其事」，正道仍在乾坤君臣，孔子厚文王而薄武王。

### 4. 读卦方法条

- 卦不为一人设（大过：可往亨，亦可独立遯世）。
- 同人：通志与类族辨物——同而能类，非一概之同。
- 咸必异类相感；恒＝知变乃能久；夬＝小人衰则养之，不可尽决。
- 「鼎取新」非圣人之言——革去故已足，鼎本亨饪之象。

## 三、邵伯温《易学辨惑》框架

### 1. 传授链（护家学）

陈抟 → 穆修 → 李之才（挺之）→ 邵雍。  
南方象学另枝：陈抟 → 种放 → 许坚 → 范谔。

挺之三关：科举之学 → 义理 → 物理 → 性命。邵子兼意／言／象／数，有一图寓阴阳消长（先天），「画前有易」。

### 2. 辟郑夬

- 王天悦记邵学，郑夬赂仆窃稿，著《易传》《易测》《明范》《时用》等，破碎妄作。
- 沈括《笔谈》引秦玠神异说＝误把邵学缩成「洞吉凶」；伯温辨：邵学大中至正在《易》，非秘闻天谴术。
- 司马光荐《易测》「不泥阴阳」与伯温所辟可并存：或夬书有义理面／占卜面两套。

### 3. 使用提示

问「邵雍师承／郑夬公案／先天是否神秘天谴」→用本篇；问先天数学细节→转皇极／邵学专技。

## 四、黄泽《易学滥觞》框架

### 1. 判教

- 汉儒明象→烦琐；王弼忘象→玄虚；程明理、朱主占——象学仍未复古。
- 自定位：明象以《序卦》为本；占法以《左传》为主；折中汉王。

### 2. 《序卦》大象优先

上经：开辟经制——乾坤定位→物生屯→蒙教→需养→讼争…；终坎离（先天意）。  
下经：人道正家——始咸恒（变易），终既未济；六子备于同人大有之后。

解需「饮食宴乐」：须从乾坤屯蒙说来——水在天为云，降而为雨养穀，故取饮食；不可就象Isolated硬套。

### 3. 变易／不易

- 上经从不易说起，下经从变易说起；各含对方。
- 天道主变（非常之雷、治乱、圣贤穷达）；人道主常（伦分不可踰）而须知变。

### 4. 十三事门（复古障碍清单）

易之名义、重卦、逆顺、卦名、卦变、易数之原、词义、占词、蓍法、占法、序卦、脱误疑字等——答「为何学易卡住」可按此清单归类。

### 5. 象有大小

乾马坤牛之争是小象；《序卦》结构才是大象。离为牛最难强通——承认有惑，先大后小。

## 五、了斋易说（陈瓘）

源本为绍兴刊遗说，篇幅寡、义理札记性质。合参时作**辅证语气**：偏君子修身、戒慎与经世，不另建象数体系。与欧阳修同属「人事／义理」侧。

## 六、边界

1. 四书皆短，合参≠宋元易学全书；程传、本义、皇极另召。
2. 欧阳修疑《文言》《系辞》部分篇章——引用须标明「欧说」非定论。
3. 黄泽全注未成，本卷是「大凡」；邵伯温不传邵子数学细节。
