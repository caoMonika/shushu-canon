# 相术合参（冰鉴 + 人伦大统赋）

## ⚠️ 先读这一段

相术是**以貌取人**的体系。这一点必须摆在最前面，不能含糊：

1. 现代对"以貌取人"有明确结论：**外貌与人格、能力、品行之间没有可靠对应关系**。任何依据长相判断人品、能力、前途的做法，在方法上不成立，在伦理上有害。
2. 相术文本里大量条款带**身份歧视、性别歧视、残障歧视**（"僮仆相""贱相""妇人眼三角者性狠如杀夫之刃""二十四齿者鬼形主命夭"）。这些是宋元明清社会等级观念的产物，整理时保留原貌供研究，**不代表本技能立场**。
3. 所以本技能的正确用法只有三种：
   - 读懂原文（古典文献理解）
   - 理解古人如何"看人"（社会史、管理史、文学研究的材料）
   - 提取其中**可迁移的观察维度**（如"看一个人紧张时的反应"而不是"看他的鼻梁高度"）
4. **不可用于**：招聘、择偶、评价他人、判断健康、预测命运。

如果你的目的是"我要判断某个人靠不靠谱"——直接看行为、看长期记录、看利益冲突下的选择。相术不提供这个能力。

## 一、《冰鉴》七篇（曾国藩系，偏"观人取士"）

### 第一篇 神骨——一切之本

**总纲**："一身精神，具乎两目；一身骨相，具乎面部。他家兼论形骸，文人先观神骨。"

所以冰鉴的次序是：**先看神，再看骨，其他都在后。** 这是它与其他相书最大的不同——它几乎不谈"哪个部位主什么"，只谈整体气象。

**神的四组辨析**（这是全书最精的部分）：

| 状态 | 静时 | 动时 | 断 |
|---|---|---|---|
| 澄清到底 | 静若含珠 | 动若木发 | 上 |
| 澄清到底 | 静若无人 | 动若赴的 | 上 |
| 败器 | 静若萤光 | 动若流水 | 尖巧而喜淫 |
| 隐流 | 静若半睡 | 动若鹿骇 | 别才而深思 |

⚠️ 关键判语：**"一为败器，一为隐流，均之托迹于清，不可不辨。"** 即：坏的那种神，恰恰是伪装成"清"的样子。这是识人最难处。

**看神的方法**："凡精神，抖擞处易见，断续处难见。断者出处断，续者闭处续。"
- 小心之人 → 从其"不了处"看，看是否疏节阔目、若不经意（脱略）
- 大胆之人 → 从其"做了处"看，看是否慎重周密、无有苟且（针线）
- **"二者实看向内处，稍移外便落情态矣，情态易见。"** —— 神比情态深，情态一望可见，神要往内看。

**骨有九起**：天庭骨隆起、枕骨强起、顶骨平起、佐串骨角起、太阳骨线起、眉骨伏犀起、鼻骨芽起、颧骨若不得而起、项骨平伏起。
- 在头以天庭骨、枕骨、太阳骨为主；在面以眉骨、颧骨为主
- **五者备，柱石之器也；一则不穷，二则不贱，三则动履稍胜，四则贵矣**
- 骨色：面以青为贵（"少年公卿半青面"），紫次之，白为下
- 骨质：头以"联"为贵，碎次之
- **"面佳不如头佳"**；但大而缺天庭终是贱品，圆而无串骨半是孤僧，鼻骨犯眉堂上不寿，颧骨与眼争子嗣不立

### 第二篇 刚柔（五行形局与内在气质）

**外刚柔** = 五行形局（金木水火土五形）
- **顺合**（木合火、水合木）→ 多富，"即贵亦在浮沉之间"
- **逆合**（金与火仇而有时合火）→ "其贵非常"
- **但逆合有方向性，这是最容易搞错的地方**：

| 成立（贵） | 反向（凶） |
|---|---|
| 金形带火 | 火形带金 → 三十死 |
| 水形带土 | 土形带水 → 孤寡终老 |
| 木形带金 | 金形带木 → 刀剑随身 |

**内刚柔** = 喜怒、跳伏、深浅
- 喜高怒重、过目辄忘 → 近"粗"
- 伏亦不伉、跳亦不扬 → 近"蠢"
- 初念甚浅、转念甚深 → 近"奸"
- 判语：**"内奸者，功名可期；粗蠢各半者，胜人以寿；纯奸能豁达，其人终成；纯粗无周密，半途必弃。"**
- 感叹：**"观人所忽，十有九八矣。"**（这三样恰恰是常人忽略的）

### 第三篇 容貌（容与貌要分开看）

**"容以七尺为期，貌合两仪而论"** —— 容是全身，貌是面部。

**容贵"整"**，但"整"不是整齐，而是：
- 短不豕蹲、长不茅立、肥不熊餐、瘦不鹊寒
- 背宜圆厚、腹宜突坦、手宜温软曲若弯弓、足宜丰满下宜藏蛋
- 定格：五短多贵、两大不扬、负重高官、鼠行好利
- 加分项：手长于身、身过于体配以佳骨 → 封侯；罗纹满身、胸有秀骨配以妙神 → 拜相或鼎甲

**貌分清、古、奇、秀四类**，但关键是看两个"星"：
| | 出现年龄 | 位置 | 见于何时 | 主 |
|---|---|---|---|---|
| **科名星** | 13–39 岁 | 印堂眉彩，或钢针或小丸，常有光气 | 酒后、发怒时易见 | 早荣 |
| **阴骘纹** | 19–46 岁 | 眼角，如三叉样 | 阴雨天、假寐时最易见 | 迟发 |

- 二者全 → 大物；得一亦贵；二者全无 → 前程莫问
- 阴骘纹见于喉间 → 主生贵子

**出贵征 / 贱征**（原文直录，供理解其逻辑）：目深则清、鼻高则灵、口阔而方禄千种、齿多而圆不家食、眼角入鬓必掌刑名、顶见于面终司钱谷；舌脱无官、橘皮不显、文人有伤左目、鹰鼻动便食人。

### 第四篇 情态——本技能最可迁移的一篇

**"容貌者，骨之余，常佐骨之不足；情态者，神之余，常佐神之不足。久注观人精神，乍见观人情态。"**

→ 实用含义：**长相处看神，初见面看情态。**

**四种恒态**：
| 态 | 表现 | 成器条件 | 反之 |
|---|---|---|---|
| 弱态 | 飞鸟依人，情致婉转 | 弱而不媚 | 媚则败类 |
| 狂态 | 不衫不履，旁若无人 | 狂而不哗 | 哗则败类 |
| 疏懒态 | 坐止自如，问答随意 | 疏懒而真诚 | 不真诚则败类 |
| 周旋态 | 饰其中机，不苟言笑，察言观色，趋吉避凶 | 周旋而健举 | 不健举则败类 |

**"皆根其情，不由矫枉"** —— 这四态本身都不算坏，坏在"过"和"伪"。

**三种时态**（临场反应，可作识人清单）：
1. **方有对谈，神忽他往；众方称言，此独冷笑** → 深险难近，**不足与论情**
2. **言不必当，极口称是；未交此人，故意底毁** → 卑庸可耻，**不足与论事**
3. **漫无可否，临事迟回；不甚关情，亦为堕泪** → 妇人之仁，**不足与谈心**

作者补了一句很重要的限定：**"三者不必定人终身。反此以求，可以交天下士。"** 即：这三条不是给人判死刑，反过来做就能交友。

⚠️ 这是全书最能与现代识人接轨的部分——它看的不是长相，是**行为模式**（谈话时注意力是否在、是否无原则附和、是否对无关之事过度动情）。可以放心用。

### 第五篇 须眉（眉主早成，须主晚运）

**眉**：
- 眉尚彩（杪处反光），贵人有三层彩，一二者次之
- 宜疏爽不宜凝滞；一望有乘风翔舞之势为上，如泼墨者最下
- 倒竖者为上，下垂者最下
- 长有起伏、短有神气；浓忌浮光、淡忌枯索
- 如剑者掌兵权，如帚者赴法场
- 最下乘：压眼、散乱、细而带媚、粗而无文

**须**：取其与眉相称
- 多者宜清、宜疏、宜缩、宜参差不齐；少者宜光、宜健、宜圆、宜有情照顾
- 卷如螺纹（聪明豁达）、长如解索（风流荣显）、劲如张戟（位高权重）、亮若银条（早登廊庙）
- 紫须剑眉、声音洪壮；蓬然虬乱尝见耳后，配神骨清奇 → 不千里封侯亦十年拜相
- 反例：辅须先长终不利、人中不见一世穷、鼻毛接须多滞晦、短毙遮口饿终身

### 第六篇 声音（声与音要分开）

**"声主'张'，寻发处见；音主'敛'，寻歇处见。"**

**辨声之法，必辨喜怒哀乐**：
- 喜如折竹、怒如阴雷起地、哀如击薄冰、乐如雪舞风前
- 大概以**轻**为上
- 声雄者：如钟则贵，如锣则贱
- 声雌者：如雉鸣则贵，如蛙鸣则贱
- 上上：远听声雄、近听悠扬、起若乘风、止如拍琴
- 上：大言不张唇、细言不露齿
- 下：出而不返（荒郊牛鸣）、急而不达（深夜鼠嚼）、字句相联喋喋利口、齿喉隔断喈喈混谈 —— 市井之夫

**音**（声之余）：贫贱者有声无音，尖巧者有音无声（"禽无声，兽无音"）
- 开谈多含情、话终有余响 → 雅人，兼称国士
- 口阔无溢出、舌尖无窕音 → 实厚，兼获名高

### 第七篇 气色（面部如命，气色如运）

**四层时间尺度**：
| 尺度 | 内容 |
|---|---|
| 终身 | 少淡、长明、壮艳、老素 |
| 一年 | 春青、夏红、秋黄、冬白 |
| 一月 | 朔后森发，望后隐跃 |
| 一日 | 早青、昼满、晚停、暮静 |

**正色为黄**（科名中人）：黄云盖顶必掇大魁、黄翅入鬓进身不远、印堂黄色富贵逼人、明堂素净明年及第；眼角霞鲜利小考、印堂垂紫获小利、红晕中分定产佳儿、两颧红润骨肉发迹。

**忌青忌白**，但性质不同：
- 青：心事忧劳 → 青如凝墨；祸生不测 → 青如浮烟
- 白：酒色惫倦 → 白如卧羊；灾晦催人 → 白如傅粉
- 例外：青而带紫（金形遇之飞扬）、白而有光（土庚相当亦富贵）

**最不佳者四条**：太白夹日月、乌鸟集天庭、桃花散面颊、赪尾守地阁 —— 有一于此，前程退落，祸患再三。

## 二、《人伦大统赋》（金·张行简，偏"分部断法"）

皇庆二年（1313）薛延年序，称其"芟诸家之冗繁，撮百世之机要，提纲挈领不三二千言，囊括相术殆尽"。

### 总纲与分部次序

**"欲察人伦，先从额上。"** —— 额（天）→ 眉 → 目 → 耳 → 鼻 → 人中 → 口 → 齿 → 舌 → 项 → 背 → 肩 → 指掌 → 胸腹 → 脐 → 足 → 气色。

三才分配：**额为天，颏为地，鼻为人。**

### 基本框架

- **四渎宜深且阔**（耳目口鼻为四渎）
- **五岳必须穹与隆**（额为南岳、颏为北岳、鼻为中岳、左颧东岳、右颧西岳）
- **五官欲明而正**：口、鼻、耳、目、人中
- **六府欲实而充**：两辅骨、两颧骨、两颐骨
- 量化判语：**"一官成十年贵显，一府就十载富丰"**

### 逐部要点

**额（天）**
- 偏狭 → 贱夭；耸阔 → 富贵
- 伏犀骨起（印堂至天中隐隐骨起直入发际，光泽无破）→ 公侯
- 额道纹（左右横直如刀痕，别无纹理冲破）→ 军帅大将
- 日月角为父母宫：**左为日角为父位，右为月角为母位**；右偏妨母，左偏妨父
- 山林（天仓上）丰广 → 多逸豫；边地（驿马上）缺陷 → 凄怆
- 覆如肝、立如壁 → 寿福繁；耸若角、圆若环 → 食禄无量
- 丰隆明 → 早达；卑薄暗 → 死无所葬
- 福堂（眉上）气黯惨 → 幼岁多屯；驿马前色黄光 → 壮年受赐
- 乱纹薄额纵横相交 = "曲水漫浪" → 贫薄孤独
- 鼎足三峙（伏犀+日月角俱起）→ 三公；牛角八方（八骨齐）→ 通达八方

**眉**
- 眉宇宽广 → 心田坦平
- 眉骨低凹 → 狠愎；陡高 → 狂狷
- 粗浓浊厚 → 愚钝；疏秀有彩 → 聪慧
- 短不及目 → 贫贱；长能过眼 → 宠荣
- 尾散 → 资财难聚；头交（毛侵印堂）→ 身命早倾
- 中间直断 → 惠性少；两头高仰 → 壮气横
- 毛直 → 性狠；毛逆 → 祸生
- 覆目软柔压眼 → 少断；偃月高揭 → 好争
- 眉头促锁、印堂终日不开 → "鬼形"，伤短命
- **眉长及寸 = 寿毫，四十以上生者得寿考**
- 印堂纹：十字 → 高位；天字 → 一生亨通；坤字 → 禄二千石；土字 → 将百万兵；玉田 → 列土分茅；水鸟 → 纡朱曳紫

**目（神之所游）**
- 贤良 → 澄澈若水；豪俊 → 神和惠而黑白分明
- 性端正 → 平视无颇；情流荡 → 转盼不宁
- 瞳子黄润 → 至黄发之寿；白干不秀 → 终白衣
- 神陷 → 短寿；睛凸（蜂目）→ 极刑
- 斜盼 → 遭毒；凝视无力 → 自克其形
- 淫眼 → 神荡；奸心 → 目若尘垢蒙深
- 睡眼（神浊如睡）→ 夭寿；惊眼（视物急而惊）→ 暴死
- 病眼（困倦如久病）→ 无远寿；醉眼（神昏如带酒）→ 服毒死
- 上等：豁如视而有威（名扬四海）、迥然惊而不瞬（神耀三清）
- 贱目举例：犬（荒淫）、羊（招祸）、鹅鸭（不善终）、鸡鼠猴蛇
- 豕视 → 心术不正贪多欲；狼顾（回顾而身不转）→ 性狠怀杀心，"绝不可交往"
- 后尾如刀裁 → 文章博雅；前瞳似曲钩 → 智足经营
- **女相另论**：和媚有常者贵重；圆凸不秀者贱轻；眼长为贵；睛莹澈多贞；眼下气青夫必丧；尾后色白男必憎；三角多嗔；四白带杀
  ⚠️ 此节性别偏见最重，属时代观念，不可用于评价现实中的女性。

**耳（心肾之司牧，又为禄星）**
- 垂珠朝海 → 延算余财；偃月贯轮 → 朝王执玉
- 圆成 → 和惠；偏缺 → 惨酷
- 薄如纸 → 贫早死；坚如木 → 老不哭（多吉少凶）
- 白或过面 → 声誉飞腾；莹且如轮 → 信行敦笃
- 似猪（大无轮廓又无垂珠）→ 愚钝贪婪；似鼠（小而有廓无轮）→ 多疑能积蓄
- 轮靥明 → 假学则贵；孔毛长 → 善持不覆（寿考）
- 似猴（尖而向前、耳门窄）→ 性谲诈难测；似鹿 → 有呼群之义（能与人共用）
- 薄而向前 → 卖尽田园；反而倒后 → 居无室屋
- 昏暗 → 寒士无禄位；焦枯 → 肾气不足家贫
- 寿越眉兮贵（耳过于眉）、色鲜如血者位高、明润者聪明、贴肉者殷富
- 轮靥生黑子 → 智足经邦；耳门骨藏丰满（匿犀）→ 封爵之臣

**鼻（嵩岳居中，天柱高矗）**
- 梁贵丰隆实贯额，色贵莹光溢目
- 窍小 → 悭劣；头低 → 终身无子孤独
- 斜如芟藕 → 困乏；圆若悬胆 → 荣食鼎禄
- 青黑多凶；黄明广福
- 柱缺 → 终身难进；梁断 → 三十当畏（用贾谊见鵩鸟典）
- 大而滞 → 商旅奔波；小而狭 → 早离父母作僮仆
- 极贵之色似老蚕之光明（"人将发，自准而明，然后通于诸部"）
- 准头隆 → 诚信；法令深 → 严肃有寿
- 尖薄 → 多病；兰台（鼻翼）小缩 → 悭吝
- 兰台明 → 家财殷实；井灶（鼻孔）露 → 厨无粟
- 鼻骨横起 → 不可为友；鼻上纹理乱交 → 诡行，父子不同心

**人中（沟洫之象）**
- 深则疏通，浅则迟延
- 浅短 → 绝嗣夭命；深长 → 宜子遐年
- 有靥（黑子）→ 其母产难；横纹截断 → 饿死途中
- 上狭下广 → 多后旺；下狭上广 → 屡孤眠
- 深长 → 诚信著；宽厚 → 功名先
- 微如一线 → 死填沟壑；如破竹之仰（长远有棱理）→ 家世高贵

**口（语言之钥，是非之关）**
- 端厚寡辞 → 免辱；诽谤多言 → 招愆
- **口若四字 → 乘肥马衣轻裘；口大能容拳 → 出将入相**
- 唇欲厚、语欲端、音欲朗、色欲鲜
- 上下纹交 → 子孙众；周匝棱利 → 仁信全
- 色如血 → 有殷富之资；如括囊 → 贫寒孤苦；含丹 → 多艺（一说孤寒）
- 合势欲小，开势欲宽
- 食物如谗狗狼餐、饿马啮草、鼠蜂偷食 → 皆下贱之相
- 大言寡信者唇略绰不收；偃蹇者无机巧又夭寿
- 青黑 → 祸发；黄白 → 病缠
- 左右纹粗 → 凶恶；上下急荡（不语而唇自动）→ 多屯
- 如鸟啄 → 难与交；同剑镡（口型方正）→ 义士可与交欢

**齿（观寿算）**
- 康宁 → 齐且密；贱夭 → 疏不连
- 上覆下 → 少困；下掩上 → 晚鳏
- 白若瓠犀 → 文章（班马之才）；莹如昆玉 → 寿考（乔松之寿）
- 当门二齿（内学堂）缺 → 命蹇没世；全而大 → 名闻普天
- 焦黑 → 困乏；鲜明 → 钱足
- 二十四齿疏不连 → "鬼形"主夭；三十六齿 → 长年
- 尖若立锥 → 乏衣食；齐如编贝 → 登廊庙

**舌**
- 短少薄钝为下，长大方利为先
- 方长 → 咳唾成玉（文高四海）；短小 → 皂隶执鞭
- 黑子（靥）→ 多凶恶；有粟粒 → 居官食禄
- 色黯紫 → 布衣露肘；鲜明光莹 → 腰金之贵
- 七星理（七靥）→ 享千钟之禄；三川纹 → 食万户之田

**项（颈）**
- **瘦人项短 → 致灾殃；肥人项长 → 必夭横**（这是"匹配"逻辑，不是单一好恶）
- 如罂如瓶 → 凶；似鹅（太长）似豕（太短）→ 皆不善终
- 丰圆厚实 → 多财产；光隆温润 → 足权柄
- 瘦人结喉 → 身孤；肥人结喉 → 刑克
- 项后丰起 → 厚福；颔下绦垂 → 遐龄

**背**
- 贵在丰隆，与身体上下相称
- 贫夭绝嗣 → 偏侧欹斜；富贵有后 → 阔厚平正
- 势若踞山之蹲虎 → 利宾于王（王佐之才）；形如出海之伏龟 → 考终厥命
- **龙骨（臂）欲长而充实，虎骨（膊）欲短而坚硬；上壮下细为"龙吞虎"，下壮上细为"虎吞龙"**

**肩**

**指掌**

- 足底弓刀纹 → 家富累千金；鱼鸟纹 → 官高封一品

**气色（总收）**
- **"在皮上者谓之色，皮里者谓之气"**；气"如粟、如豆、如丝、如发，藏于纹理之中、隐于发毛之内"
- 辨四时之气"如春蚕吐丝之微微"；察五方之色"如浮云覆日之旭旭"
- 地阁明 → 饶田宅；天岳暗 → 罹桎梏
- 粟黄缯紫 → 多豪贵（青龙之气）；脂白晙青 → 合贤淑

### 赋末歌诀（整本的浓缩）

> 形滞之人行必失，神滞之人心不开，气滞之人言必懒，色滞之人面尘埃。形神气色都无滞，举事心谋百事谐。
> 色在皮而气在血，脉聚作成多喜悦；散则成忧静则安，部位吉凶皆有诀。

**"滞"是全书的总病**——形、神、气、色四者，只要有一个"滞"，就出问题。反过来，四者无滞，诸事顺。这个框架比任何单个部位的说法都更接近可用的观察维度。

## 三、两书怎么配合用

| 用途 | 用哪本 |
|---|---|
| 快速形成一个整体印象 | 《冰鉴》神骨 + 情态（先看神，再看临场反应） |
| 要逐部位细看 | 《人伦大统赋》 |
| 判断能不能深交 | 《冰鉴》第四篇三种时态（这是唯一可放心用的部分） |
| 判断气色状态 | 《冰鉴》第七篇（四层时间尺度）比大统赋更系统 |
| 理解古人"取士"逻辑 | 《冰鉴》（曾国藩是实务家，他的标准偏行为） |
| 理解相术的完整体系 | 《人伦大统赋》（三才、四渎、五岳、五官六府是全框架） |

## 边界

1. **见文首"先读这一段"**——相术不能用于评价他人，这是本技能的第一约束。
2. **文本性质**：
   - 《冰鉴》题曾国藩，学界对其作者归属有争议（多认为是后人辑录托名），内容为清代相术的"文人化"版本，几乎不谈吉凶祸福，专讲气象与识人，与其他相书风格明显不同。
   - 《人伦大统赋》金代张行简著，元皇庆二年（1313）薛延年作序并注，是相术史上体系最完整的赋体著作，历代注家众多。本库文本含"音注集解"部分混排，非纯原文。
3. **两书的内在矛盾**：《冰鉴》明说"他家兼论形骸，文人先观神骨"，暗贬部位断法；《人伦大统赋》恰恰是部位断法的集大成。两者方法论不同，不要混着用同一套结论。
4. **文本缺陷**：《人伦大统赋》个别字有 OCR 讹误与缺字（"蜣□""如□血""曌"等），原书所附六幅面部图在本库文本中缺失（只有文字），无图则部位定位无法精确复原。引用缺处标注不补。
5. **时代性内容**：文中"僮仆""皂隶""贱相""孤寡""妨母"等表述，以及关于女性、齿数、残障的断语，属宋元明清社会观念，保留供研究，**不代表本技能立场，不可转述用于现实评价**。
6. 相术不是科学，外貌与人格/能力无可靠对应。任何据此作出的判断都缺乏依据。
