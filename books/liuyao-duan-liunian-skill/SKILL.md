# 六爻断流年（曲炜）

取材：《六爻断流年》（曲炜著）。作者自述其流年法在《六爻详真》中仅略述，本书专披露多年流年实战经验。结构：起卦要求 → 推断程序 → 信息取象 → 吉凶判断 → 应期 → 六个完整流年卦例。与 liuyao-fenlei-zhanduan-skill 的"流年逐月推法"互补（那本是李顺祥/入门教材的框架，本书是曲炜的完整操作流）。

---

## 一、起卦要求（流年卦专用）

- **意念**：求测者双手扣钱，静心默念「×年各方面运气如何？」三次以上再摇。意念必须是**疑问句**，不能是「我×年肯定好」这类肯定语。
- **环境**：不受外人干扰，最好预测师与求测者单独一室；摇卦中不交谈、不听人说话，全程意念集中。六次连摇，钱撒硬质平面让其自动滚落，不手按阻挡。
- **装卦**：沉稳；先把起卦年月日准确写在卦例上方，再装卦配六神。

## 二、七步推断程序

1. 先看**世爻**（一卦之主）：旺衰、是否逢空入墓——直接揭示卦主能动性与运气高低。
2. 看**动爻**：何爻发动、旺衰、与世爻关系、生克到何爻。
3. 查**暗动**之爻：与世爻向背、生克到何爻。
4. 最后看**静爻**：旺衰与受生受克程度。
5. 结合爻位、爻象、六亲、六神组象断具体吉凶与应事。
6. 断应期（以月为单位）。
7. 需要时提趋吉避凶方案。

## 三、按身份定看点（有的放矢）

- 公职人员：财、官运、身体平安、婚姻、六亲。
- 老年人：身体、六亲为主。
- 平民百姓：财、身体、六亲、婚姻（不看官运）。
- 了解越多断越细：知道他是开车的，世临白虎被冲克就往车祸断；当官的不怕官鬼持世；从文的兄弟持世父母生之反主文上有喜。**不熟识的人先做必要交谈**（说明理由，求测者一般配合）——不了解实况只能断大概吉凶，了解后才能信息定位断具体事。预测师是"命运医生"，求测者提供"病历"最受益的是自己。

## 四、信息取象（六亲＋世爻）

**世爻**：代表卦主。旺＝能动性大、运气高；衰＝能动性差。世动＝一年积极主动参与事务。**何爻持世，一年主体就体现该爻之象**。动爻冲克世爻＝该爻代表的人事物对卦主不利；生合＝带来好处。

- **兄弟**：劫财阻隔。兄动＝多破耗、办事多枝节；**子孙同时发动反为喜（财路源长）**。象：投资破费、分财合伙、帮助协助、克妻分离；临朱雀动＝争端口舌。兄生世也有好信息但必劫财（除非子孙动）。兄持世＝求财心切、易投资或合伙求财。
- **子孙**：福神、财源、平安、无忧。克官之神——**当官之人忌子孙动（剥官削职）**，平民与生意人最喜（财源广进）。象：旅游、运动、变化、表达、玩乐、排忧解难；人物为子女小辈下属。无官之人子孙持世旺＝一年平安；**女人求测子孙持世不利丈夫**（克夫、不和、分离）。子孙持世若有动爻克世，反主不平安。
- **妻财**：钱财、家产、效益、利润、物质享受、欲望、女人妻子。财动生世＝得财方面益处；财动克世＝因财/女人/生意带来压力伤害。
- **官鬼**：名誉、地位、职位、压力、祸端、小人；官方、政府、法院、领导、老板、管束者；管理、税收、检查；盗泄财爻＝花销、收费、消耗。官生世（公职）＝升职或事业好变化；官克世＝祸端、犯小人、受训斥。**官鬼持世身不安**（平民主忧虑不安），但卦中有财动生世＝财找人、求财易得；公职之人利官持世。
- **父母**：辛苦劳累、文化学习、消耗花费、父母长辈、烦恼麻烦、工作事业单位、车辆房屋契约手续、文书诉讼、子女克星灾难、证件帐目数据。父持世＝一年辛苦操劳烦心；但**文教或公职之人利父持世**，官爻生世则得领导赏识加官进职。
- 组象用"两象定一象"理论收敛。
- **真/假六亲与爻位配合定人事物**：父母爻受克，三、四爻（人爻）受克多主人事之灾；真六亲人有灾；假六亲在五、六爻受克多代表事物（工作、车辆、房屋、契约）。再配六神定具体事象。

## 五、流年吉凶判断原理

- **内因＝主变卦各爻动静组合；外因＝年、月、日**。内因是决定性因素：内因有的事逢流月才引发；**内因没有冲克世爻，即使外因全冲克世，也不会有大灾，顶多不顺**；内因有克世或兄动劫财，即使该爻休囚，逢旺之月必有祸端。内因没有的事，外因日月引发也较轻。
- **流年支是一年的皇帝，主管大象，不能忽视**（除月、日建外必看）。
- 起卦时各爻旺衰是"基准线/底"，主变卦各爻旺衰代表现在时、卦主现状。
- 没大事也有小事：从身体到六亲、财运到事业、想法到得失逐一推断——平淡也是实际内容，不要硬找大事。

**病伤官非明显标志**：
- 被发动的白虎爻所克、或某爻临白虎被克 ＝ 病伤灾明显信息。归属看被克六亲：父＝长辈、子＝子女晚辈下属、兄＝兄弟姐妹朋友同事同学、财＝妻子女人、世＝自己、官（女测）＝丈夫。在人爻（三、四爻）或临真六亲被克 → 人为灾的可能性大。
- 朱雀克世＝是非缠身/火灾；玄武动克财＝防丢物被骗被劫；勾陈克世＝田土契约之忧、受牵连、熟人相害；青龙动克世＝酒色之忧（临财生世反主得妻财之喜）；兄动临玄武克世、或财临玄武被变爻克＝**一年不沾赌博，逢赌必输**，非份之财不可取；螣蛇克世或世临螣蛇被克＝小人陷害、受牵连、阴物怪异、官司牢狱、圈套。

## 六、应期（以月为单位）

口诀（源自其《六爻特训班讲义》）：

> **动待合，静待冲；衰待旺，旺待墓；冲待合，合待冲；空待出，墓待破；伏待引，吟待冲。**

运用：
- 测一年财运：财休囚 → 财旺之月得财；财被兄劫 → 待兄受制之时得财；兄休囚发动 → 兄旺之月破财；兄动入墓或逢空 → 出墓出空之月为破财应期；兄被合 → 破合之月应期；财不上卦 → 财出现引拔之月为应（卦中有兄动则破财，无兄动则得财）。
- 其余六亲同理。
- **卦中只有一处病**按上法推；**多处病**须把用神与世爻所有的病都治好时才为应期。
- **断流年出空以月为单位推，不能以日为单位**（例：子孙午火出空克官 → 午月丈夫病灾）。

## 七、流月逐月推法（卦例精要）

逐月看流月地支临何爻、与卦中各爻的生克冲合，结合内因有无引发。规律（据例题归纳）：
- 内因有的爻被流月引动 → 应该爻之事；内因没有的字临月 → 只是思想压力或轻微象，不构成大事。
- 流月冲世 → 必有变动、奔波、改变（逢冲必动，否则有灾）。
- 流月冲动财爻（如未冲丑）→ 钱财流转多，挣了又投，稳不住。
- 世爻进气/值月 → 担财能力加强，是较顺之月；世空之月无所作为，出空后才能有所作为。
- 兄弟旺之月（寅卯）→ 破耗多；兄弟入墓之月（未）→ 不劫财反增财力；抑制兄弟之月（申酉）→ 得财。
- 出空之月：财出空可得财，但忌神同时出空则喜忧参半（财运好而父母/身体不佳）。
- 变爻被合之月冲开 → 印证（戌合变爻卯木，戌月财运好）。

## 八、卦例四则（教训浓缩）

1. **陈某 50 岁测年运**（大过之夬）：世临父母亥水休囚被财动克——因酒色肾虚腰酸（青龙财克水）；财化空化父母临青龙＝挣的钱化作字据没现金，或花钱买房（初爻为地）；巳月子孙冲世＝为投资奔波，未月财被冲＝找房买房，亥月世值月＝财利最好，子月财出空＝机遇压力并存（父亲病），丑月＝最不顺（父病重、己身不佳）。全年逐月皆验。
2. **张女士 50＋测年运**（无妄之履，心脏不好）：子孙持世＝心里求平安（逢空＝对身体没底），旺相＋兄动生世＝千灾万祸化为尘；但女人测子孙持世不利丈夫，寅木动冲官＋官月破入墓 → 丈夫病灾，**午月子孙出空克官为应**（阑尾炎手术）；兄动化进临白虎＝因病破财；财虽有气但内因是破财 → 得少破多。未月兄入墓得财、申酉月抑制兄弟得财（秋收）。
3. **温先生测年运**（山风蛊之鼎）：世月日双冲又自空但无动爻克、有财动生世 → 身体平安；官持世（非公职）＝忧虑不安，幸财动生世反主有利；财动克父临白虎 → 母亲病灾（应酉戌月，实八月住院）；子孙不上卦＝子女不在身边；辰月妻挣钱（财化酉并入世、临青龙＝节日装饰之财），未月冲动丑土＝海边租摊位投资，申月世出空得生才有所作为。
4. **司先生测后半年**（讼之比）：兄持世＝得财也伴口舌官非；子孙戌土变官鬼子水冲克世、官临青龙＝因投资财源之事引起官司（亥子月官值合应期）；世动变财申金冲应上父母、申金出空之月＝丢工作（申月离职）；**两旺相战（世与官皆旺互不服）有口舌纠纷；一方旺一方无气则不讼反为病灾**——断官司的窍门。
5. **王女士测年运**（大畜之明夷）：官持世（非官）＋玄武＝一年不安、暧昧之事；世化兄丑临日建合克财 → 辰戌丑未月破财；上爻官化子孙克官、官旺不服 → 口舌官非由丈夫引起（变爻在上爻本宫）；财临勾陈＝丈夫旧情人；财为世之原神不能伤，初爻足位临白虎被合克 → 丑月脚被车压伤。
6. **沈先生测年运**（讼之观）：世旺动无克＝平安；兄持世临朱雀动＝求财伴口舌；子孙动通关 → 妻子无碍；辰月子孙化兄弟＝合伙投资（承包采石场），未月财进气、申酉戌月财得令最好，子丑月冲开午未之合＝分红争执。

## 九、使用边界与素材缺陷

1. 本书应期口诀与其《六爻特训班讲义》配套，口诀条文简洁、未展开各诀的细分情形（如"吟待冲"的反吟伏吟细分）；复杂应期请与 liuyao-shicao-yingqi-skill 的应期十九法互参。
2. 卦例一（陈某）原文有 OCR 讹字（「巳月」误作「巴月」、「父母爻」误作「父母父/父父」、「妻财」误作「财父/妻财爻」混排），本技能已按上下文校正引用；个别排盘（如例三天泽履）爻位与日辰标注原书即简。
3. 曲炜的"内因决定、外因引发"与姜效龙"内因是根据、外因是条件"同构，可与 liuyao-guosanguan-skill 的有用值判定联用：先用姜法定爻有用无用，再用本书程序推流年事象与流月。
4. 作者强调"了解卦主实况才能断细"——这与射覆类凭卦断不同，流年卦允许并鼓励先访谈后断卦，引用其卦例时注意每个断语都建立在已知条件（年龄、职业、病史）之上。
5. 测流年以年为体、以月为用；若用户只问某月某事，不必起整年卦，走 liuyao-fenlei-zhanduan-skill 的对应门类即可。
