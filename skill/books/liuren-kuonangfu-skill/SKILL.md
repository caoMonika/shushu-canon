# 大六壬括囊赋（略疏·可执行版）

源：本地 `六壬括囊赋略疏--.txt`（GBK可解码全文）。《大全》卷四亦收括囊纲，本篇以略疏的操作链为主。

## 一句话流程

> **先观气势（刚进柔退、明暗）→ 立课体大象（进退迟速）→ 细按类神强弱虚实 → 神将刑害与神煞校正。**

刚者宜进主明，柔者宜退主暗；事之变化不过明暗进退。

## 二、起式法理（赋内）

1. 月将加正时，五行克贼为用。  
2. **内外**：支二课内、干二课外；一三阳（显）、二四阴（晦）。阴发用＝自晦而显，事有意外。  
3. **南北**：贵临亥→辰顺，戌→巳逆。  
4. 来方：常占可轻，兵占与金口「来就成去」宜参；出行去方克行年大不宜；来方吉神将主吉庆。

**八妖**（宅见孽）：直符/飞符、飞廉、天目、火光、天怪、天鬼、游魂(飞魂)、月宿(月煞)。起例从《指南》——飞符甲巳逆…；飞廉正戌二巳…；天目春辰夏未秋戌冬丑；等。俱不宜占宅。

**贵人刑处 / 华盖**：贵失位为殃；华盖（四墓）覆四孟＝废而复起，林下官宜。

## 四、旺衰总则

- 凶神旺则凶「相对可控」之论与「鬼贼当时无畏忌」须分占类；吉神衰则吉无。  
- **旺为人、休为物**；有生气活物、休废死物（勾旺印绶/囚讼禁；武旺失物凶小、休失人凶大）。

## 五、干支尊卑

- 干长上、支贱卑。支克干＝乱首（宜卑不宜尊）；干克支＝残下（利上不利下）。  
- 上下相生＝内外和；将神遇合＝访寻主客怡。  
- 天乙顺利出外、逆利隐避；用在贵后传归贵前＝先昧后显，反之先明后暗。  
- 贵临魁罡＝入狱：仕罢官、讼换衙、已入狱则录囚可放（辰戌日占为贵人入宅非入狱）。贵再诣卯酉＝谒贵动摇他室。
