| 楠曰 | 楠曰：壬生丑日水源深，叠叠财官共拱临。水入巽官寻贵格，陶朱之富异乎人。 |
| 注释 | 注释：冬月水成冰冻，盛寒时也。至后则一阳发动，暖气初生，有火得用，则虽坚冰寒冻，亦可解矣。 |
| 又曰 | 又曰：时土一位贵，藏在支中是。日主要刚强，利名方有气。 |
| 补曰 | 补曰：禄得天时，乃时干得正官，而且见其言之禄，必有奇花金带之荣贵。与上文大同而小异。解谓禄马为官，则是为天时即干，则泛而不切。曰天下，则年月亦在其中矣，于时干，则隐而晦矣。 |
| 歌释 | 歌释：提纲即是月令，先观气候浅深吉凶。官印与财神，忌劫冲刑，衰运逢吉，则为吉断，遇凶则为凶评，生於节气，属何神，贵贱贫富由命定。 |
| 诗释 | 诗释：正官无印本无权，佩印如何又不然。只为印多官泄气，不如乘马得高迁。 |
| 解曰 | 解曰：煞星者，七杀偏官也。制神者，食神也。使月上逢七杀，而有食神降制得宜。又身居强旺之地，则富贵荣昌必矣。若食神逢枭，则食神先自损矣，不惟失其富贵，且有灾殃。所谓食制杀逢枭，不贫则夭是也。 |
