# 许负相法 × 心相篇

旁参：`xiangshu-bingjian-renlun-skill`（冰鉴·人伦）。本 skill 补「汉魏相书条款体」与「德性心相」两极。

## ⚠️ 边界（必读）

1. 外貌≠人品能力；不可用于招聘、择偶、评人、断寿断病。
2. 原文含性别/残障/阶级歧视条款——保留为文献，非立场。
3. 正确用法：古典文献理解；提取可迁移的**行为/德性观察**（心相篇），而非骨相判决。

---

## 一、《许负相法》十六篇结构（形相条款）

序称汉许负撰、明人重录；体例为「部位→短句吉凶」。

| 篇 | 审什么 | 速记倾向（文献义，非科学） |
|---|---|---|
| 相目 | 秀长/龙凤/卧弓/四白/神光 | 目为先；神光与黑白分明最重 |
| 相鼻 | 准洪直、截筒、梁正藏窍 | 准头与梁为财官枢纽 |
| 相人中 | 深长平正 | 主子息寿；漫平短促忌 |
| 相耳 | 高眉、轮廓、门厚、毫 | 高于目眉、垂珠得地 |
| 相唇/口 | 色赤相当、齿齐 | 唇不覆、掀露多忌 |
| 其余篇 | 齿舌眉额颧颐手足等 | 同源「部位吉凶句」体 |

**读法**：先神气与目，次鼻准人中，再耳口；条款互相冲突时，以整体清浊为准，勿一条定终身。

## 二、《心相篇》框架（德性相）

总纲：**心者貌之根；行者心之发。** 审心观行，先于骨格。

可执行对照（文献分类，非诊断）：

| 维度 | 吉向 | 凶向 |
|---|---|---|
| 言语 | 木讷优容、耐久朋 | 反复、尖酸、轻出违言 |
| 待人 | 敬老慈幼、功归人过归己 | 重富欺贫、欺蔽阴私 |
| 处事 | 迟而不急、见机能藏 | 飞扬浮动、喜怒不择 |
| 财义 | 公平出纳、轻财仗义 | 贱买田园、较量锱铢 |
| 性情 | 知足、恻隐、能守患难 | 忮求、乐摘人非、过刚 |

「何知／如何」一节：用**行为模式**解释夭折、恶死、无嗣、火盗、官非——本质是劝善书，不是骨相术。

合观结语：骨格步位与血气精神相辅；**知善守之、知恶弗为**。
