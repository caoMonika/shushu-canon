# 历代占验汇选（精抄本·张容平增补本）案例断法集成

## 一、两书版本

- 《精抄历代六壬占验汇选》：清代程树动等编辑的古案例集抄本，卷一至卷六，按日干支（甲子日、乙丑日、丙寅日……）分系案例，每例载课式+断语+注解。
- 《新编增补历代六壬占验汇选》：张容平补编、李崇仰重注、翔大图书公司印行。增补共收集**六百六十七个占验实例**，囊括《六壬口鉴》《六壬指南》《断案》《方本占案》《苗公达断经》《牧夫占案》《六壬雪心》《大六壬一针见血》《一字诀玉连环》《指归灵文论》《新编日用涓吉指》《青钱秘诀》等古籍案例，另附张容平自验案例。

## 二、案例统一体例（读案例方法）

每例结构：**占日干支+月将+占时+来人年命** → 课式（四课三传+天将盘） → **断语**（来意/吉凶/应期） → **注解**（容平注解/直指析义/一针见血/雪心曰/牧夫曰/彦和曰等各家评） → **验证**（果于某月日应）。

读案例要诀：
1. 先看**来意**：古案多"占来意"，断来意抓"时为日刑日破日马主外动""发用为日财上乘玄武为盗""初传空亡行人未归"等第一眼机。
2. 再看**分事项**断语：天时/婚姻/疾病/行人/出行/官讼/求财/考试/生产/胎产/失物/盗贼/风水各门有固定断口（如"占病制鬼之位乃良医""占行人责玄武及末传""占婚姻贵家女媒妁得力"）。
3. **应期**：驿马逢合日到、冲日应、空亡出旬获、月破应月、岁破应年；"初传×末传×"定快慢。
4. **验证句**（果于……）是断法正确性的锚，回推断语与课象的对应关系。

## 三、来意判断判据（汇选高频）

- 时为日刑、日破与日马并：主外动（追捕/出行/道路事）。
- 发用天魁为日干之财、上得玄武：来意为盗/失财。
- 初传空亡：行人当未归，应在半途；凡事有迟疑之象。
- 发用见六害：虽见生我助我亦为无益，阴阳昏滞——占病沉困、占行人未归。
- 干欲脱支反从中取用：进退不定，彼此欺诳，如市井牙侩。
- 天空乘日禄：来意为失（奴仆/财物）。
- 占时乘日鬼：来意捕盗；乘日禄：来意失物。

## 四、分事项断法举要（从案例归纳）

- **疾病**：白虎乘墓入内门主产厄；干支全伤防两损；虎乘遁鬼殃非浅；制鬼之位（午克酉类）乃良医；天医（正月起子顺行/正月起辰顺行两种）加三传病必可医；病由私情暗约者"失去情而病安"。
- **行人**：责玄武及末传；玄武在辰加丑、末传寅为马当主来；伏吟课逢冲应之，末传乘六合船车动，到日逢合人到；初传空亡半途阻。
- **考试/会试**：帘幕贵人高甲第；朱雀遁丙乘旺主文词华丽；三传递生格合周遍、干支交车生——必中；传将递生主程迁。
- **官讼/官宦**：贵居由上为刑宪；天罡加日本名天狱被他争屋；官贵覆天罗之位（亥空亡）参劾；身宅坐墓必自甘受人欺；龙神克日成弹章。
- **婚姻**：合后占婚宜用媒；系贵家女媒妁亦得力；干支交车相害脱上逢脱盗侵失财而离居；芜淫课（干上神克支支上神克干）夫妻反目。
- **求财/索债**：三传皆财神往来必有因；支上亥水生日——债非不还实因好赌好饮日就衰败，卖屋才能得财。
- **风水**：辰戍重见为石（不可买）；末乘蛇辰戍重见=纯粗石地；伏尸支上临墓虎；来龙山向合法以干支上神合者断。
- **盗贼**：玄武之阴定贼情；游都所临方定贼来方（丑东北/子北）；丙丁日捕人至；两妇人穿绯衣负薪类象法（玄武乘神+地盘定人数方位颜色）。
- **产育**：白虎乘墓入酉内门主母死；天后认了（中传天后）却无虑；三传日同初占行人要来方动。

## 五、古案名家断风（正文多引"某曰"）

- 邵彦和：重课格名目（登三天/天狱/乱首/曲直/失友）与人事对应，断应期精（某年某月兴讼、果于立秋前一日到）。
- 陈公献（指南）：重贵人禄马与官宦格局，"官贵覆天罗""日干支乘墓所为不通"。
- 徐次宾：重来意与先锋（占时/发用），"时为日刑主外动"。
- 苗公达：古经法"刚日先看日上神，柔日先看辰上神"；天医治病应验。
- 王牧夫：重现实情理（淮南盐务/索债卖屋），"此等占古之所无故无成蛇"。
- 雪心：占行人责玄武及末传；连茹主贼不止一人（子数九丑数八故八九人）。
- 一针见血/玉连环/直指析义/方本占案：注解书系，多出毕法赋句（"虎乘遁鬼殃非浅""干支全伤防两损，害贵讼直遭屈断""二贵皆空虚喜期"）。

## 六、应期推定归纳

- 驿马临干支：动之象；到日=马之合日/冲日。
- 伏吟课逢冲应（伏吟主静，冲日动）。
- 空亡：出旬（空亡填实之日）获/应。
- 月破应月内，岁破应年内。
- 三传进（进茹）事速，退茹事迟。
- 初传应初段，末传应归着；"果于某月某日"回推可校准。

## 使用边界与素材缺陷

1. 精抄本（卷一~六）与张容平本（一、二）均为影印 OCR，**循环重复严重**（如"案例一：申时占申为鬼来意为捕盗"重复数十遍、"吉"字表格循环），水印（秘籍网 www.miji8.com/翔大图书公司印行）密布；判据只取可辨条目，重复循环已剔除。
2. 案例断语部分以图像形式印刷，正文 OCR 常将课式盘（地支+天将）打散成乱码表格；本技能提取判据规则，**具体课例的完整课式须回原书核对**。
3. 本技能蒸馏时可辨来源：精抄卷二、张容平本（一）为主；精抄卷一上/下、卷三~六、张容平本（二）为同书异卷，体例一致（已按同书多卷合一体例收录），未获卷目内容以纲代目，缺卷待检。
4. 案例中"容平注解"多为补注（风煞正月起寅逆行十二月、末传胜光不论救神等），已收入判据；"愚按"为编者按语，与古案原断有别。
5. 与 liuren-duanan（邵彦和断案）、liuren-duanan-shuzheng（断案疏正）、liuren-zhinan（指南占验）有案例重叠——汇选是集大成选本，单书全帙以上述专项技能为准。
