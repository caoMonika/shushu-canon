# 六壬神课金口诀·基础体系（《心髓指要》本）

金口诀又名《孙膑神课》，明清题"洞春道人真阳子辑"，清代杨守一精阅、熊大木校正、周敬弦重订；今传以米鸿宾校注《六壬神课金口诀心髓指要》（北京古籍出版社 2004）为善本。它**不是大六壬的分支**，而是另一套独立立课法：不用天地盘四课三传，只用**四位**推断。凡读大六壬者最易犯的错，就是拿四课三传的规矩套金口诀。

## 一、两位一体：先分清"大六壬"与"金口诀"

| 项 | 大六壬 | 金口诀 |
|---|---|---|
| 结构 | 天地盘→四课→三传 | 一地分、二将神、三贵神、四人元 |
| 换将 | **交中气**换月将 | **交节**换月将（关键差异，须死记） |
| 贵神 | 十二天将，随贵人昼夜顺逆布于天盘 | 十二贵神，以地分为落点顺逆数取 |
| 推演单位 | 课传（纵向时间链） | 四位（横向空间 + 三才同现） |

作者考订：金口诀既托名孙膑，实际成书必在"舍式而用符号"之后（秦汉以后），文风亦与《孙膑兵法》迥异，故**非孙膑亲著**，属后人托名或总结。此说可采信。

## 二、四位与三才：立课的全部零件

一课四位，自下（或自上）排定：

1. **地分**——问课人所立／所坐之方。以正北子、正东卯、正南午、正西酉为基准排十二支，每支 30°。取"来人所从之方"或"所坐之方"作地分，是立课之本。
2. **将神**——以月将加于占时，顺数至地分所得之支。将神是"时间之神"，主月日辰。
3. **贵神**——以天乙贵神按日干定旦暮（昼贵／夜贵）与顺逆，数至地分所得之神。
4. **人元**——以**五子元遁**（甲己还加甲、乙庚丙作初、丙辛从戊起、丁壬庚子居、戊癸壬子为真途）从日干遁出。

三才与人事对应（断事第一依据）：

- **人元＝天＝客＝君＝祖＝外**；
- **贵神＝主＝宰相＝臣＝父＝官禄**；
- **将神＝己身＝妻＝财＝亲属＝内**；
- **地分＝地＝田宅＝子孙＝奴仆＝鞍马＝六畜**。

> 断事时"主客"关系随占项翻转：**占身**以贵神为主、人元为客；**求财**则贵神为财、人元为我。这一点不先定好，全课无主。

## 三、消息妙论：解课总纲（全书第一句，须背）

> 凡占课，**入式歌言其大象，五动爻观其大意，以格局看其事体，凭驿马、神煞定其吉凶，以空亡、月破、支干三合六合验其成败**，潜心推测，无不神妙。

即五层顺序：象→意→格→吉凶→成败。跳到"吉凶"而跳过"象、意、格"，则断必乱。

## 四、日干所属与贵神起例

- 十干所属：甲乙东方木、丙丁南方火、庚辛西方金、壬癸北方水、戊己中央土（戊阳土、己阴土）。
- 十二将神（交节换将，固定名号）：亥登明（正月将/娵訾）、戌河魁（二月/降娄）、酉从魁（三月/大梁）、申传送（四月/实沈）、未小吉（五月/鹑首）、午胜光（六月/鹑火）、巳太乙（七月/鹑尾）、辰天罡（八月/寿星）、卯太冲（九月/大火）、寅功曹（十月/析木）、丑大吉（十一月/星纪）、子神后（十二月/玄枵）。
- 十二贵神（按与天乙的前后位排列，各带干支五行）：前一螣蛇丁巳火、前二朱雀丙午火、前三六合乙卯木、前四勾陈戊辰土、前五青龙甲寅木、**中央天乙贵人己丑土**、后一天后癸亥水、后二太阴辛酉金、后三玄武壬子水、后四太常己未土、后五白虎庚申金、后六天空戊戌土。
- **贵神治旦暮**：甲戊庚日旦大吉（丑）暮小吉（未）；乙己日旦神后（子）暮传送（申）；丙丁日旦登明（亥）暮从魁（酉）；六辛日旦胜光（午）暮功曹（寅）；壬癸日旦太乙（巳）暮太冲（卯）。天乙不居魁罡（戌为狱、辰为牢）。
- 顺逆：贵神落在亥子丑寅卯辰一带者顺行，落在巳午未申酉戌一带者逆行；以天门（戌）地户（辰）为界。

## 五、用爻：先定"以哪一位为用"

金口诀无"发用"，而取**用爻**。法有五条：

1. **三阴一阳，以阳为用**，取象少阳，事在男子；
2. **三阳一阴，以阴为用**，取象少阴，事在女子；
3. **二阴二阳，以将为用**，随将之阴阳辨男女；
4. **纯阴反阳，以将为用**——"方内之物"，宜主不宜客、利内不利外，主城郭内藏之物；阳人出外，旧暗新明；
5. **纯阳反阴，以神为用**——"方外之物"，宜客不宜主、和外不和内，主四远所藏之物；阴人还家，新暗旧明。

配套两条铁则：

- **"发用空亡，事多虚假；五动空亡，事多不成。"**
- **用爻落在贵神者，主自己或外人；落在将神者，主自己或内人**。在外求事以贵神为主，在内求事以将神为主。

## 六、五动：断事的主干（必须逐字记住）

动＝克。四个位之间的克，构成五种"动"，各有其歌诀与应事：

- **干克方为妻动**（人元克地分）：主妻妾之事；有官求财防损折；寻人主在家；访人则主人不悦（上隔克下，行必有阻）；外来取索；卑下有口舌；射覆则"论物以翻为正"，器物一边有缺。
- **神克干为官动**（贵神克人元）：利求官，逢驿马必迁转；常人主公府之事；有官者望财难（财动伤官）；官动逢合则官中财物可得；人元受克，事在自己，不宜外求；问病在喉咽。
- **神克将为贼动**（贵神克将神）：主内贼生、勾连诈不明；损财、卑幼病；谋望必无成；架媾奸私；偷攘宛转；内爻受克事主暗昧；病亦不轻。
- **将克神为财动**（将神克贵神）：利求财，占官定不谐；家人出外；身灾非妻妾；疾病难瘥（神受克主病在心胸）；营求喜自来；财物终有损；职位恐退。
- **方克干为鬼动**（地分克人元）：忧灾怪；官亨人出外；争讼事连他人；乖戾因间外（卑逾尊）；口舌喧争；冤仇损害；病在目下领上（仰合）；家宅未安泰。

## 七、三动：不属于五动正数

- **方生干为父母动**——为印绶，凡占小干大，大吉；
- **干生方为子孙动**——主干子孙之事，小吉；
- **干方同为兄弟动**——事在比肩朋友，小凶。

## 八、五合：合看事体共为

- **神与干合为官合**（干神合）：仕人得荣禄，利求官，常人主官事；
- **将与神合为正合**：婚姻欢美、会合亲友；不宜占病；求事有成、互相依辅；
- **将与干合为隔合**：内外相望、有人接引，但因阻隔而事体迟留；
- **将与方合为进合**：共同上路，以卑动尊、以小致大，事成迟缓；
- **方与干合为鬼合**（方克干而克中带合，含纳音支合，如辛纳酉与巳半合）：求官得禄、仕人升迁，但亲属不和、主忧患，占病不宜。

通则：同旬支干相合为"君臣庆会"，异旬相合为"天地德合"。**合中值空亡**→占物则圆而中空，求事则望而难成，且主"合而不合、分而不分，先合后离"。

## 九、格局：三合、虚一、三奇、朝元、俱比

**三合全身（四课）**：
- 寅午戌＝**炎上课**（财帛文书喜美之合），忌亥子水坏局；人元丙则火局全、庚则鬼动克身、甲则相生。
- 亥卯未＝**曲直课**（交易婚姻和会），忌申酉金坏局。
- 申子辰＝**润下课**（行移干蛊争战），忌辰戌土坏局。
- 巳酉丑＝**从革课**（阴阳淫滥轻薄），忌巳午火坏局。

坏局细判：**局上受克为迅速，局下受克为阻隔，局身受克为坏局（事成一半）**。三合全而有妒合（如炎上局见壬癸水）者，主"合而不合、顺中有阻"。

**虚一待用**：三合缺一字即为"破体课"（炎上破体、曲直破体、润下破体、从革破体）。所缺之字在年／月／日／时透出之时，即为**应期**——行人至、谋望成。作者许为"课中之要论，不可不察"（若有日冲、月破、空亡、受制则另详）。

**三奇德秀**：甲戊庚为德全，乙丙丁为奇全，壬癸辛为秀全。三奇全者利见大人、百事吉昌、孕生贵子；正三合顺吉，逆三合则顺中有阻。

**一类朝元**：一干见本属三支（甲见三寅、乙见三卯……）。占主事体重叠、闭伏不动、无荣无誉、阻隔淹滞——因有比肩而无父母官鬼妻财子孙，又无生克发用。**纯火、纯金不作此论**（火有百事凋残之功、金有凶杀之气）。

**四位俱比**（五行同而阴阳不同）：金比主兵丧讼事、邪淫奸私；火比主是非官司、灾祸伤残、怪忧惊恐；水比主家计流移、奸私蛊病水厄、寡妇孤儿、盗侵；木比虽吉而无生——"仁而无恩，有兄弟而无父母，重婚姻而绝嗣续"，求望难成；土比主事体重叠、流延阻滞。

**五比同类**：方比为正比（事在比肩，多不成）、干神比为近比（事在外而干自己）、方将比为远比（事在朋友同类）、神将比为次比（事在门户亲属）、四位比为合比（事在亲属，重叠牵连）。

## 十、克者为无从旺断

**四位俱无克**（不受克者为旺爻）→ 不取用爻，**只取旺神断事**，名"从旺断"。若问某事是否存在，受克则不存在。

## 十一、五行气化与阴阳相生

- **天干五合化气**：甲己化土、乙庚化金、丙辛化水、丁壬化木、戊癸化火。课中不见某行，而神将遁干构成合化者，即作该行论；射覆则物属该类，应期在该行旺日时。
- **不化五种**：受制不化、妒合不化、时冲不化、逢空不化、非其位不化。
- **阴阳相生**：五行最喜阴阳均衡（甲阳木能生丁阴火之类），阳见阳、阴见阴为"阴阳偏枯"，主"顺中有隔、吉中有危"。四位相生（上生下、下生上、内生外、外生内、一生三、三生一）为发用之美端；**虽内有白虎朱雀劫煞魁罡，处相生和气之中，亦"革而顺从、阻隔逢通、遇恶逢善"**。

## 十二、四位生克颂（断吉凶的直接口诀）

> 上克下为人（官事起家内），下克上为出（破财当向外）；上生下则他人征用自己，下生上则自己征用他人。
> 吉能克凶事将空，凶能克吉事难成；方来克将钱财散，将若伤方斗讼生；位来生客己寻人，干若生方人谒己；二上生下财满箧，二下生上子孙兴。
> 凶神受克忧患消减，吉神无伤福庆繁昌；人元不伤争讼理长，人元受制争讼无气；主休客旺我短彼长，位强身弱我忧他乐。

又：**四位相生百事吉，四位相克百事凶；阴多阳少男子事，阴少阳多女子因。**
人元与贵神相克为**外战**，将神与地分相克为**内战**，皆主口舌是非、灾患伤财。

## 十三、应期合德（五法 + 又法）

> 凡课应期最难推测，唯取**合处**为妙。

1. **天地合德**：干支俱合之处为应期（甲子日得戊辰将 → 取癸酉月日时）。
2. **将干近合**：以将干之合取近应（乙日得戊寅将 → 癸日；甲子日得丙寅将 → 辛未日时）。不必待干支全合。
3. **奇合**：三奇缺一字，缺者之日时必应（有甲戊无庚 → 庚日时；与命家"虚拱暗位"同法）。
4. **三合**：缺字透出为应期（寅午无戌 → 戌月日时）。
5. **六合**：将神是寅 → 亥月日时；卯 → 戌；辰 → 酉。占行人望事，旺相带劫煞及田马驿马者，**逢合即至**。
6. 又法：课得前一辰遇丁甲者，三旬以内逢本日将为应期；后一辰遇丁甲者，三旬以外逢本日将为应期。

通则：**冲为动，合为止**；合逢冲即破。"神若得日不出日，得时不出时"——用爻与日支或时支相同者，应期极近。

6. 学派差异并列：金口诀一系"四位三才、五动三动为纲、以合定应期"；北海"类象为核心"（`liuren-beihai-gaoji`）；刘科乐"理气象类与易简"（`liuren-liukele`）；伍剑虹"层次结构与局"（`liuren-jianhong`）。三者不可混参。
