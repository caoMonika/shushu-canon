# 诸葛神数（笔画签）

题诸葛亮；实为民间 384 签诗系统（对应易 384 爻之数）。文献／游戏式检索。

## 占法（编码层——可执行）

1. **报字**：必须三字，不可二／四。
2. **笔画编码**：
   - 第1字→百位，第2字→十位，第3字→个位。
   - 笔画 ≤9 照算；≥10 则减 10（或减 20）取个位；恰 10／20 作 0。
3. **收束到 1–384**：总数 >384 则反复减 384，直至 ≤384。
4. **查签**：以所得数为签号，读该签诗。

**例**：林(8)山(3)冲(6)→836；若超过则减 384 至落在 1–384。

## 签诗性质

源本收录大量四言／七言签诗（如「天门一挂榜…」「地有神…」）。断事仅文学隐喻；同一签可作多种附会——**有效性不可校验**。

## 与铁板神数区别

| | 诸葛神数 | 铁板神数 |
|---|---|---|
| 输入 | 三字笔画 | 生辰取数 |
| 输出 | 384 签诗 | 号称万条条文 |
| 校正 | 无系统考刻 | 有考刻改输入（见 tieban-shenshu-skill） |

## 边界

娱乐／文献检索；勿用于婚丧、医疗、财务决策。
