# 增订医方歌诀 · 蒸馏技能

**来源**：《增订医方歌诀》，清·王泰林撰
**体例**：每方先歌诀后按语——歌诀记组成主治，按语引经据典释方义，间采柯韵伯《伤寒来苏集》、喻嘉言、王晋三诸家
**覆盖说明**：本次蒸馏覆盖补益、发汗、攻下、和解四类之可辨读部分；和解之剂以后原文缺失或文字错简严重，未入。
**文字质量声明**：所据文本为扫描解析件，个别行文字序错乱（如桂枝汤条），蒸馏时已按文意重理，引用原文请核原书。
**使用边界**：古籍文献参考，不构成医疗建议。

## 一、本书读法

1. 歌诀中的括号即按语：`( )` 内为药量、出处（《金匮》《伤寒论》《局方》《本事方》等）与方义
2. 王泰林按语的典型风格：**先引原文 → 指摘错简 → 辨病机 → 定治法宜忌**（如越脾汤按语先指"《金匮》风水一门证多错杂"）
3. 读本书可得其**水气病治法框架**（见第四节），这是全卷最系统的部分

## 二、补益之剂

### 麋茸丸（《普济本事方》，许叔微）
- **主治**：小便失禁
- **组成**：麋茸一两（鹿茸亦可）、羊肾二对（酒浸煮烂）、苁蓉、麋茸、五味子、鸡内金、附子、桑螵蛸
- **方义（按语）**："失禁诸方多用涩，惟此独得寻源计"——古方固涩或兼通太阳，究非寻源探本；小便不约则**三焦俱澈**，当**举督脉之阳以保护诸阳之气**，故麋茸为必需；然必佐芳香入阴之品（茴香、杜仲、破故纸）乃能抵下焦而升阳
- **方法论**：涩剂治不了的三焦气化失职，改用温补督脉+芳香入阴——"升举"与"入阴"并用

### 柴胡四物汤
- 熟地、川芎、当归、白芍各钱半，人参、黄芪、甘草各三钱
- **功用**：疏通少阳、和卫调营——疟久血虚、产后感邪调补之剂

## 三、发汗之剂（水气病治法精华）

### 越脾汤系列（《金匮要略》）

| 加减 | 主治 | 病机要点 |
|---|---|---|
| 越脾汤（原方） | 风水恶风、一身悉肿、脉浮不渴、续自汗出无大热 | 风为阳邪，肺脾胃三经受风热闭郁汗液——非真水病，是"风中肌肤，津气不行" |
| 越脾加术汤 | 里水一身面目黄肿、脉沉、**小便自利亡津口渴** | 里水当分利，但小便自利则里已无水、水在皮中，惟有发汗一法；加白术实脾胜水止渴——**权变之法** |
| 越脾加半夏汤 | 肺胀咳而上气、喘、目如脱状、脉浮大 | 温邪挟饮填肺；越脾散邪多蠲饮少，故加半夏辅其未逮；脉浮大属阳邪，故用辛寒不用辛热（此其所以不用小青龙） |
| 桂枝二越脾一汤 | 太阳病发热恶寒、热多寒少、脉微弱 | **脉微弱无阳者不可发汗**；柯韵伯：必兼烦渴、脉不微者宜之，且仲景言"无阳"则必不用麻黄石膏，此汤可用柴胡桂枝汤代之 |

### 水气病总诀（按语提炼）
> 恶风无汗汗之宜，小便不利利之是。脉沉虽寒必温经，脉浮而下须兼使。

- 脉沉属少阴：用**麻黄附子汤**（甘草麻黄汤加附子）——熟附温肾固液，"不使麻黄深入肾经劫液为汗，则水去而汗不伤阴"
- 脉浮在表当发汗，若兼小便不利则**兼解其表**（五苓散之属）

### 甘草麻黄汤
- "水病发其汗即已"——麻黄得甘草引入中焦，散水和脾，**取水谷之津为汗**
- 王泰林注此深得"厥旨"

### 三拗汤（《局方》）
- 麻黄留节、杏仁去皮尖、生甘草——"发中有收、取其发、取其涩、补中有发"
- 主治：感冒风邪、鼻塞咳嗽痰多胸满气短

### 仓廪散（人参败毒散加陈仓米）
- 主治噤口痢（下痢不欲食）——胃中湿热蕴蒸清道；人参败毒升清化浊，陈米充脾胃之气
- 变方：人参石莲汤；痢后大渴脾气虚→单煎陈米汤（王肯堂《证治准绳》）

## 四、攻下之剂

| 方 | 要点 | 宜忌 |
|---|---|---|
| 海蛤散（《本事方》） | 治妇人伤寒**血结胸**膈痛不可近 | 鸡子清调服不伤肺胃之阴——"伤寒邪热炽络、血痹着上焦之良治"；王海藏桂枝红花汤加海蛤桃仁"总不如此方之妙" |
| 结胸灸法（《本事方》） | 巴豆十四枚+黄连七寸和成膏填脐心艾灸，腹鸣响则结胸消 | "凡胸中病俱可根据此为治"；灸后以温汤浸手帕拭之恐生疮 |
| 十枣汤 | 芫花、甘遂、大戟等分末，大枣十枚煮汤；下利胸胁痞硬痛、汗出短气干呕 | 仲景利水之最峻者；**羸弱虚人勿轻掷** |
| 小胃丹（《丹溪心法》） | 老痰顽痰壅塞胸膈、喘急便秘 | 药力甚猛，壮实人痰饮最宜，老弱均忌 |
| 三一承气汤（陶节庵） | 合三承气为一重用甘草，**攻补兼施** | "最得仲景之秘"；加柴胡黄芩铁锈水名六一承气，坠热开结 |
| 黄龙汤 | 热结利（胃有燥屎口渴反下利清水）——三一承气加人参当归桔梗姜枣 | 阳明实证兼体虚；年老气血虚者去芒硝 |
| 黄龙汤（《活人书》） | 小柴胡去半夏姜枣 | 治妊娠寒热如疟、产后伤风、病后劳复热不解 |

## 五、和解之剂（桂枝汤类，文本有错简，按文意重理）

### 桂枝汤（"和方之祖"）
- 组成：桂枝三两、芍药三两、甘草二两、生姜三两、大枣十二枚
- 方义：桂芍相合，一散一收——桂枝**外而引之入阴则汗止**，芍药**内而散之归阳则寒除**；"安内攘外"之剂
- 按语引柯韵伯：此方治**头痛发热汗出恶风**者，无论伤寒杂病、有汗无汗（表实者加麻黄），但见此症即服

### 禁忌与变方（按语提要）
- 服桂枝汤吐者（酒客病）→ 不可与；内热者先治内热
- 桂二麻一汤、桂二越脾一汤：脉弱者减发
- 芍药甘草汤：治伤寒脉浮自汗恶风**脚挛急**——"阴虚筋急"

## 六、王泰林学术要点（蒸馏者提炼）

1. **辨原文错简**：反复指《金匮》水气门"证多错杂"，读者"自会之可耳"——不盲从古经
2. **重权变**：里水用发汗、固涩改温补，皆"正法之外有权变"，权变的判据是病机实况（小便自利与否、津之亡否）
3. **剂量与炮制入歌**：麻黄留节"发中有收"、甘草生用"补中有发"——药性细节即治法
4. 引诸家而不盲从：采喻嘉言"无阳即亡津"说、王晋三"阳分亡津"说，又引柯韵伯"宜用柴胡桂枝汤为恰当"——并存异说，留判于读者

---

## 七、使用要点

1. 答"越脾汤"类问题必带**加术/加半夏/桂二越一**的鉴别矩阵（第三节表）
2. 水气病四句总诀是检索钥匙：无汗→汗、不利→利、沉→温经、浮→兼表
3. 本书按语是清代经方研究的"文献综述"式写作，考据提问引它比背歌诀更有价值
4. 凡引方药注明清代剂量与炮制（如麻黄留节），并保留"不构成医疗建议"边界
