# 天元五歌（蒋大鸿）

## 大义

墓宅对参：两兴鼎盛，两废断烟；宅凶墓吉后劲，墓凶宅吉眼前欢。大地勿误求；真结在一枝一泡、一钩一曲。

## 山龙

先识起与断；不起顶非真龙穴；正龙正下。权法：接气（穴后突紧粘）、骑龙斩气（腰停凑身）。四忌：空窝、平坦、天风劫、龙胁背。山上龙神不下水——勿用三合长生硬套山。

## 平洋水龙

不可套山法。以水为龙；水行有转是真结；息道真，角转空。坐水骑龙上，忌漏道；下穴贴水。惟天玉是真经；水葬旺运速应。

## 阳宅纲

三门八卦排；引三元生旺入室；改路不轻易改门。细作见宅法举隅技能。

## 流程

分山/水法 → 山看顶晕正下或接气骑龙 → 水看转息贴水元运 → 墓宅对参 → 细排转天玉/辨正

## 边界

驳三合玉尺须标明派系；术数非可验证因果。
