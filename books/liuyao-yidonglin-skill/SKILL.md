# 重订易洞林（晋·郭璞撰，嫏嬛馆补校，虎易注）

《玉函山房辑佚书》本整理，收入《续修四库全书》。三卷＋补遗，20 例为主，附现代六爻排盘（整理者补）与"霍氏小成图"（新发明排盘，中宫＋九宫箭头）为参。校勘用蓝字（据《易学启蒙翼传》《晋书·郭璞传》《太平御览》《广记》《初学记》《说郛》互校）、注释红字，参考尚秉和《周易古筮考》。

## 一、断法特征（与纳甲六爻不同源）

1. **林辞占**：韵语占辞（"朱雀西北，白虎东走，奸猾衔壁，敌人束手"），以卦象互卦拆解林辞——离为朱雀在西北、兑为白虎在东，乾金在兑口中＝玉在口。
2. **象占互体**：随卦上兑为虎、二至四互艮为山石＝"虎在山石"；震为马在下＝"马过其左"；升卦"升虚邑"卦辞直接定断（贼不来）。
3. **卦辞参断**：泰"拔茅茹以其汇，征吉"、既济"小狐汔济，垂尾濡尾"、否"天地不交"。
4. **神煞月建**：虎刑（子月在午为鬼）、杀阴（四月在申）、龙德（十二月在艮）、天医（六月在卯）——按月令神煞定位断病断凶。
5. **应期**："气废"（立春卜得小过之坤，旺气变入坤而废）、变爻定年（"乱则何时时建寅"＝寅年）。

## 二、名例速览

- **避乱系列**（卷上）：普卜郡内皆明夷→举族南渡（日没地下之象）；同人之革无咎；随之升走焦邱险道（"虎在山石马过其左"，候一月后果验猗氏合城覆没）；泰卦前驱脱险；既济"秋吉春悲"（世亥水秋金生吉、春木生火煎水凶）；否卦"僵尸交林血流漂"→留安丰者春三月遇害。
- **医占厌胜**：遁之姤伤寒"谁能救之坤上牛，若依子色吉之尤"→求白牛不得，果有大牛自来，病愈；贲之豫"自然奇救宜飱兔"→食兔心痛而愈；临之颐"卯与身世并而扶天医"→食兔瘥；蹇卦妇病→东北田家黑狗代患死，凡三养三死而妇瘥；大过之升"法由斩祀杀灵蛇"→访知先世杀大蛇，女病数十年。
- **物怪射覆**：遁之蛊断驴鼠（"艮体连乾，其物壮巨……是为驴鼠"）；射茱萸（"子如小玲，含元珠构支"）、蚕蛾（"虫蛾及毛蠹"）、镊（"非簪非钗，常在领下"）。
- **国家祥瑞**：咸之井"东北郡县有武名者当出铎，西南有阳名者井当沸"（武进得铜铎六枚、历阳井沸）；豫之睽"会稽当出钟"（剡县井中得钟，铭"会稽岳命"）。
- **杂验**：王导震厄截柏树挡灾；慎曜伯妇病东北黑狗；柳休祖妻鼠瘘→姓石者灸鼠愈（"当得人师姓石者"）；宏景则姊病取独蹄猪（乌为日禽、猪为月畜，水火相忌）；殷鸿乔"慎勿与许姓共田作"；赵朔射履之四"子归有逸豚"。

## 三、可借鉴的实断思路

- 危难集体决策用占（逃亡路线）：全卦类象＋卦辞＋林辞三重锁定。
- 医占：病爻＋神煞（天医/虎刑）＋**厌胜物**（牛/兔/狗/猪）择象化解——象与生肖地支配应（丑牛、卯兔、戌狗）。
- 射覆：物之形质取互卦与六兽（兑口含乾玉、艮手倒震木工）。
- 应期：月建神煞所临之支、变爻之年、"气废"节气。

## 使用边界与素材缺陷

1. **辑佚本**：原书散佚，本文从《晋书》《御览》《广记》《初学记》《说郛》等辑出，异文繁多（虎易注逐一标注"某本作某"）；《说郛》误收《参同契》"日为流珠"条，存疑照录。
2. 断法为晋代象占＋卦辞＋神煞体系，**与纳甲六爻（六亲用神生克）不同源**；书中现代六爻排盘与"霍氏小成图"均为整理者后加，仅供参考，非郭璞原法。
3. 部例涉及国运祥瑞（铜铎、钟、群鹅），史书润饰成分难辨；补遗中《晋书》撮引与洞林原文互有出入。
4. 庆胜（白牛/兔/狗）属古代民俗医疗观，作史料理解，不作现实医嘱。
