# 葬法倒杖（临穴技法）

## 流程

认太极 → 分两仪 → 求四象 → 十六葬法 → 倒杖十二 → 二十四砂葬法

## 太极 / 两仪 / 四象

- 圆晕在隐微间为太极；无晕非穴；三轮大地
- 凹=阴穴，凸=阳穴；阴龙宜阳穴，阳龙宜阴穴
- 脉取中、息剖开、窟培高、突凿平

## 十六葬法

- 高山阳龙（脉）：缓盖、急粘、直倚、横撞
- 高山阴龙（息）：斩截吊坠
- 平地阳龙（窟）：正求架折
- 平地阴龙（突）：挨并斜插
- 倚≠挨（脉直 vs 突平）；撞≠插（脉斜 vs 突旁）；顶薄舍盖、下薄莫粘

## 倒杖十二

顺（缓正受）逆（急旁求）缩（急盖顶）离（虚粘平洋）没（俯饱沉葬）穿（仰口侧插）斗（横体贯腰）截（直体骑截）对（刚柔交接）缀（麓缓实粘）犯（饶龙减虎）

## 二十四砂（名即象）

担伞正葬打开悬棺垒坟剜蓝马鬣回龙骑龙拿扯停驿斗斧担凹抱儿吞吐浮沉牵牛就饱伤饥撞穴插木牵弓等——按缓急乳突堂气选用；案湾如张弓吉、反弓凶。

## 边界

前提龙真有晕；开挖合法规；术数非可验证因果。
