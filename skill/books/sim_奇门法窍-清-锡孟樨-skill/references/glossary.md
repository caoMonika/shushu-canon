# 术语表 — 《奇门法窍-清-锡孟樨》

| 术语 | 上下文线索（OCR） |
|---|---|
| 门反 | 就中伏吟为最凶，天蓬加着地天蓬，天蓬若列天英上，须知即是返吟宫，八门反覆皆如此，死在生兮生在死，假令吉宿得奇门，万事皆凶不可使。 |
| 奇墓 | 九遁凡用事谋为，惟最忌奇墓刑迫。 |
| 门合 | 戊加壬，为龙入天牢，凡占一切皆不利，门制更加凶，三门合，唱奏凯归（又为青龙破狱格）。 |
| 奇合 | 龙鸟格逢庚直符则应以凶论，然遇凶门则然，若遇休生开三吉门又逢旺相，仍以吉论，不必尽拘升殿游禄奇合论格，惟奇家最宜之格，须遇吉门用之尤验。 |
| 地假 | 杜门合丁己癸临九地为地假，宜潜伏、捕捉、修炼；临太阴宜遣人间谍、侦探等事；临六合宜逃亡、躲灾必难。 |
| 仪合 | 乙庚、丙辛、丁壬为奇合，戊癸、甲己为仪合，得吉门百事谋为有和合之象，行兵宜励士气、申盟约、招抚纳降吉。 |
| 巽离 | 壬午时。巽离（门反）乾（大格）中（地网）。 |
| 乾坎 | 乙丑时。兑（天遁、真诈）乾（地假）离（相佐）。乾坎（门反）坤（刑格）乾（投江） |
| 妖蹻 | 癸加丁，为腾蛇妖蹻，文书官司，大禁莫逃，三门若相合，谋为得半祥。 |
| 猖狂 | 六癸加丁蛇妖矫。六丁加癸雀投江。六乙加辛龙逃走。六辛加乙虎猖狂。请观四者是凶神，百事逢之莫措手。 |
| 荧入白 | 庚为太白丙荧惑，庚丙相加谁会得，六庚加丙白入荧，六丙加庚荧入白，白人荧兮贼即来，荧入白兮贼即灭。 |
| 艮震 | 以天任落艮震宫，主丰，不落者，为歉。以贵神月将分旱涝，又伤门为麦，生门为谷，蛇雀巳午为旱，传送天后为涝。 |
| 坤兑 | 丁卯时。离（奇合）巽（门合）艮（地假）。坤兑（门反）。 |
| 白入荧 | 庚为太白丙荧惑，庚丙相加谁会得，六庚加丙白入荧，六丙加庚荧入白，白人荧兮贼即来，荧入白兮贼即灭。 |
| 逃走 | 六癸加丁蛇妖矫。六丁加癸雀投江。六乙加辛龙逃走。六辛加乙虎猖狂。请观四者是凶神，百事逢之莫措手。 |
| 投江 | 六癸加丁蛇妖矫。六丁加癸雀投江。六乙加辛龙逃走。六辛加乙虎猖狂。请观四者是凶神，百事逢之莫措手。 |
| 飞宫 | 阳遁，直符、螣蛇、太阴、六合、白虎、元武、九地、九天也；阴遁，直符、九天、九地、朱雀、勾陈、六合、太阴、螣蛇也。其法不用飞宫，以甲为旬首，隐直符分顺逆而布之。 |
| 地网 | 乙加癸，为奇临华盖，宜遁迹、修道、藏形、避灾难，吉（奇入地网，客兵亨，主兵暗昧，路迷程，作事狐疑，难进步，三门相合，百事成） |
| 星符 | 星符门还加本宫为伏吟，此时百事不遂，惟宜收敛财货，进兵必遭围困，虽有门，不可强用。 |
| 星门符 | 星门符加对冲之宫为返吟，此时只宜发粮散饷，最忌行兵、谋为，主反覆不宁之象。 |
| 大格 | 庚加癸，为大格，占行人立至，占官司立止，占产子母有伤（又为太白中刑格，诸事不宜，图谋反害）。 |
| 真诈 | 乙丙丁三奇合开休生门临太阴为真诈，宜施恩、隐遁、求仙、利用、出师、招抚反侧、设运机谋。 |
| 重诈 | 乙丙丁三奇合开休生门临九地为重诈，宜进人口、求财、拜官、投爵、利用、出师、设计、埋伏。 |
| 小格 | 庚加壬，为小格，又为上格，主远行失迷道路，音信阻嗟，百事敛踪为吉。 |
| 天网 | 时加六癸，众人莫视，不知六癸，出门即死。又云：“时加六癸，为天网，惟利逃亡。”又癸为华盖、天藏，利于伏匿。又云：“六癸之下利于伏兵隐形。” |
| 飞勃 | 丙寅时。艮（回首、相佐）中（奇合）。艮（飞勃）坎（伏宫）乾（奇墓）。 |
| 刑格 | 己加壬，为地网高张，凡事不吉，灾凶更深，固守为亨（又为明堂被刑格）。 |
| 守门 | 又有三奇游六仪，号为玉女守门时，若作阴私合和事，请君但向此中推。 |
| 相佐 | 乙加丁，为奇仪相佐，文书事吉，百事可为（又为奇旺太阴，利主前征，行师全胜，四海安宁） |
| 八门 | 奇门直使飞排两宫用法不同，今于排宫图内立有间宫之法，上下两盘剪活辅补用之，庶六十时八门皆可值其使矣，格局吉凶毕现，诚为直使行宫之秘。 |
| 休诈 | 乙丙丁三奇合开休生门临六合为休诈，宜合药、治疫、祛邪、祈祷。 |
| 击刑 | 六仪击刑何太凶，甲子直符愁向东，戌刑在未申刑虎，寅巳辰辰午自午。 |
| 伏宫 | 太白天乙格。庚加戊即飞宫伏宫格也。 |
| 神假 | 死门合丁己癸临九地为鬼假，又为神假，利超荐、破土、修茔、伐邪、畋猎。 |
| 合凶格 | 开加乾（乾卦），若遇天心加于此宫，为伏吟之格，只宜访道、求贤、积粮、收获、练兵、藏宝、暗伏兵机、防守，诸事不宜；如有别星加于此宫，或三奇及格，万事大吉，合凶格则凶。 |
| 天假 | 景门合三奇临九天为天假，宜干贵、进谒、上策、献书、扬兵、颁号令、申盟约。 |

> 术语由频次粗提，可能含噪声；以原书定义为准。
