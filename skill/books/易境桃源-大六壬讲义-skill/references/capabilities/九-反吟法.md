# 九、反吟法

## R — 原文 (Reading)

> 返吟有克亦为用，壬日下克上巳发用，中末传全部取冲。

> 朱雀、六合、勾陈、青龙五位引之，后有天后、太阴、玄武、太常、白虎、天空从

> 例如，甲子日辰将辰时占，甲为日干，贵人在丑未，辰时为白天，则取天盘

> 丑乘贵人，寅乘螣蛇，卯乘朱雀，辰乘六合，巳乘勾陈，午乘青龙。

> 母爻，克日干者为官鬼爻，与日干比和者为兄弟爻，日干所生者为子孙爻，日干所

> 位干支组合就是：甲子、乙丑、丙寅、丁卯、戊辰、己巳、庚午、辛未、壬申、癸

> 男寅女申，男命自己的属相加寅顺数天盘流年上，女逆数到地盘流年上。比如

> 测婚姻，男人测干是男支是女，女人测干女支男。

> 六壬的判断顺序，一看干支定位，二看课体毕法，三看类神和八门。壬占吉

> 关天人。正时又为目下现在顷刻，故来意专以正时来断。

## I — 方法论骨架 (Interpretation)

反吟法是大六壬中的一种占课方法，主要用于判断吉凶。其核心在于通过分析天盘和地盘的相克关系来确定三传（初传、中传、末传），从而预测未来事件的发展趋势。

## A1 — 应用示例 (Application Example)

假设某人于甲子日辰时占课，日干为甲，贵人在丑未。根据反吟法，我们需要确定天盘和地盘的相克关系，并据此推断三传。

### 天盘和地盘布局

1. **天盘**：亥将加在午上，顺排十二支成天盘。
   ```
   戌亥子丑
   酉
   寅
   申
   卯
   未午巳辰
   ```

2. **地盘**：未日以亥未马星为发用。

### 排四课

根据甲子日，甲的寄宫在寅。根据天盘布局，甲上写未，未的地盘上面是子就写子，以此类推，最终完成四课：
```
戌亥子丑
酉
寅
申
卯
未午巳辰
```

### 确定三传

1. **初传**：根据天盘和地盘的相克关系，确定初传。假设初传为申金。
2. **中传**：由初传本位加临求取中传，假设中传为亥字。
3. **末传**：由中传本位加临求取末传，假设末传为寅字。

## A2 — 触发场景 (Future Trigger) ★

反吟法适用于各种占课场景，特别是需要预测未来事件的发展趋势时。例如，测婚姻、事业前景等。

## E — 可执行步骤 (Execution)

1. **定位日干支**：确定占课当日的日干和地支。
2. **布局天盘**：根据日干和地支，布局天盘图。
3. **确定发用**：根据日干和地支，确定发用的星宿。
4. **排四课**：根据天盘和地支，排布四课。
5. **确定三传**：通过分析天盘和地盘的相克关系，确定初传、中传和末传。

## B — 边界 (Boundary) ★

反吟法适用于大六壬占课的所有场景，但需要注意的是，它仅是一种预测方法，并不能替代医学或法律建议。在使用时应谨慎，避免用于非法用途。
