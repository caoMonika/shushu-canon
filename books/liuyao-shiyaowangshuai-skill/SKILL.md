# 世爻旺衰格局法：莫亚全息派＋张代祥＋王虎应高阶论

取材三份：① 莫亚《六爻预测真途》（"全息派"，自称以计算机统计上万案例）；② 《王虎应 六爻中高级班讲课记录》（2005.5）后附**张代祥六爻中级班资料**；③ 同一讲课记录前半的**空亡论、虚实论、内外环境论、延展论**。三者共同点：**先定世爻旺衰格局，再以"用神益损于世"断吉凶**，与传统"用神旺衰定吉凶"的路径相反。张代祥开篇即列"传统六爻五大不足"：燥湿土不分、世爻旺衰不分、身旺墓绝不清、作用关系混乱、六爻与梅爻混用——本技能即针对这五点。

分工：传统旺衰用神法见 liuyao-zengshan-buyi-skill；爻层次生克权见 liuyao-duangua-jifa-skill；董元辰新派（先天旬空/进退辩证）见 liuyao-xinpai-dongyuanchen-skill。本技能专收**格局判定表与空亡虚实**。

## 一、总程序（三家共用骨架）

1. 记年月日时、旬空、月破，起卦记卦名；
2. 查飞神伏神（伏神常代表想问之事）；
3. 看特殊卦象：反吟、伏吟、六冲变六合、六合变六冲、外合内合；
4. 看何爻持世；
5. **定世爻旺衰，区分用忌神**（格局）；
6. 看爻动静旺衰、找准用爻、六亲定位；
7. 六亲综合分析 → 定吉凶 → 定应期 → 建设性意见 → 做应验记录。

## 二、莫亚：应爻定格局判定表（独有）

**总原则：世爻旺衰只由卦的结构（应爻）决定，年月日不决定世爻旺衰**——年月日只定用神/爻的旺衰与应期。

| 条件 | 格局 |
|---|---|
| 六合卦（三对六合） | 皆世旺卦 |
| 六冲卦（三对六冲） | 皆世弱卦 |
| 世克应 | 世旺 |
| 世应比和 | 世旺 |
| 应生世 | 从强 |
| 应生世而世空 | 世旺 |
| 应克世 | 世弱 |
| 世受制重（未戌煅金、辰丑晦火） | 从弱 |
| 世空、应克之 | 从弱 |
| 世空、世克应 | 世弱 |
| 应空 | 世旺 |
| 世应皆空 | 从弱 |

**卦格与吉凶**（与四柱同理）：
- 世旺卦：用神**生扶**世爻→凶；用神**克制**世爻→吉
- 世弱卦：用神生扶→吉；克制→凶
- 从强卦：生扶→吉；克制→凶
- 从弱卦：生扶→凶；克制→吉

一句话：**用神益于世爻，旺而逢生应吉；弱而受制或不上卦应凶；用神不益于世则反之。** 用神不上卦断吉凶不必看伏神，只看其益损于世。

**应期**：应吉——用神益世者逢生旺时应；不益世者衰而受制时应。应凶反之。用神动空，出空定吉凶。远应年月，近应日时。

**爻之作用规律（莫亚）**：世应直接作用；动爻与任何爻刑冲合；动爻互作用；变爻只与本位动爻作用（不作用旁爻）；变出空亡之爻不与动爻作用；动爻空亡待出空才作用；空亡在月令同样不作用；静爻**相邻作用，隔不作用**；临年月日作用力大。

**地支作用细则（莫亚）**：
- 六冲：双方均受伤，得年月日者伤小；
- 六合分两类：子丑、卯戌、巳申＝**合绊**；寅亥、辰酉、午未＝**生合**（被生方增力、生方减力）；
- **三合局、三会局皆以绊论**；生地半合除巳酉绊外以生论；墓地半合子辰/卯未绊、午戌/丑酉生；
- 亥子水克巳午火，**辰丑土晦火（晦力大于克）**；巳午火克申酉金，**未戌土煅金（煅力大于火克金，未土尤甚）**；
- 同性生克力大、异性力小；
- 丑戌相刑、寅巳相刑（巳刑寅实则寅减力）；
- 进神：亥化子、寅化卯、巳化午、申化酉、丑化辰、未化戌；退神反之。进退有好坏须视卦象。
- 反吟（卦变冲/爻变冲）：主反复，用神化冲克凶；内卦反吟内不安，外卦反吟内外不安。伏吟（爻化同支）：主忧虑呻吟，内主我心不快、外主他心不安。

**旬空（莫亚）**：静空为真空，待太岁填实；动空为空而待用，出空填实。

**装卦速法**：世应口诀"天同二世天异五，地同四世地异初，人同游魂世在四，人变归魂世在三，本宫六世三世异"；卦宫口诀"一二三六外卦宫，四五游魂内变更，归魂内卦是本宫"。变卦装六亲**仍以主卦卦宫五行为我**。莫亚体系**不用六神、不纳天干**，只用地支五行。

## 三、张代祥：邻爻应爻定从格（中级班）

**世爻旺衰八条**（看世爻与邻爻、应爻的作用关系）：
1. 邻爻、应爻都帮扶→**从强**
2. 都克泄耗→**从弱**
3. 邻爻都克、应爻生→世弱
4. 邻爻生、应爻克→世旺
5. 唯一生扶者受伤太重→从弱
6. 唯一克制者受伤严重→从强
7. 从强格世需抑制、从弱格世需生扶（赌博只看日建与世爻关系）
8. 空亡引起的变化：需抑制卦中世空→以弱论改喜生扶（应/邻空不影响）；需生扶卦中世空仍喜生扶，但**唯一生扶之爻空亡时，世由喜生扶转为喜抑制**。

**卦爻作用关系（张代祥）**：世与邻爻作用；世与应爻作用；动爻可与世作用（力看远近）；**静爻隔不作用**，只与相邻爻作用；动爻与动爻作用但隔世不作用；世与用爻作用。**二爻和五爻是卦的两个眼睛。**

**作用力加减（张代祥独有口诀）**：
- 卯戌合、六冲：双方均减力；
- 克合（子丑、卯戌、巳申）双方减力；生合（寅亥、午未、辰酉）被生方增力、生方减力；
- **六合不化**；三合局均减力（合绊）；刑、害只在测人事关系方面有用；
- **化进化退一律按帮扶断**；伏吟反吟按正常生克断（反吟比伏吟易应吉，因反复）；
- 逢冲为减力；**暗动减一半力**（日建冲为被动），明动全力——朋友来看：明动久坐，暗动即走；
- 月冲之爻**以弱论，不称月破**，无须反断，**月破力量小于旬空**；
- 年月日时权重：长远事月建70%日建30%；论日不管月；近几天日建70%；当日日建90%；体育比赛看时辰；终身卦以太岁为主。

**地支关系（张代祥，与通行不同，慎用）**：相对为冲、横向为合、交叉为害；寅巳申全论刑、丑戌相刑、丑未冲、戌未相帮、午辰相刑、酉亥相刑、子午相刑（相生）；三刑外伤多。空亡＝五行弱的表现形式，**对冲的五行旺**。库＝医院、坟墓、牢狱、回家之象。

**虚实论（张代祥）**：卦中有的字为**实神**、没有的字为**虚神**。最需要的字不上卦→在该字代表的事上应凶；最忌的字不上卦→应吉。例：官鬼寅木为病最需申金冲而卦无申→肺不好；最需午火泄而无午→发烧；最不需子水生而有子→泌尿病。"看财不一定看财爻，80%不准，看兄弟比较准"。

**断卦要点**：先看动爻（事情主体）→世爻→旺衰→虚实→卦名；问事多爻动＝多事；间爻动＝事不顺；双财双官＝两份选择。男一三五爻正位二四六副，女二四六正一三五副。移位论（坐标原点位移）断远近大小。

## 四、王虎应高阶论（2005 中高级班）

### 空亡 11 论
1. 空亡是爻弱的表现形式；因空而弱的空间有多大，**填实反弹的空间就有多大**；
2. 冲空时旺、出空时旺、出空逢生逢值更旺、出空在对冲之支空亡时最旺；
3. **因空而吉的不空时应凶，因空而凶的不空时应吉**；
4. 化空之字出空后吉应吉凶应凶；
5. 飞神旬空，伏神可与邻爻作用；
6. 爻遇旬空，隔爻可以作用；
7. 空亡之爻可反映该爻对两个邻爻的态度；
8. 空亡是**测来意、定应期的主要技法**；
9. 动不为空；空化空时为真空；
10. 逢年、月、日、时不为空；
11. 逢时不空。

### 虚实论（王虎应版）
与某一六亲有**直接生克关系的字为实**，无直接生克关系的字为虚。需要生的不生，必在该六亲上应凶；不需要克的来克，必在该六亲上应凶。

### 内外环境论
一个六亲的**下邻爻＝内环境，上邻爻＝外环境**；外卦＝外环境、内卦＝内环境；卦内六亲＝内环境、年月日时＝外环境。内外反映该六亲在内或在外的两种存在状态。

### 延展论
测一个六亲时，**整个卦反映的都是该六亲的全部信息**（测奶奶则全卦皆奶奶：财为饭、寅木为脚、辰土为腿、午火为药医……）。

### 卦例示范（部分）
- 测外孙走失（坎之比）：六冲卦为陷阱，二爻鬼辰动化巳回头生，戌土为路丑月丑日刑戌＝路上不平安，辰在内卦＝内部人害子孙；
- 测妹离婚（中孚之履）：世空喜抑制变喜生扶，双中心点取用——以世为中心丑为忌、以应为中心卯官生巳父为用，判决对我有利；
- 测奶奶病（解之大有）：归魂卦有归天意，用忌神区分后按延展论逐爻落实，断巳日死（用神最吉忌神最弱时），乙酉日出殡（出空为官为事）。

## 五、卦名断语速查（张代祥）

六冲卦＝散、不和、快、短、难成；六合卦相反。要点：
- 乾为天：卦辞好但六冲，雄心勃勃；天风姤：女占婚不顺（他乡遇友）；天山遁：遁世待时；天地否：六合变出来才好，摇出主阴阳不交；山地剥：剥落小人当道大凶；火地晋：利考学求名，求财问婚不吉；火天大有：卦名好但内部作用不佳。
- 兑为泽：六冲口舌；泽水困：合卦但困难重重，合伙都没钱；水山蹇：山穷水尽；雷泽归妹：婚姻不顺（浮云遮日）；泽山咸：人事关系特好，男测婚不佳（兄持世）。**婚姻卦三个：雷泽归妹、雷风恒、泽山咸**（女官持世男财持世＝已在一起）。
- 离为火：六冲破财；火山旅：出差/火灾；火风鼎：革故鼎新、折足之象、家庭顶梁柱出问题；火水未济：不到位；山水蒙：蒙昧被骗；天水讼：讼卦多数出麻烦口舌而非官司。
- 震为雷：六冲快（车），开店很快关；雷地豫：六合吉利于求财；雷水解：消灾解祸；雷风恒：关系卦测婚不顺（官持世为忌）；水风井：守静调不动；泽风大过：大错决策；泽雷随：归魂中上。
- 巽为风：六冲逆境求生；风天小畜：夫妻反目；风火家人：利外地求财不易存钱；天雷无妄：防意外；火雷噬嗑：狱之意；山风蛊：病卦、被骗、病在内部血液。
- 坎为水：六冲最凶之一（艮为山同）；水火既济：始吉终凶；雷火丰：好出官司宜本地；地火明夷：伤灾窝囊。
- 艮为山：止象按六冲断；山天大畜：积蓄等待，测婚不顺行人堵车；山泽损：求财不好宜送礼；火泽睽：两亲不睦二女吵架；风泽中孚：信誉、已有计划之事。
- 坤为地：六冲不顺；地雷复：反复压力（五阴压一阳）；地天泰：问平安好求财不佳（兄持世）；雷天大壮：六冲坐不住阳气过盛干不成；水天需：游魂光打雷不下雨；水地比：关系融洽默契。
- 六合卦中**天地否最凶**；天火同人、雷风恒、水地比关系不错。

## 六、使用边界与素材缺陷

1. 莫亚书前有大量自宣文字（"全息三维""批判百神论反断论虚实论为歪理邪说"）——而**张代祥/王虎应体系恰恰使用虚实论**，两派直接对立。并用建议：格局判定（莫亚表）与虚实论（张王）可互补——先定格局，再用虚实找"缺的字"，互不否定；引用时注明立场。
2. 莫亚"六合卦皆世旺、六冲卦皆世弱"是**简表**，其卦例中也有按"世克应"覆盖卦象的情况（如天水讼例），以判定表逐条核对为准，勿只记前两条。
3. 张代祥的地支关系（子午相刑、丑未冲、戌未相帮、午辰刑、酉亥刑）与通行纳甲体系（子午冲、丑未冲、辰戌冲）**冲突**，属其个人天文推演体系（地球自转公转论），仅在其体系内自洽，混用必乱。他书引用其"暗动减半""月破小于旬空"时须带出处。
4. 王虎应 2005 讲课记录为学员笔记：卦例排盘多错行、六神错位、"??蛇"即腾蛇；空亡 11 论与其《疑惑指迷》（liuyao-yihuo-zhimi-skill）互补，后者重答疑、本篇重条文。
5. 讲课记录中"张代祥六爻中级班资料"占全文过半，标题标注为附录，实为独立教材；本技能已拆分提炼，两套术语（世爻旺衰八条 vs 莫亚判定表）并存而不合并。
6. 卦名断语是张代祥个人实战总结（如"雷火丰好出官司""火风鼎测婚顶梁柱出问题"），与《增删卜易》卦辞解读不同，属经验断语，宜与 liuyao-liuchangming-skill 卦名意象表互参取舍。
7. 测终身、八字起终身卦（太玄数、干支顺序数、出生时间起卦）张代祥有排大限法（10年大限/小限），与张鼎运限（liuyao-zhangding-jifa-skill）同名不同法，勿混。
8. 六神：莫亚明确不用；张代祥不提；王虎应仍用。三派并存，按所用体系配套。
