# 六爻传统派主干：增删卜易体系

## 它是什么

六爻（纳甲筮法）的核心结构：把六十四卦装上地支（纳甲）、六亲、世应，再叠上月建、日辰、动爻、变爻这几层"外力"，判断用神是否有生克权，最后定成败与应期。

野鹤老人《增删卜易》的特点是不迷信古法：凡古法不应验的（如"动而逢冲必散""爻值月建逢空不空""土寄生于寅"），他一律以实测改订，并在文中明写"余试不然"。**这套体系的价值在于它有明确的操作顺序和可检验的判据链条**，而不是靠灵感。

## 一、装卦四步

### 1. 纳甲（浑天甲子）

| 卦 | 内卦三爻（初、二、三） | 外卦三爻（四、五、上） |
|---|---|---|
| 乾 | 子水、寅木、辰土 | 午火、申金、戌土 |
| 坎 | 寅木、辰土、午火 | 申金、戌土、子水 |
| 艮 | 辰土、午火、申金 | 戌土、子水、寅木 |
| 震 | 子水、寅木、辰土 | 午火、申金、戌土 |
| 巽 | 丑土、亥水、酉金 | 未土、巳火、卯木 |
| 离 | 卯木、丑土、亥水 | 酉金、未土、巳火 |
| 坤 | 未土、巳火、卯木 | 丑土、亥水、酉金 |
| 兑 | 巳火、卯木、丑土 | 亥水、酉金、未土 |

点卦由下至上，纳甲亦由下往上。

### 2. 六亲（按本宫五行定）

生我者父母，我生者子孙，我克者妻财，克我者官鬼，比和者兄弟。

口诀：
- 乾兑（金）：金兄、土父、木财、火鬼、水子
- 坎（水）：水兄、木子、金父、火财、土鬼
- 坤艮（土）：土兄、火父、木鬼、水财、金子
- 离（火）：火兄、木父、土子、水鬼、金财
- 震巽（木）：木兄、水父、金鬼、火子、土财

**变卦的六亲必须按正卦（本卦）的宫五行来安，不能按变卦自己的宫。** 这是初学者最常见的错，错了整个断卦作废。

### 3. 世应

以乾为天为例：世在六爻；天风姤世在初爻；天山遁世在二爻；天地否世在三爻；风地观世在四爻；山地剥世在五爻；火地晋世退在四爻；火天大有世退在三爻。

规律：八纯卦世上爻，一世卦世初爻，二世二世爻……五世卦世五爻，游魂卦世四爻，归魂卦世三爻。**隔世爻两位即应爻。**

### 4. 动变

阳动变阴（○），阴动变阳（×）。六爻静则不变，动则必变。变出的爻写在动爻旁边，只有动爻才有变爻。

## 二、用神取法（六亲取用）

| 六亲 | 所主 |
|---|---|
| 父母 | 父母、祖父母、伯叔姑姨、师长、岳父母、乳认父母；以及天地、城池、墙垣、宅舍、屋宇、舟车、衣服、雨具、布匹杂货、章奏文书文章书馆文契。**一切庇羁我身者** |
| 官鬼 | 功名、官府、雷霆鬼神、妻占夫；乱臣、贼盗、邪祟。**一切拘束我身者**。女占夫/男友亦取此 |
| 兄弟 | 兄弟姐妹、族中兄弟、姑姨、姐夫妹夫、结拜弟兄。彼得志则欺凌，见财则夺，故占财物为劫财之神，占谋事为阻隔之神，占妻妾婢仆为刑伤克害之神 |
| 妻财 | 妻妾、婢仆、下役；货财珠宝金银仓库钱粮、一切使用什物器皿 |
| 子孙 | 子孙、女婿、侄甥、门徒、忠臣良将、医士医药、僧道兵卒、六畜禽兽。为福德之神、制鬼之神、解忧之神，又为剥官引职之神——**诸事见之为喜，独占功名者忌之** |

野鹤的两条实测更正，必须记住：
- **占姐夫妹夫，以世爻为用神**（屡验），不以兄弟爻
- **占表兄弟，以应爻为用神**（兄弟爻不验）

## 三、元神、忌神、仇神

- 元神 = 生用神之爻
- 忌神 = 克用神之爻
- 仇神 = 克元神、反生忌神而克害用神之爻

例：金为用神，土生金→土为元神；火克金→火为忌神；木克土生火→木为仇神。

### 元神能生用神者有五（皆为有力之元神，诸占皆吉）

1. 元神旺相，或临日月，或得日月动爻生扶
2. 元神动，化回头生，及化进神
3. 元神长生、帝旺于日辰
4. 元神与忌神同动
5. 元神旺动，临空、化空

> 第五条是野鹤的重点改订：古以临空化空为无用，野鹤认为非也——"动不为空，待冲空、实空之日而为有用"。

### 忌神动不克用神者有七（皆为无力之忌神，诸占化凶为吉）

1. 忌神休囚不动，动而休囚，被日月动爻克
2. 忌神静，临空破
3. 忌神入三墓
4. 忌神衰，动化退神
5. 忌神衰而又绝
6. 忌神动，化绝、化克、化破、化散
7. 忌神与元神同动

### 但有一条压倒性前提

> "倘若用神无根，谓之元神有力亦难生，忌神无力亦休喜。"

**用神无根，一切生扶皆空。** 断卦先看用神本身有无气，再谈元神忌神。顺序不能颠倒。

## 四、月建（月将、月令）

月将掌一月之权，司三旬之令。"操持万卜之提纲，巡查六爻之善恶，能助卦爻之衰弱，能挫爻象之旺强，制服动变之爻，扶起飞伏之用。"

- 爻衰者：能生之、合之、比之、拱之、扶之，衰而亦旺
- 爻旺者：能冲之、克之、刑之、破之，旺而亦衰
- 变爻克动爻 → 月建能制变爻
- 动爻克静爻 → 月建能制动爻
- 用神伏藏被飞神压住 → 月建能冲克飞神、生助伏神

**月建合爻为月合，乃有用之爻；月建冲爻为月破，乃无用之爻。**

「月建不入爻，亦为有用；月建一入卦，愈见刚强。」卦无用神，即取月建为用神，不必寻伏神。月建入卦动而作元神福更大，动作忌神祸更深，不入卦者其力缓。

野鹤改订：古说"爻值月建，逢空不空，逢伤无害"，**余试不然，在旬内者毕竟为空**。旺相只是不受克伤，旬内仍作空论，要出旬才实。

## 五、日辰

"日辰为六爻之主宰，司四时之旺相。"月令有四季生杀，日辰四时俱旺，操生杀之权，与月建同功。

- 冲旺相之静爻 → **暗动**，愈得其力
- 冲衰弱之静爻 → **日破**，愈加无用
- **冲空即起，冲合即开**：爻遇旬空，日辰冲起为用，谓冲空则实；爻逢合住，日建冲开，谓合处逢冲。但凶神合处喜逢冲，吉神合住不宜冲
- 爻旺而动，冲之愈动；爻衰而动，冲之则散
- 爻临日建：月冲不破，月克无伤，逢动爻克亦不为害，化回头克亦不为殃——"如山如陵，与月建同权"
- 生多克少，锦上添花；生少克多，寡难敌众

野鹤对"动散"的改订见第十一节，是本书最值得记的一处反教条。

## 六、六合

子丑合、寅亥合、卯戌合、辰酉合、巳申合、午未合。

相合之法有六：
1. 日月合爻
2. 爻与爻合（须两爻俱动，一爻不动不为合）
3. 爻动化合
4. 卦逢六合（内外六爻自相和合，不动亦是）
5. 六冲卦变六合
6. 六合卦变六合

四种性质：
- 静而逢合 → **合起**（得合而起，虽休囚亦有旺意）
- 动而逢合 → **合绊**（绊住不能动，反是不动之意）
- 爻与爻合 → **合好**（他来合我，和好相助）
- 爻动化合 → **化扶**（得变爻扶助）

诸合皆吉，但**必用神有气相宜，用若失陷无济**。吉事逢之事必就，凶事逢之事难结。

## 七、六冲

子午冲、丑未冲、寅申冲、卯酉冲、辰戌冲、巳亥冲。

相冲之法有六：日月冲爻、卦逢六冲、六合卦变六冲、六冲卦变六冲、动爻变冲、爻与爻冲。

"冲者，散也。凡占凶事宜于冲散，占吉事则不宜。"但必兼用神：用神旺虽冲不碍，用神失陷凶而又凶。**六合卦变六冲者，用神纵旺亦始吉终凶，图事虽成有头无尾。**

爻冲有五：月冲为月破；静旺遇日冲为暗动；休囚遇日冲为日破；动爻自化回头冲如逢仇敌；爻遇爻冲谓之相击。

## 八、三合、三刑、六害

三合局：申子辰水局、亥卯未木局、寅午戌火局、巳酉丑金局。三合需三爻齐动，或两爻动加一爻临日月，方能成局；缺一不成，一爻空破亦不成。

三刑：寅巳申、丑戌未、子卯、辰午酉亥自刑。三刑之力轻于三合六冲，多作信息之象（官非、病伤、纠缠），不作主要吉凶判据。

六害：子未、丑午、寅巳、卯辰、申亥、酉戌。六害在六爻中权重最低，仅在用神已定吉凶后补充细节。

## 九、旬空

旬空 = 用神落在本旬所空的两个地支上。十干配十二支，每旬必空二支。

关键判据（野鹤的核心改订）：
- **旺不为空，动不为空，有日建动爻生扶者不空，动而化空、伏而旺相皆不为空**
- **只有"休囚无气而又安静"的才是真空**——到底为空，出旬亦无用

野鹤不同意"真空即凶到底"与"旺相逢空全不作空"两个极端。他的折中："逢空勿即指为不空，毕竟为空，但此空者乃目下旬内之空，待至出空之日则不空也。作忌神者仍出而为祸，作元神者仍出而为福。非比休囚之真空到底而为空也。"

应期上：**旬空最爱填冲**——出空之日、冲空之日，或值日。

## 十、月破

月建冲之为月破（正申二酉三戌四亥五子六丑七寅八卯九辰十巳十一午十二未，各月破日即此）。

古法：用神临月破谓之"悖时"，如枯根朽木，逢生生之不起，逢伤伤者更重；动而作忌神亦不能为害，作变爻亦不能伤克。

**野鹤改订**："余得其验，动则能伤于爻，变则能伤于动。何也？神兆机于动，事之无吉无凶则不动矣。既动，则有祸福之基。目下虽破，出月则不破；今日虽破，实破之日则不破，逢合之日则不破。"

结论：**月破只对"静而不动、又无日辰动爻生助"的爻才到底而破。** 破而能动，照样起作用，只是应期延后。

应期：**月破喜逢填合**——填实之日（值其地支）或合其地支之日。

## 十一、暗动

静爻旺相逢日冲 → 暗动。愈得其力，能生能克，与明动同权。

判据是"旺相"：临日月、有动爻生扶、得月合者皆旺。休囚逢日冲不叫暗动，叫日破。

## 十二、动散（野鹤最著名的反教条）

古法："动而逢冲曰散，散犹空也，如全无之象，纵有生扶不可救也。"

野鹤："余恒论神兆机于动，动则必验，惟看旺衰以分轻重，不可以散而遂言如无也。"

他反复强调几十年实测"绝不应乎散"：爻既动，事已在动，冲只是阻滞或延后，不是消失。他给出的量化判断：**旺相者冲之愈强；休囚无气者间或有散，亦百中仅一二。**

实操：见动爻被冲，先按"动而被冲、力量受挫"处理，不许直接判死。这是本体系与很多坊间书的分水岭。

## 十三、生旺墓绝

四大长生（野鹤以天时考订）：

| 五行 | 生 | 旺 | 墓 | 绝 |
|---|---|---|---|---|
| 金 | 巳 | 酉 | 丑 | 寅 |
| 木 | 亥 | 卯 | 未 | 申 |
| 火 | 寅 | 午 | 戌 | 亥 |
| 水 | 申 | 子 | 辰 | 巳 |
| 土 | 申 | 子 | 辰 | 巳 |

土的长生是六爻一大分歧点。古法有"火土长生寅上排"（土寄生于寅），《易冒》说"申中有坤，土生于申，若分阴阳则戊土生寅、己土生酉"。**野鹤专以天时考证，定"土寄生于申"为不易之论。** 本技能采野鹤说，但明确标注这是流派分歧，用别的流派需先声明。

生旺墓绝主看日建，亦看动变。论生论克、论墓论绝，宜变通不宜拘泥。

## 十四、卦变生克墓绝

变卦回头生、回头克、化墓、化绝，与变爻对动爻的作用是同一套判据，只是层次不同。凡变爻克动爻，动爻受伤；变爻生动爻，动爻得助。变爻自身若无气（被日月克、空破），则无力作用于动爻。

## 十五、反吟、伏吟

**反吟**：卦变相冲。如乾变巽、坎变离之类，六爻地支全部对冲。主反复、变动、成而复败、去而复来。有卦反吟（内外卦俱变冲）与爻反吟（个别动爻变出相冲之支）。

**伏吟**：卦变相同（本卦与变卦地支全同），主呻吟、停滞、原地打转、有苦难言。多见于内外卦伏吟。

反吟伏吟皆非吉象，但必以用神为准：用神旺，反吟主事有反复而终成；用神衰，反复而无成。

## 十六、飞伏神

用神不上卦，先看日月是否为用神；日月非用神，则于本宫首卦（八纯卦，六亲俱全）寻之，所得为伏神，本卦同位之爻为飞神。

### 伏神有用者六

1. 伏神得日月生者
2. 伏神旺相者
3. 伏神得飞神生者
4. 伏神得动爻生者
5. 伏神得遇日月动爻冲克飞神者
6. 伏神得遇飞神空破休囚墓绝者

### 伏神终不得出者五

1. 伏神休囚无气者
2. 伏神被日月冲克者
3. 伏神被旺相之飞神克害者
4. 伏神墓绝于日月飞爻者
5. 伏神休囚值旬空月破者

野鹤原则：**伏神要"出"才有用**，出的条件是被引拔（日月冲飞、飞神空破、动爻生伏）。伏而不出，虽有其神如同无有。

## 十七、进神、退神

### 进神八组（动而化进，力量递增）

亥→子、寅→卯、巳→午、申→酉、丑→辰、辰→未、未→戌、戌→丑

### 退神八组（动而化退，力量递减）

子→亥、卯→寅、午→巳、酉→申、辰→丑、未辰、戌→未、丑→戌

用法：用神元神化进为吉，化退为凶；忌神化退为吉，化进为凶。应期上——**进神逢值逢合，退神忌值忌冲**。

## 十八、随鬼入墓

用神入墓有三种：入日墓、入动爻墓、动而化墓。

- 占病见用神随鬼入墓，为大凶之象
- 占讼、占囚，入墓主被拘禁
- 占求谋，入墓主受困、被人藏起来、事情搁置

墓有吉有凶：**休囚之爻逢墓为入墓（死墓），旺相之爻入墓为入库（有收藏保护作用，可进可出）。** 入库者不被它爻克，也不克它爻——保护与限制是同一件事的两面。

应期：**入三墓俱喜冲开**——冲墓之日。

## 十九、独发、独静

五爻俱动一爻不动为独静，五爻不动一爻独动为独发。

野鹤的态度极谨慎："事之成败，由乎用神；应期迟速，亦由乎用神。独发独静，古有验之，余试亦有验也，皆在事应之后，始会神机，非初遂敢执以断祸福与应期也。"

**实操：独发独静可以作为应期的补充线索，不能舍用神而专执此断事。** 坊间"独发断事、独静断期"的绝对化用法，野鹤明确反对。

## 二十、两现

用神两现，取哪一个？野鹤的原则：
- 取**旺相**者
- 取**不空不破**者
- 取**动爻**（动者是其用）
- 取**临世应**者
- 一空一实取实，一破一全取全，一静一动取动

两现本身也是信息：同一件事有两个落点（如两处房产、两份工作、两个候选人、原放一处后换一处）。取用选其一断吉凶，另一爻作为信息象参看。

## 二十一、归魂、游魂

游魂为各宫第七卦（乾宫火地晋、坤宫水天需），归魂为第八卦（乾宫火天大有、坤宫水地比）。

- 游魂：心无定向、迁改不常。占身命一生无安家乐业之所；占行人游遍他乡；占出行行止无定；占家宅迁变不常；占坟茔亡灵不安
- 归魂：不出疆，诸事拘泥不行

**野鹤两次强调"须以用神为主，然后以此参之。若舍用神，执此而断者，谬也。"**

## 二十二、星煞

六爻中的神煞（天乙贵人、驿马、桃花、羊刃、空亡、劫煞、灾煞、月煞、亡神、将星、华盖、天医、禄神等）**只作信息补充，不作吉凶主判**。野鹤对星煞的态度是"四验"——偶验则记，不验则不取。

用法：用神已定吉凶后，用星煞添细节。如占行人用神动而临驿马主在途；占婚用神临桃花主有第三者；占病用神临天医主得良医。**反过来用星煞定成败，是本末倒置。**

## 二十三、应期总注（全章）

这是六爻里最实用的一章，几乎可以当口诀背：

1. **静而逢值、逢冲**：主事爻临子水不动，后逢子日、午日应之
2. **动而逢合、逢值**：主事爻临子水发动，后遇子日、丑日应之
3. **太旺者，逢墓、逢冲**：主事爻临午火，又遇巳午月日占卦，或卦中巳午爻太多，后逢亥子日应之，又有戌日应之（火入墓）
4. **衰绝者，遇生、遇旺**：主事爻属金，占于巳午月日即休囚无气，后逢土月日或至秋令当时则旺
5. **入三墓，俱喜冲开**：主事爻临午火，火墓于戌，后逢辰日应之
6. **遇六合，亦宜相击**：主事爻与日月作合，或动与爻合，或动而化合，必待冲开之月日应之（如主象临子与丑合，逢午未日应）
7. **月破喜逢填合**：子月占，主事爻临午火为月破，后逢未日应之（破而逢合），或逢午日应之（填实则不破）
8. **旬空最爱填冲**
9. **大象吉而受克，须待克神受克**：用神临辰土得生扶，被寅卯克，后逢申酉日冲克克神则吉
10. **大象凶而受克，须防克者逢生**：用神临辰土无生扶，再逢寅卯克，后逢寅卯亥日则凶
11. **元神来助来扶，贵看用神衰旺；忌神来冲来克，须观元气兴衰**
12. **化进神，逢值逢合**
13. **化退神，忌值忌冲**
14. 间有应于**独发独静**、应于**变爻动爻**
15. **远近当分**：远事定于年月，近事应于日时。亦有占远应近、占近应远、占月应年、占日应时者
16. **卦有恍惚者，再占一卦，不可妄断**
17. **世空元动，须待元神逢值**；**世衰元静，必须元神逢冲**

## 二十四、千金赋（黄金策）要句

《增删卜易》所附《千金赋》是六爻断语的总纲，野鹤逐句加注。可用的判断原则：

- "动静阴阳，反复迁变"——动变是全部信息之源
- "虽万象之纷纭，须一理而融贯"——一切归到用神旺衰生克一条理上
- "日伤爻，真为其所伤；月伤爻，真为其所伤"——日月之伤不可解
- "伏无提挈终徒尔，飞不摧残亦枉然"——伏神不出无用，飞神不破伏神难出
- "空逢冲而有用，合逢冲而事成"——空与合都要等冲
- "用神有气无他故，所作皆成；主象徒存更被伤，凡谋不遂"

## 使用流程

1. **装卦**：纳甲 → 六亲（按本宫五行）→ 世应 → 标动爻与变爻
2. **定用神**：按六亲取用表，占什么取什么；注意"占姐夫妹夫取世、占表兄弟取应"两条更正
3. **查用神有没有**：上卦？伏藏？两现？
4. **看用神有无根**：临日月？得动爻变爻生扶？长生帝旺？——无根则一切生扶皆空
5. **看月建**：用神月合为有用，月建冲为月破（但破而能动仍起作用）
6. **看日辰**：日冲旺静为暗动、衰静为日破；冲空则实，冲合则开
7. **看动爻变爻**：谁生用神、谁克用神、有无回头生克、有无进退化空化墓
8. **看组合**：六合六冲、三合局、反吟伏吟、卦变墓绝
9. **看用神是否被空破墓绝伤**：旬空（真空 vs 旺空）、月破、入墓、化绝
10. **定成败**：用神有气无伤 → 成；用神失陷受克 → 不成
11. **定应期**：按应期总注十七条逐条比对
12. **补细节**：神煞、六神、归魂游魂、爻位、卦名卦象
