# 测字秘牒（程省）

文献参考；测字属文字游戏式占法，**不可当作现实决策依据**。

## 总纲

一字之来必有体。「认定用神」「体立而后用行」。测不立法无以权衡；字不加减无以开蒙。先定所问（用神），再择变法，最后炼一句「取格」断语。

## 一、测字十法（技法层）

| 法 | 操作 | 要点 |
|---|---|---|
| 装头 | 字上添笔成新字 | 首犹藏，添而出之 |
| 接脚 | 字下添笔 | 全身已现，补其足 |
| 穿心 | 中穿数笔，字体大体不动 | 异于「破」 |
| 包笼 | 外围包裹成他字 | 全体不动 |
| 破解 | **破**=劈开加笔；**解**=抉出旁笔成文 | 破易解难；破≠穿心 |
| 添笔 | 补不足 | 邵子：当添亦添 |
| 减笔 | 损有余 | 略减；勿混入摘字 |
| 对关 | 取头足/开阖义 | 「字中第一要义」，用最广 |
| 摘字 | 摘一二小笔画断 | 机到则旁人言语亦可借 |
| 观梅 | 随物洞照、借境 | 前九法程式；此为心诀 |

**对关例**：先=牛头虎足／生头死足；善=美头喜足；帛=皇头帝足；友=有头没尾。

**观梅天地人日用**：天（空利于行）、地（成而迟）、人（诚则安）、日（实）、月（缺有根）、金（宝亦累）、木（春秋衰旺）、水（流通不利冬）、火（中则晦）、土（有基迟滞）。

## 二、心易六法（六书层）

象形｜会意｜假借｜谐声｜指事｜转注。

- **假借**：旦→春、千→夏、甲→秋、夕→冬；立逢人→位、遇水→泣。
- **谐声**：倒/到、秤/称、桃/逃；莺问晴雨→阴。
- **转注**：同字异读取义（临丧、旺相等）。
- **指事十目**：观人、察色、辨言、辨事、察墨、辨纸、观时、相机、正论勿奇、言语勿杂。

## 三、取格与双句/散格

1. 先五行生克，次六神动静；相生安静→吉格，否则凶格。
2. **取格**：一字炼一语（如文章定论）。
3. **双句格**：一句不尽则两句；或格在次句。
4. **散格**：以「束字义之物」作文，触类旁通。

## 四、操作次序（可执行）

1. 问事（用神）＋来字＋当下情境（墨色纸张时辰旁言）。
2. 先看能否**对关／观梅**直断；不行再选装头、接脚、穿心、包笼、破、加减、摘字。
3. 用六书校核字义是否自洽。
4. 炼一句（或两句）取格；忌堆砌、忌与问事脱节。
5. 卷七「至理」例：欠字问六甲→欠加两点为次（非首胎）＋坎中男→明日生男——说明断法须**事理与字形双证**。

## 五、边界

杂占赋、验例仅供文献结构；涉及人身健康、刑讼、婚财等现实决策，改用可核验信息，勿以测字定夺。
