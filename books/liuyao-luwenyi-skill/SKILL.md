# 吕文艺六爻预测学（方法论批判派）

取材：《吕文艺六爻预测学理论全集》（2007，六部分：学习道理／必须明白的道理／基础知识／核心理论／分类预测 43 类／附录卜筮正宗）＋《吕文艺六爻师资课堂笔记》（2005 培训班，风水命理六爻合讲）。作者立场鲜明：以"客观、现实、唯物、辩证、科学"为手术刀解剖传统六爻，大量篇幅批判易界骗术，同时自立"求测点／组合关系／外应"三大支柱。与本技能族的配合方式：**本技能解决方法论与入手问题，具体断法条文仍用 liuyao-zengshan-buyi-skill、liuyao-fenlei-zhanduan-skill 等**；吕氏对旺衰的否定属其一家之言，用时须知边界（见末章）。

## 一、求测点决定论（全书第一原则）

**求测点**＝求测者所要求测命运方向上的重点求测内容。同一个方向下求测点可以完全不同——同是测病："会不会有病灾／现在的病能否治愈／危重有救吗／何时愈／还会恶化吗"是六个求测点，同一卦或同一外应，断法与吉凶结论差异极大。

三条铁律：
1. **一事一断**：求测点明确时绝不能一卦多断。求测点明确的卦是"问什么答什么"之卦，一卦多断必答非所问（问牢狱你断财婚房，同一妻财爻无法自圆）。只有求测点不明确时才可酌情一卦多断，且须了解求测者部分情况。**一个求测点起一卦**，准确率才有保证。
2. **一事多测**："一事只能一卦"的传统规定被他判为伪科学残留。科学必须经得起重复检验——同一求测点反复摇卦，吉凶结论必须一致，否则理论就是错的。实证：某友一年内就官运摇 85 卦（列出 19 卦），卦象各异而断语同为"庚辰年升官"，果验。**前提是每次起卦的求测点相同**。
3. **求测点决定用神与分析点**：测病的"会不会有病灾"和"能否治愈"用神侧重不同；测房要再分测房与财运／官运／婚姻／健康／平安／牢狱／官司，各有各的用神。先定求测点，再取用神。

配套：**铁口直断的本质**＝精通卦理（命理风水理）＋精通人事之理（了解事情发生发展全过程）＋二者结合推导。反例：卦见"巳火入戌库"就断"蛇爬进屋"，前提是求测地有蛇；断"升县长"却不知局长调县长是降三级。不了解人事，卦理再精也断不细。又揭"大师神断"多为托儿调查后的表演。

## 二、抛弃旺衰，只看组合关系

作者统计：传统六爻理论中论述旺衰的内容不足 4%，90% 多是卦爻组合变化关系；古例即使彻底不用旺衰也能推出结果。结论：**"旺衰理论纯属错误"**，学六爻重点是研究卦爻之间的相互关系，不要停在旺衰上打转。

实用转化：判吉凶时先看**爻与爻的组合（生克冲合的结构、谁和谁组合、组合到哪）**，组合结论与月日状态冲突时，其取舍以组合为先。月日只作时间引发（外因），组合才是内因。此说与曲炜"内因外因"（liuyao-duan-liunian-skill）、姜效龙"内因是根据"（liuyao-guosanguan-skill）同构，但吕走得更远——直接不看旺衰。

批判清单（同类观点可借来检验理论）：
- **神煞理论**："神煞变化之多端，不如五行生克之一理"，古人已否定；单用神煞不能预测，单用五行六亲可以。
- **传统择日理论**：同一吉日结婚者命运天差地别，日课不能统一定吉凶。
- **八字定命**：五同生人命运不同，出生时间只相当于"出厂时间"，决定质量的是孕育环境（其风水决定论）。
- **八字／卦爻调风水**：卦爻是"X 光机"，可测风水吉凶，**不能用来长期调风水**——天时理论调地利，如按季节拆屋顶；只可作不违背风水前提下的短期补充，事应即撤。

## 三、外应预测（"善易者不卜"路径）

**外应**＝求测之事未来吉凶的现在反应。捕捉三条件（缺一不可）：
1. **正在起卦过程中**（摇卦中／时间起卦运算中），起卦前后不算；
2. **突然发生的、出乎意料**的事件（常鸣的车笛、原本坏的笔、一直在下的雷雨不算）；
3. **引起人特别注意**（无感而过不算；乞丐进门必算）。

有强烈外应可弃卦直接断；无外应则不可强取，以卦爻为主。

**分析法**：抓住外应的"关键点"→ 转成本质意义 → 与求测点结合。同一外应"开门进来一个小男孩（门未关／随手关）"：
| 求测点 | 门未关 | 门随手关 |
|---|---|---|
| 寻人 | 人很快找回 | 人已归来 |
| 求财 | 遇小人耗财但也能赚 | 遇小人破财无财可求 |
| 求官 | 小人作梗，破财可成 | 小人破坏，求官无门 |
| 危重病有救否 | 有救 | 必亡（死亡之门已关） |
| 一般病 | 无大碍 | 恶病难愈 |
| 失物 | 失物已出门难寻 | 失物在家可寻 |
| 牢狱（未入） | 牢门已开必入狱 | 进不了牢门 |
| 男测找对象 | 有争宠但能成婚 | 竞争对手，失败 |
| 女测找对象 | 白马王子出现，可成 | 不理想但已订亲 |
| 男测婚灾 | 第三者介入 | 必离婚 |
| 女测婚灾 | 丈夫回心转意 | 疑心病而已 |

关键点本质：小男孩＝小人；门开着＝有门有希望（好坏皆有希望）；门关上＝没门没希望（好坏皆不发生）。**同一外应吉凶意义随求测点变**，这是外应断法的总纲。

常见外应速查（财官方向）：小孩＝小人、官员＝贵人、男人＝君子、女人＝阴邪小人、笑声喜、哭声悲、吵闹＝口舌、吉利语言＝幸运、电话铃＝信息、门开＝有希望、门关＝没门、倒水＝破财、打破杯＝失饭碗、坐破椅＝地位动摇、铜钱掉地＝意外破财、眼中进砂＝有人失信、撕破纸＝毁约签不成、急刹声＝速停、成片鸣号＝虚名无实利、雷声＝一举成名、暴雨＝财源滚滚、狂风＝凶险有阻、乞丐＝有人相求、有人还钱物＝发财升迁、有人索债＝破财失职、制服人＝贵人、停电＝失去机会、撞车＝阻滞。伤病方向与官司方向另有对应表（如测病见乞丐／索债／停电＝死亡征兆；测官非见制服人＝有人主持公道、见哭声＝牵扯不清）。另有《搜易补·录应真经》十三类（天文／地理／来人／诸身／人事／诸物／花木／禽兽／杂见／拆字／音义／已心应）可查，用时须按求测点转换，不可照搬。

## 四、起卦资格与预测限度（边界观）

**能量覆盖原则**：自己摇卦只能测自己命运能量能影响到的事，或主动来求测之人（对方降格求助时可代测）。测自己完全不能控制结果的事（美国打不打伊朗、股票涨跌、体育比赛胜负、彩票号码）用自己摇卦＝无效——**只有该项目的直接负责人摇卦才准**。测股票应用收盘价起卦，测比赛应用球队上场射门数起卦，即用与预测对象有密切关联的数据起卦。

**定性不定量**：预测只能定吉凶方向，不能定程度（赢多少、涨几元）。因此：
- 赌博：测后不告知结果，准确率 100%；告知后再赌，准确率不到 20%（求测者贪惧改变行为，违背自然结果）。起一次测一次可准，测一把赌千把无意义。
- 股票：可定涨跌，不能定幅度，故无实用价值；宣称能测幅度者为骗子。
- 彩票：须解决三大问题——①用关联信息起卦（开奖日干支起卦、号码数取动爻）②号码与六亲爻的对应定位③出现与否的判断规则。三题未解则不可信。

**预测结果会改变被测行为**：命运预测预测的是"人按自然规律行事的结果"，不是"人知道结果后反着行事的新结果"。这是用预测指导趋避时必须知道的限度。

## 五、六爻断法操作要点（师资笔记精要）

笔记主体是风水命理（吕氏风水学），六爻仅末章，但要点锋利：

- **入手**：先定求测点 → 五行关系、六亲关系、世应关系、求测点、对应点五位一体。代人摇卦：**世为对方（被测人），应为自己**。
- **入墓分层**：用神入年墓＝久远之应，月墓＝当月，日墓＝当日，时墓＝当时；再看入的是何六亲之墓（测什么看什么墓）。测病入年墓主大凶。
- **暗动＝明动**，只是没有变爻；断法同动爻（值、合为应）。
- **日破**：用神被日冲破只代表当日不吉，出日不破；月破才论真实之破（与月日各自为政论一致）。
- **六合六冲卦**：卦中任何一爻被年月日时冲合，就不再是六合／六冲卦，失去其特殊含义。
- **三合局**：须有二爻发动且参与爻含世爻或用神才起作用；由主卦动爻变出的三合，中神必须在主卦；静爻不参与三合。此条比传统"中爻在主卦或临月日"更严（须涉世用）。
- **游魂归魂**：无特殊意义，按普通卦断，看用神与世爻关系。
- **反吟伏吟**：用神世爻不在其中则无事；伏吟老而无功，反吟反复叹息，应在四值冲开合起之时。
- **忌神**：不发动的忌神不用看；发动的忌神入墓、被四值冲克、化退无用。
- **应期**：只定性不定量；应期给时间范围，勿精确到某日（作者自认应期理论不完善）。
- **测病特殊**：凡测病不以妻财为用神，以子孙为用神（医药），参看官鬼（病）。
- **同一求测点多测**：求测点一致，摇一百次结论也应相同。

## 六、使用边界与素材缺陷

1. **《理论全集》本次抓取截断**：正文仅至第三部分（阴阳五行干支），**第四部分核心理论（求测点速查表、取用神方法、断卦思路）与第五部分 43 类分类预测正文未取到**（目录完整）。分类预测请转用 liuyao-fenlei-zhanduan-skill；求测点速查表（目录见"各种求测事项求测点速查"）本次缺失。
2. **《师资课堂笔记》OCR 质量极差**（手写体识别错误率高，风水章节大量乱码），六爻部分（末章）相对可读但也有错字，如"卦文"即卦爻、"四值"即年月日时、"归统卦"即归魂卦、"史要看到动的改对控"等需上下文猜读。本技能只收可确认的条目。
3. **旺衰否定论是吕氏一家之言**：与本技能族其余各书（增删／李顺祥／姜效龙／曲炜皆以旺衰为基）根本冲突。实操建议：用他的"组合优先"思路抓主要矛盾，但衰旺作参考不作唯一；两套并用时以 liuyao-duangua-jifa-skill 的层次法排优先级，勿因本书放弃旺衰基本功。
4. 吕氏批判性强，点名多位当代术者为"骗子"（李计忠、李涵辰、刘卫、黄鉴等）及邵伟华择时剖腹产说——这些论战性内容是作者立场，引用时注明出处，不作事实背书。其"命运由孕期风水决定"属其风水学主张，不在六爻范畴。
5. 附录部分（卜筮正宗全文、黄金策千金赋直解）为原书影印整理，属公共古籍内容，本技能未收——查古籍用 liuyao-zengshan-buyi-skill 或原文。
