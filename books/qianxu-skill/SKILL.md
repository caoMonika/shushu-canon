# 潜虚（正篇 × 发微）

司马光拟《太玄》作《潜虚》；张敦实发微。源正篇极短（图多阙），以发微补义。

## 一、总纲链

万物：虚→气→体→性→名→行→命。  
虚＝物之府；气＝生之户；体＝质；性＝神；名＝事之分；行＝人之务；命＝时之遇。

## 二、诸图职能

| 图 | 职能 |
|---|---|
| 气图 | 五行生成之气 |
| 体图 | 一至十等：王公岳牧…庶人（纲纪） |
| 性图 | 十纯→递降→五配而性备 |
| 名图 | 五十五名；周天步日；元／余／齐特殊 |
| 行图／变图／解图 | 人事与变占 |
| 命图 | 所占遇时 |

**名数**：五十有五。元、余、齐三者**无变不占**；初、上为始终亦不占。所占：自「裒」至「散」等五十二名，观二三四五六之变的吉凶臧否平。

## 三、蓍法（可执行）

- 虚数七十五，**用七十**（虚五）。
- 分二、挂一、**揲之以十**；先左后右，观余命卦名。
- 左为主、右为客；先主后客为阳，先客后主为阴。
- 例：裒卦 I 主 II 客——左余一右余二＝先主后客＝阳。

## 四、发微要点

- 虚拟元、元准易：易六十四／玄八十一／虚五十五；爻六／赞九／变七——表里而非字面对齐。
- 气：生数各含阴阳；体：五位相得有合。
- 性：相生相继、相克相成。
- 变：律吕相生喻变序。
- 行：虚→形→性→动→情→事→德→家→国→政→功→业，各用五。

## 五、边界

潜虚是宋代象数哲学体系；图位多阙处勿臆补。不作现代预测工具。
