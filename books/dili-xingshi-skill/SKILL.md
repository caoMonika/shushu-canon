# 峦头形法（本地姜 + 醒心录）

## 总流程：到地三步

1. **先观水口**——最快的一步，也是最能定层级的一步
2. **审龙**（贵龙/贱龙/真龙/假龙）
3. **点穴**（先破五俗，再避三畏）

## 第一步：观水口定层级

| 水口形态 | 结地等级 |
|---|---|
| 城门四周关拦，内有真龙结作 | 有结 |
| 罗星、龟蛇狮象守口 | 上格之龙 |
| 华表、捍门、日月镇守 | 富贵之地 |
| 北神镇塞禁口 | 大贵之龙 |
| 狮子石柱（王侯之门） | 王侯地 |
| 破墙倒壁 | 贫贱之家 |

→ 操作意义：**水口不锁，不必往里看**。凡见罗星锁口，才值得追宗问祖。

## 第二步：审龙

**贵龙 / 贱龙 的形态判据**

| 贵 | 贱 |
|---|---|
| 重重开帐，出脉中抽 | 拥胀，无星牵连贯顶 |
| 行度带蝉翼（护带） | 枝脚直硬，脉长而僵 |
| 脉细短缩（极贵） | 似鹤项鸭头，拥胀粗顽 |
| 带案带禄（贵）、带仓带库（富） | — |

**星体与所出之人**（原文对应，供辨形参考）
- 廉贞作祖（大地必有）→ 三公以上
- 龙楼 → 王侯；御屏御坐 → 宰辅文臣
- 紫气、太阳、金水、巨门、印浩 → 文贵格
- 五星九星聚构 → 理学名贤
- 太阳覆金土星 → 巨富
- 文曲水星行度 → 主邪淫（但水火土金反成富贵）
- 联珠逆生 → 翰苑文宗；五星归垣 → 贤圣
- 贪狼星秀 → 顶甲之龙；玉尺金水芦鞭 → 神童才子
- 屏帐俱全 → 状元；五脑梅花 → 科甲连登
- 三台宝盖 → 父子同科；九脑芙蓉 → 兄弟连科

**行止判断**：过峡跌断必可追；送少迎多（送山少、迎山多）行必远；来高去小（来处高、去处小）结穴近前。

## 第三步：破五俗（本技能最有价值的部分）

本地姜自述"初学缠此十余年不能解脱"，这五条是形法入门绕不过的五个坑。

### 俗一：泥于尽龙（以为穴一定在大龙尽头）

- 错在哪：尽龙星体多散漫、龙虎多不包裹、明堂阔无衬砂 → 变空旷，全无好地
- 引证：《疑龙经》"君如寻得干龙穷，两砂不关又不拦，风吹水劫不是穴，须知此处是疑龙"；"大地不在大穷大尽之处"；"余气不去数十里，断然不是王侯地"；"脉尽处须防穴尽绝"
- 正解：**腰结多于尽结**。本地姜覆按大家祖坟，腰结者甚多，近取诸山腰结居十之九
- 比喻：人身有心腹必有手足；屋宇有厅堂必有廊廓

### 俗二：泥于龙虎钳口（以为龙虎抱成钳形处就是穴）

- 错在哪：只认钳口形状，不问龙虎有无、砂水顺逆，就在钳口点穴 → 真正的吉地反被遗在龙虎之旁
- 本地姜判为"俗眼之害，惟钳口为第一"
- 正解：大地多"下手一边兜转"，或有龙无虎、或有虎无龙、或边短边长、或架左架右、或外山周回
- 反例观察：龙虎均停、明堂阔大的万人悦慕之地，多立见败坏；能"剪下手一边"点穴的反发福
- 引证："两宫齐到，忌当面之倾流"；"两宫齐到人皆道好，却主杀伤反生烦恼"；"君如识穴不识怪，只要左右抱者住。左抱右回未必吉，分明异穴生贤良"

### 俗三：泥于两水合襟（以为两水交会处必有穴）

- 错在哪：两水合襟在前，则山嘴必尖、流神必直、龙虎必长，真气荡然
- 唯一的例外：合于右而转左出、得右砂稍拦；或合于左而转右出、得左砂稍拦——这样才"庶几可裁"
- 更大的坑：送龙枝脚三五六条也会合，行龙桡棹三五节也会合，这些都不可作穴
- 引证："两水合处莫当中，流神倾泻最为凶"；"两水合处莫当中，不在右边在左边；仙人倒杖须横作，下手纵宽也进田"
- 判语：**宁居坐空（下宽）也不居合水之直处**——因为坐空之忌小于合水直冲之凶

### 俗四：泥于顶正星峰（以为穴必点在正顶）

- 错在哪："误葬皆因贪正面，神仙多是下偏坡"
- 可正下的四种情况：地小、顶平、脉缓、微高微突（此时龙身无煞，美意停息不窜）
- 必须侧下的情况：山形粗雄硬直、稍倾泻、不分阴阳、煞当头——直下必伤人
- 侧下的两种依据：
  - **审来龙**：龙不善则另择；龙特达而砂水秀异不可舍者，于龙虎臂上细寻稍平、高低远抱处
  - **裁砂水**：左砂有煞点于右，右砂有煞点于左；剪着去水一边尤善
- 古法穴名（说明侧下是常态而非例外）：跳墙虎之脉穴、飞天龙之耳穴、太阴金之角穴、太阳金之角穴、凤形鹅形之眼角与支翅、蛇之耳窝、下水龟之肩井
- 臂上取穴层级：咬虱穴 → 鼠肉穴 → 曲池穴 → 堂心穴（臂太直取尽头）→ 袖口穴（臂飞扬如舞袖，取略平坦处）

### 俗五：泥于阔大明堂（以为明堂越大越好）

- 错在哪：明堂的作用是"聚后龙之气、界穴前之水"。太阔则风乘气散、堂气荡然
- 关键条件：**阔大明堂必须有一砂紧拱、内局自成家务**（"汪汪万顷明堂水，内局周围如转环"），否则发福迟；若连内局水口都无，则破败涂地
- 判语："明堂容万马，水口不通舟"——容得下万马，但水口连船都过不去，这才叫好
- 反例：无内局、只有清贵龙与秀异朝山 → 主贫穷孤寡五六代后才发；或暂贵不富、有官无禄、富贵不长久，"有头无尾，得一失三"

## 第四步：避三畏（先求无祸，再希福）

### 畏一：到头硬直

- 判据：作穴处务要平正，稍硬即谓之"杀"
- "枪头莫下，鼠尾莫扦"；"劝君莫下枪头穴，葬下人丁绝"
- 具体形态：片来略无停息、峦头粗硬太直如饱腹状、势如覆钟状、绷面金星、直体金星而卧梭——**俱有死无生**

### 畏二：穴前倾泻

- 底层原理：**砂主人丁、水主财；水聚财聚，水散财散**
- "明堂如播米，子孙穷到底"；"龙虎似推车，田地不留些"
- 阴流直水（看不见的地下水路）比明流更凶、应验更快："阴水不顾家，葬下乱如麻"
- 识破一个骗术：水边看像"生蛇屈曲"，登穴高处远望只是一脉荡然。**真正的屈曲标准**：左转右十余丈、右转左十余丈相交织成横水样
- 容忍度判据：去水地"依法亦要八分得才可"；畏处多、可取处少则该弃

### 畏三：顺砂过堂

- 底层原理：**顺逆专以水之来去为主**
- 定义：右水倒左，则左边高山、田塍逐级高者为"下砂/进神"（愈出愈长愈福）；若该在下的砂反在上，不论长短即"顺砂/退神"，逆窜而过者"尤至毒害"
- 口诀："天门欲其开，地户欲其闭"；"所喜者三门宽阔，所求者五户闭藏"；"水来自左，无左亦可；水来自右，无右亦就"；**"剪下砂莫剪上砂，剪进神莫剪退神"**
- 观察法：水来这边必逼窄、山高田高；水去这边必阔旷、山低田低。若能把山川性情"拘转"成来处一里宽一里、去处一里紧一里，则地理过半
- 引证："两水夹一案，定作退田断"；"退官退笔从尖尖出，进官进田笔弯弯兜水入"；"东宫过西宫长房败绝，右边尖射左臂少子贫寒"
- 例外：逆局逆龙（山逆水逆）力量大，此时上案上手砂不妨

## 附：龙虎砂逐形断语（醒心录）

### 总纲
"只可龙欺虎，不可虎欺龙。"
- 龙（左）宜起库而蜿蜒，属吉神
- 虎（右）宜俯伏而驯俯，属凶神，**虎手尤可畏**
- 无龙则要水绕左边，无虎则要水居右畔
- 先到后到，湾环抱穴，遮蔽八风，勿令吹散，生气始佳
- 本身生出、圆净、逆水插上者力重；顺水弓抱者力轻
- **逆水不忌雄强，顺水最嫌弱软**

### 十吉格 / 十凶格
- **十吉**：降伏、比和、逊让、排衙、带印、带笏、带剑、带牙刀、交会、开睁
- **十凶**：相斗、相吞、相射、飞走、推车、折臂、反背、短缩、顺撺、交路
- 另忌：高压、强硬、摆面、断腰、嘟尸、嫉主、破碎、巉岩、粗恶生石、瘦弱露筋、插落投河、内抱员墩、腋下夹尖砂

### 单边断语要点
- **龙首低、虎雄欺**（虎高龙矮）→ 长子贫穷小子富
- **青龙尖如按剑**横在面前 → 儿孙主法场、割喉
- **龙山凶势粗恶带石巉岩如牛角** → 长房出凶人，周年瘟火
- **青龙窜、摆转头向外随流水不收** → 子孙离乡，三五年走他州
- **龙上有人行路**（路在龙脊）→ 年年灾祸、儿孙悬梁
- **虎嘴长似持枪**：枪头向外 → 外乡亡；向内 → 家中自杀伤
- **虎山头似绳长** → 自缢吊高梁；若是断坑头落水 → 子孙遭溺
- **虎山窜如反手、又似娥眉风摆柳** → 妇人淫乱、花酒丧身
- **虎山雄如三猫儿回头望穴** → 儿孙遭虎咬
- 龙畔三尖入 → 三子命中急；虎畔三尖长 → 媳妇受灾殃

## 边界（必读）

1. **本技能只覆盖形法，不含元运理气**。形法判"能不能结"，理气判"什么时候发"。两者结论可以相反，不要混用。理气见 `dili-bianzheng-skill`。
2. **本地姜书的版本问题**：正文是清末民初广东化州人梁凿贵的无题手抄本，由后人转录上传，**前言自述"几经周折，仅得其一本手抄本，且没有书名"**。所以：作者归属可靠（地方记载），但文本经过至少一次手抄转录，讹字难免（如"红**妓女穴"处明显有脱字、"不知何虎有营生"疑为"何处有营生"）。引用时标注来源性质，遇缺字不补。
3. **《地理醒心录》**题"明·天中星垣主人"，内容为龙虎砂口诀体，属明代形法流派常见体例，本库文本仅 3.3KB，疑为节录而非全本。断语中的"淫乱""乞食""法死"等为时代性套话，整理保留原貌，不代表本技能立场。
4. 传统术数知识，非可验证的因果机制。实际选址/营建涉及地质、排水、结构安全，须依专业工程意见与当地法规，本法不能替代。
5. 涉及他人墓宅的评断，属民俗文化范畴，不构成对具体人命运的判断，也不应作为对他人的评价依据。
