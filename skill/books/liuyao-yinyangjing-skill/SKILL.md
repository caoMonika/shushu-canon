# 六爻阴阳经（苏文）：四柱六爻同息与阴阳分类生克

依据 `_src`（`txt_...9cc8f3cd...`，苏文《六爻阴阳经》，承其《四柱阴阳经》1–6 期辅导资料）蒸馏。总纲：**六爻与四柱全息同息**——世爻完全等同于四柱日干，卦爻人体信息与八字可逐条互证（每例均以"六爻课局与四柱同息比较"列对照点）；万物变化只守一个"阴阳之理"。方法论核心是用八字验证卦理：卦理若与四柱同息规律矛盾，则卦理有误。

## 一、十二地支阴阳分类生克（全库独一份的地支分类）

| 类别 | 地支 | 别名 |
|---|---|---|
| 阴 | 亥 子 丑 辰 | 太阴 |
| 阳 | 巳 午 未 戌 | 太阳 |
| 中阴 | 申 酉 | 少阳 |
| 中阳 | 寅 卯 | 少阴 |
| 至中 | 未 戌 | （重出：未戌兼属太阳/至中） |

- **同性能够共存，且有互旺之意**；同性内部出现合，以**合绊**论。
- **阴阳作用必有损益变化**。十二地支之间只有阴阳作用生克关系，别无其它——这是本书断一切的总开关。
- 辰丑与未戌**不能共存**，二者作用必有减力：艮纳辰丑、坤纳未戌，后天八卦艮坤阴阳对立即相克（干巽、兑震、坎离对立皆相克），**不存在"土气相冲而旺"之说**。

## 二、破旧立新（本书旗帜观点，与传统全面冲突）

1. **否定四墓库**：月日建为辰必扶亥子、为丑必生申酉、为戌必扶巳午、为未必耗寅卯；古人"亥子旺见辰论库、衰见辰论墓"违背阴阳之理且实测不准。**五行之间只存在阴阳生克，无墓库**。
2. **否定空亡**："空亡同其它神煞一样，均属谬谈，应当废弃而不用。"空亡之爻照样生克（寅木动照样生变爻巳火；酉金耗世爻照样起作用）。古法"逢空填实定应期"实质是**该爻值年月日时四建增力**而已，非空亡之功。卦例经四柱同息比对验证。
3. **静爻同样具备生克大权**（反对只重日月动爻）：静爻可引发生死吉凶大事。例：官鬼未土静爻脆动爻酉金作用巨大，丑年冲未则未不脆酉——85 乙丑父去世、97 丁丑母大病。
4. **流年断法次序**：必须先看流年对卦爻旺衰损益，流年断完再断月、日、时；**绝不可跳过流年从月或日时直接断起**（斥传统断卦思路为错误）。

## 三、六爻格局（世爻=日干）

- **正格**：世爻旺而可抑（四建/课局之字能直接或间接减力使之趋向中和）／世爻弱而可扶。
- **从格**：从强（旺极不可抑，顺其旺）／从弱（弱极不可扶，顺其衰）。与四柱相比少了化格。
- **运限**：不用卦爻起运限（经研习诸古法均不正确），**以四柱大运代表六爻运限**，再以流年引发课局信息——因课局与四柱同息，大运引发八字信息的机制同样适用于六爻。
- **旺衰评定**：以月建、日建影响最大，年建、时建次之（同四柱月支日支对日元）。

## 四、位置力量与天干纳支

- **卦爻位置力量**：相邻两爻位置力量发动性最强，隔爻次之；断旺衰要特别考查世爻的**上爻、下爻、变爻、伏爻**（对世损益影响最大）。例：三卯与日元相隔不作用；官鬼申金紧邻世爻耗之=辛金合绊丙火之同息。
- **四柱天干纳六爻地支**（天干信息由地支爻体现）：甲乙→寅卯爻；丙丁→巳午未戌爻；戊己→辰丑爻（土生金角度）／未戌爻（土克水角度）；庚辛→申酉爻；壬癸→亥子辰丑爻。天干甲泄壬=课局动爻寅泄世爻子。

## 五、断卦操作要点

- **同息比较法**：拿到课局先与命主四柱逐条对照（用忌、组合、位置），一致则卦可信；断事用大运+流年引发课局组合（如"子合绊课局忌神丑财大吉→财发"、"辰冲戌为凶→胃病耗财"）。
- 静爻脆/克之作用看**冲破该静爻之字**何时出现（丑冲未=解除未脆酉）。
- 阴宅断法一例：官鬼未土起好作用→断"东北来龙、西南最低"应验；世爻与三爻兄弟亥水距官鬼远近不同→断自己富贵寿元大于姊妹。
- **天人感应**：多次摇卦均可正确反映人体信息（意念不同、侧重面不同），此即摇卦机理；同年同月同日同时生者命运差异由感应空间点不同造成。

## 六、全息调整四法（"天下万物皆可致病，天下万物又皆可为药"）

1. 阴阳宅调整（从出生时阴宅测用忌，自谓密法未公开）；
2. 六亲避忌：财为忌则娶妻败家、子孙为忌则生子丢官——知某六亲有害就少接触以减少感应；
3. 方位：到用神方位诸事平顺，到忌神方位诸事不顺；
4. 药物：药有五味配五行，按命局病根选味（肾病根在木旺则首选辛味之药）。

3. 地支阴阳分类（辰丑归太阴、未戌兼太阳/至中）为其一家之言，库内仅此一份；"同性互旺、同性之合论绊"是其独有判据。
