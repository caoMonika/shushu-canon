# 六壬说约·粹言·辨疑（三家断法）

## 一、《大六壬说约》清·张鋐（嘉庆庚申，江村人）

自序立总纲：习壬四十年，"吉凶不外生、克二字。诸凡吉神吉将吉星皆可以生总之，凶神凶将凶杀皆可以克概之"，持此断课十中八九。删繁汰杂、义归中正，故名"说约"（博学详说而后能说约）。

### 1. 入门法（法详尽而语显明）
- **干支**：干为身，支为人、为事。**支生干为吉，克干为凶**——大纲也。干寄宫：甲寄寅、乙寄辰、丙戊寄巳、丁己寄未、庚寄申、辛寄戌、壬寄亥、癸寄丑。
- **月将**：太阳所躔之宫，每逢中气过宫，据时宪书定。月将加时成课。
- **四课**：地盘干支上所乘天盘之神布四课。
- **三传**：用神为"主事之神、吉凶之先兆、祸福之根基"；中传移易之门，末传归宿之地；中末取相因之神。
- **发用十一门**：元首（一上克下）、始入（一下贼上）、重审（有克有贼取贼）、比用（取与干比）、涉害（俱比取涉深；孟上神为见机格，仲上神为察微格）、遥克（蒿矢/弹射）、昴星（阳虎视转蓬/阴冬蛇掩目）、别责（阳取干合上神、阴取支三合前一神）、八专（阳顺数三/阴逆数三）、伏吟（有克用刑，自任/自信/杜传格）、返吟（有克依五法，无克井栏射格）。
- **天将**：阳贵起子顺布（甲布子……癸布丑），阴贵起申逆布；卯至申时用阳贵，酉至寅时用阴贵；贵临天门前顺行、地户前逆行。
- **六亲**：生干父母（文书）、干克妻财、干生子孙、比干兄弟、克干官鬼（异阴阳为官、同阴阳为鬼）。
- **年命**：本命定位（男命甲子以地盘子为命宫），行年男丙顺数、女壬逆数。

### 3. 十二天将（吉凶之指决于十二将）
- 总则：**生神乘某将指某等人德，克神乘某将指某等事殃**。将随神转（贵乘申酉属金论），神克将内战、将克神外战。乘神生干则凶将亦吉，乘神克干则吉将亦凶。贵人统御十一将：生合日干年命虽蛇虎不凶，克冲虽龙常不吉。
- **贵人**（己丑土，吉）：临子解纷（投谒不见/去官兆）、丑升堂、寅凭几卯登车（占病贵作鬼临卯迫魂主死）、辰戌履狱、巳受贡午乘轩、未列席申移途、酉入私室（逃去）、亥登天门秉笏。得地得令则展猷施仁，失地失令偃蹇。贵空陷忧喜皆无实。
- **螣蛇**（丁巳火，凶）：主惊恐忧疑怪梦胎产。临子坠水丑盘龟寅生角（衰则不宜干进）卯当门辰象龙巳乘雾午飞空未入林申衔剑（凶极）酉露齿。占怪异占梦先视蛇及蛇阴；旺相活物有形有声，休囚死物有声无形（加寅猫豕怪、卯狐犬怪、申道路怪、酉金缯怪、戌坟墓怪、丑宅舍怪）。蛇乘财旺为用因贱货获利。
- **朱雀**（丙午火，吉凶）：文书词讼音信口舌。丑掩目寅卯安巢（雀发用则口舌必起信即到）辰投网巳午衔符（文书音信即至）未临坟啄食申励嘴。科举以雀为主星，与幕贵生合必中；词讼雀生干词得理。**雀临午为真朱雀**非细之讼直达朝廷（须与太岁月建生合，否则大祸）。占信雀为用即到，乘神与干知信中意思。
- **六合**（乙卯木，吉）：婚姻喜庆委曲成就。寅乘辂卯入门（婚姻来福）辰违礼巳不谐午升堂未纳彩。占婚要神（媒）；占生意主星；缉捕忌六合入传（私门难获）。乘卯酉子午为"六合不合"阴私相怀。
- **勾陈**（戊辰土，凶）：征伐争斗讼狱。丑受钺寅遭囚卯受制辰升堂（狱吏勾连）巳捧印（改官）午反目未入驿申趋户。占战勾克武主胜；占捕勾克武可获；占讼勾生合则和解、勾阴见雀讼必固结、勾见蛇虎成大案；讼师自占勾旺相临年命为用生合支上者投之多。常占不离**迟滞牵连**四字。
- **青龙**（甲寅木，吉）：财宝婚姻增福。子入海丑蟠泥寅乘云卯驱雷（得地有为）辰入庙（占天无雨）巳掩目午烧身（巳又飞天占雨占官升）未在陆申伤鳞酉折角。占官文视龙（武视常），乘太岁月将官居极品；占财主星须入课传；占婚须生合干支年命；占盗忌龙入传（贼远去）；占行龙入传转往他处。披刑带煞作鬼即变杀神。

### 4. 卷中精要
- **分野分方**：十二宫配古国今省府；占远处用分野、近处专按分方（亥西北子正北……），地盘为彼处，视地盘上神将推吉凶（仕人占任所看官星食神二马天恩临处）。
- **星煞**：只列大星煞（"小星煞皆无验"）——岁煞（太岁/岁德/岁合/岁破/岁刑/劫灾岁三煞/大煞/大将军/破碎/病符/丧门吊客）、四季星煞（天城天吏天喜天赦钥神转煞四废三邱五墓丧车浴盆天目天耳飞火鬼关管）、月星煞（月建/生气/成神/会神/天财/天恩/天马/天医/解神/月破/死气死神/血支血忌/产煞/咸池/月厌/飞廉/天鬼/雷公风伯雨师）、日干星煞（日德/五合/日禄/进退神/阳刃/直符/游都鲁都）、日支星煞（支德/日马/华盖/破碎/桃花/八妖/河加井）。
- **旺相休囚死**：当时旺、时生相、生时休、克时囚、时克死。干支神将虽休囚死得生扶不以全衰论。干旺略生即起逢克无妨，干衰略克即伤逢生未必益。
- **长生十二神**：干用八长生（阳生阴死），支用四长生。长生入占生扶悠久（戊寅庚巳系官鬼、乙午己酉辛子癸卯系脱气，课吉论长生凶论鬼脱）；印神次之（乙亥子/丁寅卯/戊己巳午/庚未戌辰/辛未戌丑/癸申酉；甲丙壬只有长生无印）。**墓**：干支坐墓困厄无立足（占病忌）、戴墓抑塞被蒙；长生坐墓不能生扶、戴墓新事欲废；长生坐干支之墓旧事中新事又起；禄神入墓失禄；**吉神类神入墓最忌，日鬼入墓最喜**；三传生旺传墓成而后败，墓传生旺败而复成；中传见墓中间有阻，末传见墓百事无成；昼墓（辰未）刚速夜墓（戌丑）迟缓；**墓喜冲忌合**（冲开化吉，合闭大凶）。
- **德**：阳干德在寅巳申亥己位、阴干德归于合。日德发用或临干并日合贵人有意外之喜（不利占病讼）；日德发用为鬼仍作德断（德化鬼，丁辛二日）；**文德格**（日德作官星发用乘雀）应试得官；**鬼德格**（日德发用得同下神克日）邪正同途（辛未乙酉两课）。德宜旺相忌衰囚，值空亡忌，临死绝减力十之六。
- **合**：五合上（甲己中正/乙庚仁义/丙辛威权/丁壬淫泆/戊癸无情；逢龙即化，视化出之德生克）、六合次（辰酉午未相生紧；子丑卯戌相克、寅亥巳申合中带破刑难成久）、三合又次（水局流动/火局党侣不正/木局繁冗/金局矫革；虚一待用格、凑合格主意外遭逢）。合神克干乘凶将貌合心离。
- **鬼刑冲破害**：日鬼临干发用灾切近而速；救神=子孙（克鬼）、父母（脱鬼生干）；**明暗两鬼（攒眉格）**两重灾难只能解明；日鬼为用末见财=财动生鬼两番灾（自招其祸因贪财）；鬼多有制先惊后患（鬼乘虎难制）；**鬼脱生格**（鬼用生末传为干长生）先凶后吉。刑主伤残（无恩/无情/无礼/自刑），冲主动散（凶逢旺不可冲、逢衰可冲），破主更变（凶事可解吉事无成），害主疑忌（宜静不宜动）。
- **始终**：初起中移易末归结。初吉末凶终于凶，初凶末吉终于吉；初凶末克之可获济，末吉初克之无成。
- **数日颜色新旧亲疏远近众寡迟速**：数目用类神上下相乘（旺加倍休囚减半），随机酌断；颜色干支天将各有所主（乙青带白、辰黄杂黑等）；新旧用起旺相/长生/孟为新，休囚/墓/季为旧；亲疏看合生与否；远近看隔位数；众寡看三合局/比肩/连茹/河魁；迟速看贵人前后（前速后迟）、用神旺相（旺仲尤速）。
- **已往未来**：用临干前为已往、后为未来、临干当时；天罡同断（罡离干四位无灾）。

### 5. 卷末杂说（实占心法，二百余条择要）
- **拟易**："六壬与易无殊"——干上吉支上凶三传凶者宜静守；干上凶支上吉三传吉者宜动行，即进退存亡之道。
- **提要**："壬数吉凶视十二神，变化视十二将，旁推视诸星杀"——时人忽略神将漫推星煞，舍本逐末百无一验。
- **遁干**：只视旬遁之干，不推五子元遁（三干叠排毫无验处）。
- **占要**：诚占必准（心一而已）；一事只占，再占则渎（疾病危急灾难逼迫虽迭占亦准）；取课金非贪财，为使人不得已而心诚。
- **正时**：正时与所占之事针对者必准；课体显明者准，茫昧者不准。亦可以月将加所见所闻之时布课。
- **生克**："用取克而吉视生，此六壬之神机妙用"；无克不成事，无生不成名。
- **合冲**："合则视冲，冲则视合"——合不动故视冲，冲将散故视合（冲合之神须出现）。
- **衰旺动静**：干衰宜生旺不必生；合神衰不能成合、冲神衰不能冲动。神吉动静宜生不宜克、不宜合（伏而不发）；神凶宜克宜合宜冲（动）。
- **用神**：断事凭用神神将但未可拘泥——昴星别责八专井栏用神空则舍用专取干支年命；三六合吉凶全在用神（动机），但两局互克互冲者未可全凭。
- **四废**：为用百事无成（俟废神当令）；阴神生之不以废论；作月合月将不以废论（卯酉）；临旺相地上旧事从新。
- **四墓覆四生**：未可漫云复起，须视传内有生干之神始的；须未加亥戌加寅丑加巳辰加申方的。
- **困厄**：极困时不宜得大吉课（宜中平，一端好处即转运之极）；极困忽得大吉、极散忽得抟结之课，须吉处寻凶、合中寻冲，令本人自忖才德。
- **数人数事**：一课数事舍课传就盘内类神推；一课数人就各本命推（雀生合本命/两贵拱夹/贵加命/德禄加命者中）。

- **应期**："总不外一时字，时至自应"；远则课象散漫类神离干远，近则课传结类神临干或为用。
- **次客**：诸法纷纷无义可寻，全无取焉；课同而占事不同各按所占断，课同占同者以各人年命参较。
- **天时**：占晴雀为主（雀用有气久雨必晴），占雨龙为主（久晴必雨）；晴期视生、雨期视合；久否大小视龙雀阴神。占雷六合卯巳（遁丁迅雷），占电蛇雀巳午，占风虎寅（三传寅午戌暴风），占雪太阴酉（三传纯阴虎武中末雪大）。
- **地理**：武为风水所（临宫定方），青龙来脉、螣蛇穴场（龙生蛇旺相不空有真龙正穴）、勾陈明堂照山、阴后水口、白虎凶煞；贵顺行水右转逆行左转，三传与贵紧关包固气聚为上；地下视蛇宫（临亥子有水、申酉山根石骨、巳午有虫；坟墓煞枯骨煞下有古墓伏尸）。干为人支为坟，支上吉并生气生干人丁繁盛；初传一代二传二代三传三代，何传吉旺何代兴发。
- **住宅**：干人支宅，支生干吉；三传生干人口旺、生支家业兴。地盘子内房丑庭院寅申走道卯酉门户辰戌墙巳灶午堂未井亥园厕。占新旧：干/初传旧宅，支/末传新宅，旧吉宜守新吉宜迁。
- **终身**：先视寿夭（命上长生荫爻旺相乘吉将寿高）再视休咎（初少中壮末老，三递生富贵寿考）；命上神将推人品（贵龙常有官君子、蛇鄙贱摇惑、虎残暴、武邪淫卑污）。
- **婚姻**：首重男女年命作合（女命六合/行年六合/交车合等必成），无冲刑破害万不能成；将来吉凶以财官判（财官旺相白首同归，空陷中道弃捐）；女占婿视官爻、男占妇视财爻乘将定性情；媒妁不入课传尚须待时；六合上三合忌（庞杂）；近亲远婚看比用/遥克与隔位；娶赘看官用/财用随龙后。
- **子嗣**：命上见子孙旺相不空者繁衍；初传子爻一二年得、中数年、末晚年；最忌父爻为用克子；比爻为用遁干作子以兄弟之子为子。
- **考试**：县府院试雀为主星（乘旺相文佳），贵人为试官（雀与贵生合定获隽）；乡会试以**幕贵**为试官（雀与幕贵生合中式，衰废克冲斥落；雀衰与幕贵生合中副榜）；金殿须雀与太岁生合；名次按雀乘神数断。会殿须禄马俱到。
- **官禄**：先视命上（长生荫爻日德贵龙常为命里有福）→ 日干旺相 → 三传（荫爻官星乘吉将）；无生起官星之神将而骤见官星恐是灾晦；雀生官由甲第、龙生官由捐纳、蛇武生官出身不明。推官品官星上下相乘；龙作印文官、常作印武官；三传俱鬼旺刑部臬司、俱火旺学院、俱土旺封疆。占升转以长生荫爻为主（不入占上台不荐）。
- **贸易求财**：荫爻逢丁马行商、不逢坐贾；货物揣类神、本看日财、利息看遁干天将之财。财不宜太旺（干衰不能进财）；财加命命中合得、加行年本年应进、加干财来就我、支作财加干人愿馈我。三传纯子孙不求财财自至（年命见财可望大获，终不免脱耗）；墓神为财大不吉、绝神一得不能复得、胎神暗财日增月益。财乘阴武暗财赃财。财数相乘作数以少为断，财衰干旺一口吸尽。
- **疾病**：本人自占克干为鬼，占亲属定六亲以克六亲者为鬼（亲友主仆代占仍依日干）；制鬼子孙=医星、脱鬼父母=救星、制虎者救星；鬼虎临命纵有制亦带疾终身。类神夹克/内外战为用病已深，中传制之可救反生无救；日干空遭夹克必死；忌墓神财爻为用克伤生气；**子为用作鬼必死**（子宫哭泣煞坟墓煞，占小口尤忌）；二马临干支乘龙常值空=纸钱孝服煞不救。毒症取蛇为类（蛇不入占视太乙）；痘花取雀为类（雀不入占视胜光太乙，逢生起发、入墓花回）。
- **灾难出行**：日鬼为难星子父为救神；干上凶支上吉宜避他方、干支皆凶初中末吉宜远行、盘内长生临官方避之。出行干现居支所到，干上吉支上凶不宜行反之不宜守；支上见长生印爻日德贵人财龙视所图；进茹罗网不能行、退茹行必迂回；最喜三递生、最忌三递克。
- **行人克期**：干支六合课传三六合支传干皆必到；三传逆行到、顺行不到；连珠间传不能即到；游子斩关顺传转他方逆传来速；刚日伏吟/返吟/四绝体到速；寅加酉为关辰戌加卯为隔申加卯为锁（乘将克之阻而复通、生之阻绝不到）；初空未登程中空中途阻末空近处阻；传墓入墓皆即到。克期：水视卯（卯遁干逢绝为到期）、陆视二马旬丁白虎（马以克处为到期）；或视用神合日（近六合远三合）。
- **音信**：雀为主星，临干或为用即到（中末迟远）；乘丁马速；雀不入占与干生合久后仍有信；空亡无信。克应期：雀临干极速多应本日，余以乘神或遁干逢合之日。
- **干贵**：《指南》诗诀"干谒之利三六合……末传合处是成期"至准不易；三递生到干谒贵如意；求名求荐视长生印爻、求财视财爻，最忌求名而见纯财。投书视雀与贵生合可投。
- **缉贼藏赃追逃**：武乘神推贼形状、遁干推服色、临宫推匿处；上下生合有窝家难获、冲克无窝易获；贼踪三传（武临宫现在匿处、武阴转徙之方、阴之阴逃往之处）；三合者辗转不离局易缉；武入墓易捕、乘太阳易败露；勾为兵役（勾克武必获、勾空无役在外）；罗网课捕必获。藏赃视武所生（金藏河井、水藏林木、木藏窑灶、土藏土窖、金石下）；失物视类神临方，空亡难得。追逃：武阳神临方女藏处、武阴神男潜处。
- **杂占**：灯花/雀噪/眼跳以胜光雀为类；扣门视正时神将（神扣门人、将来事）；歧路干上吉左支上吉右，三歧罡加孟仲季定；物价财旺价昂财衰价低（龙贵蛇贱）；沽酒酉为类（加孟新酒仲陈季败，乘贵常甘醇、合龙酸、蛇雀燥、武后淡浊）；占猫以寅为猫、其子爻数目断（实占三只，压死验）；射覆以正时为先机、用神为本质、乘将为变化（实占茶船/钱串验）。

## 二、《六壬粹言》清·刘赤江（蛟门慕甫编）

### 结构与精要
- **卷一 辨非十则**：辨正十处讹说——月将、十干寄宫、旦暮贵人、五行十干生墓、土墓从火、涉害、别责、八专、行年、列宿分野。教学纠偏价值高（如"土墓从火"等争议点的辨析）。
- **卷二~四 课法补谈**：立课（两仪阴阳、三传初中、上克下贼、比用、见机察微、蒿矢弹射、昴星俯仰、不备、八专、伏吟杜传、驿马、旦暮贵）→ 经课（顺茹进间退间、曲直炎上从革润下四局、生胎顺病胎逆、四仲关隔、季神穭穠、四绝暗干、墓覆干头、十二地盘）→ 要将（太阳月将主宰、正时先锋、岁主一年、月建一月）。
- **卷末 实占章**：含占宅、占病、占婚、占讼、射覆等门，各系实占验案（如射覆断"水火所铸、首尾高中洼下、龙属水形长、后水加午受煎熬为茶"断茶船；断钱串"初传空取不空为断、亥丝绳申钱义、递生连而不断、亥四申七合二十八"——数目断法实证）。

### 断法特点
- 重**立课法度辨讹**（十则辨非逐一澄清流传谬误），是教学纠偏类上品。
- 实占以**三传取象**（水火相加定材质、递生定连断、初末定首尾）与**数目相乘相并**为长。

## 三、《六壬辨疑》（同治己巳牧源堂梓，楚北张次功一系）

- **源流辨**：考壬学源流——汉志无壬籍，唐《五行志》始载《六壬杂占》九卷，宋志载三十家；又引《国语》伶州鸠、《越绝书》公孙圣、《吴越春秋》伍员范蠡四课，证其来甚远、兵家所藉重。驳"出黄帝元女"之谬。
- **体用观**：河图主常（数极于十为体）、洛书主变（数极于九肇用）；天地盘之用、三传四课之发动、三奇六仪八门九星之加临、八将三基五福十精之经纬——"成变化行鬼神利物前民用"。
- **新旧始终断**：日辰见亥木生将来事主新物应在父母，见卯木旺目下事主不新不旧忧同类，见未木死已过旧事旧物忧妻奴下人；刚日用神干前未来干后过去，柔日反之；初旺将吉末囚将凶=始吉终凶事先成后败，初休囚凶带刑害末旺将吉见德救制=始凶终吉事先难后遂。"统节之体，乃蜃气楼台之课。"

## 判读心法（三家合参）
1. **总纲**：生克二字（说约）→ 神将得地得令（说约十二将）→ 立课法度无讹（粹言辨非十则）→ 源流体用不惑（辨疑）。
2. 用取克而吉视生；合则视冲冲则视合；衰旺动静四字贯穿。
3. 大星煞有验小星煞无验；神将为本星煞为末。
4. 实占杂法（射覆/数目/寻访/物价）随机触类，未可拘泥成说——"漫执成说以谈，百无一验"。

## 使用边界与素材缺陷
- 三书皆断法精要/杂法类，起课基础与课体大全请配合 `liuren-xinjing`、`liuren-daquan`；毕法条文见 `liuren-bifa`。
- 《说约》版本为现代排印本，正文完整清晰；自序"隶首起数、六壬始于大桡成于隶首"系作者考据说，与辨疑的"唐宋成书"说并存，各依其据。
- 《粹言》OCR 繁体转简有讹（"車法"当为"课法"、"華法"当为"毕法"、"旦謦"当为"旦暮"、"罩銓"等），目录页码错杂；正文大意可辨，细读须对原书。秘籍网水印行已剔除。
- 《辨疑》前半为源流辨（序），后半为新旧始终物类断；中间课体条目 OCR 中等。序中"袁金溪""张次功"等人物考据未及详核。
- 三书实占验案中的数目断（相乘相并）"只得大略，未能一一不爽"（说约原文自注）——数目断只作约数参考。
