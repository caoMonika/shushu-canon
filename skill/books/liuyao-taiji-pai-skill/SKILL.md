# 太极派六爻（四柱化格局法课程）

网络课程讲义（依托元亨利贞网排盘示例），体系特征是**把四柱旺衰格局思路搬进六爻**：先定世爻旺衰成格局，再看用神对世爻是生扶还是克制定吉凶（"和四柱原理类似"为全书口头禅）。基础装卦部分（起卦、八宫、纳支、世应口诀、六亲六神）与他技重复，此处只收判据与该派独有规则。格局路线可与《liuyao-shiyaowangshuai-skill》《liuyao-xiaoao-qianian-skill》对读。

## 一、卦格四分与吉凶判定

- **世旺卦**：用神生扶世爻以凶断，用神克制世爻以吉断。
- **世弱卦**：用神生扶世爻以吉断，用神克制世爻以凶断。
- **从旺卦**：同世弱（顺其旺势，生扶吉）。
- **从弱卦**：同世旺（顺其弱势，克制吉）。
- 格局判定要点：应爻生合世爻可成从强；世爻空亡先论弱；六冲卦应爻冲世论世弱。断卦主要看三点：①用神与世爻的作用；②世爻的临爻对世爻的作用；③年月日对各爻的作用。

## 二、爻之作用规律（九条）

1. 静爻与静爻相邻作用，隔不作用。
2. 世爻与应爻可直接作用；世爻与临爻作用。
3. 动爻可与所有爻发生刑冲合。
4. 动爻与动爻之间可生克制化。
5. 动爻的变爻只与该动爻作用，不与其他爻作用。
6. **动爻化出的空亡之爻不与动爻作用**（卦例：寅木化酉金回头克，酉金空亡则不作用，财仍吉）。
7. 动爻空亡不为空，出空发生作用。
8. 静爻空以空论，吉凶反断。
9. 月令空亡则月令无法决定各爻力量。

## 三、用神取舍（该派特色）

- **用神不现**：不取伏神飞神那套（"经验证不正确、起码不完善"），**直接看该用神五行在四值中的状态**断吉凶。卦例：测妻出走，财爻不上卦，子水在四值中旺 → 无恙即归；方向按卦宫定（艮宫→东北），应期按用神旺"今明两天"。
- **用神两现**：先舍空亡取不空；都不空则取**卦宫正统爻**（本宫首卦同位之爻）。卦例：离为火测子病，子孙丑未两现，取卦宫丑土为主看。
- 伏神仍记录（写在飞神旁），但断吉凶时以四值状态优先。

## 四、断卦实例要点（11 例浓缩）

- 测姻缘（地泽临）：从强卦财爻生世大吉，但父母巳火动空化回头生，出空冲亥水泄世 → 不成；父母=工作，女方嫌其工作。
- 测求财外出（天山遁）：世弱世空（信心不足），世爻官鬼化财回头生，当月帮扶 → 大吉；父母辰土晦世有麻烦，但动化子水回头绊 → 无碍。
- 测竞赛奖（天火同人）：世弱官鬼持世化父母卯木忌神，忌神被未土合绊受制、酉月世有力 → 得奖。
- 测钱包（雷天大壮六冲）：世弱喜生扶，财爻子水冲世为忌，兄弟辰土动合绊子水 → 找回（忘在同学家）。
- 测生意（山地剥）：世旺子孙持世需抑，财寅木泄世吉，寅化酉金回头克但**酉金空亡不作用** → 生意不错。
- 测衣服（雷天大壮）：从弱需抑，财子水被丑土回头绊+戌土克 → 找不到，兄弟引发为被偷。
- 测贷款（地天泰六合）：世旺兄弟持世，财亥水弱+官鬼空（官方不满意）→ 仅批数千元。
- 测阿姨病（天水讼→火水未济）：从强，财申金动空，动空出空填实发力，戌月旺、化未克力弱 → 申日出空病亡。
- 测讨债（火水未济）：世空世弱，财酉金旺为忌、辰土动生忌 → 讨不回。
- 测妻子出走、测孩子病：见上"用神取舍"。

## 使用边界与素材缺陷

1. 源为课程讲义 PDF OCR，排盘截图/mermaid 图残留乱码，个别爻排盘错行（如"乾为天六亲配干支混排"），卦例干支与旬空需以正文为准。
2. 该派格局判定简略（应爻生合世→从强等），未给系统的四值能量权重算法——量化格局可参《liuyao-xiaoao-qianian-skill》（月令五成年日各二成半）。
3. "六神只能辅助、可不用""进退神无实际意义"等主张与传统派相左，属该派立场。
4. 与《liuyao-shiyaowangshuai-skill》同为世爻旺衰格局法但细节不同（如动空论、用神不现处理），并用时以其中一套规则为主，勿混。
5. 讲义含推广语与网站水印（元亨利贞网、9d19.com），已剔除。
