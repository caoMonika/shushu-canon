# 术语表 — 《穷通宝鉴-明-余春台》

| 术语 | 上下文线索（OCR） |
|---|---|
| 时日月年 | 两间不杂，按察	时日月年 |
| 或支成水 | 或支成水局，加以壬透，名为水泛木浮，死无棺木。 |
| 常人 | 正月甲木，初春尚有余寒，得丙癸逢，富贵双全。癸藏丙透，名寒木向阳，主大富贵。倘风水不及，亦不失儒林俊秀。如无丙癸，平常人也。 |
| 或支成火 | 或一片戊土，甲不出干，终非大器，且恐孤贫，正月之丙，忌戊晦光，或支成火局，端取壬水为贵，无壬、癸亦姑用，若壬癸俱无，取戊以泄火气，但属平人。 |
| 或支成木 | 或支成木局，干透比劫，反取庚金为先，次用丁火。 |
| 何也 | 或成火局，不见滴水者，乃僧道鳏独之命，即有一二癸水，多遇火土，用之无力，瞽目之人，得戊己透火气，亦主刑克孤寡，行北运多凶，何也，所谓燥烈水激反凶。 |
| 或支成金 | 或支成金局，方可用丁，不然，三月无用丁之法。惟有先庚後壬取用。 |
| 金妻水子 | 用丙者，木妻火子。用癸水见火多者，金妻水子。 |
| 方妙 | 十一月甲木，木性生寒，丁先庚後，丙火佐之。癸水司权，为火金之病。庚丁两透，支见巳寅，科甲有准，风水不及，选拔有之。若癸透伤丁。无戊己辅救，残疾之人。或壬水重出，丁火全无者，庸人也，得丙方妙。 |
| 科甲定然 | 九月甲木，木星凋零，独爱丁火，壬癸滋扶，丁壬癸透，戊己亦透，此命配得中和，可许一榜。庚金得所，科甲定然。 |
| 水妻木子 | 或四柱木多，用丙用丁，皆不足异，端用庚金为妙。凡四季甲木，总不外乎庚金。譬如木为犁，能疏季土，非庚金为犁嘴，安能疏土虽用丙丁，癸庚决不可少也。九月却不取土妻庚子，当取水妻木子。 |
| 土妻金子 | 若在六月，见辰支，名为逢时化合格。以癸水为妻，丁火为子。若二己一甲争合。取支中比劫为用。以甲为用者，壬癸为妻，甲乙为子。其余用庚者，土妻金子。用丁者，木妻火子。女命以妻作夫，用作子。十干皆同。 |
| 木妻火子 | 若在六月，见辰支，名为逢时化合格。以癸水为妻，丁火为子。若二己一甲争合。取支中比劫为用。以甲为用者，壬癸为妻，甲乙为子。其余用庚者，土妻金子。用丁者，木妻火子。女命以妻作夫，用作子。十干皆同。 |
| 异路功名 | 或一派癸水，有丁无丙，平常之人。或一癸透干，异途显宦，难由科甲。癸居子辰，异路小职。或丙藏支下，癸透年干，己出月上，虽非科甲，异路功名。又或重重癸水，或支藏癸水，由行伍出身得功名。 |
| 用甲者 | 用壬者，金妻水子，用甲者，水妻木子。 |
| 癸水 | 或癸丁与庚齐透天干，此命可言科甲，即风水浅薄，亦有选拔之才。癸水不出，虽有庚金丁火，不过富中取贵异途官职而已。壬透可云一富，若全无点水，又无庚金丁火，一派丙戊，此无用之人也。 |
| 之人 | 或见一二庚金，独取壬水。壬透清秀之人，才学必富。 |
| 或四柱多 | 或四柱多土，干上有乙木，切勿作弃命从才。 |
| 出干 | 凡甲多庚透，大贵。庚藏，小贵。若柱中多庚，则又以丁为奇，富贵人也。如庚申年、丙戌月、甲申日、壬申时，此主功名显达，有文学。若无庚丙年月，又无火星出干，虽曰好学，终困名场。 |
| 用丙者 | 用丙者，木妻火子。用癸水见火多者，金妻水子。 |
| 木妻 | 若在六月，见辰支，名为逢时化合格。以癸水为妻，丁火为子。若二己一甲争合。取支中比劫为用。以甲为用者，壬癸为妻，甲乙为子。其余用庚者，土妻金子。用丁者，木妻火子。女命以妻作夫，用作子。十干皆同。 |
| 火子 | 若在六月，见辰支，名为逢时化合格。以癸水为妻，丁火为子。若二己一甲争合。取支中比劫为用。以甲为用者，壬癸为妻，甲乙为子。其余用庚者，土妻金子。用丁者，木妻火子。女命以妻作夫，用作子。十干皆同。 |
| 或一派壬 | 或一派壬水，见一戊制，虽不科甲，亦有恩庇。或无戊透，则有辰戌丑未之戊，但辰宫癸水，贪合成火，不能制壬，此平常衣禄。若支下全无一戊，此系奔流之人，加以金多生水，下贱之命。 |
| 富中取贵 | 或癸丁与庚齐透天干，此命可言科甲，即风水浅薄，亦有选拔之才。癸水不出，虽有庚金丁火，不过富中取贵异途官职而已。壬透可云一富，若全无点水，又无庚金丁火，一派丙戊，此无用之人也。 |
| 用癸者 | 用丙者，木妻、火子。用癸者，金妻、水子。 |
| 虽不科甲 | 十月乙木，木不受气，而壬水司令，取丙为用，戊土次之。丙戊两透，科甲定然。有丙无戊，虽不科甲，亦入儒林。支多丙火，运入火乡，亦主显达。 |
| 富贵双全 | 正月甲木，初春尚有余寒，得丙癸逢，富贵双全。癸藏丙透，名寒木向阳，主大富贵。倘风水不及，亦不失儒林俊秀。如无丙癸，平常人也。 |
| 富贵 | 正月甲木，初春尚有余寒，得丙癸逢，富贵双全。癸藏丙透，名寒木向阳，主大富贵。倘风水不及，亦不失儒林俊秀。如无丙癸，平常人也。 |
| 次用丙火 | 八月甲木，木囚金旺。丁火为先，次用丙火，庚金再次。 |
| 支成火局 | 支成火局，可许假贵，戊己一透，可作富翁。 |
| 或一派戊 | 或一派戊土出干，不见比肩，名为才多身弱，终为富屋贫人。 |
| 用壬者 | 用癸者，金妻、水子。用丙者，木妻、火子。用壬者，金妻水子。 |
| 壬甲两透 | 十二月丙火，气进二阳，每雪欺霜，喜壬为用，己土司令，土多又不可少甲，壬甲两透，科甲堪宜，甲藏则秀才而已，或无甲得一壬透，富中取贵。 |
| 火妻土子 | 凡甲木，多见戊己，定作弃命从才而看。从才格，取火妻土子。 |
| 平常人也 | 正月甲木，初春尚有余寒，得丙癸逢，富贵双全。癸藏丙透，名寒木向阳，主大富贵。倘风水不及，亦不失儒林俊秀。如无丙癸，平常人也。 |
| 或一派庚 | 或一派庚辛混杂，常人，得时月两透庚金、无辛者，定主清贵，或辛年辛时，名为贪合，酒也之徒，女命一理。 |

> 术语由频次粗提，可能含噪声；以原书定义为准。
