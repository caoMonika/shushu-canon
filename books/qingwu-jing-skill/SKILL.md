# 青乌经（形法短诀）

## 总纲

山川融结，峙流不绝；山凝水澄；四合周顾辨主客。气乘风散，脉遇水止。

## 山水交媾

| 组合 | 断 |
|---|---|
| 山来水回 | 富贵丰财 |
| 山止水流 | 虏王囚侯 |
| 山顿水曲 | 子孙千亿 |
| 山走水直 | 从人寄食 |
| 水过东西 / 三横四直 / 九曲 / 重重交锁 | 财→官→贵→极品 |

## 五不葬

不畜（腐骨）、不及（绝灭）、腾漏（翻棺）、背囚（寒泉）、穴不温（孤贫）。另忌童断石过独逼侧。

## 形止与平洋

势止形昂前涧后冈→侯王；形止势缩前案回曲→富厚。平洋情当内求沼沚池湖，勿外觅。

## 贵地象

公侯龙马玉圭；宰相绣墩大水朝；外台捍门屯军；官贵文笔鱼袋；文士笔尖水不随→虚名；大富圆峰金柜；贫贱乱如散钱。

## 葬戒

盗葬/逼祖忌；穴吉葬凶同弃尸；**内气萌生，外气成形，内外相乘**。

## 流程

四合主客 → 山水交否 → 五不葬 → 势形 → 砂水层级 → 葬法 → 细部转葬书/形法

## 边界

依托书；与葬书一脉；术数非可验证因果。
