| 战利为客 | 休加乾，乃宫生门，若下干生上干、或上干尅下干，战利为客，求名得意，官讼得理，诸事求谋，多耗散不遇，有始无终。 |
| 大胜 | 凡为宫克门是主强客弱，若地盘奇仪克天盘奇仪、或得天盘生地盘，为主兵大胜，诸事吉庆由我主张，然亦不可太过也，若地盘克天盘，主兵先胜，宜急回兵不可攻剿诸事先吉后忧。 |
| 商贾 | 开：宜征讨、谋望、入官、见贵、应举、远行、嫁娶、移徙、商贾、营建，不宜治政有私人窥伺。 |
| 其于事也 | 子：为水、为河、为池井、为沟、为后宫，其于人也，为妇人、为盗贼、为乳妇，其于物也，为鼠、为燕蝠，其于事也，见吉神为聪明，见凶神为淫泆。 |
| 乃门宫比 | 休加坎，乃门宫比和，再看上下干生尅，合吉凶格，详主客用之。如天蓬星亦在坎，谓之伏吟格。战宜固守，凡事迟缓，惟利积水、养鱼、通渠、导河、收货、积粮、置买、鱼、盐、茶酒之利。 |
| 若上克下 | 乃宫克门，若地下奇仪，克天上奇仪，或上生下，战利为主，诸事皆吉，先破费而后成耳，若上克下，事虽吉不免艰难，战不可攻，当防虚诈。 |
| 乃宫生门 | 休加兑，乃宫生门，若合吉格，或下干生上干，或下干受上干尅，为客兵大胜，凡事不吉、多破败。 |
| 若上生下 | 死加震，乃门被宫尅，若上生下，或下尅上，战利为客。若合吉格，诸事有势，但吉而不实耳。若合凶格，主有始无终。 |
