# 六爻疑惑指迷与失误复盘（王虎应）

取材：《王虎应-六爻疑惑指迷》（问答体，六章）＋《王虎应-六爻预测误中悟》（21 章失误卦例复盘）。两书定位为作者已有著作的补充：《疑惑指迷》专答"预测中最容易搞错、含糊不清"的问题，非初学者用书；《误中悟》以自身失误卦例复盘，推导出新规则。全部卦例为实测。

## 一、摇卦与起卦规范

- **谁摇卦**：求测人摇、预测师摇都可以。关键在求测人**真正动念**（想借卦知吉凶的欲望）。念头既起，谁摇都准；预测师代摇时脑子越空越好。人未到可先起卦，写好断语再验证（作者实测可行）。野鹤《增删卜易》早有先例：两人交叉用卦（长者摇的卦断年轻人功名、年轻人摇的卦断长者子病）方验。
- **同时问两件事分开摇**：易错位。判据：卦的特征反推何卦应何事（财临白虎=宰割→羊杂割店；用神叠叠需墓库收藏→饭店）。
- **钱币**：任何能分正反面的硬币皆可，"乾隆钱才灵"是无稽之谈。人民币/日元/自制钱皆验。掉地上的钱币照算，立起的看见面；用盘子承接。
- **意念**：不需要一个劲默想所测之事。念头既起即可摇。
- **一事可连摇**：第一卦信息明确就不必再摇；不明可再摇参断。多卦矛盾时不是卦错，而是**各卦反映事情的不同角度/时段**（如三卦测出行：一卦应去程延误、一卦应回程换机、一卦应全程平安）。同日多人测同一病人（夫/姐/侄女），各取各的用神（财/兄弟/父母），都应同一结果。
- **替代取卦**（不便摇时）：① 三枚钱装口袋搅乱取出看正反，六次成卦；② 围棋子三黑三白，取三颗：一白两黑=少阳，二白一黑=少阴，三白=老阳，三黑=老阴。皆验。时间/数字起卦不主张（动爻单一，出不了伏吟反吟三合，信息大损），急用偶尔可以。不用爻辞。不用洗手焚香。修道出家人照样能测（不脱五行）。
- **卦不能劝**：对方不动念别劝他摇。勉强摇的卦常反映劝卦人的事。子日能摇卦（"筮必心诚，何妨子日"）。
- **子时定日**：晚 12 点为一日分界。23:00–24:00 属前一天，00:00 后属第二天（作者以猫卦、感情卦实证）。
- **跨国预测**：以**摇卦人所在地方的日期**为准，不换算时区（行李卦：按美国申日应验，中国酉日=美国申日）。
- **可测过去**：三年前的病、断指年份（官鬼月破戌土→甲戌年实破）皆可测出。
- **断错的卦必须回头研究**，悟通即升级；搁置是最大损失。

## 二、断卦入手五步

1. 标出**空亡、月破、暗动、伏藏**之爻（漏看直接影响吉凶）
2. **取用神**（两现时集中取一个，另一个参考）
3. 看**日月对用神的作用**——日月为根本，定用神有根无根（日月一生一比=有根；日月皆克=无根，除非自化回头生）
4. 看**动爻对用神的作用**（动爻示趋势与复杂过程）；静卦则看旺相之爻对用神的作用（旺相爻可生克休囚爻）
5. 叠加**爻位、六神、十二长生**综合判断；应期围绕用神与动爻定

## 三、基础构件辨析

- **天干**：不主吉凶，用于**取数**（钱数、震级、身高、分数）。用范围先天数：乙 8、卯 6 → 1400 万日元（实中标的标底 1250 万）。
- **卦身**：与吉凶无关。偶尔用于判断来意、找床帐（床帐休囚临绝=未婚）。
- **神煞**：不为主，仅**天乙贵人、驿马、桃花**常用应验（"旺马游魂逃学儿"；贵人属相化解：甲戊庚牛羊→找属牛人帮忙）。其余不用。神煞须结合用神喜忌。
- **纳音**：不主吉凶，可与六亲结合取象（妻财丁卯炉中火+朱雀父母=开饭店），化解时用。
- **错卦**：预测中无意识装错六亲/卦宫却断对了——预测完才发现错就不必改正，以错卦断（灵感符号论，作者存疑待研究）。
- **占此应彼**：一定非静卦且有动爻。"神兆机于动"，动爻组合出强烈信息而与所问无关时，即暗示更重大的事情（问调动防病灾、问领证防子宫癌、问生孩防老人去世）。卦是潜意识的延伸，显意识未知而卦已示——这是一卦多断的原理。**卦中有不好信息必须提醒对方**，听不进不勉强。

## 四、独发与独静

**独发**（一爻独发，暗动不算）四用：
1. 表**应期**：动而逢值逢合（与用神关系紧密时）
2. 表**原因和性质**（如尿道炎卦中亥水独发=病位病因）
3. **淡化五行生克，以象为主定吉凶**——十二长生起主导：长生、沐浴、帝旺多吉；死、墓、绝多凶，**死最凶，绝次之，墓又次之**。用神弱而遇长生沐浴帝旺有生机；用神旺而遇死墓绝转凶。用神独发宜化长生、回头生、进神，忌化死墓绝（姥姥手术卦：父母辰土化巳火按化绝看→术后即死）。
4. **占此应彼**（见上）

**独静**（全卦仅一静爻）二用：表应期、表原因性质。判断反以**独静之爻**为征兆（工作调动卦：五爻全动独静世爻子孙持世克官→不调）。

独发卦例要点：出行卦官鬼巳火独发生世但为世绝地→车祸（巳日出空）；绑架卦子水独发为用神死地→撕票；溺水卦同理。**独发时不可只按生克断吉**。

## 五、三合局成立条件

- 卦内至少**两个动爻**；**中间地支（子午卯酉）必须在卦中发动**。
- 不成立的情形：中间支在卦中但不发动；中间支在变爻（一般只作用本位爻，除非用神变爻即中间支）；另外两支发动而中间支只出现在日月（"亥卯未齐全"但卯静不动→不成局）。
- **虚一待用**：两爻动（含中间支）缺另一支，可由日月补、暗动之爻凑、或待未来时间补上成局。
- 只有中间支发动、另两支在日月 → 不成局。
- 例：巳酉丑三合（借变爻酉）克用神→凶；申子辰合水局生世（《增删卜易》原断"升任"实为"调遣"，中间支在变爻不能作用他爻——作者指出原书解释有误）。

## 六、年月日时精义

- **月破不分五行**：月冲之爻即月破。"土冲越旺"之说是错的（有书把土月冲当暗动，误）。
- **暗动**（静爻被日冲）分五级强弱：
  1. 被冲爻得月生/比/拱扶（月为元神或同五行）→ 最有力
  2. 月生合之爻被日冲 → 同上
  3. 月克中带合被日冲 → 较弱
  4. 月不生不克被日冲 → 中等（亥月申爻寅日冲）
  5. 月克（非长生非合）+动爻来克被日冲 → **日破**，非暗动
  另：月建长生之爻被日冲也是暗动（巳月酉金卯日冲，虽克带长生）。
  **伏神、变爻、动爻皆无暗动**（伏神被日冲叫冲出；旺动爻被冲"冲之愈动"，休囚动爻被冲"冲散"无生克权）。
- **爻冲暗动**：仅一爻独发时，旺相之爻（不空破、不被合）冲动有气之静爻为暗动（《卜筮正宗》："静得冲而暗兴"）。
- **日合为绊**：不分动静。用神（含静爻）被日合皆为绊住，应冲开之期。"静爻日合为合起当动爻看"是错的。
- **月合为旺不为绊**：与日合本质不同。"月合为绊"是今人乱章法。爻逢月合有用、逢月破无功。
- **太岁**："尊而不亲"，**不参与生克**（冲爻不为岁破，合爻不为岁合）。太岁入爻且发动旺相才有生克权；过去/未来太岁常用于**断应期**（酉为来年太岁→次年分手）。
- **时辰**：一般不看。事情紧急（走失、找物）时必看时辰，冲合应时（酉时合处逢冲→孩子已到家；辰日合住酉时之冲→次日找到货）。

## 九、误中悟补遗（失误复盘推出的新规则）

1. **父母临日/合日定婚期**：《卜筮正宗》"日逢父合，已期合成于三星"——父母为婚书，临日/合日主婚期已定。婚姻应期**不全围绕官鬼**，父母爻临日是硬判据（作者据此卦悟出后连验）。细节仍看官鬼：官空=婚姻不牢、官不合父=结婚对象非当时男友。
2. **失误卦里藏完整信息**：断"不成婚"的卦应验在后——子孙丑土月破=丁丑年实破流产、实破克官=离婚、卯木独发为世沐浴=洗澡致流产。卦没错，是没看到位。**保留失误卦，日后回看**。
3. **择日法**（无特定用神时看世爻）：世弱选生世之日；世过旺选克世/入墓之日；世空选实空；世破选实破、合破之日。搬家卦二爻月破=房要拆（搬家原因）、六合变六冲=临时住、父母伏二爻=房下有房（地下室）、火主二数=住二层。
4. **应期误差存疑**（作者公开求解）：生孩子卦断申日实破元神应在辰日生（差 4 天）；搬家卦断未日生应在戊申日——"元神弱极"之说未定论。**应期定到日有 ±1~4 天误差是常态**，断语宜留余地。
5. **不能让求测人左右你的思维**（第八章标题）：求测人的暗示、反复摇卦的坚持、"你是不是测不准"的质疑都会干扰判断。断语要独立。

## 使用流程

1. 摇卦环节：确认动念、谁摇、日期（子时/跨国换日）、是否连摇
2. 装卦后标空破暗动伏藏 → 取用神（遇特例事项查第七章对照表）
3. 日月定根 → 动爻/旺静爻作用 → 叠爻位六神十二长生
4. 若一爻独发/独静：切换到"象主吉凶"模式（十二长生定吉凶），勿死套生克
5. 若三合：先验成立条件（中间支发动？虚一待用？）
6. 应期：值/冲/合/实空/实破，急事加时辰
7. 占此应彼扫描：动爻组合出的强信息若与所问无关，单独提示
8. 断错必复盘，回看失误卦补规则
