# 三、对于底本脱漏字，本次整理时进行了增补，新补

## I — 方法论骨架 (Interpretation)

本节主要处理底本脱漏字的增补问题。对于无法补入的文字，用“口”代替；无法计算字数者用空格。同时，对穴位及中药的别名未作改动。

## A1 — 应用示例 (Application Example)

假设底本中有一处文字缺失，原文为：“大椎针痛（于）[兮]五枢兼于背缝”。根据规则，无法补入的文字用“口”代替。因此，增补后应为：“大椎针痛口五枢兼于背缝”。

## E — 可执行步骤 (Execution)

1. **识别缺失文字**：首先，仔细阅读原文，识别出缺失的文字。
2. **判断是否可补入**：根据上下文和相关知识，判断该文字是否可以补入。
3. **增补文字**：
   - 如果可以补入，用原字替换缺失处。
   - 如果无法补入，用“口”代替。
4. **核对与确认**：将增补后的文字与底本进行核对，确保无误。

## B — 边界 (Boundary) ★

- 对于底本残缺或脱漏的文字较多而无法补入时，每一字用一个“口”代替；无法计算字数者用空格。
- 对于穴位及中药的别名未作改动。
