# 大六壬《壬窍》分占断法

清·无无野人编著（道光壬寅年），自序云"占分二十余门，门分总论、看法、类神、诸煞四条"，凡占通用之法"录凡占总诀数页以冠其首"。十卷本。本技能提炼凡占总诀与各门分占判据。

## 一、凡占总诀（通用断纲）

### 1. 旺衰总则
- 五行**均从旺论，不均从多论，不多从生多者论**。
- 吉地之吉气神自当之，将无与也；凶地之凶气神自当之，在将为失势。
- 空不宜，惟**神生其将而神自空者，尚有出旬可望**。
- **吉凶系于阴神**——阴神者，事之主。类阴之气，迟速攸关：旺相应速，休为已过，囚死必迟，空亡小应。
- 凡类到则神煞应之，否则空凭神煞者不应。

### 2. 类神取用
- 事类神兼二三，以**入课传为取用**；皆入皆不入则不用兼神，责将神。
- 类吉者以内外战而反凶，类凶者以内外战而反吉——仍合**类之阴神**决吉凶。
- 类下失地利无气、上失天时休囚，须得**月建生合辅助类上所得之神**。
- 三传克类而类又见七处克（煞盛类伤），须日辰年命上有生助类神者为救，或有克制煞神者为救；俱不救则得吉时救之。
- **所占不入仍凭类**（毕法）：类不入七处，仍以类神上下与日辰、年命、正时论生克。
- 占两三事便有两三类，吉凶各以类应；非其事类勿言之。
- 要见类神者（寻人觅物）：类不见则难求；见而失天时地利休囚，宜月令引出、日辰助扶，落空得冲为救。
- 不必见类神者：占官爵未得官宜见官星，已得不必；占病逢生类者宜见、克类者反以不见为幸；占婚已成夫妇不必定见龙后。

### 3. 阴神为本
- 阴神之天官主其事因，阴神地神司其吉凶，气则迟速攸关。
- **类见于阳而情归于阴**：阴神生合类神或生比日辰则吉。生克制化之权一切惟阴神操之——**俯视重而仰视尤要**。
- 阳神吉而阴神助之愈吉，制之则吉不终；阳神凶而阴神助之愈凶，制之则凶自散。

### 4. 八门责用（吉凶之应，应于八占）
| 门 | 所责 |
|---|---|
| 先锋门 | 正时 |
| 值事门 | 正时上所得天官 |
| 外事门 | 见于日上 |
| 内事门 | 见于辰上 |
| 发端门 | 见于初传 |
| 移易门 | 见于中传 |
| 归计门 | 见于末传 |
| 变体门 | 见于年命 |

八门上不见正时，则责发用三传。

### 5. 三传总断
- 吉事欲三传生助，凶事欲三传克制。**始凶而终克始则吉，始克终则凶**。
- 三传凶而行年吉能解；俱凶不可解。初凶末空可解凶，吉事则不成。
- 凶遇冲破反凶为吉，吉遇冲破反吉成凶。
- 私用责年命，公用责岁月。岁月日时为六壬大占纲领。大要吉则欲无伤，凶则欲有救。

### 6. 鬼墓细断
- 鬼最忌临身宅；临干支三六合地为眷属亲党，临刑冲破害处为疏远。"辰神传命属他人，鬼来无路不相侵。"
- 墓乃土气，畏木克，值木旺可解凶；墓之遁干木旺则论木不论墓（"克者为无"）。干旺而支相兼墓言，墓旺而干相兼干言——从旺断而衰者不论。墓无克则取冲（冲不为墓），**旺能冲衰，衰不能冲旺**。
- 辰戌丑未衰旺有别：丑中金水旺秋冬，戌中金火旺夏秋，未中木火旺春夏，辰中水木旺冬春。论土己土不相，戊土死气；夏令一切土皆旺相（中央土旺戊己，四季皆相）。
- 日逢丁皆言动，支旺从支言；干旺从干言。丁为妻财/官鬼吉凶异而动同。

## 二、分门占断选要

### 坟墓占（卷二，全书最精一门）
- **看课五行偏胜定地形**：金胜多高冈大原道路、下有骸骨砖瓦金石，吉出将凶出兵；木胜多园林古木、下有棺椁谷麦，吉出文艺凶出痴愚；土胜平坦丰厚，吉丰足凶出痴聋哑；水胜有河池泉井沟涧，吉出智慧凶出淫邪；火胜宜冈岭燥土，吉出文儒秀士，凶出性刚气傲（火发必速衰亦易）。※原书水火两条缺，编者自补并注明"未识当否"。
- **天将类地形**：贵人神祇小庙，蛇冈岭湾高下，雀鸟巢盆池花果，勾墓土台坑水濑，合门户旛竿，龙参天树，阴碾碓碑石柱，武泉坟萦盘，常香台祭桌冥器，虎墓道石坊，空枯树坟滩塔。
- **来龙**：青龙与天目（龙神）主来龙，宜乘旺为真龙，乘生炁尤妙；龙与墓相生无刑克吉。土宿（贵勾常空）临四季为重土山势紧抱，逢火高耸逢木平塌。
- **穴**：支之阴神是穴，螣蛇主之——蛇落处生旺则穴的，空亡墓绝为绝穴。
- **水法**：元武临处即风水所在（临壬癸亥子水法萦回）；阴后为水口，喜与墓穴紧关包固，后神相合水聚天心，后空过穴反跳，后冲支直射明堂。贵左旋水局顺、右旋逆。蛇为罗城喜引从拱护。勾阳外明堂、勾阴内明堂（午亦明堂），得贵德禄马财印合吉。
- **何房吉凶**：左青龙主长房，右白虎主季房，前朱雀主中房；一云长房龙、二虎、三雀、四武、五勾周而复始。龙空陷虎刑破大凶。
- **发用定葬后**：用木出文人（休囚出木工棺椁业）；用火出文人爵禄（休囚浮游火工）；用土富贵田宅（休囚痴愚土工守坟）；用金出武将（休囚斗狠盗贼屠宰）；用水多谋计好交游（休囚淫奔水厄僧尼九流）。
- **墓在何处**：地形推月将——寅花巳涧卯桥船，午岭辰冈未堰子，申河古道酉麻田，戌堆粪秽平畴地，亥水支流分陌阡，子为地头仰瓦，丑作平坡。
- **类神**：日为人丁/亡人（日阴为亡人），辰为宅为水，辰阳为墓/生坟/主山，辰阴为墓/死坟/穴；支阳对冲为案山（朱雀亦案山），青龙来龙，蛇罗城/穴，虎墓道，武水法，阴后水口，勾阳内明堂勾阴外明堂，常香台祭器，贵人视水局顺逆。死坟以日鬼之墓为墓，生坟以日墓为墓。
- **论墓**：干支乘墓虎临支上必有伏尸鬼；岁墓作干墓乘蛇虎临卯酉、及卯酉日干墓乘蛇虎加支，名**墓门开**主重丧。

### 出行/行人占（卷三）
- 出行占其去、行人占其来，类神马煞及干支三传可例视。
- **进茹逢空宜退寻传后吉神，退茹逢空宜进寻**；前后皆无吉神则以干前后细推。
- 行人占（附信息占）以类神入传、马煞动向、干支三传生克决来期（详见源稿）。

### 婚姻占（卷五）
- **总则**：已婚责干支为夫妻，未婚责龙后为男女。
- 课体定先求与性情：元首男先求女，重审女先求男，知一涉害舍远就近，遥克别责舍亲就疏，昴星乖离，八专淫泆，伏吟迟退，反吟反复；三合六合因亲作眷，从革还防分异。
- 空亡虽成有破；忌孤寡加天空发用临日辰（其家必有孤寡之人）。忌太阴入卦及亥卯未酉发用临日辰（男女不正/阴私间隔）。
- 三传日财生起官鬼在干上——因妻财致祸（贪淫）；生起官鬼在支上——祸由妻家起。传鬼化财（官鬼局空独存财）——妻财自危险中来，非畏妻即被妻伤。
- 大局：男看青龙、功曹、官星、干神；女看天后、神后、财星、支神。
- 九丑：占日戊己辛壬乙合子午卯酉、大吉丑临支上——无克不妨，有克凶；克干伤长老，克支伤少小；阳日害男阴日害女。丑乘蛇主惊异、雀官讼、勾争斗、空虚诈、虎病丧、武奸盗、阴暗昧。
- **芜淫**（上神互克干支）与**解离**（干支互贼上神）：心腹之患，纵龙后财官入传作合，非男女乖违即夫妻反目。外战失在男，内战失在女。
- 别责（三课无克）两处许亲/先曾嫁娶争竞；阳不备二女、阴不备两男（脚踏两船/断弦复续/望门再醮）；芜淫则苟合私奔，成后或有讼。
- 孤辰寡宿：男忌孤辰女忌寡宿；作奇仪三光阳及岁月建将反为有救（重婚再嫁）。
- 狡童（男诱女）泆女（女诱男）：生合为和从，克制为强逼；传见卯酉水局更武有气尤的。
- **来意标志**：太常乘日本（长生）加干上来意必占婚；加支上宅中有婚礼。财乘太常占婚、官乘太常占姻。
- 天后在传而后之阴神作白虎——占婚不久克妻。
- **看法**：先视七处龙后为男女类神，其乘神即类神——不战有气则喜，外战轻可求、内战重难求（纳音为救）。俯临四吉地（贵德禄马财印合）为有气，八凶地刑冲破害为无气；忌落空（神将和而神自空尚有出旬之望）。再看阴神：生旺比合类神干支年命者成后无咎，刑冲克害者成后有悔；事因视阴神上天官。

### 考试占（卷四，附武试）
- **必察**：朱雀、官鬼爻、昼夜贵、主试类神、魁罡、德神、二马、青龙、印绶、长生及岁月建将。
- 文书为先：雀为文书，长生为学堂，印绶即文书；龙常官贵禄马德合在课传吉，逢六阳/太阳月将更显达，临日辰年命发用尤吉。
- 干支或初末得昼夜贵、夹拱贵禄年命、初末引从干支皆主遂意。**天心格**功名联捷直达；**一旬周偏格**占事不脱；**回还格**（三传在四课中自作三合）吉凶照旧；非三合干支为不备凡事不全；**源消根断格**（课传俱下生上）纵成名终成痨瘵。
- 喜忌：雀常喜，勾武虎空阴后忌；天喜皇恩五马印绶奇仪龙德富贵喜，死炁病符月厌墓空休囚刑害忌。雀落空、龙归墓（龙乘未）、天空发用、武乘神克日、虎乘神伤日皆不吉。
- **看朱雀**：宜乘神旺相得四吉地及官德禄马财印合、或作岁月建将而不内外战；雀受乘神克取纳音为救。阴神生扶雀及生合日年岁月建将官贵者利。雀与印爻克太岁必因文字犯规遭责。**雀乘午为真朱雀**主文名超众，但克太岁犯时责、克帘幕主试不喜、榜将出雀乘丁马防改移。
- **主试类神**：县试视支之官（父母爻），府试视月建，院试视月将；岁试兼太岁，科第兼辰戌丑未；乡会以**幕贵**为主试（会试尤重六甲），廷试以太岁为主试。**试官空亡，置卷不视**。
- **官鬼为功名类神**：日干年命上官星旺相、阴神作贵德禄马财印合或生合年命俱为身强；官星不见或无气而克年命、阴作刑冲破害脱墓绝，文合主试亦失望。
- **帘幕贵人**（昼得暮贵、暮得昼贵）：日干年命上逢之大利；遇旬首六仪作帘幕尤的主甲第必高。喜生旺恶墓空。雀乘神与幕贵乘神阴阳互相生合有气必中式。干支/初末/年命拱幕贵或两贵引从干支，主得贵人力。幕贵忌空忌墓忌克日忌受克。

## 三、判读心法
1. 先立类神 → 审入不入七处 → 阴神定事因与迟速 → 八门责用补缺。
2. 俯视（乘神地利）重于仰视（阴神天运），但阴神操生克制化之权——两参不可偏废。
3. 神煞随类而变，不可呆看；类到则神煞应之。
4. 分占体例固定四条：**总论**（该占责什么）→ **看法**（步骤）→ **类神**（对应神将）→ **诸煞**（应期凶煞）。
