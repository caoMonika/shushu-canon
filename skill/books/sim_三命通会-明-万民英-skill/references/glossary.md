# 术语表 — 《三命通会-明-万民英》

| 术语 | 上下文线索（OCR） |
|---|---|
| 大贵 | 己亥，自生之木。根本繁盛，不忌众金，惟嫌辛亥、辛巳、癸酉之金；若见乙卯、丁未水、癸未木，未有不大贵。阎东叟云：“己亥之木，得时则清贵，非时则辛苦。” |
| 又曰 | 戊子、己丑，水中之火，又曰神龙之火。遇水方贵，为六气之君火也。《五行要论》云：“戊子含精神辉光全实之气，作四时保生之福，入贵格则为大人君子，器宇含弘，富贵终吉。” |
| 辰戌丑未 | 丁西火，鬼神之灵响，火无形者，喜辰戌丑未。天乙，喜神，平头，破字，聋哑，大败。 |
| 又云 | 又云：以煞止煞，多掌兵刑之任。盖言太岁受刑而别刑若乃制刑太岁者。假令癸巳生人得戊寅日，却得庚申时之类。盖癸巳为戊寅所制，得庚申木却制戊寅之土。本有刑而却无刑，故曰以煞制煞。 |
| 巳时 | 壬癸日，壬为旺，癸为建禄，只是身强，奈名利二者却被月令销熔尽了，颇宜时带偏官，贵，如壬日戊巳时，癸日巳午时是也。次宜日时带诸不见之形，贵。如年月时三宫皆不遇，其命可知，运喜行偏官，忌正官。 |
| 寅时 | 六甲年丁卯月乙未日戊寅时六乙年己卯月甲戌日乙亥时 |
| 经云 | 经云：凡命定其无刑，先论太岁。盖言人恶见三刑，若月日时带煞而太岁不干预者不论，故曰先论太岁。 |
| 酉时 | 诸印要逢库墓，若生旺扶助互换，禄马贵人并相合者，至贵之命。最忌刑冲破害，三合六合上见鬼，如甲戌日得癸酉时， 则减力。水命人得本家印无益；得木印损气；得土印，支干有交涉者，名官印；无交涉者，名鬼印。 |
| 申时 | 又云：以煞止煞，多掌兵刑之任。盖言太岁受刑而别刑若乃制刑太岁者。假令癸巳生人得戊寅日，却得庚申时之类。盖癸巳为戊寅所制，得庚申木却制戊寅之土。本有刑而却无刑，故曰以煞制煞。 |
| 丑时 | 遁时如甲子日子时生人即甲己，还加甲，便知子时乃甲子，丑时乃乙丑，顺行十二时。 |
| 戌时 | 甲日甲戌时，甲用丙为食，辛为官，戌上食神入火局，辛有余气，身被火焚，为人好善，平常衣禄。甲以戊为父，癸为母，戌上旺甲伤戊，内有暗戊伤癸，戊癸受克，难为二亲。 |
| 亥时 | 申为名都。坤为地，其体无疆，非名都不足以喻之。申，坤也，都者；帝王所居；申宫壬水生，又与艮山对，是水绕山环也。凡命爱申年亥时，乃地天交泰。 |
| 未时 | 卯为琼林。卯系乙木，居位正东，于时为仲春，万物生焉，色若琅之青，故曰琼林。卯年遇巳未时者，是为兔入月宫之象，主大贵。 |
| 俱吉 | 甲禄寅。如甲见丙寅，甲土克丙水为财，为福星禄；戊寅火土相生，为伏马禄，俱吉。庚寅谓之破禄，半吉半凶。壬寅谓之正禄，带截路空亡，必为僧道。甲寅谓之长生禄，大吉。 |
| 子时 | 遁时如甲子日子时生人即甲己，还加甲，便知子时乃甲子，丑时乃乙丑，顺行十二时。 |
| 辰时 | 巳为大驿。大驿者，人烟凑集，道路通达之地。巳中有丙火戊土，是其象也，又巳前有午马，故曰大驿。巳生喜得辰时， 蛇化轻龙，于格为千里龙驹。 |
| 午时 | 又云：“六旬后两号天中，见合长生旺不凶；加临冲克兼刑禄，官职升腾位更隆。”如巳酉丑人丁丑月、癸未日、戊午时，午未空亡而戊癸之火旺在午，反为贵格，是火虚有焰也。 |
| 年月 | 由是论之，年月日时均重，而时为尤重。人命贵贱、寿夭、穷通、得丧只在生时之辨。时有八刻，有初正末气不同，须细 察之。 |
| 卯时 | 甲日丁卯时，伤官羊刃，甲用辛为官，丁字伤之，用巳为财，卯中乙木劫之，主为人凶狠。若柱透辛，伤官见官，刑害百端，运气凶险，不得善终；柱有七煞合刃，行财官印绶，大贵。 |
| 平常 | 甲日得卯，旺相。乙日得卯，建禄，甲乙生卯月诸格无取，只利得身强命长。颇宜带时上偏官及诸不见之形，贵。偏官者，甲日庚时申时、乙日辛时酉时。若年日时三宫无此，其命平常，原带偏官，喜合，忌正官运。 |
| 亦贵 | 甲辰日甲子时，若水位年月，水泛木浮，主移根换叶；申月，煞星会印，俱贵。子月，行水木运，亦贵。酉月正官，大贵。寅午戌月，俱吉。乙卯月，刑折。癸巳月，水火中死。癸亥月，凶死。 |
| 风宪 | 甲辰日丙寅时，龙虎拱门，又龙吟虎啸，主贵，或一生近贵，财源或得或失，名利既济未济。未、寅年月，官至六卿；戌月风宪；酉月三品；子、亥、丑月四五品，行西方运，大贵；卯、巳年月平常。 |
| 贵显 | 七月之水，正能滋实万物，不宜与火同行，徐、扬火多者，贫夭无依。金为母曜，适当其时，子母相生，文章清贵。土来同处，化祸为祥，木若联行，亦行贵显。 |
| 俱贵 | 甲辰日甲子时，若水位年月，水泛木浮，主移根换叶；申月，煞星会印，俱贵。子月，行水木运，亦贵。酉月正官，大贵。寅午戌月，俱吉。乙卯月，刑折。癸巳月，水火中死。癸亥月，凶死。 |
| 亦吉 | 甲申日丙寅时，时日并冲，忧伤妻子。若年月日同，大贵；巳、亥二三品；辰、子年月，会水以煞化印，吉；未月财库，亦吉。 |
| 富贵 | 甲戌，自库之火。不嫌众水，只忌壬戌。所谓墓中受克，其患难逃。《五行要论》云：“甲戌火为印为库，含至阳藏伏之气，贵格逢之，富贵光大。惟忌复生，防吉中有凶。” |
| 主贵 | 有南方离明马，谓未马已，丑马亥，辰马寅，戌马申，辰戌丑未系土之位，以生处为马，故辰戌丑未人飞在午，为南方离门之马，遇此者，爱于午相冲。为飞马，见鞭策入格，主贵。 |
| 壬子 | 壬子木，伤水多之木，喜火土及夏。羊刃，九丑，平头，聋哑。癸丑木，伤水少之木，喜金水及秋。华盖，福星，八专，破字，阙字，羊刃。 |
| 诗曰 | 诗曰：专禄庚来就巳位，也须制伏始为奇，武职当权为帅座，忽逢七煞祸来时。 |
| 是也 | 未为花园。花园属之未，不属之卯，何也？卯乃木旺，自成林麓；未乃木库，如人筑墙垣以护百花也，以百花言未中有杂气耳；未年人双飞格，最妙，如辛未见戊戍，两干不杂是也。 |
| 癸巳 | 癸巳水，水之不息，流入海，喜亥子，乃变化。天乙，官贵，德合，伏马，破字，曲脚。 |
| 之命 | 诸印要逢库墓，若生旺扶助互换，禄马贵人并相合者，至贵之命。最忌刑冲破害，三合六合上见鬼，如甲戌日得癸酉时， 则减力。水命人得本家印无益；得木印损气；得土印，支干有交涉者，名官印；无交涉者，名鬼印。 |
| 印绶 | 又云：“印绶之星中见空，顺临墓库福重重；若还夹贵归元位，带煞须为给事中”如甲午、癸酉、丙子、壬辰时，虽空，却与癸酉作六合，又墓库夹贵，所以入格，是水空则流也。 |
| 身旺 | 戊己日为财，喜露财身旺，忌坐刃透比。不遇亥子日生，难为财运。喜身旺与财，身弱喜旺，忌劫。 |
| 丙午 | 丙午火，月轮，喜夜及秋，水旺也。喜神，羊刃，交神，平头，聋哑，悬针。 |
| 戊午 | 戊午火，日轮，夏则人畏，冬则人爱，忌戊子、己丑、甲寅、乙卯。伏神，羊刃，九丑，棒杖，悬针。 |
