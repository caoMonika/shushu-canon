| 其状 | 风邪之气，若先中于阴，病发于五脏者，其状奄忽不知人，喉里噫噫然有声，舌强不能言。发汗身软者，可治；眼下及鼻人中左右上白者，可治；一黑一赤，吐沫者，不可治；汗不出，体直者，七日死。 |
| 故也 | 风邪伤人，令腰背反折，不能俯仰，似角弓者，由邪入诸阳经故也。 |
| 是也 | 风 退者，四肢不收，身体疼痛，肌肉虚满，骨节懈怠，腰脚缓弱，不自觉知是也。由皮肉虚弱，不胜四时之虚风，故令风邪侵于分肉之间，流于血脉之内使之然也。经久不瘥，即变成水病。 |
| 之间 | 中风者，风气中于人也。风是四时之气，分布八方，主长养万物。从其乡来者，人中少死病；不从其乡来者，人中多死病。其为病者，藏于皮肤之间，内不得通，外不得泄。其入经脉，行于五脏者，各随脏腑而生病焉。 |
| 诊其脉 | 诊其脉，虚弱者，亦风也；缓大者，亦风也；浮虚者，亦风也；滑散者，亦风也。 |
| 与血气相 | 历节风之状，短气，白汗出，历节疼痛不可忍，屈伸不得是也。由饮酒腠理开，汗出当风所致也。亦有血气虚，受风邪而得之者。风历关节，与血气相搏交攻，故疼痛。血气虚，则汗也。风冷搏于筋，则不可屈伸，为历节风也。 |
| 肺主气 | 风气者，由气虚受风故也。肺主气，气之所行，循经络，荣脏腑，而气虚则受风。风之伤气，有冷有热，冷则厥逆，热则烦惋。其因风所为，故名风气。其汤熨针石，别有正方，补养宣导，今附于后。 |
| 搏于血气 | 注者住也，言其病连滞停住，死又注易傍人也。阴阳俱虚，腑脏不和，为风邪搏于血气。血者阴也，气者阳也，邪搏于阴则寒，搏于阳则热，致使阴阳不调，互相乘加，故发寒热，去来连年，有时暂瘥而复发，故谓之寒热注。 |
| 所以然者 | 时气病七日，法当小愈，所以然者，阴阳诸经传病竟故也。今病不除者，欲为再经病也。再经病者，谓经络重受病也。 |
| 伤寒 | 大病者，中风、伤寒、热劳、温疟之类是也。此病之后，血气减耗，脏腑未和，使之虚乏不足。虚乏不足，则经络受邪，随其所犯，变成诸病。 |
| 死又注易 | 注者住也，言其连滞停住，死又注易傍人也。注病之状，或乍寒乍热，或皮肤淫跃，或心腹胀刺痛，或支节沉重，变状多端，而方云三十六种，九十九种，及此等五注病，皆不显出其名，大体与诸注皆同。 |
| 血气 | 血气俱虚，风邪并入，在于阳则皮肤缓，在于阴则腹里急。柔风之状，四肢不能收，里急不能仰。 |
| 之经也 | 邪客于足太阳之络，令人肩背拘急也。足厥阴，肝之经也。肝通主诸筋，王在春。其经络虚，遇风邪则伤于筋，使四肢拘挛，不得屈伸。 |
| 冷热不调 | 大小便难者，由冷热不调，大小肠有游气，游气在于肠间，搏于糟粕，溲便不通流，故诊其尺脉滑而浮大，此为阳干于阴，其人苦小腹痛满，不能尿，尿即阴中痛，大便亦然。其汤熨针石，别有正方，补养宣导，今附于后。 |
| 可治 | 心中风，但得偃卧，不得倾侧，汗出，若唇赤汗流者可治，急灸心俞百壮；若唇或青或黑，或白或黄，此是心坏为水。面目亭亭，时悚动者，皆不可复治，五六日而死。 |
| 注者住也 | 注者住也，言其连滞停住，死又注易傍人也。注病之状，或乍寒乍热，或皮肤淫跃，或心腹胀刺痛，或支节沉重，变状多端，而方云三十六种，九十九种，及此等五注病，皆不显出其名，大体与诸注皆同。 |
| 傍人也 | 注者住也，言其连滞停住，死又注易傍人也。注病之状，或乍寒乍热，或皮肤淫跃，或心腹胀刺痛，或支节沉重，变状多端，而方云三十六种，九十九种，及此等五注病，皆不显出其名，大体与诸注皆同。 |
| 肠胃之间 | 胃为水谷之海，水谷之精，化为荣卫，其糟粕行之于大肠以出也。五脏三焦既不调和，冷热壅涩，结在肠胃之间。其肠胃本实，而又为冷热之气所并，结聚不宣，故令大便难也。 |
| 言其病连 | 注者住也，言其病连滞停住，死又注易傍人也。人有阴阳不调和，血气虚弱，与患注人同共居处，或看侍扶接，而注气流移，染易得上，与病者相似，故名生注。 |
| 滞停住 | 注之言住也，言其连滞停住也。风注之状，皮肤游易往来，痛无常处是也。由体虚受风邪，邪气客于荣卫，随气行游，故谓风注。其汤烫针石，别有正方，补养宣导，今附于后。 |
| 以鼻纳气 | 又云∶踞坐，伸右脚，两手抱左膝头，伸腰，以鼻纳气，自极七息，展右足着外。除难屈伸拜起，胫中疼痹。 |
| 自极七息 | 又云∶踞坐，伸右脚，两手抱左膝头，伸腰，以鼻纳气，自极七息，展右足着外。除难屈伸拜起，胫中疼痹。 |
| 饮食不节 | 风邪者，谓风气伤于人也。人以身内血气为正，外风气为邪。若其居处失宜，饮食不节，致腑脏内损，血气外虚，则为风邪所伤。故病有五邪∶一曰中风，二曰伤暑，三曰饮食劳倦，四曰中寒，五曰中湿。其为病不同。 |
| 不通 | 又云∶一足踏地，足不动，一足向侧相，转身欹势，并手尽急回，左右迭互二七，去脊风冷、偏枯不通润。 |
| 五脏六腑 | 风头眩者，由血气虚，风邪入脑，而引目系故也。五脏六腑之精气，皆上注于目，血气与脉并于上系，上属于脑，后出于项中。逢身之虚，则为风邪所伤，入脑则脑转而目系急，目系急故成眩也。 |
| 不治 | 阳毒为病，面赤，斑斑如锦纹，喉咽痛，清便脓血，七日不治，五日可治，九日死，十一日亦死。 |
| 于皮肤 | 中风者，风气中于人也。风是四时之气，分布八方，主长养万物。从其乡来者，人中少死病；不从其乡来者，人中多死病。其为病者，藏于皮肤之间，内不得通，外不得泄。其入经脉，行于五脏者，各随脏腑而生病焉。 |
| 冲任之脉 | 带下病者，由劳伤血气，损动冲脉、任脉，致令其血与秽液兼带而下也。冲任之脉，为经脉之海。经血之行，内荣五脏，五脏之色，随脏不同。伤损经血，或冷或热，而五脏俱虚损者，故其色随秽液而下，为带五色俱下。 |
