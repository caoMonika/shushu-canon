# 急救便方 · 蒸馏技能

**来源**：《急救便方》（维基文库公域本；作者题署不详，内容为明清民间急救方汇编体）
**性质**：仓猝急救手册——重**外治、取嚏、吹鼻、熨法、物理引流**，汤药为辅
**文本说明**：IMA 库内 TXT 为加密损坏件；本技能据维基文库文本蒸馏
**使用边界**：仅古籍文献/民俗史参考。现代心肺复苏、中毒、创伤处理以现行急救规范为准；不可按书操作替代专业救护。

---

## 一、总原则（全书暗线）

1. **心头微温 = 尚有生机**（一日以上亦可试救）；身僵色变勿妄断已死
2. **五绝通用钥匙**：生半夏末吹鼻 / 皂角末吹鼻取嚏；韭菜汁灌鼻；人中与足大趾甲缘灸
3. **冻死忌直接火烘**；**汤火忌冷水冷泥激**（防火毒攻心）
4. 夜间中恶"原无灯者不可用火照"——书中反复强调，属民俗禁忌层

---

## 二、五绝急救流程

### 1. 自缢

```
徐徐抱住（勿猛断绳）→ 缓解放卧 → 正喉
→ 摩擦胸臆 + 屈伸手足 + 按腹
→ 一人口裹衣抵肛勿泄气
→ 约一饭时待气出 → 官桂汤/粥润喉 → 笔管吹两耳
兼：细辛皂角末吹鼻；重者灸涌泉（男左女右）
```

- **时机**：旦至暮较易；暮至旦阴盛难；心下微温则坚持

### 2. 溺死

| 步骤 | 法 |
|---|---|
| 开气道 | 撬口横衔箸，利出水 |
| 引流 | 健夫倒驼背负；或覆牛背牵行；冬月草灰厚覆 |
| 通上下 | 竹管吹口耳鼻脐肛；半夏搐鼻；皂角末裹塞肛 |
| 忌 | 未出水先灌大量冷水；冬月不换湿衣 |

### 3. 冻死

- 胸前微温者：炒米/灶灰熨心，冷换；目开后温酒姜汤粥**稍稍**灌
- **先火烘则死**（书中明禁）；微笑时掩口鼻
- 毡卷轻滚至四肢温；落水微气者先换干暖衣再同法

### 4. 中恶 / 魇死 / 压跌

| 证 | 首法 |
|---|---|
| 中恶卒死 | 鸭血灌喉；蒜/韭汁灌鼻；皂角或半夏吹鼻；刺上唇粟泡 |
| 魇死 | **勿骤近叫**；吹面、咬脚跟/拇趾、频呼其名；皂角吹鼻得嚏 |
| 压死坠跌（心头温） | 扶坐提发，半夏吹鼻 → 姜汁菜油灌 → 散血药或童便 |

**总治卒死三方**：韭汁灌鼻（加皂角麝更捷）；半夏冷水丸纳鼻；葱心黄茎入鼻（男左女右）至鼻目出血为有机。

### 5. 中风中暑中毒霍乱（书指归内科细论）

- 通法提纲：生姜自然汁和童便
- 暑天中暍：**勿饮冷水**；灶灰/热土壅脐淋热汤

## 三、诸伤速查

| 伤类 | 要点 |
|---|---|
| 跌打昏迷 | 野菊+童便酒；或苏木白麻皮木耳焙末黄酒黑糖；气绝用韭汁童便 |
| 金疮出血 | 煅石灰、轻粉、血竭、白蜡掺后盖膏 |
| 目伤突出 | 急揉进；鲜猪肉片掺当归赤石脂贴 |
| 烟渣入目 | **勿水洗**；乱发/棕缓揉 |
| 铁屑入目 | 真磁石吸 |
| 毒箭 | 犀角刺疮；或麻油内服+人粪/蓝靛外涂（文献层） |
| 鸟枪子 | 生南瓜片贴；或蜜酒热服使子粘出；磁石末腊肉贴 |
| 汤火 | 老瓜水/乳调铅粉/大黄白蔞油调；**先热童便护心**；盐末护肉后再敷 |

### 咬伤

- 蛇：拔头心红发；生何首乌捣汁冲酒服、渣敷；五灵脂涂（蛇蝎蜈蚣）
- 虎咬：清油一碗 → 白矾纳伤口；或砂糖水、生葛汁
- 蜘蛛：羊乳；或酒醉待虫出；蓝汁

## 四、中毒门

### 砒毒

- **不久在上宜吐**；入腹则铅水、鸭血等（文献记载，现代禁用此思路自行处理）
- 绿豆捣新水调；柏子壳+红土+鸡蛋清；靛花；冬青汁；黑铅磨水等——均为历史解法索引

### 鸦片烟毒

```
轻：鸭/鹅血、酱油、凉水灌吐；白矾雄黄末清水调
重（身冷似死、肢软）：阴湿地放平 → 撬牙横筷张口
→ 冷水/金汁频灌 + 胸前冷水摩荡 + 发浸冷水盆
→ 三四日待烟气退；忌见日；七日勿殓
调酒服者书称难救；灯油频灌可吐（烟膏见油）
```

### 其他

- **野芋毒**：地浆/粪汁或大豆浓汁（文献）
- **水毒**（涨水）：缸内贯众+雄黄明矾澄清
- **蛊/挑生**：尝矾不涩反甘、嚼黑豆不腥 → 中蛊；上吐（升麻/胆矾）下泻（郁金）；后四君子调
- **物性相反**：甘草↔鲙、蟹↔柿、河豚↔鹿肉等——作饮食禁忌文史表，不作现代营养结论
