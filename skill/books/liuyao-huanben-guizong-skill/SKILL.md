# 王炳中《还本归宗——六爻预测指南》

沈阳市周易研究会会长王炳中著（2008，中国商业出版社，"中国易学文化传承解读丛书"）。定位：尊重古法而不拘泥，约300卦例多为作者实测。**本技能据现存文本蒸馏**：上部基础理论+六十四卦卦意分述（仅存1–46卦）；下部高级理论（耗护神、真假变爻、三场理论、动态择吉、调运解灾、通灵论等）正文缺失，仅存目录名目（见"边界"章）。基础性内容（阴阳五行、装卦）与他技重复处从略，参见《liuyao-zengshan-buyi-skill》等。

学习法：扎实基本功 → 大量实践（"古书也不全对"，如六冲变六冲未必凶）→ 多读古籍博取众长 → 形成稳定场态。职业道德：不戏测（酒后/不信/玩耍不测）、保密、不测违德法之事、防宿命论（"预测是为了更好地走路"）。

## 二、独创概念名目（正文缺失，仅存自序/目录）

耗护神（原/忌/仇神之外）、真假变爻、真假旬空、真假月破、用神破译论、多用神概念、**三场理论**（周易预测三场）、星辰下界、月建日辰与流月流日/太岁流年之辨、复合应期。查用这些概念时须知：**本书文本不含其展开论述**，不可据名目臆造规则。

## 三、基础论中的独到观点（散见）

- 太极图旋转：北半球顺时针、南半球逆时针（南半球当以北为火南为水）；八卦图应**由内向外**看（太极为立足点）。
- 五行生克辩证全诀（"金赖土生，土多金埋……强土得金，方制其重"）为总纲；纳甲中**刑、害、破有作用**（驳《增删卜易》弃刑说），主细节多断：鬼克带刑多官非，鬼克带害多病灾。
- 天干合冲纳甲不用但作知识拓展（甲己中正合夫从妻化等）。
- 似卦（大过/小过类坎、中孚/颐类离）、包卦（恒=坤包乾）、互卦主事之中程，均入断。

## 四、八卦类象溯根法（第四章，方法论核心）

从每卦**基本属性**出发按"特性→派生意象"逐层推演（乾：天→高大广阔；三连→男性首脑；圆→球类镜表；现代→轿车电脑……共13特性）。使用心法：

1. **一卦多象**：一卦可名可动可形（乾=领导者/领导/有领导力）。
2. **广泛联系**：由基本意象顺藤摸瓜（坤为地→土→瓦工→平→方→静→众→藏→贫）。
3. **一象多卦**：依侧重点定卦（杯子：饮水=兑；泥粗=坤；竹制=巽；金贵=乾）。
4. **近义辨析**：同为广场，坤=大而破旧不规范，乾=现代高级广阔；同为"漂亮"，中女=离(beautiful)、少女=兑(pretty)。

## 五、六十四卦卦意直断（1–46卦，判据精华）

卦意功用：断来意（鼎/丰主名官文书，咸/姤主婚恋）、直断性质（测婚得离不谐、求财得损难赚、事得涣多散——引《易冒》）、多断细节、指导发展（大有=怀柔得众）。每卦"课/象"命名+判据，浓缩如下（测病/婚/财/天气/出行等）：

- **乾**（六龙御天）：刚健首脑，利仕途不利纯求财；头/肺/骨病；晴天；老人有归天危；婚不美。**坤**（承载万物）：臣道利副手；腹胃病；纯阴婚不美；平房；行人不动。**屯**（万物始生）：艰难初生，四大难卦；肝肾脚气；积蓄之财；测房必得。**蒙**（启蒙）：教育之卦，师象；血病结石；防蒙蔽；数不过六。
- **需**（密云不雨）：等待，饮食宴乐；头骨饮食病；婚暧昧。**讼**（天水违行）：官司口舌多不吉；脑骨神经病防误诊；先小人后君子。**师**（以寡服众）：归魂，兴师动众；消化/结石；测婚不吉易婚外；测财大吉。**比**（众星拱北）：归魂，亲比竞争；胸部乳腺肠胃；婚太挑剔难成；利流通领域。
- **小畜**（密云不雨）：小蓄阻力；气管便秘忧郁；夫妻反目。**履**（如履虎尾）：礼卦，惊无险；呼吸性病金属伤；婚多风波；鞋袜生意。**泰**（天地交泰）：亨通，婚吉，外柔内刚；利小钱办大事；防泰极否来；应正月。**否**（天地不交）：闭塞，外刚内柔；食道胃癌气血病；得不偿失；应七月。
- **同人**（二人分金）：归魂，合作相争；肺血管眼病；防第三者。**大有**（金玉满堂）：归魂，大收获女强人；肺脑血管；股市到顶。**谦**（仰高就下）：六爻皆吉唯一卦；脾胃肾虚；婚有"富婆小白脸"象。**豫**（凤凰生雏）：和乐名气；消化肾梗阻；婚吉；乐器娱乐生意。
- **随**（如木推车）：归魂随和；腿伤肝病；婚有三角；应黄昏深秋。**蛊**（以恶不久）：归魂腐败整饬；性病虫积；内忧大于外患；女祸男。**临**（以上临下）：领导宽容；腹部手术腿足病；防八月凶；主十二月成。**观**（春花竞发）：政治专卦、精神卦；呼吸道风湿；大艮象多观察；应八月。
- **噬嗑**（日中为市）：饮食刑罚官非；胃肠肿瘤；市场之象。**贲**（猛虎靠岩）：文饰虚荣；眼病心梗；喜气婚卦；装修广告业。**剥**（群阴剥尽）：小人得势宜静；重病下肢；女欺夫；九月卦股市崩象。**复**（反复往来）：反复复兴；腹脚病旧病复发；婚"梅开二度"；十一月卦。
- **无妄**（守旧安常）：意料之灾，走正道可解；"勿药有喜"；晴空而雷。**大畜**（积小成大）：大蓄大止，食禄利仕途；便秘梗阻；浓云不雨。**颐**（近善远恶）：养育农业卦、游魂；外强中干防不实；盒箱大车象；食疗胜药疗。**大过**（本末俱弱）：非常行动、游魂；非常时期立功；建筑质量差；老夫少妻反吉。
- **坎**（船漏重滩）：重险，肾血耳骨病；婚不吉；雨大；防水灾。**离**（大明当天）：依附光明；心眼血病；婚离散；晴防火灾；利文。**咸**（至诚感神）：感应婚卦"娶女吉"；流行病性病脚伤；来得快；已孕易男。**恒**（四时不没）：恒久不变；食道胃肠肝病不利；婚吉；求变遇之不动为好。
- **遁**（豹隐南山）：退避保守；重病凶小疾反吉；六月卦。**大壮**（先曲后顺）：壮大当止防盲动；神经脚病；冲高回落。**晋**（以臣遇君）：晋升转机；心脏胃热；晴天；贵人帮。**明夷**（出明入暗）：韬晦，工伤卦；心眼病重凶；停电之象；股市转熊。
- **家人**（开花结子）：家庭卦利女性；家族企业；微风。**睽**（二女同居）：乖离事与愿违终有果；神经分裂血栓；"口舌相伴财散人离"。**蹇**（背明向暗）：困难见贵；脚病结石；利西南不利东北。**解**（草木舒伸）：解难缓和，坏事最吉；胃热久病痊愈；动作要快；已孕女孩。
- **损**（掘土为山）：先损后益慢来；流产腿伤破财；合作不久。**益**（滴水添河）：损己益人"衰之始"；肝胆病加重；测财得利。**夬**（神剑斩蛟）：决裂快速；头伤性急；股市泡沫破；三月卦。**姤**（或聚或散）：淫奔邂逅多不吉；流行病性病中风；因女人起祸；五月卦。**萃**（鱼龙会来）：聚合丰盛；多病并发症；婚外情；股市跌。**升**（积小成大）：升进发达（文本至此截断）。
