# [二十二难]

## I — 方法论骨架 (Interpretation)

本节主要讨论了《难经》中的脉诊理论，包括手三阳、手三阴的脉络分布和功能，以及奇经八脉的作用。通过理解这些基本概念，可以更好地进行临床诊断和治疗。

## A1 — 应用示例 (Application Example)

假设患者出现头痛症状，根据《难经》中的描述，可以通过检查手太阳经的气冲穴来判断病因。如果气冲穴处有异常，可能提示邪气侵袭或气血失调。

## A2 — 触发场景 (Future Trigger) ★

当患者出现不明原因的头痛、眩晕等症状时，应考虑使用《难经》中的脉诊方法进行诊断。

## E — 可执行步骤 (Execution)

1. **定位气冲穴**：在少腹毛中两旁各二寸处，足阳明脉之所发处。
2. **检查气冲穴**：观察气冲穴处的气血流动情况，如有异常，记录下来。
3. **综合分析**：结合其他症状和体征，进行综合分析，判断病因。
4. **治疗建议**：根据诊断结果，制定相应的治疗方案。

## B — 边界 (Boundary) ★

本方法仅适用于中医临床诊断，不应用于医疗决策。
