# 术语表 — 《神相铁关刀-清-云谷山人》

| 术语 | 上下文线索（OCR） |
|---|---|
| 何知此人 | 何知此人水中丧？地阁有廛须眉重，水法不清神昏暗，眉无黑子少年痛。 |
| 经曰 | 辅骨小儿，鼻准微端者八品之侯也。又曰，胸背微丰，手足润泽，及身端步平者，此皆八品之侯；夫鼻须洪直而长，胸脾须丰厚如龟形，手足色须赤白，此皆富贵人也；故经曰：手足如棉富贵终，手足厚好立使在旁也。 |
| 人也 | 左传曰，周肉史叔服如鲁公叔，教闻其能相人也，见其二子焉，叔服曰谷也，食子谁也，收子谷也，丰下必有，后于鲁国○杜预曰，丰下谓方面也。 |
| 又曰 | 辅骨小儿，鼻准微端者八品之侯也。又曰，胸背微丰，手足润泽，及身端步平者，此皆八品之侯；夫鼻须洪直而长，胸脾须丰厚如龟形，手足色须赤白，此皆富贵人也；故经曰：手足如棉富贵终，手足厚好立使在旁也。 |
| 何知妇人 | 何知妇人临盆死？颧红似火神如醉，所黑发枯死必然，掌上乌鸦宿不取。 |
| 神相铁关 | 神相铁关刀-清-云谷山人 |
| 地阁不朝 | 何知死后无吉地？法令直冷丑位是，地阁不朝颐又尖，边地不分无所冀。 |
| 无气反此 | 头有气，顶丰圆骨不孤露，有辅粥，有枕骨，颧高无纹无筋端正；无气反此。 |
| 唇红齿白 | 何知此人孝动天？眉清起伏又疏尖，发软须轻神轩爽，唇红齿白面皮宽。 |
| 冢墓 | 丘陵、坟墓在山林下一寸许；邱陵冢墓取象坟穴，如建墓于山林之内，故不能高于山林位也；有气亦为风水所钟。 |
| 得一 | 行乃一身之举动，形为之所流露也。贵人之行，气从下降，力聚踵履之间，故身不摇而足不乱也；得一"重"字所以贵。 |
| 主无子 | 女人过于肥者，主无子；过于瘦者，主刑克；过于高者，主刑克；女人眼露、唇抓、齿露，主为厄；掌中震位黑皆然。 |
| 诀云 | 诀云：圆颇丰颐，侍立多而心腹；唇丹口阔，奴仆盛而心忠；呼聚喝散，无非眉重须密；人中无须多怨谤，地阁歪斜狡猾迟。 |
| 龙宫冲破 | 何知早年子不受？额上纹通奸门陷，龙宫冲破地反天，人中平臃同为鉴。 |
| 何知小儿 | 何知小儿灾难多？山根青黑命门乌，额角准头青乌现，青黄人口死难逃。 |
| 不明 | 黄色在天庭主升官，黄明在三阳主得贵子；黄明在准头主财，黄色宜黄明，而不明反生灾病。 |
| 主刑克 | 发粗主刑，发厚主愚，发秃主愚懒，发黄主贫，发健主刑，发白于少年主短命，发脚生钻主刑克，发脚偏主刑克，发理不顺，主凶暴赛滞。 |
| 之辈 | 又凡掌大者长者，粗者皆主劳碌之人；圆者、厚者、小滑者、软者、不露筋节者，多是富贵之辈也，可不知乎哉。 |
| 中来 | 凡人形貌清古，气清性毒，言根至理，有山林之趣，此自修行中来。 |
| 口如吹火 | 赤日黄晴为育优，胸高额凸皱眉头；口如吹火牙如炭，一世孤伶一世愁。 |
| 暗不利 | 正二月是寅卯属木，宜参右耳右颧，次看鼻，鼻乃一相之主；又看额，额乃大中贵人，姑无论黄明、黄光。红明、紫气、青润俱佳，总宜润者为贵，暗不利，不必泥春属本定青色也，余仿此不复赘。 |
| 宜改 | 如眉不好眼虽好，而仍十足，不若粗浓低压者，宜改之，务宜于眼长短大小均配乃合，否则必困。 |
| 故曰 | 人中在唇上之沟洫处，人生到此一大关隘，寿年、财帛、子嗣皆虑此而冲，故曰人冲，俗呼人中，字有错误。 |
| 邱陵冢墓 | 丘陵、坟墓在山林下一寸许；邱陵冢墓取象坟穴，如建墓于山林之内，故不能高于山林位也；有气亦为风水所钟。 |
| 光明 | 太阳、中阳、少阳，取象于日火者，言其初起也；太，大也，大有光明之义也；中者，日之方中也；少者，将没而尚存其阳也；三阴如之。 |
| 山根青黑 | 何知小儿灾难多？山根青黑命门乌，额角准头青乌现，青黄人口死难逃。 |
| 头大颈小 | 何知小儿必难养？头大颈小囱门陷，脱凸枕骨山根无，声断短促灾妖鉴。 |
| 发尖冲印 | 何知少年克父母？发低耳反筋在额，唇及鼻眷霜相同，发尖冲印天庭黑。 |
| 骨又粗 | 何知至死无儿孙？三阳黑枯骨又粗。目撮如囊人中肿，必然克尽乃身逃。 |
| 人中无须 | 何知妇人反劫财？两眼低垂散尾多，两额不起悬壁反，人中无须奔怨何。 |
| 三十五至 | 三十一岁至三十四岁行眉运，三十五至四十行眼运。 |
| 骨肉调匀 | 颧有气，骨肉调匀，高圆起于正面，夹拱鼻中，无暗昧色，龙宫丰满；无气反此。 |
| 是有神 | （见正文） |
| 之相 | 大凡淫妇之相，每于举动行为，言语饮食之间，总有一番矫操造作处，是为淫妇无疑。 |
| 刑克 | 何知此人相刑克？形似猪肝色不华，身粗面绝孤贫苦，眼下无肉子妻妨。 |
| 富贵福寿 | 发者，血之余也；而人生之富贵、吉凶、祸福、贫贱均可知矣。发宜软，宜幼，宜疏，宜香，得此则为富贵福寿；忌硬，忌粗，忌长，长过身也，忌秽；得此则为贫寒夭折。 |

> 术语由频次粗提，可能含噪声；以原书定义为准。
