## I — 方法论骨架 (Interpretation)

金口诀立课的四大元素包括人元（简称干）、贵神（简称神、星）和将神。这些元素共同构成一个完整的课式模型，由当天的一组时辰干支和神、将组成。

## A1 — 应用示例 (Application Example)

假设今天是甲午年，时为丑时，亥将申方。根据金口诀的计算方法：

1. **计算将神**：
   - 将神 = 方辰5 + 将未8 - 时午7
   - 结果 = 6巳（太乙）

2. **计算贵神**：
   - 贵神 = 1 + 方辰5 - 贵卯4
   - 结果 = 2腾蛇巳

3. **计算干**：
   - 干 = 方申9 + 0 = 9，结果为壬

## A2 — 触发场景 (Future Trigger) ★

## E — 可执行步骤 (Execution)

1. **确定当天的时辰干支**：例如甲午年，时为丑时。
2. **确定地分（方）**：例如亥将申方。
3. **计算将神**：
   - 将神 = 方辰5 + 将未8 - 时午7
   - 完成标准：得到一个具体的将神，如6巳（太乙）。
4. **计算贵神**：
   - 贵神 = 1 + 方辰5 - 贵卯4
   - 完成标准：得到一个具体的贵神，如2腾蛇巳。
5. **计算干**：
   - 干 = 方申9 + 0
   - 完成标准：得到一个具体的干，如壬。

## B — 边界 (Boundary) ★

金口诀立课法适用于中国农历日期和时辰的预测。不适用于其他历法或非特定时间点的预测。
