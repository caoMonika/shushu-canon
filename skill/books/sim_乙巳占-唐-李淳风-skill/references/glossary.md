# 术语表 — 《乙巳占-唐-李淳风》

| 术语 | 上下文线索（OCR） |
|---|---|
| 兵起 | 天雨血，是谓天见其祅。不肖者不得久处其位，不出一年兵起。 |
| 上来 | 贪狼之日，时加奸邪，风从阴贼上来，有劫相杀之事。 |
| 一曰 | 一曰浑天，即今所载张衡《灵宪》是也； |
| 期三年 | 日晕三重，诸侯王反，天下受兵，期三年有攻战。 |
| 兵大起 | 凡天雨杂物，其类甚多。若雨禽兽，是谓不祥，不出三年，其下兵兴。天雨虫，人君不亲骨肉而亲他人，与裸虫同类，故虫从天坠地，骨肉去也。不救，兵大起。其起也，立王公，率同姓诸侯，无偏党侧，灾消。 |
| 又曰 | 京房曰："临狱不解，兹谓进非，厥咎天罚。故天雨血者，兹谓不亲，民有怨恐，不出三年，亡其宗人。"又曰："佞人用，功臣弃戮，故天雨血。" |
| 一云 | 九日提气。日月四旁有赤云曲向，名曰四提。提似珥而曲，不出其年，兵起，王者死，赤为亡地，有自立者。一云气形如三角，在日四方，为提。 |
| 发屋折木 | 徵风。发屋折木，不出三日、三十日。若有大灾，吏忧自行，当四方有告急事，或有火妖。性恐怖惊乱。（凡言吏者，理入官，上至三公皆是也。） |
| 乙巳占 | 《乙巳占》 [唐]李淳风 |
| 之象 | 甘氏曰："无云而雷，陨石坠地，大可一丈，圆形如鸡子，两头锐，名曰天鼓。所下之邦，必有大战，伏尸数万，不可救。"春秋鲁僖公十六年，陨石于宋五，此时宋襄公之应也。望之是星，至地为石。失其所，无光荣之象也。 |
| 有兵 | 天雨鱼鳖，国有兵丧。天雨骨，是谓阳消。王者德衰，令不行，佞不用，不出三年，内有争。天雨筋，国大饥。 |
| 两军相当 | 两军相当，数日并出，当分营以应之。 |
| 期一年 | 轸：月宿轸，则多风。月蚀轸，则贵臣亡，后不安。月犯轸，月凶丧，车骑出，兵车用，期一年。 |
| 十日 | 墨子曰："商纣不德，十日雨土于毫。"天雨土，君失封。 |
| 大人忧 | 娄：月犯蚀变于娄，有兵在外，不战而和，有聚敛之事，多有搜狩弋猎之事，民多狱怨，国君纳女，游猎无度，大人忧，将军死。 |
| 彗孛干犯 | 彗孛干犯月五星，有兵丧，中国兵动，四夷来侵，百姓不安。 |
| 苍白气入 | 苍白气入勾陈中，大司马戮死。赤气出勾陈中，大将战有功。白气入勾陈中，天子立宗庙事。黄白气出勾陈中，兵在外告罢事。黄白气入勾陈中，将不战。黑气入勾陈中，大司马军中死事。黑气入勾陈中，其祸除。 |
| 发风三日 | 京氏云：东方寅卯木之角，发风三日，发屋折木，扬沙石，（自此已后，并云怒狂风。）国有大寇疾病。 |
| 天下大乱 | 日蚀而晕傍珥，白云来去掩映，天下大乱，大兵起。臣弑君，君失位。 |
| 国易政 | 亢：荧惑入亢，有芒角犯凌之，当有白衣之会。火入亢天子庭，有兵水灾。火守亢，成句巳，而环绕之三十日，天子自将兵，国易政。火逆行守亢，为中兵。火犯亢者，臣乱，多疾疫。 |
| 天下乱 | 月行急，未当中而中，未当望而望，皆为急。兵大战，军破将死，大臣执政逼君，主将有女主擅权，天下乱，易宗庙。 |
| 尔雅 | 古书云：风者，通已前并用，总有八号，谓之八风。取《尔雅》风名，风而雨为霾，阴而风为翳，日出而风为暴，回风为飘，焚轮谓之颓，扶摇谓之焱。 |

| 春夏犯 | 流星犯亢，府车忧。春夏犯，大妖言，王者忧；秋犯，其分疫；冬犯，盗贼起，水灾。 |
| 外官占第 | 月干犯列宿占第九　　　　　　　月干犯中外官占第十 |
| 大旱 | 日中乌见，主不明，为政乱，其分国有白衣会，大旱。 |
| 大水 | 日昼昏，行人无影，至暮不止者，上刑下急，民不聊生。不出一年，必有大水，下田不收。 |
| 将军死 | 尾：月犯尾，贵戚有诛者，其国将军死。月在尾，后宫有争，人君子孙不吉。 |
| 秋冬犯 | 流星犯冲房，大兵起。一云大水灾。春夏犯，土官忧；秋冬犯，人大饥，太宰反。 |
| 有丧 | 一曰冠气。青赤色立在日月之上，冠带之象也。天子当立侯王，封建亲戚，授之茅土以为蕃屏。白则有丧，赤则有兵。 |
| 其祸除 | 苍白气入勾陈中，大司马戮死。赤气出勾陈中，大将战有功。白气入勾陈中，天子立宗庙事。黄白气出勾陈中，兵在外告罢事。黄白气入勾陈中，将不战。黑气入勾陈中，大司马军中死事。黑气入勾陈中，其祸除。 |

| 有忧 | 日出一竿无光曜者，其月有三死，若有忧。若人君宰相不从四时行令，刑罚不时，大臣奸谋，离贤蔽能，则日月无光并见瑕谪，不改其行，其国五谷不成，六畜不生，人民上下纵横，盗贼并起。 |
