| 初傳 | 初傳之上中傳取 中傳之上末傳居 |
| 二天將 | 十二天將飛佈以貴人為首、先找出貴人落宮、視落宮之 |
| 為初傳 | 為初傳、再由初傳之地盤看天盤之字 |
| 為中傳 | 為中傳、再看中傳之地盤其上神為末傳。 |
| 發用 | 不論賊或剋均取上一字發用 |
| 上神 | 二：一課上神子加在丁亥之間、看地盤 |
| 未在地盤 | 晝占、甲貴人在未、未在地盤午逆佈 |
| 四課中一 | 第一課寅木辛金、第二課午火寅木、第三課酉金巳火、第四課丑土酉金。四課中一、二課為下賊上、 |
| 為末傳 | 為中傳、再看中傳之地盤其上神為末傳。 |
| 四課無賊 | 四課無賊剋則取二、三、四課之上神、遙剋日干者發用、若無一課剋日干則取日干 |
| 丁貴人在 | 晝占、丁貴人在亥、亥在地盤午逆佈 |
| 日干 | 亥子丑寅卯辰順佈貴人。巳午未申酉戌逆佈貴人、落宮因占卜日干及晝夜不同而變。 |
| 天盤 | 為初傳、再由初傳之地盤看天盤之字 |
| 酉在地盤 | 夜占、丁貴人在酉、酉在地盤丑順佈十二天將 |
| 日干上神 | 陽︶日取日干上神發用。柔︵陰︶日取辰︵支︶上神發用、中末傳同前。 |
| 甲貴人在 | 晝占、甲貴人在未、未在地盤午逆佈 |
| 日支 | 四：三課上神辰加在日支亥旁、視地盤 |
| 午逆佈十 | 晝占、甲貴人在未、未在地盤午逆佈十二天將 |
| 中末二傳 | 無遙無剋昴星論 陽仰陰俯酉位參 中末二傳須記取 日上神與辰上神 |
| 甲寅旬子 | 例：辛酉日丑時、大寒後子將、夜占   甲寅旬子丑空亡 |
| 丑空亡 | 例：辛酉日丑時、大寒後子將、夜占   甲寅旬子丑空亡 |
| 取日上神 | 發用、中傳取支上神、末傳取日上神。 |
| 賊上 | 一、賊剋法：取課先從下賊呼 如無下賊上剋初 |
| 剋下 | 四課中只有一課上剋下或下賊上、上剋下稱 |
| 小滿後申 | 例：丁丑日子時、小滿後申將、夜占  甲戌旬申酉空亡、空亡之符號 |
| 甲辰旬寅 | 例：甲辰日已時、大暑後午將、晝占  甲辰旬寅卯空亡、空亡之符號 |
