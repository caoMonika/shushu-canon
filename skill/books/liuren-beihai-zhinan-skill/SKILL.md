# 北海闲人注《指南》（《占验今诠》＋《指南诠解》）

两本一套：`_src\beihai-zhanyan-jinquan.md`（占验二十一章注释）、`_src\beihai-zhinan-quanjie.md`（《指掌赋》《心印赋》释读＋课传气势例解）。核心不是新体系，而是**读例法**与**成案判据库**：把陈公献的断语逐句追回到"象"，再往回追到《会纂》《毕法》《指掌赋》的明文。

## 一、读课例四问法（北海的看书法）

每读一个课例，只问四件事：

1. 这课占的是什么事，属哪个占类？
2. 作者下了哪些断语？
3. 这些断语所依据的象各是什么？
4. 这些象与事的结合，体现了怎样的壬学思想？

配套提醒："占类、占事的主要求问方向非常重要。疑在哪里，占的重点就在哪里。占此而言彼，难验。"

## 二、三条铁律

**1. 类象与判辞一一对应。** 先分清层次：课传里哪个象管哪件事，哪句话是说哪个象。缠夹不清必致思维混乱。壬占理气第一、类象第二；吉凶之象的"并聚"决定课传气势。"有象则有事"——课中出现某象，就会发生某事；某事的象出现得越多，发生概率越高。

**2. 无一字无来处。** 断语必须有先贤成文作依据。依据的优先次序：《会纂指南》（在《指南》卷三，分类占歌诀，最精最验，须熟读成诵）＞《毕法赋》（课体格局）＞《指掌赋》《玉成歌》《照胆秘诀集》（事象论列）。"一切创为异说、凭一己小聪明、不以经典赋文为依据的做法，都是可笑的、有害的。"

**3. 壬学即人学。** "课义虽言五行，实字字切着人事。" 每象必须还原成生活场景才能断准：如"龙神克下上官不足"→《会纂》"龙常克下鸳班憎"→朝中文武讨厌他、上司不喜欢、官当不成。

北海补一条反向鉴别：即使没有明文的类象，也可依自然之理、整体氛围推出来；反之"任何一个象，如果不合理，那就是空的，没有重复操作意义"。传奇式的"错误正断"（记错类象也断对了）只算天机偶然，不可作经验。

## 三、并聚取象法

- 单象不足以定事，须看同方向之象的叠合。占雨例：龙神飞天（云翻）＋贵登绛明（运水）＋罡居卯（阴阳变易）＋日居贵前（阳气舒）"四象合一，方敢断有大雨"。
- 蒙胧象必须找到落点才算成立：龙神飞天只代表云在空中翻滚，须贵人居亥子（江湖）才是真下雨。
- 反面也要用：课传一片凶象时，"全无和治之气"就是最集中的判语，不必逐象列举。
- 急事、诚心占，象极明、并聚多；坚决反对戏占——课式模糊则思维混乱。
- 取象要会取舍：先贤断课简捷明了、不务琐屑，所取之象皆有明文、显象确切，这是准确率的来源。

## 四、六大占类成案判据

### 天时

- 风：寅为箕宿好风；未为风伯，斗罡加未即"鼓动风伯"；劫煞（寅午戌在亥、亥卯未在申、申子辰在巳、巳酉丑在寅）主迅速，克日则狂风；白虎临申相克则猛烈。风之方看虎所临，风之时看虎所临之支化干（申应庚日）、巳为风府。
- 雨：青龙主雨，龙加辰巳午未为升天，龙加本家寅为入庙（休不行雨）；贵加亥子为登绛；丑为雨师，酉为雨泽；申为水母；亥子为江湖。
- 晴：太阳（月将）发用主晴，乘朱雀更主大晴；巳在冬至后为雪、乘空则无雪；天空为晴象。
- 雨量："衰旺空刑须细辨，克日有气滂沱见；无气空亡微雨来。" 旺则大、衰则小、空则小、刑冲克害则激烈、日鬼旺相则雨大。
- 雨期：壬癸亥子入课传，看其所临之支化干（临寅卯甲乙日、临巳午丙丁日）；不入课传则看青龙所临及合神（子乘龙，子丑合则看丑）。多个水神入传则不止一场雨，以先到者为先。空亡在此有两用：一为克应之期（出旬方验），二为雨量（水空则雨小）。
- 火土局亦可主雨（三传火土亦主大雨）——不能一见火土便断晴，要看气势方向。
- 斗罡所加即变化之所："斗罡指处必破"；罡加卯为阴阳易绝之位，晴雨变易。
- 分野：天罡所加定分野（加巳则荆楚等）。

### 地理（风水，全《指南》仅一例，示范性极强）

- 天将分职：玄武为风水（亦为坐山）；龙神为来龙（春辰夏未秋戌冬丑，非青龙）；蛇为穴、又为罗城；朱雀为案山；勾陈为明堂（乘神内明堂、阴神外明堂）；青龙左辅、白虎右弼；太阴天后为水口。
- 四课定位：第四课主山，第三课主山坐向，第三课之对冲为朝山；三传为葬者以下三代（初代、二代、三代，末传之阴神参看第三代）。
- 山水向背：贵人顺行为顺水局、逆行为逆水局；三传顺行而贵人逆行则山水相向、包裹紧密为吉。
- 房分：孟为长房、仲为中房、季为少房；青龙主长房、白虎主季房；朱雀主中房。龙空虎战则长季人财不旺。
- 缺象即缺失：诸类象逢空即为该处有缺（龙神空则无真龙、蛇空则无正穴）。
- 支之六亲与十二长生与干同等重要（支鬼、支胎、支绝、《毕法》多法干支并举）。
- 孕、寿等附带断：木胎在酉作胎神则婢妾有孕；胎神长生所临之支定孕月（酉长生于巳、巳加子→十一月）。

### 婚姻

- 成否看干支：干男支女（据干阳支阴，万古不易）。干支生合、支上生于、无空破则女家愿成。
- 偕老看三传：财官相生、夏月旺相、不空则偕老。"欲知偕老是何术，全凭财官虚与实。财乘旬后凤孤飞，官坐空亡鸾失匹。"
- 成而有讼：末传财遁日鬼＝"财乘暗鬼官讼起"；干上月大耗、发用岁大耗则为讼破财。
- 有子：不必看子孙爻，子乘青龙（"子乘龙合，儿孙欢庆"）即有子；胎神入传且长生在某岁支，则该岁生子。

### 孕产

- 男女五步：①三传合局，水局木局为男、火局金局为女；②无合局则天罡加干，干阳男干阴女；③日与一二课共三课，二阳夹阴生女、二阴夹阳生男；④再以胎神断：卯子为男、酉午为女；⑤干上之支所寄之卦定阴阳（卯震长男、酉兑少女、子坎中男、午离中女、戌亥乾）。
- 双胎："重逢建将为双胎"（月建两现、作胎神乘旺），或日辰之胎神并现于课传。
- 产期："欲识产期何者善，胜光所临最为便。又有冲胎一法看……生养之下究产期。" 胎、养、天喜、长生之日多验；伏吟主迟故以月应，伏吟亦宜冲。
- 子母存亡："支伤损母干损儿，两处无伤母子笑"；"合受下克伤儿命，下制天后危母身"（六合为子、天后为母）。
- 难产：魁度天门（戌加亥）阻滞；天狱课（墓神发用、斗系日本）无冲则不出。
- 胎鬼：酉作胎神多为偏房婢室之孕；"胎乘鬼死堕胎推"（胎神乘死气日鬼则女胎不存）。
- 干加支为子恋母腹（难产），支加干为母俯见子（顺生）；四课不备主不足月。

### 考试、乡试

- 主象：河魁（戌）临干或临年命发用＝印，直断考中；旬首发用＝出类拔萃；幕贵（帘幕贵人）临干或临年命，试必高第（科考专视此神）。
- 德入天门（日德加亥）不问空亡皆中。斗鬼相加（丑未相加）古称夺魁，实须丑未年、丑未日方成立。
- 亚魁星酉：北海实证为"落榜者中最优"，非第二名；只因作幕贵才中副榜。
- 真朱雀（午乘朱雀）：土年进士考必中，须入课传年命；三凶——克太岁、克幕贵、考后朱雀乘丁马。
- 天心格（年月日时四建全在四课）最利考试仕途，主非常喜庆。
- 文章之象：朱雀旺相则新奇合时、遁丙则华藻、临巳午为翱翔、生太岁则合朝廷风尚；干支交车生合＝"词源沛"。
- 武试：申为箭，加午中红心、加子卯酉中中垛、加寅申巳亥四角花、加辰戌丑未脱靶；从第几课发用即中几箭。
- 迁动之象：德禄驿马入传、催官符（三传财生干上鬼）、将逢内战（"惟宜占官，从卑贱而迤逦迁转"）。
- 一课占数人：以年命分人；三传逆合则可反长者在前之常理。

### 仕宦

- 吉象并聚则升：龙常并见、城吏全逢（天城申、天吏寅）、三传递生人举荐、德禄驿马入天门、发用月将贵人乘丁马＝目今荣转。
- 凶象并聚则退：三传递克众人欺（必被参劾）、贵履天罗地网、干支乘墓、禄马空陷、太阳西坠/入山、龙神克下（上台不足）、罗网主丁艰、顾祖（午辰寅）在朝多不满任、伏吟见马（归象）、干支皆败、鬼临三四。
- 升迁之期：《会纂》"迁期干年支月推"——龙神与日干寄宫相距几位断年、与日支相距几位断月。
- 官鬼之分：官鬼乘贵常龙为官，乘蛇玄阴为鬼，乘白虎为催官符（升迁、赴任）。
- 月将作官星、贵人时**仍以空亡论**，不得因是太阳而破例；"月将不空之说，大谬也，切记"。仅在天时、家宅、恩泽之象上，乘空落空可作悬空论。
- 干神归支：为原地不能动之象（不能赴任）；干神归支而被支克，纵来亦失意。

## 五、克应期通则（北海反复强调的几条）

1. **应近不应远，应旺不应衰。**
2. 三传合局已是一种气势，可视作"类神"：**旺待衰时、衰待旺时**，或**冲其中神之时**为吉凶定格之期（"合局课多以冲中神为克应之期"）。
3. 伏吟主迟，以月应；伏吟亦宜冲（冲养神、冲墓）。
4. 以月建上神之天将断月；以"建"前一二三位推近月（二月占而象在巳，则取巳月）。
5. 太岁亦须乘旺方有用——"变"是过程之义，变死为活。
6. 空亡两用：一作克应之期（填实之月/年），一作虚实之辨（象虚则事不实）。
7. 反吟多不满任；回环格主来而复去；返吟见马为归象。
