# 刘虹言《易学难精》（卦例集＋六爻课）

作者刘虹言（本名刘刚，1973 年生，四川岳池）。全书两部分：13 类卦例实断（生意财运、工作官运、婚姻感情、疾病伤灾、门面风水、怀孕生产、失物偷盗、官司口舌、行人走失、各类考试、流年运程、比赛竞技、生活杂占）＋课程理论（六爻六个层次、四柱总论）。卦例均带"起卦钥语/前提条件/反馈"，讲义体。

## 一、核心理论：爻的六个层次（第一层四值，本书精华）

### 1. 太岁：无成败权，但有修改应期权

- 太岁不直接生克卦爻（"衰爻逢太岁生不会旺，旺爻逢太岁克不会衰"），但**修改应期**。
- **太岁介入**＝卦中有爻与太岁相冲/相同/相合 → 此卦有信息，可放心断过去验证思路，再断未来；**没有太岁介入的卦＝意念不到、无信息，最好不要预测**（错了丢名，对了也总结不了经验）。
- **太岁入卦**＝爻临太岁：不论喜忌、不论所测长短，**吉凶就在本年内出现（测远事应近事）**。例：问明年工作，太岁戌土入卦→断当年即变动，果然当年机构调整。问终身命运而世临太岁→全按当年事断（修路受贿案，应期申日）。
- **废"阳爻主过去、阴爻主未来"**：实践准确率太低，弃用；断过去改由"太岁介入＋用神有病无病"决定。
- 太岁冲合卦爻的应期用法"未得实践，不敢妄说"——作者诚实标注。

### 2. 月令/日辰/时辰

- 月令介入：吉凶多在本月出现（中短期事本月开始本月结束），定应期直接参考。旺衰次序带情义：寅月寅最旺、卯拱扶次旺，**午火比巳火优先**（寅午半合有情、寅巳相刑无情——测比赛可据此断胜负）。
- 日辰、时辰为低层次，逐级细化应期。测远应近、测近应远，"奥秘全在年月日时四值"。

### 3. 用神多现：全部都要看

- 通行法则（初中级）：**无病的用神代表过去/现在状态，有病的用神代表未来状态，用有病的断应期**。
- 高级法则：**真假用神**——真用神代表过去，假用神代表未来，"有真假用神介入时一切以真假用神为准"，此时可能有病的是过去、无病的是未来。例：测失物，辰土真用神化回头克＝丢东西之象（过去），未土假用神得司令助＝可找回（未来）。
- 变爻能量走向、动爻化泄、日月能否通关、日月入卦不受伤、飞伏神、相同字"并"之后的好坏——均为后续课程条目（高级课内容本书仅存目录与提要，细节在第三课未收入）。

### 4. 静爻有能量

古人"有动爻则全看动爻"是误区：**静爻旺相都有能量，只是作用缓慢**，对旁爻同样生克制化（例：月建入三爻阻隔世应，也须纳入断局；"月建入爻"为阻隔之病，去病之日为应期）。

## 二、卦例实断风格

- 每例先立"起卦钥语"（意念限定）＋前提条件，再逐爻演绎成"生活故事"，最后回归应期。例：老婆偷钱出走（财合官＝跟第三者、财动化兄＝带钱走、子水动金生水再生鬼＝未断绝、子化回头克＋月破＝不吉后投河、太岁生世之财当年再婚）。
- 重视"卦与事件对应性"：卦中要有显示该事之象（测失物先看卦有无丢物之象），无象则"此卦没信息，不可勉强断之"。
- 测终身命运遇太岁入卦，直接转断当年事，不硬圆"终身"。

## 三、四柱部分（附）

批评"以日元为核心"的断法为谬误，主张注意命局组合；含神煞、十神、性格、事业、婚缘、流年课目。与六爻部分独立。

## 使用边界与素材缺陷

1. 本书为课程讲义选编：六个层次课的第 2–6 层（变爻能量走向/日月通关/暗动/爻位/飞伏/并字）**只存条目与提要，正文细节缺失**（在"第三课高级预测"内，源文件未收）；真假用神仅举例未展开定义。
2. 卦例以论坛求测为背景，反馈多为单方陈述；作者自述"已初步进入预言家的境界"属自评，不作采信依据。
3. "太岁无成败权""月令介入吉凶本月现"等是该派独家判据，与传统派（太岁亦论生克）不同，不可混用；使用时应注明出处体系。
4. 四柱与六爻两部分互不相干，按需分开取用。
