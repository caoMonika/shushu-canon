# 增删卜易卦评：实战拆卦方法论（朱辰彬）

取材：《朱辰彬〈增删卜易〉卦评》（网络版，评至 205 例，部分卦评者为郑祥易、王祥彬续评）。每例结构：原卦＋野鹤原注＋朱氏四步评注。价值不在基础条文（那些在 liuyao-zengshan-buyi-skill），而在**他怎么拆一个卦**：取用为什么这么取、定性卡壳时走哪条路、应期怎么收敛。其《讲义》中的"卦意分析法"术语散见评注，此处按评注内容还原。

---

## 一、四步评注流程（每例固定骨架）

1. **选取用神**：先问"问卦人的心思到底在哪个点"（谒贵求财两可时看心思——五爻兄弟动临勾陈对财卯，勾陈表象玄武本质，知其重财）。明确后按取用次序定爻。
2. **吉凶判断**：定性只走一条主线（卦理生克／卦象／卦意），把日月、动变、空破的层次捋清；**定性未出之前不谈应期**。
3. **应期细节**：以定性为前提（"吉断应吉、凶断应凶"），再纵观全卦复合取应期——不只看世用，动兆（忌神化退之期、暗动之期）都是参考应期。
4. **启示**：与现实现状对照——**凡真卦之显露必与事件现状密切相关**（寅木暗动克用＝病重现状）。卦面信息与现状一一对应，才可作预测依据；卦有多显，未必答你所问。

---

## 二、取用进阶

- **世应动取用次序**：临世应、临动爻（含变爻）位置的用神备选，成为真用神的几率约 90%——野鹤"动必有因"的体现。世应动位置皆有用神时，**有殊取殊**（月破、值月都算特殊；问他人事应位优先），**不取"有旺取旺"**——取用时挑旺爻等于主观主导吉凶，违背客观预测。
- **客观取用**：对照现实取用（测仆人＝我控者，古代以妻财为用）；细节层面信息相合即事件相关。
- **进阶取用不固守套路**：要贴近事实环境特征定夺（占考学：与功名直接挂钩之录取考取官鬼，否则取父母；占终身财福须财官择一，勿两者皆用）。
- **卦种决定取用**：应期卦（问何日回）与吉凶卦（问能回否）取用定性完全不同——应期卦先看有无动兆排除"应期意外"，再抓空亡等定性信息；吉凶卦则伏神日破即事败，"飞空伏现"也难出头。

## 三、定性的"真假"之辨（本书最硬的工具箱）

| 概念 | 吉凶层面 | 应期细节层面 |
|---|---|---|
| 动爻月破日冲 | **不为真破**（动为始，落后还有后程；"动不为真破"） | 破象仍要在细节里体现 |
| 变爻月破日冲 | **化破为真破**（变为终局，难扳回） | |
| 动爻旬空 | **假空**，当不空看（动不为真空） | **所有空都必须应**，填空之日应事 |
| 静爻旬空 | 真空（衰而空才是真空） | |
| 动化绊（如午化未） | 多为**假绊**，不影响运动趋势（真绊仅两种情况） | 冲绊之日功能恢复——断丑日不断子日，因子日冲绊同时冲去元神 |
| 六冲近病即愈 | 有前提：用神不受动爻冲克、非自变凶兆 | |
| 特殊日月组合 | 月破本只凶在月内，**日辰再来克＝凶无时效限制**（如树无根，动来生也枉然）；"月建乃万卜之提纲，岂可助桀为虐" | |
| 月冲日冲 | **不属于**衰败式特殊组合，逢动生成依然受益（例 205） | |
| 卦出太过 | 动如未动，或预兆与动兆**相反**的趋势；问病重老人得太旺＝器满将倾 | |
| 受克太过之用 | 生旺之时反而是**应凶**之期（回光） | |

日月功能总纲：卦显＝事情本身，动爻＝发展趋势，**日月＝环境与现状**。特殊条件下日月可独立定吉凶（成事在天）；无吉凶的卦象，吉凶只在日月环境条件下显露。

## 四、卦意分析法五式（生克卦理解释不了时走卦意）

1. **世化用忌**：自占自事，世爻直接变出用神（不回头作用）＝事主变化与事情接轨，吉；世化忌神＝趋势朝伤害事情方向，凶。（例：世动化出财酉金，即使按卦理"世克变财"也断吉得财——古人只好补"动不克变"，实为卦意。）
2. **用忌互化**：忌神连用神为凶——**多见于代占**；与世爻连接时不适用（差之毫厘谬以千里）。
3. **牵连聚合法**：与用神连接的是世爻（子占父得世化父）＝父子相逢之象，疑虑自消；动变与世无关时才用用忌互化。
4. **藏爻确认法**：藏伏用神通过飞神属性折射吉凶（仆人匿于铁匠家，用神伏于火爻下——卦象是现实的倒影）。伏神空破已注定事败时，**飞神可作"替身"用神**（问行人：用空世空皆主归——世空者将与行人相见）。
5. **卦象卦名直读**：蛊＝有所用事（主动策划）、师＝追根究底、临＝近兆、渐＝进退缓慢、六冲＝加速突发、家人＝团圆／完结、无妄≠无妄之灾（成语不是专业断语）。**卦象以最简单直白方式预示，避免复杂思路**。

## 五、卦种定位（决定整卦走法）

- **事卦**：问事情成败，以事爻为中心，世爻较从属。
- **心态卦**：忧患之占（占防患、占忧），**喜忌两用神**——子孙为喜神（解忧），官鬼为忌神（忧患），对比旺衰定忧患是否属实。子孙旬空＝短期不能放心；官鬼旬空＝短期忧患未发（暂时放心）。**短事之占，子孙官鬼空可直接翻转定性**。心态卦的六冲六合直接挂钩喜悦忧患趋势。**暗心态卦**：事卦之问被心态信息覆盖（如"防"字起问）。**问病重老人而卦主实为忧惧，非纯事卦**。不是所有世爻回头克都凶——心态卦子孙回头克世反是短期放心之兆（忧患被克去）。
- **灾卦**：可出现在任何问事中，专司"预见风险"的特别提醒，重点在提示避凶（占卜目的之一是避凶，知道趋势后在卦中找化解之道）。
- **应期卦**：问"何时"，动兆排除意外后，用空／世空等定性信息直接定归期。
- **终身卦（时效卦）**：持世信息与动兆同等重要；动兆虽吉但持世不利，长期不算好；占寿元用神变出子孙也是寿终提示；月令时效卦中世用临月令可保无伤。
- **多占**：客观多占值得提倡，前后信息互通衔接令疑问清晰（例 150、172、175）——与吕文艺"一事多测"（liuyao-luwenyi-skill）同调，但朱以"再占"为补充手段而非原则。

## 六、67 条古筮知识点汇要（例 131–205，摘其未散见上文者）

- 长久事占，发动的元神变衰也是凶兆。
- 用事爻在变爻位，应期取变爻逢值逢冲。
- 世之对位是读心方式之一；星煞六神五行六亲是**细节**钥匙。
- 非世用之爻旬空在细节层有"逢空需填"寓意。
- 勾陈＝陈旧、牢狱、田地、郁结；六神立体组合定位（子水临未土＝人在未地，两土＝两地）。
- 五行属性用于细节状态（水＝缠绵拖沓）。
- 星煞用于细节定位，**不用于吉凶定性**。
- 特殊日月组合直接落在世用身上才具特殊寓意。
- 卦象只反映心中疑惑，不回答口中之问；明知故问则问东答西。
- 土爻代表地方，内卦世土受克＝人在本地受伤。
- 一事一问，勿一卦掺多事（同例 168，与吕文艺一致）。
- 问行人：用神旬空人可回、世爻旬空将见面；用神动生世或克世都是回归预兆。
- 独静之卦，静爻是应期重点；六爻五动同理。
- 师卦追根究底、临卦近兆、渐卦缓慢 vs 六冲加速。
- 应期拓展留意动兆：与动爻属性相同的元素也可归入理论应期；跷板现象以相冲思维推细节应期。
- 特定某人的嫁接事占需"世应用"三点定位。
- 短事定性：先剔除无用动爻，再据有用之动主导；但**并非所有化克化绝化退的变废动爻在吉凶层都无用**（例 182）。
- 问事得用神动克旺世：长事凶，**短占反是成功预兆**。
- 纵横交错的重叠信息点定位卦象元素。
- 应期断某日不易，给时间范围更稳（与吕文艺应期观一致）。

## 七、使用边界与素材缺陷

1. 素材为网络整理版（约 26 万字符），**卦评至 205 例但非 205 例全评**：例 131 起才带"古筮知识"提要，前 130 例只有四步评注；部分卦排盘为 OCR 图（例 155 卦图散成 mermaid 乱码，爻位已据上下文还原）；例 205 后署"卦评者：郑祥易／王祥彬"，**后期卦评非朱辰彬本人手笔**，观点与前文略有出入时以前文为准。
2. 朱辰彬另有《传统摇钱古卜入门教材 36 章》（5 万余字），本书简介提及但**未包含在本素材内**；其《讲义》卦意分析法章节原文未收，五式系据散见评注归纳，术语或与原书不完全一致。
3. 本书对野鹤原注多有商榷（例 1"有旺取殊"之辨、例 3 隐去暗动之评）——尊重原注为历史文献、同时给出己见，引用时注意区分"原注"与"朱评"。
4. 基础条文（用神两现、旬空月破、进退神、应期总注等）见 liuyao-zengshan-buyi-skill；爻位六神取象见 liuyao-xiangyi-quxiang-skill；心态卦的系统论述还应参王虎应（liuyao-yihuo-zhimi-skill 射覆与特殊取用部分）。
5. "真假空／真假绊／动不为真破"与姜效龙的"变爻弃权／有用值"（liuyao-guosanguan-skill）是同一批问题的两套解法：姜按"月日基准＋动变加减"算有用值，朱按"真假之辨"直接豁免——并用时以朱的豁免条款处理特例、姜的表定常态。
