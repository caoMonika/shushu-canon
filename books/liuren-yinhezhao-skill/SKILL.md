# 大六壬《银河棹》《隔山照》杂占射覆断法

两书合编：《银河棹正附集》（明末容城孙华南一系秘传，崇祯癸未张松源题于云门山，附集配图）以河洛太极为基，立三遁消息体系；《隔山照》（又题阳山照/阳山焰，OCR 异名）为十二日将射人、射覆类物、杂占快捷断法手册。**两书原件 OCR 严重损毁**，本技能仅提炼可辨识判据，细则须回查原书图页。

## 一、《银河棹》：三遁消息体系（OCR 重度损毁，存骨架）

### 1. 源流与体例
- 传承：明正统中土之变后，容城孙华南先生得秘本于高教寺一系，"专重取象、详言生克"，易象太极河洛为之指授；崇祯癸未张松源题序（"编都珍重而勿轻示人"）。原书分正集/附集，附集配图盘（格相照图、课相照图）。
- 总纲："六壬之原最重和"——干曰天和属阳而动，支曰地和属阴而静；天干象天周旋、地支象地静承，"非动无以观其变"。四课三传以支女（类神）都贵元女借支以演成本，以日辰为主。

### 2. 三遁与消息（核心可辨识体系）
- **三遁**：天遁、地遁、人遁——"天通地与人之进，中有神"，配合月将加时推"来时次第"与"避难赴时"。
- **月将加时消息**：三道取来（时上神、用神、天官道建期及降期），"既得来情察旺衰轻重"，将神详细推去向。
- **用神消息**：用神乘神将定来意与去向；"宜克濁用，干宜生比日和则吉"。
- **年例**：男起丙顺行，女起（旬中）逆行——行年推法（数字 OCR 混乱，原表须回查）。
- **人元伏藏**：人元二六逆行即日伏中和，天人元和神类神即在其中。

### 3. 气旺与时令
- **一气旺**：春水、夏火、秋金、冬水（一说冬土/四季土），凡神乘旺皆诸事速成、花果食物新鲜，又名"天旺"。
- **时用事**：近速不利久长；结党长生位上事不已，墓绝将止。如甲乙日寅卯为时用事。
- **局数三候**：自四三传局数位更为三候——都将（硬）局数位三候，配合阴阳太太定迟速。

### 4. 贵人取法（消息式内）
- 占时常数至贵人内得何神为地（如丙子亥将子时，贵为华盖逆行至时上见元和属壬子，又遂数至贵人下）；"天歌失传但存其注"——原歌诀佚，仅存注文。

## 二、《隔山照》：十二日将射人与射覆杂占

### 1. 十二日将作天将射人（加临断来意）
以功曹（寅）等十二支神加临地盘断来意/人事（原文密排小字，存可辨句）：
- **功曹加巳**（生下）：主宅田木器、文书之象；功曹官吏入官争讼，见龙有天文字权；加寅木主宅图木器。
- **太冲**（卯）：天车之位，舟车之事，出外警恐惊疑；克生比和定案。
- **胜光**（午）：酒食欢宴婚姻之象；旺主社长上吉，休主暗昧私敬，囚死兵殃阴私多塞。
- **神后**（子）：妇女阴私、阴谋之事，多以虚作实；比主欺诈暗盗，旺相利、死哭声。
- **大吉**（丑）：田土墓田，奴仆下人之事。
- **登明**（亥）、**天魁**（戌）、**太乙**（巳）、**天罡**（辰）、**小吉**（未）、**传送**（申）、**从魁**（酉）：各有旺相休囚死定案格（原文表格 OCR 散裂，按"比和生克定案"通则断）。
- **王钥匙**：功曹/太冲加临断来意之快捷表（"准功加无生上所凶免吉"——以生克旺衰定吉凶免灾）。

### 2. 射覆类物
- **大神照总则**："使用以五行衰旺分明，不必兼取中末传"——射覆小事只用发用神的五行衰旺+四季时令定案。
- **十干像物**：甲寅斑点文书、旺为树木；金上见木为鹤鸳鸿鹄；毛色之禽视朱雀、走兽猫狸视白虎（同青钱赋类神法）。
- **方圆**：天空主空虚之物、太冲主方圆之物；巳弓申箭（骑射）。
- **日辰观人物**：日辰观男女（支如用装），天罡加孟仲季定长次（斗罡加子孟女年居长仲则为次）；阳男阴女冲前冲后（元辰法同翠雨歌）。

### 3. 杂占快捷条
- **占家宅**：干神将位断（丁巳林大道六合前房主山）；用传冲支不安，华盖覆日人民太阳小；支上勾陈临克田圈屋宇；白虎临兄弟单思、太阴动杀宅畔有赘。
- **占婚姻**：天上神将加年位、魁罡临命多不利（同翠雨歌）；天后临旺相此女轻盈貌若仙；寅加子戌女三夫、用丑临寅好有谋。
- **占病**：十二天将决病症（心痛肌痛等）；月厌加临必因保重命迍；病用属盛克干主凶、生旺可痊。
- **占商贾求财**：日辰旺相上下相生买卖称情；青龙临处求财方；"干压日占精贷"（干克日慎借贷）。
- **占出行**：行年加丁助日辰见龙常东西酒店（出行方向吉）；坑宫辰戌树林山阜、巳午城池市井神庙——**遁干为方向**（所遁之干临地盘何类地形即往何方）。
- **占身命**：干支定位（干为主支为宅），日上神将百不失一。
- **五里数**：三合五里五十里（六合土五十里）——距离数法（先天数同翠雨歌天罡数）。
- **家长行年加命**：行年加本命上见何神断一年吉凶（同管辂神书行年法）。
- **孤寡/玄胎四生**：四上克下名无禄、四下克上主孤独；玄胎四生之类（三传四孟）。
- **三传生子**：传为子曰长传生子曰生，占胎产子息。

## 三、判读心法（两书会通）

1. **银河棹消息三步**：月将加时定来情→三遁（天官道建期/降期）定去向与应期→气旺衰定迟速（旺=速成新鲜、墓绝=止）。
2. **隔山照射人两步**：十二日将加临定人事类别（来意）→旺相休囚死+生克比定案（不必看中末）。
3. **射覆专用发用**：只取发用神五行衰旺+时令+像物（十干像物/方圆/毛色），忌中末传混杂。
4. **方位遁干**：出行/寻物以遁干所临地盘地形类象（辰戌树林、巳午城池、申酉道路等）定方向，与青钱赋十二支神物所居互参。

## 四、使用边界与素材缺陷

- **《银河棹》OCR 已死**：6.4 万字符中仅约 170 行可辨（大量"高教寺高教寺…"、"和神和神相隔…"复读垃圾），三遁体系的**起例细节（人元二六逆行表、年例数字、贵人数法算例）数字与干支链全部错乱**，本技能只存框架名词与总则，**凡涉具体排盘数字一律不可信引**，实占须另据《大六壬大全》《心镜》或有图原书。原书附集图盘（格相照/课相照）在 OCR 中仅存图注残句（"天之四神和神相隔"），图内容未存。
- **《银河棹》序文可辨**：孙华南得书于高教寺、张松源崇祯癸未（1643）题于云门山、"专重取象详言生克"——此源流信息可用。
- **《隔山照》OCR 重度**：pdf 扫描 8MB，书名 OCR 作"天王陽山照/陽山焰/隅山照"等异形；十二日将表、十干像物、家宅婚病诸条均为密排小字图，OCR 后字链断裂（"子及子及"、"金鉢金鉢"复读），仅存每条起句与部分断语。本技能所收判据**均为可辨识且语义完整者**，表格定案细则（旺相休囚死逐格）不可引，须回查原书图页。
- 隔山照与《翠雨歌》《青钱赋》《管辂神书》多条重复（魁罡临命婚姻忌、家长行年、先天数、类神射物），以那三书的清通文本为准，本技能仅收隔山照**特有**条目（十二日将射人、大神照不必中末、遁干为方向、王钥匙）。
- 兄弟技能：射覆类神大全见 liuren-cuiyu-fu（青钱赋节）与 liuren-duanshu（射覆门）；行年本命法见 liuren-guanlu-shu；消息应期参 liuren-shuoyue"始终"节。
