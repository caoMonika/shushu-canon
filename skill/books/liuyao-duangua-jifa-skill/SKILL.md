# 六爻断卦技法：四层次与生克权

## 它是什么

传统六爻教到"用神旺相则吉、休囚则凶"就停了，实际断卦最常见的困境是：**两个爻一个说旺一个说衰、一个说合一个说冲，到底听谁的？**

李顺祥这一系的核心贡献就是给出优先级：把卦中所有爻分成四个层次，高层次压过低层次，同层次比旺衰；再给出"合冲互解互破"的固定顺序。有了这两条，判据冲突就有解了。

## 一、断卦九看总纲

林潮《六爻断卦技法》的口诀，适合当作流程骨架：

> 一看空，二看冲，三看刑合衰旺中。
> 四看化出进退死，五看神煞凶不凶。
> 六看用爻之位置，七看伏神出牢笼。
> 八看反伏吟流泪，九看外应十观容。

顺序含义：
1. **空**——用神、元神、忌神是否旬空
2. **冲**——月破、日破、暗动、动散
3. **刑合衰旺**——三合六合三刑，以及旺衰总判
4. **化出进退死**——动而化进、化退、化绝、化墓
5. **神煞**——只补细节，不主吉凶
6. **用爻之位置**——在世应、在内卦外卦、在天人地爻
7. **伏神出牢笼**——伏藏能否引出
8. **反伏吟**——反复、停滞
9. **外应观容**——求测时的环境、神色、时机（此条属感应层，无法核验，不作为判据）

前八条是判据，第九条是记录性的旁证。

## 二、爻的四个层次（本技能的核心）

| 层次 | 是什么 | 权力 |
|---|---|---|
| 第一层次 | 日建、月建 | 对卦中任何一爻都有生、克、拱、合之权。日、月建同功同权 |
| 第二层次 | 变爻（主卦动爻在变卦中的同位爻） | 可生克主卦中的动爻和静爻；主卦的动爻静爻**无权**反生克变爻。变爻自身之力受日月制约 |
| 第三层次 | 卦中动爻（含因冲而暗动的爻） | 可生克静爻；被变爻和日月所制；不能制变爻 |
| 第四层次 | 卦中静爻，含伏藏之爻 | 只能生克同层次的静爻，**不能生克动爻** |

三条由层次直接推出的硬规则：

1. **低层次爻克不动高层次爻。** 静爻再旺也克不了动爻；动爻再旺也克不了变爻；任何爻克不了日月。
2. **动爻被克时，静爻不能通关。** 即使这个静爻临日月、力量相当于第一层次，"也是无奈"——力量与权力是两个概念，不能混。
3. **变爻对本位动爻有生克合冲时，优先生效，不再作用于旁爻。** 只有当变爻对本位动爻没有生克合冲关系时，才会去生克主卦其它爻。

### 层次会随日月变化而变

爻值日或值月建，叫"日月入卦"，此时该爻层次上升，力量相当于第一层次。但——

> **值日月的静爻不发动，对动爻仍无生克权，只是不被动爻变爻克伤。**

这条极关键，是判断应期的钥匙。例：卦中兄弟午火旺动劫财，财爻酉金虽静但临日建。午火是第三层次，酉金相当于第一层次，午火克不动酉金——**只有等午火进入午月、上升为第一层次，而酉金因日月转换不再是第一层次时，午火才能克伤酉金**。所以破财断在午月，不断在巳月或酉月。

## 三、生克权的判断标准（三套，分别记）

### （1）静爻有无生克权

1. 在日月两方都休囚 → 无生克权
2. 一方受克、一方休囚 → 无生克权
3. 双方都受克 → 更无生克权
4. **一方受生、一方受克 → 临界状态**，看卦中动爻的向背
5. 入日月墓、入动爻墓 → 暂无生克权；出墓后有无，看此爻在临界状态的上线还是下线
6. 旬空 → 暂无生克权；同上看上线还是下线
7. 被日或月任一方合：**生合**为合起，力量相当动爻；**克合**则暂无生克权
8. 被动爻合住：无论生合克合，暂无生克权，待上层次爻解合

总则：**静爻有无生克权，关键看日月对它的向背。** 一生一克为临界；一方生一方只是休囚不受克，有生克权；双方均生扶更有；一方克一方值临，也有。

### （2）动爻有无生克权

1. 日月双方都休囚但不受克 → 中和状态，**仍稍有生克权**，看卦中其它爻向背
2. 被变爻或日月合住、合而不化 → 暂无生克权（**例外：测出行走动时，用神逢生合有生克权**）
3. 被日月变爻冲破 → 无生克权
4. 入变爻墓、入日月墓 → 暂无生克权
5. 旬空 → 旬内暂无生克权
6. 日月只是休囚不受克，但化退、化泄、化绝 → 生克权减小；化回头克 → 无；化回头生、化进神 → 有
7. 日月一方受生一方受克 → **有生克权**（注意与静爻相反！）
8. 日月两方都得生扶 → 更有生克权
9. 日月一方休囚一方受克，或双方均受冲克 → 无生克权

**动爻与静爻的最大差别就在第 7 条：动爻"一受生一受克"仍有生克权，静爻"一受生一受克"只是临界。**

### （3）变爻有无生克权

1. 临界状态是：日月一方受克、一方休囚
2. **只有日月双方都受克时才无生克权**（变爻比动爻更耐克）
3. 入日月墓 → 暂无
4. 旬空 → 旬内暂无
5. 被日月合住 → 暂无
6. 月破只要不是彻底破，出月值日便有生克权；**日破永无生克权**

> 变爻的生克权大小及有无，**只受日月制约，不受主卦变卦其它爻制约**。

## 四、临界状态（这一系独有的概念）

多数卦书对"日冲静爻"只有非此即彼两种结论：暗动或日破。李顺祥主张存在临界状态：

- 静爻在日月只休囚而不受克，日建只冲不克 → **介于暗动与日破之间**
- 判据：卦中有动爻变爻生扶 → 论暗动（上升为第三层次）；有动变爻克泄耗 → 论日破
- 若在日月一方以上受克，日建冲之（无论只冲不克还是连冲带克）→ 日破，无生克权

土爻相冲有特殊性（土冲土双方均增力）：
- 申月、辰日，戌爻：月只休囚不克，日帮扶 → 暗动
- 寅月、辰日，戌爻：月休囚受克，日帮扶 → 临界，看动变向背

## 五、合冲互解互破顺序（必须背下来）

卦中出现多层合冲时，按以下顺序逐层解：

> 先有主卦之合冲 → 变卦可解主卦之合冲 → 变爻与主卦爻之合冲，日月可解 → 月建与变爻、主卦爻之合冲，日建可解 → 日建与卦爻之合冲，逢进行时之日、月可解。

一句话：**上层次解下层次，后来的解先前的。** 判定某爻最终是被合住还是被冲开，就按这条顺序走到最后一层。

## 六、冲对生克权的影响

### 同层次相冲（四种）

1. 月建与日建相冲——**不看**，对断卦没有实际意义
2. 动爻与动爻（含暗动）相冲：
   - 旺者胜、衰者败；旺者仍有生克权，衰者因冲而散无生克权
   - 两方都旺 → 均减力，主克方减力小，被克方减力大；**土爻相冲双方均增力**
   - 双方都休囚 → 两败俱伤，都无生克权
3. 静爻与静爻相冲——有动爻或暗动的卦中一般不论（无冲力只有冲象）；**六静卦中仍论**，但谁也冲不败谁。人事上反映为内心矛盾、心绪紊乱、没有明显行动
4. 变爻与变爻相冲——一般不看，只看变爻对主卦爻的作用

### 高层次冲低层次（六种）

日月冲变爻、日月冲动爻、日月冲静爻、变爻冲静爻、变爻冲动爻、动爻冲静爻。

核心判据：
- **日月冲变爻** → 变爻被冲散冲脱，不能正常发挥作用
- **日月冲动爻** → 动爻被冲散或冲脱，失去正常生克权。**月冲日合可解（须爻旺相）；日冲则逢进行时日月合住可解。** 月日冲旺相动爻叫**冲脱**（可解），冲休囚动爻叫**冲散**（不可解，永无生克权）
- **月建冲动爻**，无论旺衰都论月破，但旺相动爻或休囚而不受克的动爻，在值日、逢合之日、出月后有生克权
- **日建冲静爻** → 旺相为暗动（升至第三层次），休囚为日破或临界
- **月建冲静爻**：冲休囚静爻为彻底破；冲旺相静爻月内为破、逢合值日出月有生克权；**月建冲值日建之静爻，不但不论破，反而为暗动**
- **变爻冲本位动爻**：只冲不克则本位动爻减力但仍有生克权；连冲带克则无论旺衰都无生克权（除非本位动爻临日月建，且只适用于测短期之事）；**卯酉冲遇酉辰合为合解冲，冲让位于合**
- **变爻冲旁爻**：变爻对本位动爻无生克合冲时，才去冲旁爻，判据同上

## 七、合对生克权的影响

### 六合化气的两个条件（缺一不成化）

1. 卦中两个爻都动，或动爻与本位变爻相合（静爻与静爻只有合象没有合力，不论合，只作信息之象）
2. **日月必须有化神，且日月任一方不得是化神之克神**

例：未月午日，卦中戌爻卯爻动 → 卯戌合化火成功。亥月午日 → 合而不化，双方均减力。

### 合而不化的后果

- 同层次爻合而不化 → 双方均减力，暂时失去生克权
- 一方特别旺、另一方不旺，或高层爻与低层爻合 → 弱的一方、低的一方失去生克权
- **日月与卦爻相合，一律论合而不化**

### 一条极易错的细则

> 动爻逢日或月合，无论旺衰均论绊住，暂时失去生克权。**但用神爻动逢生合，不论绊住，为增力**；而原神、忌神、仇神、闲神无论生合克合都为绊住。

例外之例外：**测出行时，用神无论动静旺衰、无论生合克合、无论合化成功与否，都作"被合住"之象**——因事绊住、暂时走不了。因何事绊住？看主合之爻为何六亲。如被父母爻合住 → 因父母、车辆、文书之事绊住。

### 三合局

申子辰水局、巳酉丑金局、寅午戌火局、亥卯未木局。

- **实合局**：三个爻都动，或日月动变之爻与卦中动爻凑成三合
- **待合局**：三爻中有一爻不动或逢空，待填实值日成局
- 少一字不成局，待日月补上缺字；多一字必须都是动爻，一静一动不算，多一字时待日月合去多余一字才成局
- 成局后仍有化与不化两种：化神在日月且无克化神之五行 → 化；否则合而不化 → 论绊住，动爻失生克权

## 八、入墓对生克权的影响

**基本原则：卦爻只入高于自己层次的墓，不入同层次及低层次之墓。** 入墓期间失去生克权，但也不受其它爻生克——保护与限制是同一件事。

入墓的三种形式：
1. 动、变、静爻逢日月为墓 → 必入
2. 主卦静爻可入卦中**动爻**之墓，不入主卦静爻之墓。前提是这个动爻自身有生克权（动爻被日月变爻制住、合住、冲散则不能收墓）
3. 动爻可入**本位变爻**之墓，不能入其它动爻变出的墓。动爻不入动爻之墓（同层次权力平等）；日、月也不入动变爻之墓

出墓三法：冲墓、冲入墓之爻、合墓。

- 入日月墓 → 只能冲墓爻，不能冲日月
- 静爻入动爻墓 → 合墓、冲墓、冲爻皆可
- 动爻入变爻墓 → 冲爻、冲墓、合墓，**只有入动爻变爻之墓在合墓时可解墓**

> 坊间"入日墓过月则出墓""入月墓过月则出墓"的说法，实测不成立。爻入墓就留下了入墓这个原象，必待合冲才能解除。

## 九、空亡对生克权的影响

旬空之爻，无论旺衰，旬内都无生克权，也不受其它爻生克。解空只有两种：**出空、冲空**。一般冲空只能发挥一半力量，出空才能全部发挥。

- **真空**：休囚逢空，出不出空都无生克权
- **假空**：有气逢空，出空后有生克权

按形式分：
1. 静爻旬空：冲空时若本身旺相可发挥一半力量，出旬后完全正常
2. 动爻旬空：冲空、出空都可正常发挥
3. 动爻不空但**变爻空**：动爻不能正常发挥，待变爻出空；冲动爻、冲空变爻都无用
4. 动爻与变爻俱空：待出空才能发挥；冲都无用
5. 伏神逢空：有气为假空，出空逢值有用；无气逢值也无用。**伏神逢空，冲空、冲飞都无用，解不了空，伏神也引不出来**

**权力序：旬空、入墓的权力大于一般生克。** 同等条件下有旬空、入墓现象，首先论旬空、入墓。

时限要变通：测月余之事按日推出空；测年运按月推出空；测一日之内之事按**时辰**论出空。

## 十、"制"的四种情形

"制"是使对方完全失去生克能力，与"克"不同：

1. 上层次爻对下层次爻的冲克 → 可达到制的程度
2. 多个同层次爻克一个单独爻 → 可制
3. 通过合局力量克一个单独爻 → 可制
4. 同层次爻一对一相冲 → 克不伤，只是牵制，双方均减力，**照样有生克权**

判灾轻重：用神在临日月旺相时被制 → 灾大；用神休囚被制 → 灾小。求财卦财爻旺相被兄弟制 → 破大财；财爻休囚被克 → 破财数额不大。

## 十一、取用：求测角度决定用神

这是本体系第二重要的方法论。

> 同一人、事、物，由于求测者的**求测角度**不同，用神随之改变。

### （1）测人

- 不熟悉、无亲属关系、无工作关系、无深交 → 一律取**应爻**
- 有关系的：同辈取兄弟，长辈取父母，小辈取子孙，为我所用者取妻财，管我者取官鬼
- **但要看求测者站在什么角度**：
  - 测姐姐的身体（出于亲情关心）→ 兄弟爻。虽然她是教师，也不能取父母爻
  - 你开公司，姐姐是你手下职员出外办事，测事能否办成 → 取妻财爻（工作关系）
  - 弟测哥外出何日回，哥是公司老板、弟是职员，从公司业务角度测 → 取官鬼爻
  - 与父亲下棋测输赢 → 世为自己、应为父亲（从对立角度），不取父母爻
  - 你的弟子后来成了你的领导，从工作角度测 → 官鬼；从培训角度测 → 子孙

### （2）测物（用神转换原理）

同一物，角度不同用神变：

- **雨伞**：经销/生产测营销 → 子孙（财源）；店里丢了一批伞 → 妻财（财物）；顾客测质量好坏 → 父母（保护功能）
- **牛**：丢失找牛 → 子孙（方向、生死存亡）+ 妻财（能否找回、破财）；买牛测优劣病情 → 子孙；卖牛测何时卖出 → 妻财（价值交换功能）
- **房子**：自住 → 父母；**要卖的房子 → 妻财**（此时房子体现的是交换价值，不是居住保护功能）
- **猪**：测何时卖出 → 妻财为主，子孙代表猪的质量肥瘦
- **找工作**：为了功名前程 → 官鬼；只为养家糊口生存 → **取生世之爻**（子孙/父母视何者生世）

### （3）父母爻取用原则（李顺祥版，比传统更收束）

凡具有承载、保护、抚育功能的人物事 → 父母。含天地、宅舍、城墙、舟车、衣物、雨具、文章、契约、通讯信件电话电报消息、教师、长辈。

### （4）五亲取用原则各一句

- 官鬼：约束我、陷害我、令我恐惧者；以及能荣身的名声地位名誉
- 兄弟：与我竞争、争夺、分割、劫掠者；以及帮扶我、与我同类同辈者（含假牙假肢拐杖）
- 子孙：娱乐、开心、自由、放荡、靠口靠技艺、展示演说、运动、求平安解灾祸
- 妻财：一切为我所用、由我控制驱使的人物，及利益利润

## 十二、真假六亲

**内六亲**（门内）：爷爷奶奶父母叔伯兄弟姐妹儿女孙辈夫妻。
**外六亲**（门外）：外公外婆岳父母姑姨表亲姨夫妹夫姐夫舅舅小舅子。

取法：
- 内六亲 → 取**本宫内卦**出现的六亲为真六亲；外卦的为假六亲
- 内卦不是本宫或无此六亲 → 看内卦**伏神**；仍无 → 以世爻为基点，按实际关系找（如世爻为土、测同辈妹妹 → 取土爻官鬼）
- 外六亲 → 取**本宫外卦**出现的六亲为真六亲；无则看外卦伏神；仍无 → 以世爻为基点推

真假的意义：
- **真六亲**代表此人的肉体、身体 → 真六亲受制，是人有灾
- **假六亲**代表此人的表面、精神、能力、地位、态度，或代表事物 → 假六亲受制，是破财、事物受损，不是人有灾

代测的特例：**父测儿女的工作、婚姻、升学、应聘、考工之类，可以直接以世爻代表子女**，不必找真假用神。

## 十三、用神两现

三种主张，各有毛病，如实列出：

**《增删卜易》**：舍休囚用旺相，舍静爻用动爻，舍月破用不破，舍旬空用不空，舍破伤用不伤。——专挑有利的一边取。李顺祥批评：照此则"用神两现有旺相者，事吉的概率就很大"，实测并非如此。

**邵伟华**：两现都不动或都动时，取离世爻近者，或取旺于日月者。

**李顺祥**：卦不妄成，两现必有两现的道理，**不可绝对用一弃一**。应结合实际：
- 生意求财财爻两现 → 可能是两笔财、一内一外（本地财+外地财）。已知只有一笔，在外地求财取外卦财爻，在内地取内卦
- 求官官爻两现 → 身兼数职之象。内卦之官为现有官位，外卦之官（位高）为欲求之官。问提升以外卦为用；问保官位，看上卦之官是否破损无气，无气受伤则官位下降
- 朋友外出未归兄弟爻两现 → 以外卦兄弟为用（外卦主外，符合"人在外"的事实），内卦作辅助

## 十四、断卦要先问条件

李顺祥反复强调的一句，值得当真：

> 六爻预测是"条件预测"，不是无条件预测。不知条件去断卦，只是猜测。断来意也要先知道性别、年龄，才有起点。

所以实操第一步不是看卦，是问清：测什么、为谁测、什么身份关系、想要什么结果、事已到什么阶段、期限多长。

## 使用流程

1. **问条件**：测何事、为谁测、关系角度、期限
2. **定层次**：先标日建月建（第一）、变爻（第二）、动爻（第三）、静爻伏神（第四）
3. **取用神**：按角度取，测人辨真假六亲，两现辨两现之理
4. **判用神生克权**：静/动/变三套标准分头套，注意临界状态
5. **判用神旺衰**：日月向背为纲，动变生扶为目
6. **查空墓冲合**：空墓权大于一般生克，先论空墓；再论冲（分层）、再论合（辨化与不化）
7. **按互解顺序收口**：主卦→变卦→变爻→月→日→进行时，逐层解，得最终状态
8. **定成败**：用神有无生克权 → 事成不成；有无被制 → 灾大灾小
9. **定应期**：用"爻值日月的层次转换"推——低层次爻升为高层次时才能克伤原象高层次爻
10. **补信息象**：转取象技能补细节
