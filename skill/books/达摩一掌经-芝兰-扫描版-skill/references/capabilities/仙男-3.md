# 【仙男】

## R — 原文 (Reading)

> 接上例：阿贵（晨）70年3月11日西時（下午5點半

> 把握住「男生顺時針，生逆时針」的原则。剛我們已由

> 日得知在酉宫的【刃】（想像棋子此時是放在酉宫），接著日上

> 起時（子時）的意思就是要在「酉宫一一刃」顺時針跳10格

> （因爲酉時，是子、丑、寅、卯、辰、已、午、未、申

## I — 方法论骨架 (Interpretation)

「仙男」是《达摩一掌经》中的一种招式，其核心在于掌握“男生顺时针，生逆时针”的原则。通过日上酉宫的【刃】（想象棋子在酉宫），然后跳到子时，即酉宫下一个时辰，再顺时针跳10格，同时【刃】本身也要跳一次，才能到达午宫。

## A1 — 应用示例 (Application Example)

假设我们当前位于酉宫的【刃】，按照上述原则操作：
1. 从酉宫开始。
2. 跳到子时（酉宫下一个时辰）。
3. 顺时针跳10格。
4. 【刃】本身也要跳一次。

最终到达午宫。
