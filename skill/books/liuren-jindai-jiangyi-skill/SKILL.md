# 近代六壬讲义群（教本体系）

这一组不是某一派的心法，而是**近代以来的六本/六路教本**。它们的共同点：都把六壬当成一门要教给学生的技术，因此把"怎么起课"写死成程序、把"怎么断"拆成门类、把"证据"落在课例上。差别在于**驱动方式**：韦千里用程序驱动，张定洲用课例驱动，仙鹤居士用课体驱动，叶飘然用古案驱动，伍建宏用哲学驱动，固山额真用表格驱动。

## 一、共同的骨架：占演八步

六本教本起课次序几乎一致，只有一步详略不同：

1. 查明太岁、月将、日干、日支；
2. 定占时（正时／活时）；
3. 立天盘（月将加占时，顺布十二支）；
4. 演四课（十干寄宫→干阳、干阴、支阳、支阴）；
5. 发三传（九宗门）；
6. 布天将（贵人起例→顺逆布十二贵神）；
7. 遁干（旬遁为主，五子遁用于射覆）；
8. 定年命（本命加行年）。

韦千里把这个次序写成"演法第一步到第四步"，张定洲写成"占演程序"，林烽写成"起课流程"，文字不同、位置相同。**任何一本的正文都以此八步为经，缺一步则后面的断语无根。**

## 二、四课的读法：一三课是表面，二四课是实质

近代教本的共识，也是它们相对古籍最大的推进：

- 干阳神（第一课）＝求测者当前状态、处境、运气、口头说法、已经显露的想法。
- 干阴神（第二课）＝其内心真实想法、未显露的状态、暗中影响阳神的力量。
- 支阳神（第三课）＝对方／宅／所测之事的表面状态。
- 支阴神（第四课）＝对方内在实情、隐藏条件、真正动机。

其论证很硬：干上阳神实为干支之"中传"，干阴神即干支之"末传"；末传主结局，故二四课比一三课更重。**近人多只看一三课甚至废二四课，是本末倒置。**

干支定位口诀（各本互见，取其全）：
- 干：人、我、外、尊、天、动、远、高、大、夫、表、男、左、南、陆路。
- 支：宅、彼、内、卑、地、静、近、低、小、妻、里、女、右、北、水路。

分门占时再换：占胎产干为子支为母；占坟墓干为人支为亡人之墓；占出行干为住支为行；占交战干为我军支为敌；占婚姻干为男支为女。**定位一变，同一课吉凶全变，这是教本反复强调的第一件事。**

## 三、韦千里：程序化教本（民国上海）

四卷本，徐乐吾序、自序述学壬经历，书名在《六壬秘笈》与《六壬占卜讲义》两名之间流转（两份 PDF 同为 9,112,169 字节，实为同一书）。

- **卷一 入门篇**：十天干、十二支、五行阴阳、月建节气、太岁、月将、**占时三法**（木盒十二孔置珠摇动、随口报时、十二竹签／象牙签抽取）、地盘、天盘（月将加时）、十干寄宫、四课演法四步、三传九宗门（贼克／比用／涉害／遥克／昴星／别责／八专／伏吟／返吟，逐类配例）、遁干、年命。
- **卷二 占断上篇、卷三 占断下篇**：分门占断，一门一法，先立类神再落断语。
- **卷四 三传总览**：六十甲子日十二课三传总表，供背诵与速查。

特点：**先演法、后占断、末附总表**，是民国以来最规整的入门程序书。凡遇"课上不清楚三传是怎么来的"，回此书卷一逐例对照最快。

## 四、张定洲：课例驱动（台湾，1988 戊辰自序）

师承台北命学研究中心钱思吾，参袁树珊、韦千里，自述"先贤课例＋韦千里二十则＋自撰一百余则，编成二百则课例"。

结构：第一章六壬初步；第二章六壬入门必修课程（五行衰旺、十二长生、德合禄马与丁神、阴神与遁干、应期、占时、月将、日辰、三传、年命、空亡、论太岁月建）；第三章十二天将与十二地支说明；第四章古今卦例类编；第五章**六壬毕法一百条**；末附**分类占十八节**（求财、官禄、谋望、胎产、疾病、家宅、婚姻、出行、访谒、词讼、盗贼、逃亡、行人、坟墓、失物、交易、奴婢）。

张定洲独有的三处硬货：

1. **"乘"与"临"必须分开**：天将加于天盘曰"乘"，加于地盘曰"临"。书中明写"乘与临之区分非常重要，不可混淆"。断语里"蛇乘未""贵人临亥"是两件事，混用即错位。
2. **十干寄宫歌**：甲课寅兮乙课辰，丙戊课巳不须论，丁己课未庚申上，辛戌壬亥是其真，癸课原来丑宫坐，分明不用四正神。
3. **刑冲破害逐条配象**（可直接取用）：子午冲谋为变迁、举动乖异；卯酉冲分离失脱、更改门户；寅申冲邪鬼作祟、夫妻异心；巳亥冲顺去逆来、悲喜不明、奴婢逃亡；辰戌冲主争斗、官讼、坟墓不安。害：子未主事无终始、官非口舌；丑午主事不分明；寅巳主公讼不利、夫妻多阻。刑：刑日阴不可远行，刑月建不可涉讼，刑干应在外而速，刑支应在内而迟。

其贵人顺逆一说与林烽相反（张：贵临地盘巳午未申酉戌六位顺布、临亥子丑寅卯辰六位逆布；林：贵临亥至辰顺、巳至戌逆），**两说并列，用时先以自己应验的一说为准，不可混参**。

## 五、仙鹤居士：课体驱动（六十四课＋兵占）

六章：一推演方法（地盘／天盘／四课／三传／贵神／六亲，附《镜花缘》六壬叙述、六十甲子日三传总表）；二**六十四课**（第一至第六十四节齐全，逐课立名、立象、立断）；三神煞宜忌（德、合、鬼、墓、破、害、刑、冲八节）；四判断辑要（日辰、发用、三传、四课、占时、月将、天将、类神所主八节）；五**兵机百吉金解**（十一节）；六**兵占解**；另有现代占例分析一章。

两处他人少有的：**类神分九目**——天文、地理、宫室、人物、脏腑、饮食、器物、数目、人事亲族；**兵占专章**——以日为我军、辰为敌，配游都鲁都、天城天牢、斩关、天网断进退胜负。

独门断语举例：
- "罡作天后临日上，主伤胎""子作白虎临宅，母位有破，日辰尽伤"——胎产双凶之象。
- "占孕与产不同，孕忌蛇虎，产喜蛇虎，以其为血神也"——孕产取将相反，最易断错。

## 六、叶飘然：古案大全解（《大六壬通解》下册）

华龄出版社 2011 年 1 月第 1 版，全三册，1268 千字，ISBN 978-7-80178-791-0。下册以**门**为纲：胎产、疾病、失盗（盗贼／逃亡／捕亡）等，每门先立总法，再列历代课例。

每例三段式：
1. **原文层**：原课式＋原断＋原注（楚衍、邵彦和、苗公达、苗叔芳、徐次宾、祝泌、刘日新、王牧夫、郭御青、陈公献、张江村、程树勋）；
2. **解**：叶氏自己的疏解，讲发展观、类神取用、应期推算；
3. **考**：多例做天文历法校正，如"淳祐七年七月十三甲子日处暑，此课时间有误""皇祐元年五月十四日乙巳日夏至，故本课真实时间当为五月二十四日乙卯日"。

可直取的门类总法：
- 胎产："占胎产当以支位之胎神为类用；六十三岁人血气已衰，不当以干之胎神论"——**年命老幼决定取干取支**。
- 胎产："干为子，支为母；支上神为胎，青龙、六合为子息之将。"
- 疾病：先辨日干支为人体上下部，干为上部支为下部；白虎为病之主杀，看白虎与谁并——"占病何如辨死生，先推白虎与谁并，假令今日干居水，土神为虎病难醒"。
- 失盗：玄武立处即贼处；初觉逃时只就玄武立处求之；"日传归日、辰传归辰皆不是外人"——三传不出干支必是家贼。

## 七、伍建宏（剑虹）：哲学与预测机理

《中国数术预测学系列教材》之一，含四篇：《中国数术哲学思想》《大六壬的预测机理》《大六壬课验分析》《中国数术干支推算法》。

它不是课法教本，而是回答"六壬凭什么这么起课"：
- **宇宙论**：无极太极说→太极变异与三生万物→"三"与四象→八卦与六十四卦运动→八卦与六壬时空体系。
- **数的四层**：生数成数、数的原理、变数极数衍数、本数用数设数。
- **预测机理**：六壬"天机"发端→太极展开、矛盾分化→太极环闭、四象定象→太极变异、三传发用。**这套话翻成断语就是：四课是太极展开后的分化格局，三传是太极变异后的运动轨迹。**
- **课验分析三问**：主次问题（谁是主谁是宾）、吉凶问题（谁克谁、有无救）、应时问题（何时应）。任何一课先答这三问，再谈细节。
- **干支推算法**：六十甲子序数推法、推属相、推日干支、五鼠遁推时干；干支五行关系克／生／制／化／合／德逐条。

用它给断课找"为什么要这样断"的根据；**不要用它替代九宗门与类神**——它不给断语。

## 八、固山额真：表格速查（《推盘布局·六壬学即查即用版》）

爱新觉罗·固山额真著，内蒙古文化出版社 2003 年第 2 版，ISBN 7-80506-970-0，属"时尚生活速查手册"全八册之一。十章：第一章基础（上）（起课、地盘、天盘、月建、月将、天干、天干经纬、十干统运、地支）……第八章验例、第九章系辞旁通、第十章文献研究。

用法：**当工具书，不当断法书**。可取之处全在表：
- 十二支逐项资料卡：所属、先天范围数、配卦、人体、月令天干司令分野；
- 天干文献考表（天干字义训诂溯源）；
- 十干统运（客运）；
- 第九章"系辞旁通"用《系辞》串讲壬理，可作文本引用；
- 第十章"文献研究"是书目考据，查版本源流用。

其标题中英对照（Revolving astrolabe — foresee situation），是它作为"速查手册"的定位标记，非学术著作。

## 九、教学法差异对照（选哪本看什么）

| 需求 | 用哪本 |
|---|---|
| 三传怎么来的、一个课一个课对 | 韦千里卷一（程序最细） |
| 某一类事怎么断、有现成断语可查 | 张定洲分类占十八门 |
| 课体吉凶的命名与提示 | 仙鹤居士六十四课 |
| 想看古人原断、学疏解层次 | 叶飘然下册 |
| 想知道为什么九宗门这样设 | 伍建宏预测机理 |
| 查干支资料、查书目 | 固山额真速查表 |

## 十、教本体系的三条共同戒律

1. **六壬测异不测常**：日日起课必渐不准，因为把"异"变成了"常"。教本一致反对拿六壬当日报用。
2. **课不可乱起、乱用则不灵**：起课前必先明确所问何事，一事一断；同一时辰多人问，用活时（换时辰／换本旬日／换六十甲子）。
3. **断语必落到应期**：只断吉凶不报时间，教本视为未完；应期之法见 liuren-linzheng（林烽《断应期诀窍》十四法）。

## 十一、与兄弟技能的分工

- 起课程序与九宗门、四层次、空亡十种分类、神煞分年／月／季／日／支／旬六层 → `liuren-linfeng`（林烽《大六壬详解》，现代最系统的教本）。
- 应期专法 → `liuren-linzheng`。
- 兵占、兵机 → 从 `liuren-bingqin` 与仙鹤居士第五章对看。
- 古案原断的疏解层级 → 与 `liuren-yixianke`（易仙客三级疏解）对看，两家的疏解体例最接近。
- 课体命名分歧（六十四课 vs 毕法百条 vs 课格三十余）→ 三家并存，不裁断。

## 使用边界与素材缺陷

1. 韦千里两书 PDF 同为 9,112,169 字节，是同一件的重复；**该件 OCR 呈整行复读**（同一句连印数十遍），只能取结构骨架与个别断语，具体课例数字不可引。
2. 韦千里《六壬占卜讲义》与《六壬秘笈》内容高度重合，本技能不区分引用自哪一本。
3. 张定洲原书名页时代为"戊辰冬"（1988），序中另称作者"张咏铭"，为同一人字号，非两名作者。
4. 仙鹤居士本**缺第七章**（原书页码跳跃，第六兵占解之后直接接现代占例分析），故兵占只存骨架。
5. 叶飘然下册只取到胎产、疾病、失盗三门；婚姻、官讼、出行、科名等门在本卷未覆盖，不可据本技能断此类。
6. 叶飘然书中屡次校正古课时间，说明**传世课例的干支多有讹误**；引用古案断语时须连同其"考"一起引，不可只取结论。
7. 伍建宏教材疑为系列教材之哲学总论卷（"中国数术预测学系列教材（一）"），六壬课法不全，仅作机理与干支算法来源。
8. 固山额真本为"速查手册"性质的通俗读物，书名页 OCR 作"六學學／推船布局"，其断法部分分量很轻，不可当权威。
9. 张定洲与林烽的**贵人顺逆说相反**，本书两存；凡断课须先声明用哪一说，不得两说混用。
10. 各本原 PDF 均带"秘籍网 www.miji8.com"水印，并夹在水印行中的标题易被误认为正文标题，取结构时须剔除。
