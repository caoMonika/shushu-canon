# 北海闲人高阶断法（《一揽登堂断法述要》＋《毕法赋全解》为主）

北海一系的书要配套看：`liuren-beihai-jichu` 是入门与起课，本技能是**取类—察类—定性**这一层，`liuren-jinchushou`（判断入手1—7）是实战七讲，`liuren-jinzhang`（金针）是要素教材。四本讲的是同一套东西，深浅不同。

## 一、断课总纲：理气象类

北海全部断法，压缩成一句话：

> 以理气为指导，先取准类象，再对类象进行分析，类象吉旺则吉，类象凶休则凶，此外不必他求。

此语出自《壬归·壬占易简约例》的"理气象类说"：数生象，象分类，理以气应，占以理求。落到操作上只有两条：

1. **理外无物，象外无辞。** 学壬只着力于"理气"和"类象"两件事，其余（课体、神煞、格局）都是从属。
2. **类象是核心，理气是指导思想。** 取类与察类皆以理气为依据。

由此得出一条极硬的判据：**六壬水平的高低，只取决于取类是否精准、察类是否正确。** 课体填满吉神吉将，若类神空亡，一切免谈；反之干支败气、中末空亡，若龙官发用，此职必得。

## 二、取类的两大系统

### 1. 日辰（干支定位）

日辰定位"是彼是我、是内是外，决不可混淆"，定位不准则判断不灵。定位依据不是"谁问谁为干"，而是四对范畴：**阴阳、动静、尊卑、内外**。

- 婚姻：干男支女。理由在干阳支阴、干动支静、干尊支卑，不在男尊女卑，故不可改成"谁问谁为干"。
- 选战：以挑战者为干、在任者为支——依据是动静（在野者动、在任者静），不是尊卑。
- 讨债：我去讨（我动）则我为干；我坐等对方答复（我静）则我为支。同是讨债，干支可互换。
- 出兵：干为前、支为后。支克干主敌袭我后；干加支主敌当前伏截。
- 出行：干为行人、支为他乡；但干神归支时，支改作家论（以速归断）。
- 逃亡：干为逃者、支为逃方；出现①干神归支 ②末传落在三四课 ③类神或逃者年命入三四课，则支转为家宅。
- 经商：辰为主、日为客。占宅占人：看日辰而次详课义。

《轩辕肘后经》定位口诀可用作底表：日为尊、老、官人、贤德、车、陆、夫、病人、人口、表、既往、出、南、左、男、往、人、弓箭猎师；辰为卑、幼、百姓、奸邪、舟、水、妻、鬼祟、家宅、里、至处、入、北、右、女、住、物、鸟兽所获。

### 2. 类神

"类神"不等于月将，其范围包括：**干支、月将、天官、六亲、神煞、遁干、十二长生运**，以及特殊课体所显的信息。

同一件事常有多路可取，选择标准是"哪一路与所占之事最契合"：

- 占升迁：驿马（神煞）、催官使者（日鬼乘白虎，六亲＋天官）、天吏寅/天城申（月将）、龙神（天官）、官星（六亲）皆可。
- 占怀孕只取胎爻（十二长生），不看子孙、传送、神后、六合。
- 占财之有无看财爻（六亲）；青龙只是"财将"（天官）。占工作看禄神，占事业看长生，占宅看支上神。

### 3. 通类与分类（以财为例）

《壬归》：青龙为财帛之**通类**，其余天官是**分类**；通类为主，分类为宾。

- 贵人之财兼视天乙，炉冶之财视腾蛇，文书之财视朱雀，交易之财视六合，争讼之财视勾陈，欺绐之财视天空，疾病死丧之财视白虎，尊长之财视太常，不正之财视玄武，阴私嘱托之财视太阴，妇女之财视天后；将本求利之财只看青龙。

**变通**：课传无天乙，见大吉即视大吉之三传；无青龙，见功曹或太常见之即以其三传定休咎，不必更求青龙。条件——"须与日辰行年与制类者"，且日年落空则百事无成；唯"类自作空，不以空论"。

## 三、察类三方：察天、察地、察人

类神取出后必过三关，这是北海断法的核心操作。

**察天（知五气之殊）**——四时旺相休囚死＋空亡。

- 旺气：有喜庆；相气：益财；死气：绝灭；囚气、休气：败坏。
- 空亡：所谋不成、所忧易脱、事不实、人不来。

**察地（知加临之变）**——看所临地盘：地盘之神的六亲属性、对类神的生合刑害、类神在地盘的十二长生状态。

- 临长生：所谋大遂；临死：其事必止；临败：其事必败；临绝：事结、人信至、病死；临墓：事必隐晦。
- 十二气分吉凶两组：长生、冠带、临官、帝旺为**四吉**（下临有气则事强）；沐浴、衰、病、死、墓、绝、胎、养为**八凶**（下临无气则事弱）。细分：长生主生生不匮，宜将本求息；沐浴主涣荡消除，气当其败；冠带主庄严整饬，宜冠冕峥嵘之财；临官主显荣利达，宜官贵公府之财；帝旺主当时乘势，然日中则昃；衰主日消月耗，宜早图；病则奄奄困顿；死则有去无来；墓则财神归库，遇刑冲尚可图；绝有复生之理但需时日，宜割绝之财；胎养微而又微，不可过赊。

**察人（知制救之情）**——看阴神（类神所乘天官与阴神）。

- 阴乘吉将、气旺扶类：有默扶阴益；阴乘凶将、气囚制类：有耗散攘夺之虞。
- 阴生日干、生合日上神：取之无咎；阴克日干、刑害日上神：妄取必有他殃。
- **夹克**：类神下临克地而天官又下克之——凡事逼迫，不由自己，吉不成吉，凶则大凶（《毕法》只明言夹克财损财、夹克比肩身不由己，不可乱推）。
- **夹生/比和**：下临生地而天官又生之——吉事顺美，凶事有救。

**不得之象（求财类）**：财爻现于课传而空亡、落空、遁鬼、乘闭口、乘玄武、作大小耗、作破碎，皆作不得论。

## 四、得气失气与四格判词

《壬归》"吾身之与万类，得气则吉，不得气则凶，两言决矣"。得气有四看：现于课传（现则得，不现则失）、旺相（旺则得，休囚则失）、不空（空则失）、不临死墓绝败且阴神不克刑脱耗。

由"得/失"与"欲得/恶得"交叉得四格，是全套断法的定性框架：

| | 得 | 失 |
|---|---|---|
| 欲得之类 | 事吉 | 事凶 |
| 恶得之类 | 事凶 | 事吉 |

- 求财的欲得之类：财爻入课传旺相不空。婚姻的欲得之类：天喜、太常、长生、财爻。
- 占病的恶得之类：死神死气、丧门吊客、鬼墓蛇虎、前后引从、丁马交加、铸印斫轮、龙常并见。
- 求财的恶得之类：比肩爻、岁破月破、玄武、天空、旬遁暗鬼、财坐鬼地、鬼坐财地。
- 反凶为吉靠"失恶得之类"：占病虎鬼空亡或虎阴制鬼；占财三传财局空亡而天将来生财爻，反主得财。

## 五、单纯之象与组合之象

- **单纯之象**＝平常说的类神（干支、月将、天官、六亲、神煞、遁干、十二长生）。
- **组合之象**＝课体结构（六十四课、百法及其正格变格）。如"墓门开格"＝墓＋蛇虎＋卯酉门＋卯酉为年命；"催官符"＝三传财爻生于上鬼爻（占官升迁、占病主死、占婚妻悍戾）。
- 铁律：**课体结构只是象，类神才决定事情的结局。** 姻缘纵有三传交车相合、三六相呼，若财官年命空亡，只能谈一阵子散伙；选举魁罡加临年命必当选，贵人临身却不一定，因为贵人不是选举的类神。

课体与类象冲突时的取舍，北海一律以"类神是否现而旺"为准，这与徐伟刚一系的"课体重于类神"正好相反，见 `liuren-xuweigang`、`liuren-jingjian` 对照。

## 六、类神多现与依理而断

- **多现处理**：只需一个类神者，取一为主、余者参看；事情本身复杂者，多现即多面，必须兼看。占行人走失，玄武、本命、行年同现，取行年（年主当前、命主一生）。
- **依理而断**（北海最看重的一条）：
  1. 按生活实理取类。古籍无载的行业照实理想——律师取天空（口舌虚诞＋奏书）；应聘取德禄（薪水）而弃催官（上任/远行不定）。
  2. 按生活实理分析类象。有的占类"不克不成事"：讨债干上克支，欠债人惧而速还；干贵克贵人则贵人必怒。
  3. 常理上的凶象，恰合所占之事则为吉。占出国签证遇末传天空（天空正是签证类神）反断签成；僧道得纯阴纯阳、欲行阴私得玄武、屠宰得白虎、空手求财得禄作天空，都是宜得之象。
  4. 特殊语境推翻通例：出行传将逆行、干神归支本为不动，但回老家、女子回娘家则不以此断。
- 《理气象类说》之外，北海另立"理"之用法：势之进退（贵人顺行传又顺行、三传进茹、自墓传生）；势之大小（子卑下阴冷、午阳极必变、戌领袖卑微；虎势大而威猛、龙势大而文雅）；势之久暂（干上帝旺盛而不久、干上长生悠久绵长）。

## 七、毕法赋：如何给一课做全景定性

**性质**：宋凌福之据邵彦和《断案》理则抽象出的一百条判断法则，故称"百法"。北海判语：**七成以上实例，课传大势与吉凶可以直接套用赋文**；它是壬课的"形象格局"大框架，再纬以类神象意，使课体与类象结合。

**结构四层**，读法即用法：

1. 赋文一句，代表一种课的形象格局（如"前后引从升迁吉"＝初末传夹拱干上或支上神）。
2. 小注一句，或直陈（"引干宜进职，引支宜迁宅"），或引兵占原则（"攻必取，战必胜"），或引史典（"班超封万里之侯"）。
3. 正格（如引干格、引支格）与类格变格。
4. 北海的加法：**把每句赋还原成生活场景**——"前有拉的、后有推的，不想动也得动"。

**前十九法要点（本技能所据正文即止于此）**：

- 一法 前后引从：初末夹拱干上为引干（进职）、夹拱支上为引支（迁宅）。
- 二法 首尾相见：干支同位或初末同神，始终一贯，宜守成、宜攻取。
- 三法 帘幕贵人：幕贵临身入传，考试高第；斗鬼相加（丑加未/未加丑作年命日干）古称夺魁，北海验案多不中，须丑未年日方成立。亚魁星酉——北海实感为"第二等"，非第二名。德入天门（日德加亥）不问空亡皆中。
- 四法 催官使者：日鬼乘白虎，惟赴任宜见。
- 五法 六阳数足、六法 六阴相继：纯阳宜动宜公、事显；纯阴宜静宜私、事晦。
- 七法 旺禄临身：禄临干上，徒妄作，不战而屈人之兵，宜守。
- 八法 权摄不正：禄临支上，权不在己。
- 九法 避难逃生：弃旧从新，舍墓就生。
- 十法 朽木难雕：休囚无气之木作事，不可强为。
- 十一法 众鬼虽彰全不畏：鬼虽多而我有制、鬼空、鬼衰，则不畏。
- 十二法 虽忧狐假虎威：赖地盘制脱气之神，尚不至全脱，宜静不宜动。
- 十三法 鬼贼当时无畏忌：鬼乘时令旺而反不惧（旺极将衰）。
- 十四法 传财太旺反财亏：财局过旺反耗。
- 十五法 脱上逢脱：脱气叠见，防虚诈。
- 十六法 空上乘空：事莫追。
- 十七法 进茹空亡宜退步、十八法 踏脚空亡进用宜：连茹遇空，进退以空位前后定。
- 十九法 胎财生气妻怀孕／二十法 胎财死气损胎推（生死以胎爻乘生气死气分）。

后续各法（二十至一百）本素材正文缺，须另取全本补，见边界章。

## 八、可直接套用的实战判据（自课例抽出）

- 财爻三现而一乘天空、一作旬空、一乘玄武＝明现无财之象；三传化退、退到四课之外，则商谈不成。
- 占子孙六不宜：落空、投墓、传见官鬼、煞带二死（死神死气）、蛇虎魁罡加临年命、气乘囚死。全见者主死亡；加临旺相而传得其吉者反有喜庆。既见游煞、斩关、丁马而传又逢凶、年上见玄武空亡者，主逃亡劫耗。
- 类临空亡十有九死，在外者不得还家。
- 天后乘河魁加卯（临门）、内战不安、卯为月破又为盗神、天魁为下贱之神——主下贱妇女因失盗亡财而不安。
- 贵人临辰为入狱（贵人履狱）：在任者难安于位，若非病厄则有过失。
- 八月寅为死符、为枯骨，乘死木为棺；未为木墓，子孙投墓非吉。
- 官占：日马坐墓、禄神临绝、传将逆行、命上贵履天罗、年上蛇作日鬼，主不惟不迁，寻常退位；幸官鬼俱空则退位无大咎。
- 分野：寅为幽燕（京、河北、辽宁），申为四川，天罡所加定分野。
- 占行人：中末空亡、退连茹＝行人在半路欲回；占出行同象则走不了——同一象，占类不同吉凶相反。

## 九、使用边界与素材缺陷

2. **《毕法赋全解》**（`_src\beihai-bifa.md`，79K 字符）有完整目录（百法＋前言），但正文只到**第十九法**。二十至一百法仅有目录文字，不可据目录臆造正文；引用某法时若超出十九，须标"目录仅存，正文缺"。
3. **《心法指要》**（`_src\beihai-xinfa.md`，117K 字符）为繁体课例汇编，**OCR 严重损坏**：大量整行重复（"3.王為象學，王為象學…"连续数十字）、页眉水印混排、表格塌成数字列，目录不可提取。仅零星断语可用（如"交車合，干上子與支丑合，干辛寄戌宮，戌與支上卯會"）。**不得以该本作为判据来源**，只能作为课例意象参考。
4. 三本均为"秘籍网/日月图书网"水印扫描件，水印广告行需过滤，正文间有数字页码与盘式字符（地支盘、天将缩写）混排，读时以"某将某时某日"起课标记定位课例。
5. 与兄弟技能的学派分歧：北海"类象为核心、课体只是象之一"；徐伟刚"将高于神、神煞极重"（`liuren-xuweigang`）；伍剑虹"神煞只作信息、重课体结构"（`liuren-jingjian`）；秦瑞生"八门五要流程化"（`liuren-qinruisheng`）。四说不裁断，遇分歧并列征引。
