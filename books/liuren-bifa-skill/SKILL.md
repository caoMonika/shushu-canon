# 毕法赋·毕法案录蒸馏

底本：①《大六壬毕法案录》(完整版卷一卷二)，同治十一年辛未至十二年壬申半亩园开雕，辑者自称"德"(楚人，十九岁从李寿昌学壬，历咸丰粤寇乱世占验四十余年)，以《毕法》一百条为纲，逐条系占验案例(正议/案验/参议/附议)，卷首载**毕法正文百条全文**；②《畢法賦》(康熙鈔本《兵禽捷要》所收)残篇；③《畢法賦演参》(OCR 几乎全坏，仅记缺陷)。《毕法赋》原为宋·凌福之(凌福之先生《毕法赋》序见于《断案》辑者引)所撰百条断诀，是六壬"约而可一、管而能远"的纲领法诀，与《心镜》(liuren-xinjing)课格、《指南》(liuren-zhinan)分类占、《断案》(liuren-duanan)案例互为经纬。

## 二、逐条要义（案录正议提炼，按主题归组）

### 吉格类
- **前后引从(1)**：初传加干前、末传加干后，引从天干/行年，利迁移升擢；初末夹拱贵人为拱贵格。
- **首尾相见(2)**：旬首加干、旬尾加支(一旬周遍)，事周而复始、去而复来，占行人反主不归(支神不为本家而为本寓)。
- **帘幕贵人(3)/催官使者(4)**：幕贵加年命发用占考必中、占仕升迁；白虎乘神克日名催官使者，占官赴任极速(常占则凶)。
- **六阳数足(5)/六阴相继(6)**：子寅辰午申戌全见利公干；丑亥酉未巳卯全见主昏暗，得吉神太阳犹可反明。
- **三传递生(31)**：初生中、中生末、末生干(或生干上神)，主辗转有人举荐。
- **干支禄马(41)**：日马加干、日禄加支为富贵课，占考占官利；但须参课体(遥克/赘婿/空亡)变通，"不从赘婿长生着想则误"。
- **传遇三奇(42)**：三传乙丙丁/甲戊庚等真三奇，加旬奇日奇更的，攻之愈力收之愈切。
- **互生俱生(77)/互旺皆旺(78)**：干支上神互生(或俱生)凡事益；互旺(干旺加支、支旺加干)宜坐谋不宜动，虽有丁马斩关终不能行。
- **万事喜忻三六合(83)**：三传寅午戌或干支见未合等三六相呼，谋事多庆；但**合中犯杀(84)**——合局带刑冲破害即"蜜中砒"，和合中反见乖戾(唯占解散事反喜合中有冲)。
- **龙加生气(92)**：青龙乘生气，吉迟迟——吉应缓而久；若被冲克则吉而不终。

### 凶格类
- **两蛇夹墓(53)**：日墓乘蛇又加蛇位(如戌墓乘蛇加巳)，凶难免，得月破天罡可散。
- **虎视逢虎(54)**：昴星虎视课又见白虎，力难施，虚惊不免。
- **网罗天网(55/56)**：干前一位天罗、支前一位地网，动则缠身；本命作日墓加干名天网自裹，自招其悔。
- **华盖覆日(59)**：三合墓神加干，占昏昧、问病愦愦。
- **干支全伤(63)/值绝(79)/皆死(80)/皆败(36)**：彼此全伤防两损；干支值绝事主决断；人宅皆死各衰羸；长生前一位沐浴为败神，干支皆败事倾颓。
- **传墓入墓(81)**：中传作初传之墓为传墓、作末传之墓为入墓；凶神喜墓、吉神忌墓，须分别言之；占行人传墓速至。
- **虎临干鬼(91)**：白虎乘干鬼，凶速速；龙加生气吉迟迟——一速一缓为对待。
- **将逢内战(86)**：天将内战(如六合乘申受克)所谋危；**初遭夹克(85)**：初传上下受克，"不由己"，财遭夹克主财不由己。
- **空空如也(74)**：干支课传俱旬空，事休追；遍地贵人/子孙俱空同例，屡生不育之象。
- **前后逼迫(73)**：初传被中传克、又受上神克，进退两难。

### 虚实空亡类
- **旺禄临身(7)**：日禄旺神加干，宜守旧妄作徒劳；**权摄不正禄临支(8)**：禄临支而克支为赘婿当权，寄人篱下。
- **脱上逢脱(15)/空上乘空(16)**：层层脱耗防虚诈，家耗非常；空上加天空，指空话空全无实象，事莫追。
- **进茹空亡(17)/踏脚空亡(18)**：进茹(丑寅卯连茹)中末空宜退步；退茹三传皆空反宜进步(踏脚空亡进用宜)——**空亡吉凶须看所空何神**："吉空则凶，凶空则吉"(94 喜惧空亡乃妙机)。
- **有始无终(33)/苦去甘来(34)**：初吉中末空有始无终；初鬼末生为苦去甘来(引鬼为生)。
- **费有余得不足(57)/用破身心(58)**：脱我者实、生我者空，所费不偿所得；两贵坐克中末空、禄马投墓为用破身心无所归。
- **来去俱空(90)**：初末俱空，动而不动。
- **不行传者考初时(82)**：中末逢空传不行，吉凶以初传断。
- **妄用三传灾福异(93)**：取用一差灾福全异(参 liuren-duanan 第7例弹射取用)。

### 贵人类
- **鬼乘天乙(48)**：贵人作鬼，占病多主神祗为祟(家龛外神/灶神不安)，宜禳解，世俗好言鬼祟者切勿曲徇附会。
- **贵人差迭(46)**：昼贵坐夜方、夜贵坐昼方，事参差难成；**课传俱贵(44)**遍地贵人无所依倚，举荐多而终无益。
- **昼夜贵加(45)**：两贵递生保举升迁；**两贵受克(49)/二贵皆空(50)**：贵人自顾不暇难干谒；二贵皆空虚喜期。
- **贵虽在狱(47)**：贵人加辰戌为履狱，但临干上不以此论；**害贵讼直作曲(43)**：干阴与贵六害、干克贵，有口难辩反受屈抑。

### 占病类
- **受虎克神为病症(67)**：看白虎乘神所克即知病位(虎乘卯木克土→脾胃病见于手)。
- **制鬼之位乃良医(68)**：子孙爻即良医所在之方/姓氏(如酉制鬼，酉中有管姓)；天医乘相气亦可用。
- **干乘墓虎无占病(61)/支乘墓虎有伏尸(62)**：干墓乘虎占病大忌；支墓乘虎主宅有伏尸。
- **病符克宅(71)**：病符乘将克支，全家患；丧吊全逢(72)挂缟衣。
- **虎乘遁鬼(69)**：殃非浅，但遁干有子孙制之可解。

### 婚产类
- **胎财生气(19)/死气(20)**：财作胎神乘生气妻怀孕；乘死气损胎(损后复孕看中传)。
- **后合占婚岂用媒(40)**：初天后末六合为泆女课，占婚先奸后娶——**必须再见玄武太阴天空咸池等邪神或芜淫格才可如此断**，"不然未可妄言"，闺门端肃者得此课只主妇家先有意。
- **夫妇芜淫(64)**：干支上神互克各自为合，各怀私心。

### 行人出行类
- **任信丁马(89)**：伏吟刚日自任柔日自信，本主不动，逢丁驿二马则动；虎乘日马其动尤速。
- **避难逃生(9)**：初中空陷末传助，"在此艰难在彼丰"；干乘凶将支上吉，急往他方(引《指南》)。
- **太阳照武(39)/太阳射宅(60)**：玄武乘巳(太阳)名太阳照武，宜擒贼；太阳加支(乘宅)屋光辉、占逃亡可寻(类象取方位里数姓氏：六合属卯乘申断刘姓、发用合申相乘断百余里)。
- **魁度天门(51)**：河魁加亥为关隔，阻滞定；**罡塞鬼户(52)**：天罡加寅鬼户杜塞，反可任谋为。

## 三、案录断法精要（实占方法论）

1. **格例为纲、时变为断**："凡占不可举一废百，总要与时变通"——狐假虎威须看三传有救无救；进茹空亡在长围中不作退步论("酉为建旺不可谓空，长围不解岂可以一旬论")。
2. **类神补断**：所筮不入课传仍凭类神(97)——占信以朱雀为类、占弟以六合为类；**非占现类勿言之(98)**——与所占无关的类象(如占病见婚象)不得妄言，防误断。
3. **正时先锋**：正时发用/乘将常为事之枢纽；昼夜贵取象、年命上神定应在己身。
4. **里数姓氏方位**：发用合申相乘取数、六合属卯乘申取刘姓、亥为孩儿又为日马取方位——与 liuren-duanan 数字应期同法。
5. **占断层级**：占病讼合伙凶课，占官反吉("此课若占病讼及合伙皆以凶断，而占官则不然")——**吉凶随占类转换**，官星旺相为第一义。
6. **不验自省**：辑者"原断有验有不验者，但依案而录之"，不中者"亦当反己"——案录存不验例为考镜之资，是本书史德。
7. **奇门参证**：卷二末附《奇门便笔》数则(壬课与奇门同占互证)，及《观梅测字叙》——观梅测字近儒者事，"奇门尤不可轻试"，此为辑者杂学旁收之界限。

## 使用边界与素材缺陷

1. **毕法文本权威性**：百条正文以《毕法案录》卷一为准(最完整、有条序)；康熙钞本仅作异文旁证。毕法条文历代传本字句小异(如"权摄不正"与"权摄不正禄临支")，引用须注明版本。
2. **《畢法賦演参》不可用**：15MB 扫描件 OCR 提取后为系统性乱码(单字竖排表格转文本失败+大段重复噪声)，仅存书名于台账，未能蒸馏任何条文——若需演参体系，待用户重传清晰本或改用北海闲人《毕法赋全解》(计划入 liuren-beihai-gaoji)。
3. **案录时代背景**：案例皆咸丰至同治年间战乱流离(粤寇、汉中城陷等)实占，占类多兵灾逃难寓所行人，与承平时期占类分布不同；辑者自述"不验者亦录"，引用其断语须连同"案验"一并看，勿单取正议。
4. **法诀非独立体系**：毕法是纲领断诀，课体(九宗门/格局)基础见 liuren-xinjing，分类占断见 liuren-zhinan，实占推理见 liuren-duanan——单用毕法条文套断而不知课体取用，正犯"妄用三传灾福异"(第93条)之忌。
5. **OCR 存疑字**：案录底本偶有讹字(如"玫时难动"疑"攻时/致时"、"己灾凶逃返无疑"通行作"已灾凶逃返无疑")，繁简转换后个别异体；吉凶结论性字眼(空/不空、克/生)凡涉判据者均已与上下文互证，孤证字句标注存疑。
6. **两处"第二十四"重号**：案录卷一"庚日逢丁第二十五"后又出"庚日逢丁第二十四/辛日逢丁第二十四"，系原刻条序错简，条目内容(金/辛日逢丁)本身完整，已按内容归入第25条金日逢丁组。
