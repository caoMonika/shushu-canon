# 大易断例卜筮元龟（易占规程）

## 这本书的定位

元成宗大德十一年（1307）建安萧吉文撰集，平水进德斋刻。作者自述方法来源："上窥圣人之经旨，下窃六君子之传义，旁参鬼谷先生之遗文，演作歌诗，述为断例"。

**它不是某一派秘传，而是一本"把周易筮法 + 纳甲六爻整合成可执行流程"的教科书**，且保留了大量宋元时期的面貌（如揲蓍法全文抄朱熹《周易本义·筮仪》）。价值在于：流程完整、规则明确、没有故作神秘。

## 一、起卦法

### 法一：揲蓍法（正统，十八变成卦）

**器具**：蓍五十茎，韬以纁帛、贮以皂囊、纳于竹椟；椟前设元龟，置壶、香炉；南向为牖，设大案布蓍，旁设小案备笔墨纸砚。

**仪轨**：洒扫拂拭 → 正衣冠盥漱 → 出蓍于椟 → 焚香致敬 → 祝告（"假尔泰筮有常……吉凶得失，悔吝忧虞，惟尔有神，尚明告之"）→ 筮 → 收蓍入椟 → 再焚香而退。

**操作**（一变）：
1. 大衍之数五十，其用四十有九（取一策反于椟，象太极无为）
2. **分二**：信手分成左右两堆（象两仪）
3. **挂一**：从右堆取一策，挂于左手小指间（象三才）
4. **揲四**：以四为单位数左堆（象四时）
5. **归奇**：余策（一至四）扐于左手无名指间（象闰）
6. 再以四数右堆，余策扐于左手中指间（象再闰）
7. 合"挂一 + 两扐"置于格上第一小刻 —— **一变**

**三变成一爻，十八变成一卦。**

### 挂扐数 → 爻的判定表（这是最容易记错的一步）

| 挂扐合计 | 过揲策数 | 爻 | 符号 | 名称 |
|---|---|---|---|---|
| 13（三奇：五、四、四） | 36 | 老阳 | o | 重 |
| 17（两奇一耦） | 32 | 少阴 | ⚋ | 拆 |
| 21（两耦一奇） | 28 | 少阳 | ⚊ | 单 |
| 25（三耦：九、八、八） | 24 | 老阴 | x | 交 |

一变挂扐"不五则九"；二变、三变"不四则八"。
一变余策规律：左一则右必三、左二右二、左三右一、左四右四。
二变余策规律：左一则右必二、左二右一、左三右四、左四右三。

### 法二：以钱代蓍法（实用）

三枚钱，掷六次，自下向上成爻。掷前祝告（伏羲、文王、周公、孔子、鬼谷、孙膑、袁天罡、李淳风、邵康节、陈希夷等先师，六丁六甲神将，年月日时四直功曹）。

**意义**：这是后世"六爻铜钱卦"的直接来源。作者把祝告词写得很长，但核心是"三掷看成何卦，依卦详断"。

## 二、断卦规则：多爻动怎么取（本节最有用）

**这是全书的操作核心，也是多数人最困惑的地方。**

| 动爻数 | 以何为主 | 以何为应 |
|---|---|---|
| 一爻动 | 本卦**动爻**爻辞 | — |
| 二爻动 | **下**变爻 | **上**变爻 |
| 三爻动 | 本卦**彖辞** | 变卦**彖辞** |
| 四爻动 | **上**不变爻辞 | 下不变爻辞 |
| 五爻动 | **静爻**（不动那一爻） | — |
| 六爻动 | 变卦**彖辞** | — |
| 六爻静 | 以**象**占 | — |

另加一条总原则（断卦名及大象）：
> 例：泰之既济 → 以卦名断"人情通泰，复无不济"；再以泰之大象"天地交泰，后以财成天地之道，辅相天地之宜，以左右民"断上下交泰、裁度施为、吉无不利；既已成，尤当如既济之"思患预防"以保其终。

即：**卦名 → 大象 → 爻辞/彖辞 → 支干六神**，层层叠加。

### 六亲配法（五位配卦）

以**卦宫所属为我**，浑天甲所属为他也：
- 生我者 = 父母
- 我生者 = 子孙（福德爻）
- 克我者 = 官鬼
- 我克者 = 妻财
- 比和者 = 兄弟

例：金宫卦见水爻为子孙、见土爻为父母、见木爻为妻财、见火爻为官鬼、见申酉为兄弟。

### 飞伏神诀

> 飞神是世定于真，伏神还从本卦轮。纯卦归魂来去换，递相交代是其神。
> 乾家伏神坤家觅，坤家伏神乾家求。震巽彼此相抽换，兑卦伏神艮位取，坎家伏神离家索。

即：本宫卦（八纯）六亲不全者，到**对宫**（乾坤、震巽、艮兑、坎离）去借伏神；从本宫起纳甲，从初爻数到世爻止。

**月建六神断**：
- 青龙内象：月内有婚姻、进人口之喜；外象：求官进职
- 白虎（月破）：月内有人疾（阴女阳男）；带杀同鬼主孝服；外象主远路行人

以日干定初爻起神，逐爻上行：甲乙日初爻青龙、丙丁日初爻朱雀、戊日初爻勾陈、己日初爻螣蛇、庚辛日初爻白虎、壬癸日初爻玄武。

### 六神内动 / 外动
- 青龙内摇多喜庆；外动主外喜或拜官受职
- 白虎内惊忧疾病；外摇忧远游
- 朱雀飞扬口舌惊；外动主外来口舌（逢吉有文字之喜）
- 玄武内摇忧远路（阴私走失）；外动主损财盗贼
- 螣蛇内摇怪惊卒（家有怪异，受官大吉）；外动忧在外
- 勾陈临之言告述（田土官司）；外动主外事勾留

**六神临财**：青龙临财即吉庆｜白虎临财损病忧｜玄武临财忧盗｜螣蛇临财主遗失｜勾陈临财遇勾留。

## 六、占来情（先看旺相休囚）

**总诀**：欲知卜者来何意，先看旺相休囚气——旺相婚姻宜官职，休囚争财官退位。

| 卦象状态 | 所主 |
|---|---|
| 内外俱旺相 | 大则求官，次则嫁娶 |
| 内外休囚 | 反之（多为财、讼、丧、病） |
| 胎没二卦 | 多占孕病、鬼神为祟，或逃窜、失财 |

**六亲动的主忧**（按五行相克）：
- 财爻动 → 忧父母
- 父母爻动 → 忧子孙
- 子孙爻动 → 忧官事
- 官鬼爻动 → 忧兄弟
- 兄弟爻动 → 忧失财及妻妾

**世应关系**：应来克世 = 人谋己；世动克应 = 己谋人；世克应我吉，应克世我凶；内卦克外吉，外卦克内凶。

**日与卦世的关系**：
- 日辰生卦及世 → 多占父母及其身
- 卦与世生日 → 应卜妻财及子孙
- 卦世与日同克日 → 六畜及婚姻
- 卦世与日无相克 → 冢墓、兄弟、亲族
- 日克世爻 → 丧事、怪异

## 七、过去 / 未来（阴阳爻与月建前后）

**总则**：阴主未来，阳主过去。

- 爻在**卦前**（在月建之前）→ 未来
- 爻在**卦后**（在月建之后）→ 已往

**配应期**：太岁冲身以月断，月卦冲岁以日期。四冲：子午、卯酉、寅申、巳亥、辰戌、丑未。

例：十月（亥月）得坤宫初六五爻动，子阴爻持世而在月建之前 → 主未来。

## 使用流程

1. 定起卦法（揲蓍 / 以钱代蓍 / 报数），成卦并标出动爻
2. 按"多爻动取舍表"确定以哪一爻或哪一卦辞为主
3. 定世应（查世应定位表）
4. 配六亲（本宫五行 vs 各爻五行）
5. 填浑天六位（纳支纳五行）
6. 查空亡（旬空表）
7. 判旺衰（八节旺废 + 月建日辰）
8. 加六神（月建直符定本月值神，日建传符定各爻六神）
9. 先看旺相休囚定"来情"（所问何事）
10. 再以用神 + 六亲动 + 世应 + 六神合成断语
11. 定应期（太岁冲以月断、月冲以日断；爻在月建前后分过去未来）
