# 徐氏珞琭子赋注（补遗）

本地 `徐氏珞琭子赋注-宋-徐子平.txt` 实为**赋之白文/略注**（约 3KB），与 `珞琭子三命消息赋注` 全注本同出一赋。完整可执行体系见 `luoluzi-sanming-skill`。

## 赋句纲目（背诵/定位用）

1. 元一气先天 → 三才四时  
2. 干禄向背 / 支命顺逆 → 一辰十岁、折除三日为年  
3. 将来进、功成退（蛇灰鳝尘）  
4. 无中立有、绝处建贵  
5. 常立仁义、事或见或闻  
6. 崇宝奇贵、将星扶德；本主休囚则汩没  
7. 勾陈得位 / 真武当权  
8. 交差不仁、丙壬相畏  
9. 取用多门、见不见之形  
10. 七杀元辰；乾坤牝牡、金木刚柔、昼夜君臣、青赤父子  
11. 不可一途；冬逢炎热、夏草遭霜  
12. 初凶后吉 / 始吉终凶；根苗花实  
13. 无合有合、得一分三  
14. 天元羸弱宫吉不荣；尊凶卑吉无功  
15. 闻喜不喜、当忧不忧  
16. 八孤五墓、六虚空亡  
17. 背禄逐马 / 禄马同乡 / 夹禄 / 劫财 / 生月带禄 / 重犯奇仪  
18. 身旺鬼绝长年；鬼旺身衰夭寿  
19. 阴错阳差、返伏吟、天冲地击、四煞五鬼六害七伤罗网  
20. 历贵待时、比肩争竞；人疲马劣托财旺  

## 无注本收束提示（全注本亦有，白文更醒目）

- **贵而忘贱，灾自奢生；迷而不返，祸从惑起。**
