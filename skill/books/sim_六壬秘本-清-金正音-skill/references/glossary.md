# 术语表 — 《六壬秘本-清-金正音》

| 术语 | 上下文线索（OCR） |

| 为用 | 巳酉丑日亥为用主失物。雀临亥为监引。亥加壬癸子上主不明。 |
| 日辰之上 | 日辰之上是天乙，珍宝贵奇兼可食。方圆黄白色鲜明，水下怪精鱼类质。 |
| 上神 | 刚日先看日上神，更兼发用细详明。柔日支上先须视，用神兼取两边迎。 |
| 入于空亡 | 贵雀作鬼，入于空亡，文字贵物，乃是其赃。 |
| 丁神灵灵 | 丁神灵灵，入于宅神，门移户改，欲宁不宁。 |
| 之类 | 坎宫，神后，数九，子为纯水，在石中。其色黑，其物水中之类。为江，为河，为沟渎，其音羽，其性为智，其情为好，其味为咸，其方在北，在人为耳病、心病、肾虚之病，其形内实外虚之象。 |
| 余仿此 | 看勾陈临何方。如临午，逃者在南方，余仿此。 |
| 发用 | 五行占物之所主 /课名用神物之所主 /发用休旺 / |
| 天诏 | 丁神旺相而带皇书、天诏在岁上作丁者，乃天子之差也。带皇诏在日辰月建作丁者，乃台部之差使，主迭任差使。皇书春寅夏巳秋申冬亥，天诏正亥顺二十。 |
| 又云 | 连三传主重叠。又云：联茹旺主重叠。 |
| 之神 | 贵人者，黄帝之神，家在己丑，旺于四季，其将主贵人、官禄、庆贺、诏命等事，珍宝财物、君子迁官、小人官讼事。 |
| 带官符 | 申临寅卯，金克木也，若带官符，主有口舌文状之事。定为老人，旺则将衰，又见官符作鬼克干，主老人争财。 |
| 在位 | 大吉为丑，其数八，味甘，斗牛二宿在位。 |
| 之例 | 凡干受上神克，支能制者不畏。如丁未日干上子之例。 |
| 为应期 | 凡干支之阳神发用，以绝日为应期。阴神发用，以墓日为应期。 |
| 婚姻 | 婚姻 /疾病 /出行 /行人 /谒人察善恶 /论讼 /田六种 /晴雨 /科举 /干禄 /日辰人宅 /奴婢 |
| 之事 | 玄武者，水神凶将，家在癸亥，旺于孟冬，其将主盗贼、遗亡、奸私、离别等事。君子奴逃损失，小人淫乱之事。 |
| 假令正月 | 过时已发兼未发，用加支合正当时。假令正月丑已过，寅为目下卯前期。 |
| 之象 | 坎宫，神后，数九，子为纯水，在石中。其色黑，其物水中之类。为江，为河，为沟渎，其音羽，其性为智，其情为好，其味为咸，其方在北，在人为耳病、心病、肾虚之病，其形内实外虚之象。 |

| 冬亥 | 狱神，正月起未，顺行四季。又云，狱神正月从辰，二月戌，十二月周而复始，辰戌起止。吏神，春寅、夏巳、秋申、冬亥。天牢，正月起丑，逆行十二支。恶煞克日，主牢狱官司不利。 |
| 吉凶 | 推黄道吉凶方 /推黑道吉凶方 /犯黑道所生灾 /禳犯黑道 /占求婚成否 /访人见否 /占主人善恶 / |
| 味甘 | 大吉为丑，其数八，味甘，斗牛二宿在位。 |
| 金氏旁注 | 丑加子为鳖，空亡日辰上为田野。丑加六合为家。“家”字金氏旁注“枷”字。 |
| 天空 | 亥加子为孩童。子加亥作天空为幼女。加巳日上为嫁妇。子加辰女患，亦为水沉。 |
| 从魁 | 从魁属酉，其数六，味辛。胃昴毕三宿在位。 |
| 之物 | 乃无用不要紧之物也。假令正月甲子日卯时射之，亥加卯，三传戌午寅。若物自寅卯方来，乃空方来也。 |
| 文章 | 日辰之上见螣蛇，殊方异物带文章。或以蛇形其色赤，甘香可食味偏佳。 |
| 事不成 | 加寅为文书信喜。加卯为法术书。加辰为事不成。加巳为阴人和合，又炉冶。 |
| 经云 | （见正文） |
| 天上 | 占用上主醉散，亦主力尽。亥乘空加太岁主高人。一为天上吏。亥作太常杀加日辰为谷粟。亥加巳日占行人来。亥加子为麦。亥作太常为泄泻。亥加岁刑刑本作行年主病。 |
| 六合 | 子加日上，乘天后，为小女。子加小吉，加土，为老妇。子乘六合，为匪类。 |
| 丁神旺相 | 丁神旺相加宅，主家宅不宁，门哀改移之象。若年命传课中有生支之神，此宅主修改，尤可居也。若无生支之神，又带刑克破耗空亡，则宅已变故而不可居也。 |
| 带病符 | 用传带破废，凡事不成，谋不遂，若带病符天鬼，主残疾之人。 |
