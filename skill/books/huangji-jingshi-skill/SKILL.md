# 皇极经世（衍义 × 心易发微）

文献／象数框架。非历算软件替代品。

## 一、核心尺度：元会运世

邵雍时间金字塔（常用表述）：

| 单位 | 含下一级 | 数量级记忆 |
|---|---|---|
| 元 | 12 会 | 一世之「年」放大 |
| 会 | 30 运 | |
| 运 | 12 世 | |
| 世 | 30 年 | |

衍义强调：**体数偶（四、十二）、用数奇（三、九）**；四去一为用（一时三月、一月三十日）。

## 二、观物外篇衍义 · 数纲

- 天以一变四、地以一变四；体四用三。
- 八卦：不易四、反易二 → 六变而成八；重卦不易八、反易二十八 → 三十六变而成六十四。
- 策数：三十六去四递降 → 32／28／24，对应卦数／天数／地数位。
- 日一月一星一辰各四位 → 十六变而天地数穷；阳数常六、阴数常二。
- 运行数：一→六→十二→…→三百六十；生物数：四→十二→二十→二十八→三十六。

读法：先分**体／用／交数**，再谈消长十二限；勿把天文岁实与「皇极年」混为一谈。

## 三、心易发微 · 目录地图（杨体仁）

可执行模块：

1. **图说**：太极、河洛、先后天八卦、元会运世、六十四卦方圆、先天卦气、天地始终数。
2. **起例**：先天／后天体用、策数、轨数、先后天正数与五行生成数。
3. **分类占**：天时岁序、身命家宅、婚姻科甲、求财疾病、词讼盗贼、坟墓等「体用总断」。
4. **大定**：动卦数、阴阳加策、年除数、元会运世合卦、空缺隔借顺逆。
5. **声音／既济**：人物统于太极上下、挂一卦总括阴阳图（进阶层）。

## 四、操作入口（发微实用）

问一事 → 取时间／数字入**先天或后天体用起例** → 得卦与动爻 → 查卷三事类总断 → 用生克空亡长生例校核。具体起例数字以原书卷二为准（源本目录完整、演算表需对照原书）。

## 五、边界

皇极「推治乱」属历史哲学式象数，不是可证伪的社会预测模型；涉及现实决策勿引用元会运世定吉凶。
