# 术语表 — 《五行精纪-宋-廖中》

| 术语 | 上下文线索（OCR） |
|---|---|
| 是也 | 福会者，取十干所生及所剋是也，谓如甲木生丙火，剋之戊土之类，如甲壬见丙戊是也。<他准此并与官卿同>若人胎月日时遇之，主衣食丰足，官爵崇高，大小运行年至此，亦有迁官进财之喜。（三命指掌） |
| 又云 | 合，随水为受气临官。又云己亥是也。若论四季之月，各旺十八日，及穀雨大暑，霜降大 |
| 广信集 | 以上年月日时，一句唤就者为贵，更有吉杀，定为卿相。（广信集） |
| 莹和尚注 | 珞琭子云：丙寅丁卯秋天宜以保持。莹和尚注云：丙寅丁卯举火之类，秋天保持者，言水生于秋也。鬼谷遗文云：丙寅丁卯秋冬宜以保持。注云：木不南奔，火无西旺，火至秋冬，势恐不久。 |
| 空亡 | 凡人生值此库，若年月日时皆有者，主两府台辅之贵，或落空亡亦吉。（八字金书） |
| 王氏注云 | 王氏注云：壬癸亥子一类水也，水生于申，而旺于子，甲乙寅卯一类木也，木旺于卯，而死于午，故曰壬癸秋生而冬旺，甲乙夏死而春荣。（珞琭子） |
| 林开五命 | 凡生旺固好，然为死绝加临之，则为驳杂多难，小薄之命，凡死绝固不好，然为生旺加临之，却反为纯粹，此即为福禄之命。（林开五命） |
| 烛神经 | 大挠者，轩辕之史官也。考天书三式，以十干十二支衍而成之，为六十甲子，三式者，即轩辕感玄女所授之书（烛神经） |
| 神白经 | 主人心明，日时金见者足寿，富贵多权。（神白经） |
| 五行要论 | 五行要论云：丙寅火食灵明冲粹之气，四时生生之德，入贵格，则文彩发应，主科甲之贵。 |
| 华盖 | 癸丑羊刃贵神乙未华盖贵神载路空亡 |
| 壶中子 | 甲与乙、丙与丁、戊与己、庚与辛、壬与癸，皆干头相类也，是甲人得乙，乙人得甲，位之偏禄，偏禄者多无科名，虽富而官卑。（壶中子） |
| 三命提要 | 三命提要云：偏官亦主大福，若到晚年福谢禄衰，却为灾，若见二鬼剋禄干，虽有官蹇滞，亦须有停降之灾。指迷赋云：偏官出于杂流。 |
| 天元变化 | 天元变化书云：天干合，阳得阴合福慢，因得阳合福紧，故甲得己合为财，己得甲合为官 |
| 沉芝源髓 | 凡命君须子细推，天元先去测天机，助生清秀荣应辨，吞窃伤残贱可知。且禄之元或先伤残吞啗，虽逢吉杀，岂可便以吉言之，或先多滋助，虽犯凶神岂可便以凶论之。（沉芝源髓） |
| 生人 | 丙人怕二壬，壬人怕二戊，乙人怕二辛，余彷此。歌曰：乙木生人怕二辛，不遭鞭配也遭刑，若能免得诸刑害，两目盲盲不见人。（三命【纂】局） |
| 寅时 | 亥年乙酉月乙酉日戊寅时，时上有年临官，月日上有年受气，馀同，二气在日时中亦然， |
| 金书命诀 | 子午卯酉四位，谓之仲神，若年月日时全带或重迭，及值六害，此人幼稚便患风疾。（金书命诀） |
| 子时 | 乙酉日庚辰时为精金丁巳日丙午时为精火癸亥日壬子时为精水 |
| 余彷此 | 丙人怕二壬，壬人怕二戊，乙人怕二辛，余彷此。歌曰：乙木生人怕二辛，不遭鞭配也遭刑，若能免得诸刑害，两目盲盲不见人。（三命【纂】局） |
| 之地 | 甲子从革之金，其气散，得戊申土，癸巳水相之，则吉。戊申乃金临官之地，土者更旺于子，必能生成，癸巳系金，生于巳，水旺于子，纳音各有所归，又为朝元禄，忌丁卯丁酉戊午之火。 |
| 广录 | 寅午往来，有甲己土气，子巳往来，有戊癸火气，巳酉往来，有丙辛水气，卯申往来，有乙庚金气，亥午往来，有丁壬木气，皆在禄上也。又子巳午亥，谓之隔六合，盖一阳至六阳，一阴至六阴也。（广录） |
| 若人遇之 | 盖取十干遇生己之位也，谓甲遇壬见癸之类，水能生木，馀准此，若人遇之，主有大福禄也。（三命铃） |
| 之火 | 甲子从革之金，其气散，得戊申土，癸巳水相之，则吉。戊申乃金临官之地，土者更旺于子，必能生成，癸巳系金，生于巳，水旺于子，纳音各有所归，又为朝元禄，忌丁卯丁酉戊午之火。 |

| 寸珠尺璧 | 寸珠尺璧云：五行一字人，最忌以死绝运。 |
| 之乡 | 五行要论云：己未衰火，含馀光藏实之气，春冬之月，运入沉潜之乡，则明达峻敏，福庆深远，夏得之非和气也。秋则先吉后凶。 |
| 八字金书 | 凡人生值此库，若年月日时皆有者，主两府台辅之贵，或落空亡亦吉。（八字金书） |
| 假令甲子 | 岁窠者，盖以命建之月是也，谓如子生人在子，丑生人在丑，馀凖此，若生月遇之，运气相扶，主辞学丰胆，科名显赫，假令甲子人十一月是也，一云台阁杀，君子吉，小人凶。（三命指掌） |
| 悬针 | 三命纂局云：悬针三四字，号悬针眼疾，还多险厄临，被刑带杀须徙配，怎不为军刺面人。 |
| 破字 | 歌曰：平头必是为僧道，破字终须失眼明，杀看悬针须刺面，徙流多见杖刑并，饥贫不幸逢空阙，相貌兼知不十成，惟是相遭聋哑字，空亡无气定来精。（金书命诀） |
| 鬼谷要诀 | 如甲子、癸酉、壬申、辛亥，以此为至贵之命，盖有所归，如壬申癸卯，此无归，故作下命。（鬼谷要诀） |
| 古诗云 | 凡命以胎元论受气清浊，如胎元支干纳音得地，定小年贤明。古诗云：胎中清气旺运连，少年为性必须贤。如胎元无气，四柱不相入，五行不相生，主为性愚懵，古诗云：胎元无气杀神虚，一世为人性更愚。 |
