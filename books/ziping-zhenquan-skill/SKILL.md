# 子平真诠（八字格局法）

## 一句话地基

> **"八字用神，专求月令，以日干配月令地支，而生克不同，格局分焉。"**

这一句是全书的根，也是它与"扶抑派""调候派"最大的分歧点。所有判断都从这里出发：**先看月令，月令定了用神，用神定了格局，格局再论成败高低。**

由此推出它的方法论纪律：**不能见到"正官佩印"就说官印双全**，要先确认这八字是不是月令正官格；不能见到"财透食神"就说食神生财，要先确认月令是不是财格。原作者把不守这条的判法统称为"不知月令而妄论"。

## 一、顺用与逆用（四吉四凶）

| 类型 | 四神 | 用法 | 要点 |
|---|---|---|---|
| 吉神 | 财、官、印、食 | **顺用**（护之、生之） | 财喜食神相生、生官护财；官喜透财相生、生印护官；印喜官煞相生、劫财护印；食喜身旺相生、生财护食 |
| 凶神 | 煞、伤、劫（刃）、枭 | **逆用**（制之、化之） | 七煞喜食神制伏，忌财印资扶；伤官喜佩印制伏、生财化伤；阳刃喜官煞制伏，忌官煞俱无；月劫喜透官制伏，或用财配食化劫 |

**总原则**："当顺而顺，当逆而逆，配合得宜，皆为贵格。"

## 二、成格与败格（逐格条件，可直接对照）

### 成格
- **官格**：官逢财印，又无刑冲破害
- **财格**：财生官旺；或财逢食生而身强带比；或财格透印而位置妥贴，两不相克
- **印格**：印轻逢煞；或官印双全；或身印两旺而用食伤泄气；或印多逢财而财透根轻
- **食格**：食神生财；或食带煞而无财；或弃食就煞而透印
- **煞格**：身强七煞逢制
- **伤官格**：伤官生财；或伤官佩印而伤官旺、印有根；或伤官旺身主弱而透煞印；或伤官带煞而无财
- **阳刃格**：透官煞而露财印，不见伤官
- **建禄月劫**：透官而逢财印；透财而逢食伤；透煞而遇制伏

### 败格
- **官格**：逢伤克刑冲
- **财格**：财轻比重；财透七煞
- **印格**：印轻逢财；身强印重而透煞
- **食格**：食神逢枭；生财露煞
- **煞格**：逢财无制
- **伤官格**：非金水而见官；生财带煞；佩印而伤轻身旺
- **阳刃格**：无官煞
- **建禄月劫**：无财官，透煞印

### 带忌（成中有败的原因）
官逢财又逢伤；透官又逢合；财旺生官又逢伤逢合；印透食泄气又遇财露；透煞生印又透财（去印存煞）；食神带煞印又逢财；七煞逢食制又逢印；伤官生财而财逢合；佩印而印遭伤；透财而逢煞。

### 救应（败中有成的解法）
- 官逢伤 → 透印解之；杂煞 → 合煞清之；刑冲 → 会合解之
- 财逢劫 → 透食化之、生官制之；逢煞 → 食神制煞以生财
- 印逢财 → 劫财解之，或合财存印
- 食逢枭 → 就煞成格，或生财护食
- 伤官生财透煞 → 煞逢合

**核心判语**："成中有败，必是带忌；败中有成，全凭救应。"

## 三、相神（仅次于用神的概念）

**定义**："凡全局之格，赖此一字而成者，均谓之相。"
- 官逢财生 → 官为用，财为相
- 财旺生官 → 财为用，官为相
- 煞逢食制 → 煞为用，食为相

**轻重次序**："伤用神甚于伤身，伤相甚于伤用。"

→ 实操意义：拿到八字，找那个"一字成格"的字。它被破，格局就立败。**这是判命最要紧的一步，比看日主强弱重要。**

## 四、格局高低：有情 / 有力

| 标准 | 内涵 | 例 |
|---|---|---|
| **有情** | 该用的用上了，该合的合上了 | 甲透酉官，透丁合壬 = 合伤存官；甲生辰月透戊成格，遇乙为劫、逢庚为煞，乙庚相合皆得其用 |
| **有力** | 用神与相神都要有根、要旺 | 乙生酉月，辛金透、丁火刚、秋木盛，三者皆备 → 极等之贵 |
| 有情兼有力 | 最高格 | 甲用酉官，壬合丁以清官，而壬水根深 |
| 有情非情之至 / 有力非力之全 | 高而次 | 甲用酉官，透丁逢癸，癸克不如壬合 |
| **无情** | 该用的没用上 | 印用七煞本贵，但身强印旺再透煞 → 孤贫 |
| **无力** | 用神相神无根 | 煞强食旺而身无根；身强比重而财无气 → 或夭或贫 |

## 五、用神变化（月令藏干不止一个时）

月令除子午卯酉外多有藏干。以寅为例：甲为本气（如知府），丙为长生（如同知），戊为长生（如通判）。**不透甲而透丙，则如知府不临郡，同知得以作主** —— 用神随之变。

**变化两条路径**：
1. **透干而变**：丁生亥月本为正官，支全卯未则化为印；己生申月本属伤官，藏庚透壬则化为财
2. **会合而变**：癸生寅月，藏甲透丙、会午会戌 → 寅午戌三合，伤官化财；乙生寅月，月劫秉令，会午会戌 → 劫化食伤

**变而不失本格**：辛生寅月透丙化官，又透甲则格成正财、正官为兼格；丙生申月逢壬化煞，又透戊则食神制煞生财、仍为财格。

**原则**："八字非用神不立，用神非变化不灵。"

## 六、纯与杂

- **纯**（吉）：互用而两相得。辛生寅月甲丙并透（财官相生）；戊生申月庚壬并透（财食相生）；癸生未月乙己并透（煞食相克而得其当）
- **杂**（凶）：互用而两不相谋。壬生未月乙己并透（官伤相克）；甲生辰月戊壬并透（印财相克）

## 七、杂气取用（辰戌丑未月）

四墓为"冲气"，所藏多、用神不一，故称杂气。

**取用法**：**透干会支，取其清者用之。**
- 透干：甲生辰月，透戊用偏财、透癸用正印、透乙用月劫
- 会支：甲生辰月，逢申子会局则用水印
- 一透一用，兼透兼用，透又会则并用

**有情 vs 无情**：
- 有情（顺而相成）：甲生辰月透癸为印，又会子会申成局，印格清而不杂
- 无情（逆而相背）：壬生未月透己为官，地支会亥卯成伤官局
- 有情而卒无情：甲生辰月逢壬为印又逢丙（火生土助辰中戊），印格不清
- 无情而终有情：癸生辰月透戊为官，又会申子成水局——所克者是劫财，如月劫用官，何伤

### ⚠️ 重要驳论：四库不必刑冲
俗书盛称"财官入库不冲不发"，作者明确否定：**"子平先生造命，无是说也。"**
- 杂气透干会支已美，何必刑冲
- 四库以土为主，"土冲则灵"，金木水火不能靠冲四库而动
- 财官属土者冲则库启尚可；财官为水者冲则反累（己生辰月壬透为财，戌冲则劫动）
- 四墓之冲是"冲动"不是"冲克"，与子午卯酉之冲性质不同

**被点名的谬论**：以出库为投库、月令本非四墓却因年月日时带四墓便求刑冲、日临四库不以为身坐库根而以为身主入库求冲以解。

## 八、生克先后分吉凶

**同样两组字，谁先谁后，吉凶不同。** 这是全书最细的一层。
- 甲用酉官，丁先戊后 → 财为解伤，虽不贵而后运有结局；戊先丁后 → 官遇财生而后因伤破，终无结局
- 甲用子印，己先癸后 → 晚境稍顺；癸先己在时 → 晚景憔悴
- 己生卯月七煞，癸先辛后 → 财助用而后食制煞，大贵；辛先癸在时 → 食制煞而财转党煞，不贵且难永寿

## 九、行运

**法则**："看命以四柱干支配月令之喜忌；取运则以运之干配八字之喜忌。" 每运行一字，必以此字配命局统观。

**喜运**（举例）：官用印制伤而运助印；财生官而身轻而运助身；印带财为忌而运劫财；食带煞成格身轻而运逢印；伤官佩印而运行官煞；阳刃用官而运助财乡；月劫用财而运行伤食。

**忌运**：正官无印而运行伤；财不透食而运行煞；印绶用官而运合官；食神带煞而运行财；七煞食制而运逢枭；伤官佩印而运行财；阳刃用煞而运逢食；建禄用官而运逢伤。

**四类需要细辨的情况**：
1. 似喜实忌：官逢印运而本命有合；印逢官运而本命用煞
2. 似忌实喜：官逢伤运而命透印；财行煞运而命透食
3. 行干不行支 / 行支不行干：丙生子月亥年，逢丙丁帮身（干），逢巳午相冲（支）；甲生酉月辛透而官弱，逢申酉则官植根（支），逢庚辛则混煞重官（干）
4. 相冲分缓急轻重：冲年月则急，冲日时则缓；运本美而逢冲则轻，运既忌而又冲则重

**成格变格**（取运时比喜忌更重）：
- 成格：本命用神成而未全，运来补全。丁生辰月透壬为官，运逢申子会之
- 变格：运来改变格局性质。丁生辰月透壬为官，运逢戌则透出辰中伤官

**干支分工**："干主天，动而有为；支主地，静以待用。且干主一而支藏多。"
- 例：甲用酉官，逢庚辛则官煞杂，而申酉不作此例（申酉是辛之旺地，如府官又掌道印）；逢二辛则官重，二酉不作此例
- 支要能动须会局：甲用酉官逢午未能伤，再遇寅遇戌，二者合而火动，方能伤官

## 十、六亲与妻子

**宫位配六亲**：年月日时自上而下 = 祖、父、妻、子（地相配）
**用神配六亲**：正印为母（生我）、偏财为父（母之正夫）、正财为妻（我克）、官煞为子女（财所生）、比肩为兄弟

**验与不验的次序**（重要）："命中吉凶，于人愈近，其验益灵。"妻财子、父母（年干）验；祖宗兄弟不甚验。

**论妻**：既看妻宫（日支）又看妻星（干头之财）
- 妻宫坐财官本吉，但印格逢之反不美、伤官逢之不顺意
- 妻宫坐伤官本凶，但财格逢之可生财、煞格逢之可制煞，反主内助
- 妻星透而成局 → 坐下无用亦主内助；妻星透而破格 → 坐下有用亦防刑克
- 妻星两透（偏正杂出）→ 防刑克

**论子**：先看时支（时支是子息宫），用时支所值五行的长生十二宫断多寡，再以时干子星配之。
长生十二宫断子数歌（原文）：长生四子中旬半，沐浴一双保吉祥，冠带临官三子位，旺中五子自成行，衰中二子病中一，死中至老没儿郎，入墓之时命夭亡，受气为绝一个子，胎中头产养姑娘，养中三子只留一。
⚠️ **用阳不用阴**：甲乙日只用庚金（男）长生顺数（巳酉丑），不用辛金逆数。原作者明确反对"官为女煞为男"再分配阴局的用法。

## 十一、被点名的常见错误（可以直接用来纠偏）

1. **星辰神煞无关格局**："格局既成，即使满盘孤辰入煞，何损其贵？格局既破，即使满盘天德贵人，何以为功？"
2. **书中"禄贵"多指正官，不是禄堂贵人**
3. **"贵众则舞裙歌扇"的"贵"指官（女以官为夫），不是天乙贵人**
4. **拘泥外格**：月令自有用神就不该另寻外格；"提纲有用提纲重""有官莫寻格局"
5. **见正官佩印即论官印双全**、见财透食神即论食神生财——都是不守月令之病
6. **不知阴阳之理而以俗书体象歌诀为确论**（如"甲为大林盛而宜斩，乙为微苗脆而莫伤"）
7. **以讹传讹**：把杂气财旺生官误作时上偏官；把食神生财硬入"戊日庚申合禄格"；为造贵格而臆改生时

另有一条正理：**得时不一定旺，失时不一定弱。**
"春木虽强，金太重而木亦危；秋木虽弱，木根深而木亦强。十干不论月令休囚，只要四柱有根，便能受财官食神而当伤官七煞。"
根之轻重次序：**得一比肩 < 得支中一墓库 < 得二比肩 < 得一余气 < 得一长生禄刃**。（"得三比肩不如得一长生禄刃"）
⚠️ 阳干逢库为有根，阴干逢库为无用（阳大阴小，阳得兼阴）。

## 十二、十格要点速查

| 格 | 成立关键 | 取运大要 |
|---|---|---|
| 正官 | 财印并透而不相碍；忌刑冲破害、忌伤官、忌重官、忌官煞混杂 | 用财印者身轻助身、官轻助官；佩印者喜财乡；带伤食而用印者喜官印旺乡、忌财运 |
| 财 | 财喜根深不宜太露（生官则不忌露，有官守护谁敢劫）；忌比劫、忌财轻比重 | 财旺生官者喜身旺印绶、忌煞伤；财用食生者财食重则助身、轻则行财食；佩印喜官乡 |
| 印绶 | 官印双全；印轻逢煞；印多逢财（须财透根轻）| 用官者官露印重则财运反吉；用伤食者财运反吉、官运反灾；用七煞者喜伤食身旺、一见财乡凶立至 |
| 食神 | 食神生财（财须有根）；食带煞而无财；弃食就煞而透印 | 生财者财重食轻行财食、财食重喜帮身；带煞喜印绶；食太旺带印则最利财 |
| 偏官（七煞） | 煞用食制为上（煞旺食强身健）；忌露财透印（财转食生煞、印去食护煞）| 煞重食轻助食、煞轻食重助煞、煞食均而根轻助身；忌正官混杂、畏印夺食 |
| 伤官 | 伤官生财（身强有根）；伤官佩印（伤旺身稍弱）；金水伤官独可见官 | 用财者财旺身轻利印比；佩印者行官煞为宜、财地则凶；带煞喜印忌财 |
| 阳刃 | 透官煞制刃、露财印相随、不见伤官 | 用官者喜助官，官根深则印比反美、不喜伤食合官；官煞并出喜制伏 |
| 建禄月劫 | 透官而逢财印；透财而逢食伤；透煞而遇制伏 | 用官印护者喜财、怕官逢合、畏煞相乘；用财带伤食者财食重喜印绶 |

**阳刃一条要单独记**：它与其他格相反——"他格以煞能伤身故喜制伏忌财印；阳刃用之则赖以制刃，不怕伤身，故反喜财印忌制伏。"

## 使用流程（拿到一个八字）

1. **定月令**：月支是什么，藏干有哪些，本气是什么
2. **取用神**：月令本气透干则用本气；不透而透中气余气则用透出者；会支成局则用局
3. **定格局**：用神属财/官/印/食（顺用）还是煞/伤/劫刃（逆用）
4. **查成败**：对照成格表与败格表；有败则查有无救应
5. **找相神**：哪个字是"赖此一字而成"的
6. **评高低**：有情否？有力否？两者兼否
7. **审变化**：月令藏干多者，看是否因透干会支而变格；变后是善是恶
8. **辨纯杂**：并透的两神是相得还是不相谋
9. **看先后**：几组字谁先谁后（决定中晚年结局）
10. **论六亲**：宫位 + 星，先妻财子与父母，祖宗兄弟不必深究
11. **取运**：运干配命局喜忌，再看是否有成格变格；注意干与支作用不同、冲有缓急轻重
