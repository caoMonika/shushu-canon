# 灵城精义（形气 × 理气）

上卷形气、下卷理气。四库提要疑其晚出。文献参考；地运气运说不可作现代测绘替代。

旁参：`dili-xingshi-skill`、`dili-bianzheng-skill`、`pingyang-dixue-skill`。

## 卷上 · 形气纲

1. **气运／气势**：宇宙大关合以气运；山川真性情以气势。有地非人不下，有人非时不下。
2. **天地人感应**：地运推移天气从；天运转旋地气应；人事动而天气从。
3. **认气四聚**：龙（聚讲／行讲／坐讲）；势（权／尊／雄星）；穴（盖铅／夹胎／乘胎）；局（收襟／收堂／收关）。
4. **阴阳雌雄**：阴胜逢阳止，阳胜逢阴住；雄龙须雌御，雌龙须雄簇。
5. **大地看气概，小地看精神**；水成形山上止，山成形水中止。
6. **认气星**：大父母看尊星；宾主、胎伏、胎息、解星、恩星分层看。
7. **龙五局**：直、横、回、飞、潜——以势认气，以情立穴。
8. **三阴三阳间星**（金木火阳、水土阴）互换乃能生物。
9. **作法**：坐寿／坐旺／坐煞；全胎／保胎／破胎；脱壳借胎、投母腹；虚实先后收法。

## 卷下 · 理气纲

1. 精光在天、体魄在地；卜地必及天星。
2. **先天统龙**（四龙天星相配）；**后天布局**（三盘卦例）。
3. 落脉处挨加剪裁（乾亥双行左右落之例）。
4. **收山出煞**：看四生四势；生旺之龙发足旺方到头。
5. 生克制化消纳：如离龙乾亥水朝，可借坐向合局化煞为生。
6. 金井与门户一向为正；外就堂气与龙法生向冲突时须裁成。
7. 正针／缝针各有取义，相为用。
8. 阴龙阳龙各随所宜，勿贵阴贱阳——洛书奇偶配先天位。

## 操作次序（文献）

望势定尊星 → 察聚讲行止 → 辨雌雄止聚 → 入首形气影 → 后天坐向收煞 → 砂水堂气校核。

## 边界

不提供「哪块地必发」的现代承诺；涉拆迁、丧葬纠纷走法律与正规堪测绘。
