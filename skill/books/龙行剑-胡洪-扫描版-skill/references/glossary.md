| 手腕 | （二）接上势。当左手捏剑訣向前指出后，身体前移，坐实的右足向左足擺；右手执剑向前直刺，左手控剑訣扶于右手腕部，双臂略屈抱圓，手臂微动做揉剑（注四）动作連續三次（如图五之③）。 |
| 左足提起 | （二）接上势。右手侧举不动，左足提起，足尖向下，成独立势，同时左手持剑屈肘向胸前平举，剑貼肘底，头轉向左面，眼視剑鋒（注二）（如图二之②）。 |
| 足尖向下 | （二）接上势。右手侧举不动，左足提起，足尖向下，成独立势，同时左手持剑屈肘向胸前平举，剑貼肘底，头轉向左面，眼視剑鋒（注二）（如图二之②）。 |
| 成坐盘势 | 接上势，左足下落，向前迈一步，体闭左轉，足尖向外椒，右足向左足后倒插身体下蹲，成坐盘势（注五），右手持剑柄拉向胸前与左手剑訣相对，随即两手左右分开，左手在身后斜上举，右手持剑有力的向下辆出。且舒 |
| 足尖下垂 | 换上势。右手从下上龜鼠腿，用脆力能鋼尖向有構扇，手心朝面，剑于身前横平，鍋刃天地向，左剑指扶右手腕，周时提左足，足尖下垂，目視前方（如图十六）。 |
