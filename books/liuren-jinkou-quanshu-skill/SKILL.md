# 金口诀"全书"体例导引

金口诀自古"只留下一本书"（姜智元语）。明清传本即题"洞春道人真阳子辑、杨守一精阅、熊大木校正、周敬弦重订"的《六壬神课金口诀》，分**上、中、下三卷**。现代所谓"全书"，多是对这三卷的整理、注译或扩编。**能不能识谱，比多背几句断语更重要**——因为各家教材的差异，八成来自"取的是三卷中的哪一部分"。

## 一、古本三卷的骨架（这是所有"全书"的共同底本）

### 上卷：立式与法则
消息妙论（解课总纲）→ 入式歌解 → 十干所属／十二支所属／十二将神所属／十二贵神所属 → 贵神治旦暮 → 贵神起例 → 五子元遁起例 → 四象所属图 → 阴阳次第互用 → 五动爻诵 → 干类／神类／将类／方类 → 三动 → 五合 → 三合全身 → 虚一待用 → 三奇德秀 → 一类朝元 → 四位俱比 → 五比同类 → 干元类 → 五行气化 → 阴阳相生 → 四位相生／四位相克 → 四爻生克颂 → 应期合德 → 贵神休旺 → 五行休旺 → 五行聚管 → 五行例断 → 四位内见五行 → 贵神临劫煞／值人元／临神煞 → 魁罡所临／传送所临 → 飞符·丧门·天鬼·天罗地网加年月日 → 关隔锁 → 句中空亡／四大空亡 → 四绝／四败 → 合用神煞 → 月建旺相／月破休囚／岁君建破／论岁神 → 四象五行图 → 十干生克所主／十二支生克所主 → 贵神休旺所主／将神源会所主 → 十二贵神临本位所主 → 十二贵神见五行所主／十二将神见五行所主 → 神将同用所主 → 神将所属图 → 次客法 → 推行年法／论人行年吉凶／行年灾福歌 → 四课假令 → 被头星。

> **上卷是全书的"宪法"**：五动、三动、五合、三合、用爻、应期全在这里。基础断法看这一卷就够（`liuren-jinkou-jichu` 即据上卷蒸馏）。

### 中卷：神将杂断与课钤

> **中卷是全书的"词典"**：贵神×十二位、将神×十二位、重临十二位，共六组表；加六十甲子钤、六十四课钤。查"某神临某位主什么"就在这里。**这一卷最易被节本删掉**，所以判断一本教材全不全，先看它有没有这六组表。

> **下卷是全书的"实战手册"**：按门类排，一门之内先断法后歌诀。**军事内容（贼盗门、《璧玉经》）是金口诀的特色**——历代禁私家习三式，独六壬"士庶通用"，而金口诀托名孙膑，兵占一路保留最完整。

## 二、现代"全书"型教材与古本的关系（如何判书）

- **注本型**（如米鸿宾校注《心髓指要》）：只注上卷＋部分中卷，逐句"解曰／释曰"，胜在字义确解，**不全**（见 `liuren-jinkou-jichu` 边界）。
- **加法型**（如姜智元《高层技法》）：承认古本为底，向上加八卦、遁法、纳音、五音、次客等层，**古本内容反而简**（见 `liuren-jinkou-jifa`）。
- **课例型**（如韩万明《现代课例妙解》）：只取古法中的几条判据反复实证，**理论最少、细节最多**（见 `liuren-jinkou-anli`）。
- **"全书"型**：标榜"预测学全书"，通常＝古本三卷白话整理＋分类占扩写＋现代案例。判其优劣看三件：① 中卷六组"临十二位／重临十二位"表是否齐；② 下卷九门是否齐（尤其垄地门、鸟兽门、饮食门最易被删）；③ 附经《神枢经》《璧玉经》是否保留。

## 三、使用边界与素材缺陷

1. **本技能不提供断语，只提供体例地图。** 所据是古本《六壬神课金口诀》三卷的完整目录（见米鸿宾校注《心髓指要》绪论与目录）。
2. **李长勤《大六壬金口诀预测学全书》（另有"〔易学〕"同书重份）与《金口诀四柱预测学教程（一）》两本，本技能均未取正文。** 故本技能所述"全书型教材"特征属**通例判断**，不是对李长勤具体版本的评述。凡需引其断法、其四柱合参体系（金口诀＋八字推命），**必须回检原书，不得据本技能推补**。
3. 古本目录本身存在**坊本讹误与章目错置**：如"四爻生克颂"与"四关生克颂"两见、"十二贯神／十二贵神"混用、"神将所属图"与"四象所属图"重出、"被头星"等僻目来源不明。米鸿宾已自承"现存版本又多系坊间传本，错讹衍缺甚多，不堪卒读"。
4. 中卷"临十二位所主"与"重临十二位所主"共六组、数百条断语，是全书最实用的查表部分，但**本技能与 `liuren-jinkou-jichu` 均未逐条摘录**。要用必须查原书。
5. 与兄弟技能分工：基础法则→`liuren-jinkou-jichu`；进阶加法→`liuren-jinkou-jifa`；课例→`liuren-jinkou-anli`；小六壬→`liuren-xiaoliu-minjian`。
6. 一句提醒：金口诀"全书"之名，多出书商。**见到"全书"先查上中下三卷与两部附经是否齐**，齐则为全本，缺则为选本——此为读一切金口诀教材的第一道筛。
