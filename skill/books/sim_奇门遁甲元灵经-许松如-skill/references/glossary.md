# 术语表 — 《奇门遁甲元灵经-许松如》

| 值符 | 察用时系何宫仪所辖，即以何宫之仪及星加时干上，为值符。 |

| 之方 | 五宫位中，寄生西南，阴寄东北，为阴阳休息之地，天地归宿之方。占事不能伸理，故曰中五。 |
| 吉格 | 一六七防阴滞气，细推凶吉格中藏。 |
| 三奇 | 阳局顺布六仪逆布三奇，阴遁逆布六仪顺布三奇。 |
| 吉格者 | 以本宫年干地盘为主，看天盘星门得吉格者，荣归；得吉格而别犯刑击飞伏悖格及本干宫有劫煞丧门刑克，主卒于官，不得善终。不成格而得奇星，主荣归；无奇星，主罢黜；有凶格主拿问。 |

| 甲加地盘 | 天盘甲加地盘甲：虽曰伏吟，然有青龙出土之象，但吉凶不定，惟看门如何。门吉则吉，门凶则凶，大抵不利求财。 |
| 乙加地盘 | 天盘乙加地盘甲：阴中反阳，得凶星伤人破财，利阴不利阳。 |
| 丙加地盘 | 天盘丙加地盘甲：青龙得光，星符相合，喜庆非常；飞鸟跌穴格，百事吉。 |
| 为值使 | 察用时系何宫何仪所辖，从何宫数至用时得几宫，即以何宫地盘之门加于几宫，为值使，阳遁顺数，阴遁逆数。 |
| 合洛书之 | 奇门一宫乃坤，老阴之位。阴气至此而极，阳气至此而生。卦起于子，为阴阳来复之地，天一生水之宫。其卦为坎，其事为陷，占事如在半途。合洛书之一数，故坎一。 |
| 不吉 | 能出军雪仇，破围攻敌，威镇八方。若嫁娶不吉，主伤财。上官利武职。春秋不吉，修灶不利。此日之时有猛风激雷，兵可取胜。日奇、星奇吉，月奇武事亨通。 |
| 旺相 | 相生相克观明色，旺相休囚辨得真。 |
| 下干 | 此时遇奇仪门生宫合吉格，或干相合、比和者，求谋得意，一切无阻。如门克宫，下克上，合凶格，凡求不遇，或因求谋破财。如主星在衰墓宫，又逢上干克下干，或门克宫，因求谋招非。 |
| 以值符为 | 甲申庚落宫、甲午辛的宫，或相冲，为箭中的。再看景门，得旺相又与值符相生，中缺一不当。看武艺以值符为主考，时干为举子，甲申庚为箭，甲午辛为的，景门为策论，专以甲可。 |
| 金遇之则 | 坤受六阴之气，配厚载之德。立秋渐凉，万物将殒。金遇之则生，水遇之则澄，木遇之则藏，火遇之无光。地气下降，为西南二黑，有死门主之。 |
| 水遇之则 | 坤受六阴之气，配厚载之德。立秋渐凉，万物将殒。金遇之则生，水遇之则澄，木遇之则藏，火遇之无光。地气下降，为西南二黑，有死门主之。 |
| 白虎 | 白虎武名主口舌，功名定是玉堂栽。 |
| 生宫 | 此时得吉星，干支、门、宫相生，加临金木之宫而合吉格，下不克上者，有十分之利。若遇凶格、门迫加于金木宫，上下相克，是必无利。如合凶格得门生宫，或合吉格得门克宫，只有五分之利。 |
| 决之 | 凡争讼，有心中不平而先告人者，有被人告而求伸理者，须以开门为问官，值符为原告，天乙为被告，惊门为讼神。如开惊二门俱被克，被告败；俱克，原告败；一克原告，一克被告，则两家俱败。总以落宫决之。 |
| 合凶格 | 此时得吉星，干支、门、宫相生，加临金木之宫而合吉格，下不克上者，有十分之利。若遇凶格、门迫加于金木宫，上下相克，是必无利。如合凶格得门生宫，或合吉格得门克宫，只有五分之利。 |
| 四宫 | 甲子乙丑丙寅一宫起休 丁卯戊辰己巳二宫起休 庚午辛未壬申三宫起休 癸酉甲戌乙亥四宫起休 |
| 木遇之则 | 坤受六阴之气，配厚载之德。立秋渐凉，万物将殒。金遇之则生，水遇之则澄，木遇之则藏，火遇之无光。地气下降，为西南二黑，有死门主之。 |
| 火遇之则 | 震居兰台之宫，雷霆发泄之处，春和大布，阳气正通，甲乙正位，盛茂森森。金遇之则伤，水遇之则润，火遇之则焚，土遇之则培。为东方三碧，有伤门主之。 |
| 土遇之则 | 震居兰台之宫，雷霆发泄之处，春和大布，阳气正通，甲乙正位，盛茂森森。金遇之则伤，水遇之则润，火遇之则焚，土遇之则培。为东方三碧，有伤门主之。 |
| 大吉 | 利安迁筑城、屯营建寨、安坟立冢，春夏吉，秋冬凶。此日之时必有黑云至军前，以助兵威。赤云主胜，青白黄云俱不胜。得日奇吉，月奇如常，星奇大吉。若起造、移徙、婚姻，伤；若商贾，远方必遇侵害。 |
| 河魁 | 其方若得日禄，合成贵神、天空、天恩、天赦，百事皆吉。若逢日破，诸事不利。得日鬼，万事纠缠。如得天罡、河魁，忌行船、过水。得此遁可使六丁呼风致雨。 |
| 登明 | 又法以月将加正时，看天罡所在孟仲季，则知其来否。月将即正月雨水后登明亥将之类是也。 |
| 神后 | 得青龙，大不利，有凶；河魁、天空，不见见；白虎，有大风；神后、玄武，出兵大吉；见月厌，不可先动；日禄、日马，主得财；贵人、三煞，大战大功。又云：虎狂位遇丁景制，叱咤风生上将坛。 |
| 六合 | 诸事不宜，只宜隐迹埋名、求仙。丁己癸三干临六合宫，宜逃亡；临太阴宫，宜伏藏；临九地，宜屯守。此乃善用癸者，克天网之咎，此时闻事并虚。 |

> 术语由频次粗提，可能含噪声；以原书定义为准。
