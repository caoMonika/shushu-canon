# 术语表 — 《周易正义-唐-孔颖达》

| 正义曰 | [疏]正义曰：此二句释“利贞”也。纯阳刚暴，若无和顺，则物不得利，又失其正。以能保安合会大利之道，乃能利贞於万物，言万物得利而贞正也。 |
| 故曰 | 九二：见龙在田，利见大人。出潜离隐，故曰“见龙”，处於地上，故曰“在田”。德施周普，居中不偏，虽非君位，君之德也。初则不彰，三则“乾乾”，四则“或跃”，上则过亢。“利见大人”，唯二、五焉。 |
| 故云 | [疏]“或跃在渊”至“与时偕极”。○正义曰：“乾道乃革”者，去下体，入上体，故云“乃革”也。“乃位乎天德”者，位当天德之位，言九五阳居於天，照临广大，故云“天德”也。 |
| 无咎 | “或跃在渊”，进无咎也。“飞龙在天”，大人造也。“亢龙有悔”，盈不可久也。 |
| 者也 | 初九曰“潜龙勿用”，何谓也？子曰：“龙德而隐者也。不易乎世，不为世俗所移易也。 |
| 之义 | 用九：见群龙，无首，吉。九，天之德也。能用天德，乃见“群龙”之义焉。夫以刚健而居人之首，则物之所不与也。以柔顺而为不正，则佞邪之道也。故《乾》吉在“无首”，《坤》利在“永贞”。 |
| 贞吉 | 君子有攸往，先迷后得，主利。西南得朋，东北丧朋，安贞吉。西南致养之地，与“坤”同道者也，故曰“得朋”。东北反西南者也，故曰“丧朋”。阴之为物，必离其党，之於反类，而后获安贞吉。 |
| 利贞 | 保合大和，乃利贞。不和而刚暴。 |
| 故受之以 | 有天地，然后万物生焉。盈天地之间者唯万物，故受之以《屯》，屯者，盈也。屯者，物之始生也。屯刚柔始交，故为物之始生也。 |
| 之时 | 天造草昧，宜建侯而不宁。“屯”体不宁，故利“建侯”也。“屯”者，天地造始之时也，造物之始，始於冥昧，故曰“草昧”也。处造始之时，所宜之善，莫善“建侯”也。 |
| 悔亡 | 《象》曰：“贞吉，悔亡”，未感害也。未感於害，故可正之，得“悔亡”也。 |
| 利涉大川 | 乾下坎上。需：有孚，光亨贞吉，利涉大川。 |
| 利有攸往 | 离下艮上。贲：亨。小利有攸往。 |
| 九二 | 九二：见龙在田，利见大人。出潜离隐，故曰“见龙”，处於地上，故曰“在田”。德施周普，居中不偏，虽非君位，君之德也。初则不彰，三则“乾乾”，四则“或跃”，上则过亢。“利见大人”，唯二、五焉。 |
| 初九 | 初九：潜龙勿用。《文言》备矣。 |
| 子曰 | 初九曰“潜龙勿用”，何谓也？子曰：“龙德而隐者也。不易乎世，不为世俗所移易也。 |
| 之道 | 用九：见群龙，无首，吉。九，天之德也。能用天德，乃见“群龙”之义焉。夫以刚健而居人之首，则物之所不与也。以柔顺而为不正，则佞邪之道也。故《乾》吉在“无首”，《坤》利在“永贞”。 |
| 元吉 | 《象》曰：“黄裳元吉”，文在中也。用黄裳而获元吉，以“文在中也”。 |
| 九五 | 九五：飞龙在天，利见大人。不行不跃而在乎天，非飞而何？故曰“飞龙”也。龙德在天，则大人之路亨也。夫位以德兴，德以位叙，以至德而处盛位，万物之睹，不亦宜乎？ |
| 是也 | [疏]正义曰：“以大终”者，释“永贞”之义，既能用此柔顺，长守贞正，所以广大而终也。若不用永贞，则是柔而又圆，即前注云“求安难”矣。此“永贞”即坤卦之下“安贞吉”是也。 |
| 上六 | 上六：龙战于野，其血玄黄。阴之为道，卑顺不盈，乃全其美。盛而不已，固阳之地，阳所不堪，故“战于野”。 |
| 六二 | 六二：直方大，不习无不利。居中得正，极於地质，任其自然而物自生，不假修营而功自成，故“不习”焉而“无不利”。 |
| 利见大人 | 九二：见龙在田，利见大人。出潜离隐，故曰“见龙”，处於地上，故曰“在田”。德施周普，居中不偏，虽非君位，君之德也。初则不彰，三则“乾乾”，四则“或跃”，上则过亢。“利见大人”，唯二、五焉。 |
| 之义也 | 《彖》曰：蒙，山下有险，险而止，蒙。退则困险，进则阂山，不知所適，蒙之义也。 |
| 初六 | 初六：履霜，坚冰至。始於履霜，至于坚冰，所谓至柔而动也刚。阴之为道，本於卑弱而后积著者也，故取“履霜”以明其始。阳之为物，非基於始以至於著者也，故以出处明之，则以初为潜。 |
| 九三 | 九三，重刚而不中，上不在天，下不在田。故乾乾因其时而惕，虽危无咎矣。 |
| 六五 | 六五：童蒙吉。以夫阴质居於尊位，不自任察而委於二，付物以能，不劳聪明，功斯克矣，故曰“童蒙吉”。 |
| 六四 | 六四：括囊，无咎地誉。处阴之卦，以阴居阴，履非中位，无“直方”之质，不造阳事，无“含章”之美，括结否闭，贤人乃隐。施慎则可，非泰之道。 |
| 六三 | 六三：师或舆尸，凶。以阴处阳，以柔乘刚，进则无应，退无所守，以此用师，宜获“舆尸”之凶。 |
| 无不利 | 六二：直方大，不习无不利。居中得正，极於地质，任其自然而物自生，不假修营而功自成，故“不习”焉而“无不利”。 |
| 九四 | 九四曰“或跃在渊，无咎”，何谓也？子曰：“上下无常，非为邪也。进退无恒，非离群也。君子进德脩业，欲及时也，故无咎。” |
| 上九 | 上九曰“亢龙有悔”，何谓也？子曰：“贵而无位，高而无民。下无阴也。 |
| 大矣哉 | 乾始，能以美利利天下，不言所利，大矣哉！大哉乾乎，刚健中正，纯粹精也！六爻发挥，旁通情也。“时乘六龙”，以御天也。“云行雨施”，天下平也。 |
| 故言 | [疏]正义曰：此释所以大人“否亨”之意，良由否闭小人，防之以得其道，小人虽盛，不敢乱群，故言“不乱群”也。 |
| 有孚 | 乾下坎上。需：有孚，光亨贞吉，利涉大川。 |
| 义也 | 直其正也，方其义也。君子敬以直内，义以方外，敬义立而德不孤。“直方大，不习无不利”，则不疑其所行也。 |

> 术语由频次粗提，可能含噪声；以原书定义为准。
