## I — 方法论骨架 (Interpretation)

本节主要处理底本为繁体字刻本或抄本的情况。根据国家语言文字工作委员会的规定，将繁体字改为简体字，并对底本中的版刻异体字进行改正。对于明显错抄或误识的字，用“（）”标识并改正。

## A1 — 应用示例 (Application Example)

假设我们有一段繁体字文本：
```
刺伤寒未解，经不再传；鸠尾针痫颠已发，慎其妄施。阴交水分三里，蛊胀宜刺；商丘解溪丘墟，明脚痛堪追。
```

根据上述规则，改正后的文本应为：
```
刺伤寒未解，经不再传；鸠尾针痫颠已发，慎其妄施。阴交水分三里，蛊胀宜刺；商丘解溪丘墟，明脚痛堪追。
```

## A2 — 触发场景 (Future Trigger) ★

当需要将繁体字刻本或抄本文档转换为简体字时，应按照上述规则进行处理。

## E — 可执行步骤 (Execution)

1. **识别底本**：确定文本是否为繁体字刻本或抄本。
2. **应用规则**：根据国家语言文字工作委员会的规定，将繁体字改为简体字，并对异体字进行改正。
3. **标识错误**：对于明显错抄或误识的字，用“（）”标识并改正。
4. **完成标准**：文本应完全转换为简体字，并且所有异体字和错误字都已正确改正。

## B — 边界 (Boundary) ★

本节仅适用于底本为繁体字刻本或抄本文档的情况。对于已经为简体字的文档，无需进行任何处理。
