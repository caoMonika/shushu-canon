# 济生集 · 蒸馏技能

**来源**：《济生集》六卷，清·王上达（春亭氏）辑，光绪二十二年序刊
**定位**：穷乡僻壤不及延医之家的**胎产自救手册**——"平时家置一编，临时易于检阅"
**覆盖说明**：本次蒸馏以解析文本为据，覆盖原序、发凡及卷一（保胎广嗣）、卷二（保产临产）、卷三（妇女证治）、卷四（胎前诸症）；卷五产后、卷六儿科部分原文未能完整获取，涉及处已标注。
**使用边界**：古籍文献参考。书中剂量为清代度量，产科操作（如稳婆手法）属历史记述，现代孕产问题必须就医。

## 一、总纲：全书方法论

> "证候传变难以言尽，而其要不外乎阴阳，分言之即表、里、寒、热、虚、实。良医救人不过能辨乎此，庸医杀人亦不过错认乎此。"

1. **先论病原，次载方药**——每证先明机理，再给方，避免阴阳混治
2. **胎前无不足，产后无有余**——此言其常；但胎前亦有不足时，产后亦每挟有余症，须详审
3. **急慢惊分治**：急惊为痰火闭证，慢惊为水侮土证——虚实不分，混治辄左
4. 古方用人参者，缓证可以党参代，急证必用高丽参
5. 妇女杂病主法四字：**养血疏肝**（四物汤、逍遥散之类得其八九）

## 二、保胎广嗣（卷一）

### 核心机理
- **多欲之人常艰子且易夭**（气泄精薄），少欲之人恒多子且易养——"酿酒"之喻：斗米下斗水则醇酽耐久
- 男以**补肾**为要，女以**调经**为先；服药后宜清心寡欲，本原先壮再施
- 胎教实证链：受惊→子多胎惊；抱郁→结核流注；恐惧→癫痫；大醉后媾精→子多不育；大怒后→子多乖戾

### 三合保胎丸（屡坠者圣药）
- **适用**：素惯坠胎者（坠胎多在三五七月，此三月切忌房事恼怒）
- **组成**：熟地十二两（砂仁老姜同煮捣膏）、归身十二两、土炒白术十二两（肥白气虚加二两）、酒炒条芩六两（黑瘦性躁加）、盐水炒杜仲十二两、酒炒续断十二两
- **服法**：每早盐汤、晚临卧酒各送三钱，每日不可间断；素怯者须两料，服过七月方保无虞
- **机理**：熟地滋阴、当归养血、白术健脾、条芩清肝火凉血、杜仲暖宫、续断坚胞系
- **反例警示**：古法香砂芎艾热药安胎，"犹抱薪救火"

### 验胎与探胎
- 孕脉：左寸心动甚为孕兆；两尺旺与两寸迥别亦为子；"左手实大是男胎，右手弦洪女孕来"
- **验胎散**：真雀脑芎一两、当归七钱，浓煎胶汤酒对服——脐腹动则有胎
- **探胎散**：皂角、炙甘草各一钱、黄连五分，温酒调服——有胎则吐

### 孕后常服三方
| 方 | 服期 | 功用 |
|---|---|---|
| 安胎散 | 孕后月月数帖 | 补血顺气，腹痛加杜仲砂仁 |
| 金匮当归丸 | 孕后可常服 | 养血清热、去胎毒、临产易生 |
| 达生汤 | 九月后服数帖 | 撑开道路则儿易生 |

## 三、保产临产（卷二精华）

### 难产七因（对因预防）
安逸（气血不流）/ 奉养（胎肥）/ 淫欲（胞衣厚、胎元漏泄）/ 忧疑（心悬意怯）/ 软怯（神气怯弱）/ 仓皇（稳婆逼令早用力）/ 虚（用力太早，母力已竭）

### 六字真言与三字宝
- 亟斋六字真言：**一曰睡，二曰忍痛，三曰慢临盆**
- 飞霞三字：**未离经**——脉未离经则时尚未到，唯嘱加餐稳卧
- **临盆七候**（七备方可用力）：脐腹急痛、腰间重坠、眼中出火、粪门迸急、产户肿满、手中指筋脉跳动、胞水或血俱下

### 核心产理（原书反复强调）
- **瓜熟蒂落，不假勉强**：儿在腹中自会垂头转身，切忌催生药符催逼
- 试痛 vs 正生：痛**一阵紧一阵**为正生；**一阵慢一阵或乍紧乍慢**为试痛——试痛只需安眠稳食
- 最忌：稳婆诈称"头已平门"逼令用力 → 横倒之祸皆由此
- 催生药害：鼠肾兔脑丸大耗气血、回生丹大破血，"贵耳贱目以为平常而不用，必求奇怪之药"
- 误治救生方：横倒者**急令安睡**，大剂加味芎归汤，缓缓托入再睡一夜自然生

### 横倒等五产救护
| 症 | 手法 |
|---|---|
| 横生（转身太急） | 产母仰睡，稳婆推儿身顺直，中指探儿肩脱脐带，服脱花煎 |
| 倒产（手脚先出） | 轻手推入，拨转儿头 |
| 偏产（头偏一边） | 轻手扶正其头 |
| 碍产（脐带绊肩） | 推儿向上，中指按肩脱去脐带 |
| 盘肠产（子肠先出） | 蓖麻仁四十九粒研烂涂产母头顶即收（急洗去）；或麻油纸捻烟熏鼻 |

### 交骨不开
加味芎归汤：当归一两、川芎七钱、炙龟板六钱、妇人发一团瓦焙——水二碗煎一碗，加肉桂一钱冲服

### 酷暑严冬调护
- 夏产：宜清凉但忌凉台水阁竹席；腹痛先防痧（扭法试之——一扭即红者患痧无疑），大忌米汤粥饭
- 冬产：血冷凝滞坚收产门——速服芎归汤加炮姜肉桂，火炉烘腰背即生；宜预制开裆棉裤免脱冻

## 四、产后调护（卷二）

### 生化汤（产后第一方，"产后至宝"）
- 组成：全当归八钱（酒洗）、川芎三钱、姜炭五分（夏四分）、炙甘草五分、桃仁十粒
- 服法：热服，加陈酒六七匙；渣另贮，三帖后合煎再服
- 加减总纲：产后诸症俱以生化汤为君，余不过随症加减；七日内块痛未除可连服，不厌药频

### 产后四大忌
1. **忌生气**——月内受气，停血成块，三年之内必遭危亡
2. **忌房事**——月内犯之危亡；七七之内犯之有大病；能忌百二十日终身少病
3. **忌凉水**——月内凉水洗手足，晚年必患风痛
4. **忌见风**——月内见风，面目浮肿，晚年烂眼边

### 产后饮食
- 七日内只服生化汤；七日后黄雌鸡汤吹油澄清饮（未可食鸡肉）
- 半月内不可食鲜猪肉，一月内不可食猪油；鸡蛋须发开加冰糖冲，整个食最易停滞
- 忌食清单：瓜果冷物、鹅犬牛羊首肉、沙糖酒独煎山楂（损新血）、菖蒲生姜胡椒艾酒大热物（行血致崩）

## 五、妇女证治（卷三）

### 月经辨证口诀
> 赶前为热，退后为虚；血滞宜破，血枯宜补；总以红为正。
- 色紫黑——热（生地四物加丹参丹皮益母草）
- 黄如米泔——湿（六君子加苡仁扁豆）
- 淡红——虚（八珍汤）
- 成块紫黑——寒凝（四物加桂心牛膝）；将行腹痛拒按——气滞血凝；既行腹痛喜按——气虚血少
- 经前发热血热，经后发热血虚；经阻溺窍（小便不通腹胀）——调经饮、泽兰汤

### 带下总治
- 总纲：**脾虚兼湿热**，治以补脾为主兼升提
- 赤属热（虚而兼火）、白属湿（虚而兼痰）；瘦人多火患赤带，肥人多痰患白带
- 主方：五味异功散加味——青带加柴胡山栀、黄带加石斛荷叶、赤带加丹参当归、白带加苡仁猪苓、黑带加杜仲续断

### 室女经闭两途
血枯（少思饮食、内热咳嗽渐成怯症）vs 经脉逆转（吐衄血妄行）——皆轻候，须速治

## 六、胎前诸症（卷四）

### 用药三禁与安胎活法
- **三禁**：汗、下、利小便（过汗亡阳、过下亡阴、利小便伤津液）
- 安胎二法：母病胎动→但疗其母；胎病触动→但安其胎
- 安胎要药对：**白术**（消痰健脾）+ **条芩**（清热养阴）；火盛倍芩、痰盛倍术、血虚合四物、气虚合四君

### 胎前常见症选方
| 症 | 主方 | 要点 |
|---|---|---|
| 恶阻（三月恶心呕吐） | 二陈汤加白术黄芩 | 肥人责痰、瘦人责火；久吐胃燥合二陈四物加竹沥姜汁 |
| 子悬（浊气举胎上凑） | 紫苏饮 | 一补一泻，推陈致新 |
| 子痫（痰涎壅盛发搐） | 清气化痰，剂稍小于痫症 | |
| 胎漏（无故下血） | 阿胶汤清之；黄多如豆汁用黄 汤 | 激经（受孕仍行经）无他症不须用药 |
| 胎动欲坠 | 佛手散加砂仁 | 下黄汁加黄 一两糯米一合 |
| 胎前动红（跌伤） | 胶艾汤止血→安胎散护胎 | 一日频服二三帖 |
| 毒药伤胎（类中风） | 甘豆竹叶汤（甘草黑豆淡竹叶） | 误作风治必死 |
| 转胞（小便不通） | 八味丸空心下五钱 | 车前八珍不效时 |
| 胎前浮肿 | 大腹皮汤 | 切忌通泄药 |

## 七、使用要点（蒸馏者注）

1. 本书价值在**流程化决策**：验胎→保胎（三合丸）→临产（七候+六字真言）→产后（生化汤+四大忌），环环相扣
2. "睡、忍痛、慢临盆"与"未离经"是全书最可取的**行为医学**内核：多数难产源于人为干预过早
3. 与《经验奇方》《钱氏秘传产科方》互参：生化汤同出一系；难产方与钱氏"木茯神方"可比对
4. 引用本书方药务必标注清代剂量与"仅供参考"边界；产科急症始终以现代医疗为准
