# 雷思齐易图通变（leisiqi-yitu）

主源：《易图通变》五卷（临川道士雷思齐，空山先生）。《易筮通变》本地 TXT 全 `0xFF` 死档——筮法细节以本书序「兼筮法亦乖素旨，附见后篇」为线索，**正文未采**。

## 一、核心命题（一句）

**河图实体数止四十**；天五、地十是**虚用**行于四十之中，故合称天地之数五十有五。世人把十五实点塞进图心，愈说愈迷。

## 二、河图结构（可执行）

### 1. 四方四维

- 四奇（1/3/7/9）居四方之正；四耦（2/4/6/8）附四维之偏。
- 由正生偏、由偏成正：生数少待成，成数多不能自适于中。

### 2. 八卦配数（雷氏说）

| 生数起 | +5 得成 | 卦位印象 |
|---|---|---|
| 坎一正北 | → 乾六西北 | 阳始生、阴中阳 |
| 坤二西南 | → 兑七西 | |
| 震三东 | → 艮八东北 | |
| 巽四东南 | → 离九正南 | 阳极阴丽 |

口诀：奇得五而耦、耦得五而奇＝生之所以成、成之所以生。

### 3. 合十与十五

- 对十：坎1+离9、坤2+艮8、震3+兑7、巽4+乾6。
- 纵横斜正「无不十五」＝五虚行于成数之内、十虚合于生数之外。
- 两五＝十；参天五＝参伍；错综＝把五参进五后之数以制中。

## 三、进退与四时

- 阳进：北→东（1→3）合于巽四；阴进：西南→东（2→4）合于震三 → 春齐乎巽。
- 阳退：南→西（9→7）；阴退：东北→西（8→6）→ 秋战乎乾。
- 四月乾月／十月坤月与卦气月卦可对读，但雷氏重点在**数之进退**非京氏世应。

## 四、九六虚实

- 坤起成数六而**实**；乾极成数九而**虚**——九寄位于六，卦用九六而不见七八。
- 乾用九＝行健无所待于阴；坤用六＝利永贞，阴有待于阳。
- 六于卦犹有位，九于卦已无位而寄六——解「用九／用六」与图位关系用此条。

## 五、参两参伍（读《系辞》用法）

1. **参天**：一自参出为三；三三而九＝乾元用九。
2. **两地**：两其二、三其二成六＝坤元用六、六画成卦。
3. **参伍错综**：五前数少不用伍；五后数多，参五错于中，首尾见原奇耦。
4. 大衍五十＝伍其十／什其五之汇；「一」与「五」另有不用之用，出五十之外。

## 六、驳「旧图」

- 改作方体、实点天五于中 → 不可推用。
- 正确姿态：圆体；五、十无定点而有中道；一寄于十之中而莫见其位。

## 七、边界

- 《易筮通变》死档；筮法勿臆补。
- 与刘牧／张理钩隐（`yishu-goushentu`）同属图书派，雷氏以「四十+虚十五」为判教标准。
- 序文称至元／大德间成书；吴澄等序可证交游，不影响数法。
