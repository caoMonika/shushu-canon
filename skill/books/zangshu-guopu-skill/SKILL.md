# 葬书（乘生气总纲）

## 核心

> **葬者，乘生气也。** 气乘风则散，界水则止。外气聚内气，过水止来龙。

## 流程

原起乘止 → 藏风 → 得水 → 辨支垄 → 核四兽 → 验土色 → 趋全避缺

## 支 / 垄

| | 支 | 垄 |
|---|---|---|
| 体 | 伏地中 | 峙地上 |
| 葬 | **葬额（巅）** | **葬麓** |

首足倒施则气脱如逐。

## 乘金相水

乘金（尖圆止处）·相水（金鱼界合）·穴土（葬口至中）·印木（蝉翼夹虾须）。外藏八风，内秘五行。

## 四兽

玄武垂头（否则拒尸）；朱雀翔舞（否则腾去）；青龙蜿蜒（否则嫉主）；白虎驯俯（否则衔尸）。平洋求肘臂环抱。

## 水与土

山来水回→贵寿财；山囚水流→大凶。土宜细坚润泽五色（忌黑、聚粟、腐肉、水泉砂砾）。

## 不蓄 / 腾漏

外无聚内→腐骨；左空右缺前旷后凹→败椁。

## 边界

本地源加密，据公域吴澄本；术数非可验证因果。
