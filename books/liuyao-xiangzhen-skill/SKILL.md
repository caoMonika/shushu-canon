# 六爻详真（曲炜）：爻的四个层次与生克权体系

依据 `_src\xiangzhen_1.md` + `_src\xiangzhen_2.md`（《六爻详真》第四次印刷全本，上册止于六章二节、下册接六章三节，无缝衔接）蒸馏。总纲：**预测是"条件预测"**——没有已知条件的断卦只是猜测；断卦前先问清条件（性别、年龄、所测事项的现实环节），再在卦中一一找对应点。生克制化刑冲合害既是生克关系，也是**信息之象**（合=情愿主动、害=不情愿、刑=被动索取、冲=对立）。

## 一、爻的四个层次理论（在李洪成三层次上改进）

| 层次 | 爻 | 权力 |
|---|---|---|
| 一 | 日、月建（含年、时） | 生克一切爻，同功同权 |
| 二 | 变爻（本位动爻所变） | 生克主卦动静爻；主卦爻无权克它 |
| 三 | 动爻、暗动之爻 | 生克同层次动爻与静爻 |
| 四 | 静爻（含伏神） | 只能生克同层次静爻；动爻被克时不能通关 |

- **作用方向**：上层次有权生克下层次，下层次无权生克上层次；同层次相互生克是"牵制和流通"，谁也伤不了谁（除非多爻或三合局克一单独爻——此为"制"）。
- **变爻的旁爻作用**：变爻对本位动爻有生克合冲时（最近），只作用本位爻；无生克合冲关系时，才作用主卦其它旁爻。变爻被日月制住/合住/冲脱则无权作用。
- **日月入卦（层次转换）**：爻值日/月建上升为第一层次——但只有第一层次的**力量**，没有第一层次的**权力**（值日静爻不发动，仍不能生克动爻，也不被动爻克伤）。日月变更后层次随之改变，**断应期关键**（例：兄弟午火持世劫财，财爻酉金临日为高层次克不动，待午月午火升一层次、酉金失一层次时才破财——故断午月破财）。
- **合冲互解互破顺序**（务必记）：主卦之合冲，变卦可解 → 动爻与变爻之合冲，日月可解 → 月建与卦爻之合冲，日建可解 → 日建之合冲，进行时日月可解。先成卦顺序后有日月，据此判断"冲解合"还是"合解冲"。

## 二、生克权判断（断卦核心基本功）

**冲**：
- 动爻相冲：旺胜衰败（衰者冲散无权）；两旺均减力（主克方减力小）；土爻相冲双方增力；两衰俱伤。
- 静爻相冲：有动爻的卦一般不论（有冲象无冲力），六静卦论冲，主内心矛盾。
- 日月冲动爻：冲脱（旺）可解（日月合住）、冲散（休囚受制）永无生克权；月冲动爻皆为月破，旺者出月/值日/逢合有权。
- 日冲静爻：旺=暗动升三层次；休囚只冲不克=**临界状态**（动变生扶则暗动，克泄耗则日破——全库仅此书立"临界"说）；连冲带克=日破。月冲值日之静爻反而为暗动。
- 变爻冲本位动爻：只冲不克旺者减力有权；连冲带克无权（临日月除外，测长期仍会失权）。

**合**：合化条件=两爻皆动（或动与本位变爻/日月）＋日月有化神且无克化神。合而不化=绊住减力暂失权，待上层次冲开解合。日月合动爻皆论绊（用神逢**生合**除外，增力）；静爻逢日月生合旺者为"合起"（如动爻），克合不论合起。测出行用神逢合皆主"绊住"之象（因何事绊看合神六亲：父母合=文书/电话/车辆，财合=钱财/费用）。
- 三合：三爻皆动或待合（缺字待日月补）；多一字须皆动、待合去。成局后同样分化成功与否。同层次之合让位于上层次之合。

**入墓**：只入高于自己层次之墓（静爻入动爻墓、动爻入变爻墓、一切入日月墓）；墓爻自身须有生克权才能收爻入墓。入墓期间不受生克、也无生克权。**解墓三式**：入日月墓→冲墓爻（不能冲日月）；静入动墓→冲墓/冲爻/合墓皆可；动入变墓→冲爻/冲墓/合墓。"过日过月出墓"之说不成立，必待合冲解墓。墓象=医院/牢狱/洞穴/库房/容器/车船（结合爻位六神取象）。

**空亡**：旬空期间无生克权也不受生克（避空）。解空两式：出空、冲空（冲空只得一半力）。五种形式：静空（冲时空爻旺相得半力，出空全功）；动空（冲空/出空皆可用）；动不空而**变空**（动爻亦失权，待变爻出空，冲动爻无用）；动空变也空（唯出空可用）；伏神空（有气为假空出空有用，无气值日无用；冲空冲飞皆拔不出）。

**旺衰与生克权总表**（要点）：静爻日月两处休囚即无权；一方受克一方休囚无权；一生一克=临界（看动变向背）；一方生一方休囚（不受克）有权。动爻两处休囚不受克=中和（尚有微权，看向背）；化退/泄/绝减权，化回头克无权，化回头生/进神有权。变爻唯双方受克才无权。**"制"四式**：上层次冲克、多爻克一、合局克一、（同层次一对一冲只是牵制非制）。

## 三、刑冲合害的顺序与信息之象

同层次内：**合冲＞刑＞害＞普通生克**（特殊关系有优先生克权）。例《天山遁》世午火，生戌土（半合）力大于生辰土（无特殊关系）——"有关系先得好处"。动爻不分远近（有流动性），静爻之间论远近。合=情愿（午未合：主动给、无怨言）；害=不情愿（丑午害：帮但要说你几句）；刑=被动索取（卯刑子：官主动要钱如交税）。断卦要从生克关系里提"信息之象"，落到具体人事物。

## 四、取用体系（用神=对应点，对应点越多断得越细）

- **用神转换原理**：同一物因求测角度不同用神不同——雨伞：厂商测销路=子孙（财源）／失窃=财／测质量=父母（保护功能）；牛：丢失=子孙+财兼看／买卖=财／测优劣=子孙。找工作：为名声地位=官鬼；仅为糊口=生世之爻（子孙）。**看本质不看表象**。
- **真假六亲**（测亲属专用）：内六亲（门内）取本宫内卦之六亲为真、外卦为假；本宫内卦无真六亲看内卦伏神；再无则以世爻为基点按实际关系取（如测妹妹世为土取土爻官鬼）。外六亲（门外）取本宫外卦为真。**假六亲主事物之象**（能力/地位/表面），**真六亲主肉体人身**——判"是人有灾还是事有灾"靠它。代测（父测儿女工作等）直接以世爻代所测之人。
- **用神两现**：反对《增删》"舍一用一"。两现各有其理（卦不妄成）：财两现=两笔财（内外卦=本地外地）；官两现=身兼数职（外卦之官为欲求之官）；测行人取外卦之爻为主、内卦辅参。选定原则：符合实际那一爻为主。
- **六亲取用总则**：父母=承载/保护/文书通讯；官鬼=约束我/荣身（官运疾病盗贼）；兄弟=竞争/同类/帮扶（假牙拐杖也是）；子孙=娱乐/技艺/解灾/财源；妻财=为我所用/利益。测人：不熟无关系者取应爻；同辈兄弟爻、长辈父母爻、小辈子孙爻、我所控制者财爻、管我者官鬼爻——但**以求测角度为准**（姐姐是教师，从姐妹关心角度仍取兄弟爻；从公司业务角度可取财爻）。

## 五、卦位卦象爻位与三才实断

- 上卦=高/远/外/表面/领导，下卦=低/近/内/深层。八卦类象从爻形推（艮覆碗=坟/门坎、兑上缺=口/说、坎中实=车/有核之物……），一物可从质地/形状/性质取不同卦象（瓷缶：口朝上震、口朝下艮、质地坚兑）。
- **三才实断**：五六爻天爻（高处远处外地外国、乘飞机、官位高）、三四爻人爻（本市中距、人事纠纷、胸腰）、初二爻地爻（本地低处农村、乘车、腿足、地基）。
- 爻位细分：同位爻（1-4/2-5/3-6）；五爻贵位二爻贱位；阴阳得位与否（官爻位不正=名不正言不顺/大才小用）。
- 六爻各位大表（地理：初乡村→上外国；企业：初临时工→上股东；家宅：初地基→上屋顶；人体：初脚→上头）——断鸭子在马棚草堆（四爻门户+震巽草木+午马）即此法。
- **六神×六亲组合表**（30 组）：如朱雀临父=书信/教师/诉状；勾陈临官=熟客/情敌/纠缠官司/房地产官；螣蛇临父克世=合同圈套/车祸；玄武临财=暧昧之财/受贿；白虎临财生世=暴发/危险操作之财。六神一般不主吉凶只分类别；动爻与用神才明显体现。

## 六、断卦程序与信息定向锁定

1. **未断卦前先联系实际**：想清办成此事需哪些条件环节→一一对应到爻→看哪些条件具备、哪些缺失、有无补救（补救之时即应期）。例：石灰石出口——世（自己实力）、应（外贸局）、子孙辰（样品，二爻地爻=地下矿产）、兄弟午（朋友中间人，月破=帮不上）、父（合同）。
2. **内因外因**：主变卦为内因定成败，日月为外因定引发（应期）。日月全克世但无动爻克世→一年平平无大灾；日月生世但卦中有动爻克世→运过必灾（"内因有病灶"）。
3. **卦象信息定向锁定**（本书旗帜观点，反对测单项一卦多断）：所测之事确定后，全卦信息定向锁定于该主题——测父亲能否回，官爻只是父之原神，不是官非；世爻代表心愿非肉体。**仅测运程/流年类可一卦多断**，且围绕运气主题。测东说西、见父母爻弱断父母灾=画蛇添足。
4. **事态发展顺序**：阳爻持世从初爻向上发展，阴爻持世从上爻向下发展。

## 七、测来意四看与断应期

- **测来意四看**：①世爻（处境心思）②动爻变爻（发生何事/起因，"天机尽泄于动变"）③应爻（环境）④六神（定类别）。结合年龄性别常理（七八十岁老人多半问病/子女，不问婚财）。
- **断应期=治病**：找出用神/世爻之"病"（动待合、静待冲、衰待旺、空待出空冲空、墓待出墓、伏待引拔），**所有病都治好才是应期**。吉应期 14 条（原神空墓待出、旺静待冲、旺动待合、太旺待合/墓、逢冲待合、逢合待冲、伏待引拔……）。凶应期多在忌神旺相/原神受制时。
- **应期超前/落后于事限则事不成**（摸奖期未日结束而理论应期在申日→不得奖）。**分令时**：一时辰 12 等份每份 10 分钟（子分令时起），日内之事可精确到分令时。精度分级：年内事只能到月、月内到日、日內到时、几时辰内到分令时——"米尺量不出微米"。
- 单动爻之卦，应期常在动爻/变爻所值日月（"神兆基于动"）。

## 八、分类占断精选判据

- **求财**：长期求财须财爻生合世（相克须通关）；短期只要财世两旺有联系即可（兄弟持世短期亦可得财）。合伙：世应空=不实；财生合谁谁得财；世持财应临兄防骗；应克世=帐目不清。讨债：看世（讨债能力）、应（想不想还）、财（有没有钱）。数目三法：纳甲数（甲己子午九…）、支数（子1…亥12）、卦数（乾1…坤8，主变卦和）；旺相加倍休囚如数死绝减半。何财看财爻地支五行＋所临卦＋爻位（五六爻=天财远方之财，三四爻=人事之财，初二爻=土产近财）＋六神。方位三法（财支方位/世所克之方/财所临卦方），三法一致定之。
- **婚姻**：未婚看世应为主（应生世=对方喜欢我），已婚看财官（男财女官）；最忌六冲卦（逢冲必散）；男忌兄弟持世、女忌子孙持世；阴阳得位（男世阳女世阴，否则须一方说了算）；官爻（男测）/财爻（女测）为情敌——临勾陈=旧情人、玄武=暧昧。相貌（子午卯酉俊、辰戌丑未敦厚丑、寅申巳亥一般，值日月不论支都好看）、距离（同卦=近、上下卦分=远、被隔断=外省、不上卦=远方）、年龄（世应所临卦：乾老男坤老妇兑少女艮少年；阳爻大阴爻小，动爻增减）。
- **失物**：可寻之象（用在内卦本宫/旺相持世/宜静/官鬼空衰/世应相生/游魂=忘记）；难寻（空动化空/外卦旺动/鬼动=人偷）。方位按宫（乾西北…）＋伏神所伏（伏父下=书箱厨房、伏财下=仓库妇人）＋爻位（上=屋顶、五=路边箱柜、二=灶边）。知情人看子孙爻临支（辰=黄衣肩挑、申=开车修路……）；贼看兄鬼爻：旺=青壮休囚=老、胎养长生=小孩；支断脸型、六神断体态。
- **测病**（本书创见）：**不看官鬼爻**，把整个卦当人体——最旺五行及被最旺五行所克之五行即病症所在，配爻位定部位（亥水弱在三爻=肾、卯木伤在上爻=头风）；动爻与被日月冲之爻也是病位；六神辅助。虚病：用神不受克而世用临螣蛇/玄武。官鬼爻仅当其为原神/世爻被克时才代表病，官爻位置只示病位。治愈看用神原神与忌神力量对比。近病逢冲则愈。
- **出行/行人**：问"能否走成"与问"平安"分开断；世被合/入墓/空=走不成（大象定结果，不必再推应期）；问"何日走"才推应期。行人归期=治病（合待冲、冲待合、空出空、墓出墓、伏待现）；用神发动克世/世空=速来；三四爻=门户速归；化进立归化退返回。去向：用神五行=先去之方，变爻五行为后去之方；内卦=不出本地，外卦外宫=出省。遇《大畜》=被留住，《遁》=逃走，游魂=东奔西跑。
- **官司**：胜负看世应**力量**谁大（非看谁克谁；世临鬼旺照样胜）；财爻主理（持世=我有理）；父母=诉状（休囚空=立不了案）；间爻=证人（空=无证，克谁证词不利谁）；子孙旺动=和解之象。起因三看：某六亲临朱雀动／某六亲变官鬼／官鬼临某六神动（青龙=婚姻酒色、玄武=暧昧失盗、勾陈=田产契约、螣蛇=积怨纠缠、白虎=丧病争斗、朱雀=口舌文书）。
- **竞争比赛**：世应力量大者胜（一动一静动者层次高主动）；月=天时、日=地利、时辰=人和；间爻=观众、父母=教练（生谁利谁）。世应均动=竞争激烈难分。
- **流年**：首看世爻有无生克权（无权=一年平平难成事）；各爻旺衰是"底"，按流月推吉凶兑现（无生克权之爻逢月也兑现不了）；出空以**月**为单位推。断语 16 条（兄动克世=破财、官临白虎克世=手术血光、世空=事与愿违出空方成、世入墓=全年难有作为、财是原神不可伤……）。真假六亲判六亲之灾还是事物之灾。
- **六亲通变**（最高层）：以世爻（或所测之爻）为太极点，按"生我者父母/我生者子孙/克我者官鬼/我克者妻财/比和者兄弟"重定六亲——揭示**表面关系与实质关系**：父母持世则官鬼实为原神（领导=靠山）、财爻实为官鬼（妻管严/为财所役）；财持世则兄弟表面朋友实质小人。测父病以父母爻为原点：官鬼反而是父之原神（非病），财爻才是父之官鬼（财动父有灾）。用于人事安排：应生世=放文书策划位、世生应=放生产供销位、世克应=放实操位、应克世=弃用。

2. 书中部分绝对化断语（"用神两现不可舍一"、"测单项绝不可以一卦多断"）为作者立论立场，与其他流派（增删卜易舍一用一、一卦多断派）冲突，已在正文标注出处，按"条件预测"框架取用，勿教条互斥。
3. "临界状态"（日冲休囚静爻非破非暗动）、"分令时"、"真假六亲"、"六亲通变"、"测病不看官鬼"为本书独有判据，库内其他技能未见，使用时注明系曲炜一家之言，需实证检验。
4. 作者多处强调需结合社会常理与已知条件断卦、功夫在卦外（阅历决定断卦细度）；脱离条件的"神断"追求被明确否定。分类占断章节卦例密集，本技能只蒸判据，卦例细节以原文为准。
5. 相邻技能：装卦基础与传统规则见 liuyao-liuyao 系列；爻位取象对照 liuyao-liuchangming（爻位取象）；流年对照 liuyao-quwei-duanliunian；空亡专题对照 liuyao-shiyaowangshuai（空亡11论）——规则冲突处以各技能"使用边界"为准。
