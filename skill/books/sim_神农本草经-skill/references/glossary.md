# 术语表 — 《神农本草经》

| 生山谷 | '''丹砂'''　味甘微寒。治身體五臟百病。養精神、安魂魄、益氣、明目，殺精魅邪惡鬼。久服通神明不老。能化為汞。生山谷。 |
| 生川谷 | '''委萎'''　味甘平。主治中風暴熱不能動搖，跌筋結肉，諸不足，久服去面皯，好顏色潤澤，輕身不老。生川谷。 |
| 久服輕身 | '''空青'''　味甘寒。主治青盲、耳聾。明目，利九竅，通血脈，養精神。久服輕身延年不老。能化銅鐵鉛錫作金。生山谷。 |
| 味苦寒 | '''朴消'''　味苦寒無毒。主治百病，除寒熱邪氣，逐六腑積聚、結固留癖。能化七十二種石。煉餌服之，輕身神仙。生山谷。 |
| 味苦平 | '''雄黃'''　味苦平。主治寒熱鼠瘺，惡瘡疽痔，死肌，殺精物惡鬼邪氣百蟲毒，勝五兵。煉食之，輕身神仙。一名黃食石。生山谷。 |
| 味甘平 | '''玉泉'''　味甘平。主治五臟百病。柔筋強骨、安魂魄、長肌肉、益氣，久服耐寒暑，不饑渴，不老神仙。人臨死服五斤，死三年色不變。一名玉劄。 |

| 生池澤 | '''禹余糧'''　味甘寒。主治咳逆、寒熱、煩滿，下利赤白，血閉癥家大熱。煉餌服之，不饑、輕身、延年。生池澤。 |
| 味辛溫 | '''菖蒲'''　味辛溫。主治風寒濕痹，咳逆上氣，開心孔，補五臟，通九竅，明耳目，出音聲。久服，輕身，不忘，不迷惑，延年。一名昌陽。生池澤。 |
| 生川澤 | '''乾地黃'''　味甘寒。主治折跌絕筋傷中，逐血痹，填骨髓，長肌肉。做湯，除寒熱積聚，除痹。生者尤良。一名地髓。生川澤。 |
| 生平澤 | '''薏苡人'''　味甘微寒。主治筋急拘攣不可屈伸，風濕痹，下氣。久服輕身益氣。其根下三蟲。一名解蠡。生平澤。 |
