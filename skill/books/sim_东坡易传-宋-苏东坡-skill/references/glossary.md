# 术语表 — 《东坡易传-宋-苏东坡》

|---|---|
| 故曰 | “利”者，义之和也，“贞”者，事之干也。君子体仁足以长人；嘉会足以合理；利物足以合义，贞固足以干事。君子行此四德者，故曰：“乾，元亨利贞。” |
| 无咎 | 九三：君子终日乾乾，夕惕若。厉，无咎。 |
| 者也 | 今之飞者，夕之潜者也，而谁？非“大人”欤？曰“见大人者”，皆将有求也。惟其处安居正，而后可以求得。九二者，龙之安；九五者，龙之正也。 |
| 苏氏易传 | ①      欲往者：《苏氏易传》作“欲往焉者”。② |
| 校注 | （见正文） |
| 上九 | 上九曰：“亢龙，有悔。”何谓也？子曰：“贵而无位，高而无民。” |
| 六二 | 六二：直、方、大，不习，无不利。 |
| 九三 | 九三：君子终日乾乾，夕惕若。厉，无咎。 |
| 六三 | 六三：含章可贞。或从王事，无成有终。 |
| 六四 | 六四：乘马，班如；求婚媾。往吉，无不利。 |
| 九二 | 九二：见龙在田，利见大人。 |
| 九四 | 九四曰：“或跃在渊，无咎。”何谓也？子曰：“上下无常，非为邪也；进退无恒，非离群也。君子进德修业，欲及时也，故‘无咎’。” |
| 初六 | 初六：发蒙，利用刑人，用说桎梏；以往，吝。 |
| 初九 | 初九曰：“潜龙勿用。”何谓也？子曰：“龙德隐者也。不易乎世。” |
| 九五 | 九五：飞龙在天，利见大人。 |
| 上六 | 上六：龙战于野，其血玄黄。 |
| 贞吉 | 君子有攸往，先迷，後得主，利。西南得朋，东北丧朋，安贞吉？ |
| 六五 | 六五之位尊矣，恐其不安于童蒙之分，而自强于明，故教之曰：“童蒙，吉”。 |
| 悔亡 | 九四：贞吉，悔亡。憧憧往来，朋从尔思。 |
| 利有攸往 | “贲”：亨，小利有攸往。 |
| 利贞 | “利”者，义之和也，“贞”者，事之干也。君子体仁足以长人；嘉会足以合理；利物足以合义，贞固足以干事。君子行此四德者，故曰：“乾，元亨利贞。” |
| 而已 | 此论“元”也。元之为德，不可见也，其可见者“万物资始”而已。天之德不可胜言也，惟是为能“统”之，此所以为“元”也。 |
| 有孚 | “需”：有孚，光亨，贞吉。利涉大川。 |
| 元吉 | 《象》曰：“黄裳元吉”，文在中也。 |
| 无不利 | 六二：直、方、大，不习，无不利。 |
| 谓之 | “乾”已克四而达于五矣，其势不可复抗，故入穴以自固。谓之“不速之客”者，明非所愿也。以不愿之意而固守以待之，可得为安乎？其所以得免于咎者，特以“敬之”而已。故不如五之当位，而犹愈于四之大失也。 |
| 是以 | “是以动而有悔也”。“潜龙勿用”，下也。“见龙在田”，时舍也。 |
| 之世 | 大、时不齐，故随之世，容有不随者也。责天下以人人随己而咎其贞者，此天下所以不说也，是故“大亨”而“利贞”者。贞者无咎，而天下随时。时者，上之所制也，不从己而从时，其为“随”也大矣。 |
| 征凶 | 上九：既雨既处；尚德载，妇贞厉。月几望，君子征凶。 |
| 利见大人 | 九二：见龙在田，利见大人。 |
| 位不当也 | 《象》曰：“眇能视”，不足以有明也；“跛能履”，不足以与行也。咥人之凶，位不当也；“武人为于大君”，志刚也。 |
| 无攸利 | 六三：勿用取女，见金夫，不有躬，无攸利。 |
| 利涉大川 | “需”：有孚，光亨，贞吉。利涉大川。 |
| 何也 | 处群刚之间，而独用柔，无备之甚者也。以其无备而物信之，故归之者交如也。此柔而能威者，何也？以其无备，知其有余也。夫备生于不足，不足之形见于外，则威削。 |
| 无妄 | “无妄”，元亨，利贞。其匪正有眚，不利有攸往。 |
| 正也 | “乾”之所以取于“龙”者，以其能飞能潜也。飞者其正也，不能其正而能潜，非天下之至健，其孰能之？ |

> 术语由频次粗提，可能含噪声；以原书定义为准。
