# 图解卜筮全书·第二部（姚际隆整理，唐颖白话图解本）

明《卜筮全书》三卷：卷一《阐奥歌章》（断卦歌诀 25 条＋专题断法）、卷二《天玄赋》（18 章专题赋）、卷三《阐幽精要》（论神鬼说妖，偏家宅疾病）。底本明崇祯庚午（1630）本。本技能只收可辨识的歌赋条文与判据；白话图解为 2009 编者所加。

## 一、阐奥歌章（火珠林法总则）

### 碎金赋（六亲发动相克链）

父动克子（子孙不能生财）；兄动克财（财不能生官）；财动克父（父不能生兄）；子动克官（官不能生父）；鬼动克兄（兄不能生财）。五"变变"：子孙变变克制官鬼、妻财变变克制父母、父母变变克制子孙、官鬼变变克制兄弟、兄弟变变克制妻财。

### 卜筮歌诀 25 条（择要）

- 诸爻持世诀：世爻宜旺相；世应生克动静空亡诀：世应宜合忌冲。
- 飞伏生克吉凶歌：与《增删卜易》同（伏克飞为除暴、飞克伏反伤身、伏生飞泄气、飞生伏得长生）。
- 忌神歌：忌神宜静不宜动；元辰歌：原神生用神；用爻泄气歌：泄气则衰。
- 六爻安静诀：最宜日辰合；六爻乱动诀：顺看用爻表征；用爻不上卦/落空亡诀：寻飞伏；用爻伏藏诀：最忌克；用爻出现诀：休囚亦不凶；用爻空亡诀：忌神宜空亡。
- 日辰诀：日辰主卜猛烈；六神空亡诀、六神吉凶诀（吉凶各有主）。
- 六亲发动诀/六亲持世歌（官鬼持世利升官）/六亲变化歌（最忌化兄弟）/六神歌断（白虎主刑伤）。
- 年建天符（值年太岁）、月建直符（万卜提纲）、日建传符（六爻主宰）；神杀断例：神吉杀凶。
- 附：六神诸占定位。

### 专题断法（条文）

天时耕作（"龙水风雷俱不劲，九江四浪横天翻"类象占）、家宅风水（六爻各有所属、移徙最忌鬼动、坟茔六爻安静最吉）、身命婚育（青龙天喜带福来、婚姻阴阳得位、产育看子孙旺相）、求学仕宦（求官以父母官鬼为用）、求财出行（求财要财爻上卦旺）、行人（兄动父动是归期）、六畜蚕桑舟车、疾病医药（青龙见子可安心）、词讼盗贼（妻财安静不破时物不失）。

## 二、天玄赋（18 章，择独到处）

- **身命**：三限荣枯决于世爻兴衰动静；**内爻与外爻各管人生十五年**；内三爻定财、外三爻论生死；男宜青龙、女忌咸池。
- **婚姻**：鬼为夫财为妇、阴阳得位方成夫妇；世变为男、应变为女；卦象定姻缘（二气组合）。
- **六甲**：得男得女决于玄武（玄武临阳男？古注），青龙白虎最宜生产；父母兄弟动妻子必有伤。
- **求仕**：鬼兴财旺功名有；福马扶身必成大业；月德所主当朝御史。
- **词讼**：官鬼为用（官鬼应变可求胜）；世应相合必和解；兄化兄主牵连；词讼逢太岁上峰有主张；官鬼墓绝结案。
- **盗贼**：官鬼为贼；鬼化妻财失物可回归；二官鬼动必有内鬼；**财居内爻失物不离家舍**；贼之性别看官鬼爻阴阳、长相五行推身形六神定面目；若无妻财爻便以官鬼代（失物用神转换）。
- **求财**：无本求财官鬼兴隆；财临前后卦属先后；财爻与日辰相合方致富。
- **出行/行人**：世空难成；午爻现坤驷马踏平川；用神伏处定受阻缘由（与歌诀同）；决归期显着六爻五行。
- **家宅**：内三爻主宅外三爻主人；三四爻内外门、五六爻道路桥梁；**卦中十二宫借以问就弄**；游魂主迁、墓库主定；游魂化归魂迁而复返。
- **疾病**：先断症候后论病由；天医发动起死回生；伏克飞受药石有效；男女所忌长生沐浴。
- **地理（阴宅）**：择地以六合聚气；水口明堂宜红点穴（原文残缺处多）；青龙白虎防城主昂头；玄武作水夫观山侧水。
- **国朝章**（五爻天子、四爻公侯、将星相刑、暗动伤身＝荆轲刺秦类象）——古占国事之法，存史料。

## 三、阐幽精要（论神鬼说妖）

- 六神情性赋（青龙仁青……）；身命章、家宅说（世爻为宅、应爻为人）。
- **柳神经**：占家宅条文、地支象物、父母入墓先人坟茔有伤、水爻官鬼临龙必有观音信宅舍。
- **参玄赋**：父母为宅基、日辰冲水爻家人耳鼻之疾、父母火爻重一宅分两户。
- **五行六爻家宅论/搜精六爻**：初爻根基、二爻女主人、三爻门户、四爻大门、五爻家宅栋柄、上爻祭祖。
- **疾病论**：官鬼为病、六神主病由、天地转煞四种、火爻官鬼动进香仕神（民俗层）、五行论病歌。
- **何知章**（一眼断 16 条）：问虚实看虚实爻、问妻看妻财、问讼看官鬼、财丰丁旺青龙临、问贵贱看贵人临子孙、问家宅玄武白虎总不吉、问风水六爻要带水、问失物看官鬼妻财、问疾忌螣蛇白虎、问囚事螣蛇玄武……
- **别论**：矫摩赋（八卦蛇鬼来作祟）、搜鬼论、约爻之外互卦例。

## 使用边界与素材缺陷

1. **OCR 质量极差**：本源文为图解本转录，乱码、断句错乱、图注串行严重（尤其目录页与图解框）；部分条文（如天玄赋"地理章"、水口明堂）残缺不全，引用时须核对《卜筮全书》通行点校本。
2. 内容与《黄金策》《卜筮正宗》互见甚多（飞伏歌、用神、应期），参见 liuyao-shaoweihua、liuyao-huoduan-dianqiao，勿重复立规则。
3. 神杀体系（太岁剑锋、丧门、羊刃、孤辰寡宿、咸池）属古法神煞层；"论神鬼/搜鬼论/矫摩赋"为鬼神妖异题材，作民俗史料。
4. 白话提要与图解为 2009 年编者所加，个别白话与原文有出入（OCR 又加剧），以古赋原文为准。
