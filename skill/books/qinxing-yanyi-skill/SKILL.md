# 禽星 / 演禽（易见 × 通纂）

文献参考。合并两书：易见重「七元翻禽倒将」；通纂重「三十六禽＋花甲化道」。

## 一、总机制

课以象推，事因星验。以**二十八宿之禽**在十二支宫上演之，观彼我禽是否得地；再以飞／伏／进／退／冲／合／庙断吉凶。

## 二、七元与将头（《禽星易见》）

一元一「进神将头」（甲子直宿）：

| 元 | 将头 |
|---|---|
| 一 | 虚 |
| 二 | 奎 |
| 三 | 毕 |
| 四 | 鬼 |
| 五 | 翌（翼） |
| 六 | 氐 |
| 七 | 箕 |

- 甲子、己卯、甲午、己酉直宿为**气将**。
- **进星**：将星之前逆数十五宿；**退星**：将下顺数十三宿。
- 好宫欲**飞**（上擒下），恶宫欲**伏**（下擒上）；入本宫曰进，背本宫曰退，对本曰冲，合本曰合，在本曰庙。

### 十二辰日上星组（速记）

## 四、三十六禽与化道（《演禽通纂》）

**支禽**：寅虎狸豹｜卯兔狐貉｜辰龙蛟鲸｜巳蛇鳝蚓｜午马鹿獐｜未羊鹰犴｜申猴猿猱｜酉鸡乌雉｜戌豺狼狗｜亥猪貐熊｜子鼠蝠燕｜丑牛獬龟。

**干化道**：甲山林｜乙穰草平林｜丙火窑｜丁焚野｜戊山冈坑｜己平坡｜庚刀砧｜辛弩箭｜壬浅水｜癸长江。

**支化道**：子湖｜丑田｜寅山林｜卯林｜辰冈｜巳汤火｜午焚场｜未郊园｜申砧｜酉刀……

六十甲子「总取化道」＝干支拟象合成（通纂歌诀层）；占时先定日辰禽与化道，再看与所问「彼我」生克喜忌。

## 五、操作次序

1. 定七元／将头（或直接取日上星组）。  
2. 定我禽、彼禽及所泊支宫。  
3. 判飞伏进退冲合庙。  
4. 对照命名格与汤火刀砧等忌宫。  
5. 用通纂三十六禽化道补「象」。

## 边界

演禽多用于择时与事类吉凶文献；不可作军事/医疗实操依据。
