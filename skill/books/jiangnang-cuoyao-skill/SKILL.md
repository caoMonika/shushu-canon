# 绛囊撮要 · 蒸馏技能

**来源**：《绛囊撮要》，清·云川道人辑（乾隆九年甲子序，萍翠山房）
**性质**：经验验方集成，分**内科 / 妇人科 / 小儿科 / 外科 / 通治**五门，约二百五十余方；主旨"药简易求、已经经验"
**文本说明**：IMA 知识库 TXT 为加密/损坏二进制；本技能据维基文库公域文本蒸馏
**使用边界**：古籍文献参考。含牛黄、犀角、麝香、川乌、辰砂等药及灸熨法，不可照方抓药，不可作为医疗依据。

---

## 一、核心方法论：按门选方

1. **先定科门**（内/妇/儿/外/通治）→ **再对主症** → **取一方**
2. 通治方（如寸金丹）用于仓猝不明、寒暑风痰交杂时；确定病机后仍归专科方
3. 外治优先于内服的场景：结胸熨、阴毒熨、肿毒初起灸、头风膏贴

---

## 二、内科急症框架

### 1. 厥逆 / 痰厥 / 神昏

| 方/法 | 要点 |
|---|---|
| 牛胆星丸 | 厥逆猝不省、口流涎沫、手足拳挛；椒目大丸，开水送二十一粒（老弱减） |
| 牛黄清心丸 | 痰厥口噤、小儿惊风五痫；胆星白附等入牛胆汁制，加芒硝辰砂硼砂冰麝 |
| 艾灸法 | 中风中痰中寒中恶：两中指对缚灸指间 → 百会 → 中脘 → 气海 |

### 2. 伤寒 / 时疫外治

- **阴毒伤寒四肢逆冷**：吴茱萸酒拌蒸热，互熨心胸及足心
- **伤寒结胸**：葱姜捣炒，布包频熨胸
- **时疾厥逆**：七鲜汤（鲜藿香、首乌、荷叶边、生地、佩兰等打汁冲服）
- **中暑**：辰砂益元散（滑石、甘草、辰砂）冷水或鲜藿香汤调

### 3. 痰咳疟痢霍乱速查

- **痰火**：四汁散（花粉用梨/姜/萝卜汁/竹沥拌晒）
- **咳嗽简易**：桔梗、川贝、白菊、梨肉泡汤
- **痰哮**：川楝、枳实、香附、牡蛎等水泛丸
- **疟**：书中分立治疟 / 三日疟 / 疟初起多方，总以截疟不伤正为度
- **白痢 / 晨泻 / 霍乱绞肠痧**：各有专方（参香丸、晨泻散、绞肠痧方）
- **反胃 / 痞 / 水臌**：反胃简易方、消痞神膏、鸡金散、水臌方、葫芦散等

### 4. 血证与头面风

- **吐血除根 / 鼻血**：吐血除根奇方、血余散、鼻血不止煎方
- **肠红**：煮猪肠、治肠红方、柿饼丸
- **头风**：治头风神方、头风痛膏、熨衣方
- **风疹 / 面上疯 / 疠风**：金蟾酒、疠风煎、洗疠风便方、六黑丸

---

## 三、妇人科要点

- **横生倒产、沥浆、交骨不开、子死腹中**：加味芎归汤（当归一两、川芎七钱、龟板酥炙、男女发焙）——书称"大剂连服即产"之救急方
- 其余经带胎产方归妇人科门，临证先辨崩漏 / 带下 / 胎动 / 产后，再选方

---

## 四、小儿科要点

- **马牙**（牙根白点不能吮乳）：银针挑破出血 → 薄荷汤磨金墨擦 → 暂勿哺乳
- 惊疳泻痢类方集中在小儿科门；与牛黄清心丸可交叉用于急惊

---

## 五、外科通则

1. **肿毒初起**：蒜片安疽头、中通孔、艾炷灸（书中"肿毒初起治法"）
2. 溃后与恶疮另有膏散洗方；疠风恶疮可先洗（浮萍/地肤）再内服
3. 眼疾：弦烂风赤眼洗方、烂眼皮方、眼药方分列，勿混用内服重剂

---

## 六、通治代表：寸金丹

- **组成骨架**：乌药、防风、羌活、前胡、川芎、砂仁、厚朴、藿香、半夏、木香、紫苏、薄荷、苍术等 + 神曲糊丸、朱砂为衣
- **通治声称**：中风中寒中暑、口眼喎斜牙关紧闭（姜汤下）；伤寒时疫头疼脊强；肚痛等
- **用法提醒**：通治≠笼统乱投；神志未清时可作首手，苏后须再辨证
