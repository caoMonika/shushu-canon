# 六壬经纬（铁瓮子·格局/断占旁参）

本地原件为错页医案扫描；据 ctext《六壬经纬》序·演法·格局蒸馏。书分六卷：演法 / 定式(720局) / 格局(91款) / 神煞(44) / 类相(11门) / 断占(13篇)。演法与通行九宗门同系，**起课以 `liuren-jichu` 为准**；本 skill 专收其**格局专名与用法**。

## 一、演法要点（与通行对照）

- 干为人、支为事（占人则干我支人）。
- 月将按中气交节换，不拘月份。
- 寄宫：甲寅乙辰丙戊巳丁己未庚申辛戌壬亥癸丑。
- 取传顺序与九宗门一致：先一下贼→一上克→比用→涉害（孟→仲→阳日干阴日支）→遥克→昴星→别责/八专→伏吟→返吟（书中称「别择」「断金」等，名异实同）。
- **贵人阴阳**：书称卯辰巳午未申时用阳贵、酉戌亥子丑寅时用阳贵——与通行「昼贵/夜贵」表述易混，实作宜与 `liuren-jichu` 昼夜贵人表互校，冲突时标两说。

## 三、三传形象格局（经纬特色）

### 连茹
- **进茹**亥子丑…戌亥子：牵连引进。末空返以退论；初空不进不退。  
  名象：龙潜/含春/将泰/正和/离渐/升阶/锓阳/励明/回春/流金/革故/隐明就暗。
- **退茹**亥戌酉…子亥戌：牵连引退。末空返以进论。  
  名象：回阴/返驾/出狱/临阴/渐晞/登庸/正己/返照/联芳/游魂/入墓/重阴。

### 间断（间传）
- 进间亥丑卯…；退间亥酉未…。进间＝前时隔断，退间＝退后隔断。  
  名象含溟蒙、向三阳、出户、登三天、涉三渊、极阴、偃蹇等（与《翠羽》邵康节二十四课名相通，可互参 `liuren-cuiyu-fu`）。

### 悬胎
- 顺：亥寅巳、寅巳申…；逆：亥申巳…。象隐匿怀胎、继先传后。空一二勿以名实论。

### 关隔
- 顺子卯午…；逆子酉午…。象门户破败。四季各有专断（春羝羊触藩等）。

### 稼穑
- 顺丑辰未…；逆丑戌未…。象田园植物。春生长/夏游子/秋地角/冬五墓；逆有越库转魁杀墓伏阴。

### 三合局
| 局 | 顺/逆例 | 事类 |
|---|---|---|
| 金 | 巳酉丑 / 巳丑酉 | 锋刃杀气金事三人谋合；从革/献刃/藏金等 |
| 木 | 亥卯未 / 亥未卯 | 枝叶发生木事；曲直/合纵/从吉等 |
| 水 | 申子辰 / 申辰子 | 渊流不息；润下/出奇/呈斗等 |
| 火 | 寅午戌 / 寅戌午 | 炎上发达；间魁/顶墓等 |

三将空一二，勿与合局实论。

### 六亲气局（格局卷后半纲）
- **印绶**：初生干、三传/干支合局生干、干支上互生、传内递生干等皆是。  
- **伤官/官讼/妻财/劫财**：按传与干之泄克财比关系命名，再视神煞临乘定吉凶。  
- 另有遐龄、洁己、凶服、衣禄、崇位、荒淫、禁系、决绝、孕儿、刑伤、摇动、破损、仇害、和合、天恩天祸、及时失时、孤寡鳏孀、干贵、文书、争讼、喜庆、朝天、灾丧、宴会、逃脱、暗昧、斫轮铸印轩盖斩关、六阴六阳、回环一体、斩首断桥刖足、始终等——**认格后统一口诀：视所乘何神、所属何煞、所临何煞定吉凶**。

## 四、神煞·类相·断占（纲目）

- 神煞删定为 **44 种**并附解义（去无用者）；细表未全录入本 skill 时，回原书卷四或 `liuren-shensha`。  
- 类相 **11 门**提纲；断占 **13 篇**为幼学规矩，变化须「神而明之」。  
- 用书顺序（自序）：演法→定式对720→格局认91→神煞→类相→断占。

## 五、使用流程

1. 用 `liuren-jichu` 起课排传  
2. 在本 skill 对三传/干支加临**认经纬格名**（连茹？关隔？培本？）  
3. 按「乘神·属煞·临煞」定吉凶  
4. 应期与类神细断回 `liuren-wuyao-quanheng` / `liuren-zhinan`

1. 本地 TXT 错源；定式720局未收入（略去）。

3. 贵人昼夜表述与通行本可能不一致，须互校。
