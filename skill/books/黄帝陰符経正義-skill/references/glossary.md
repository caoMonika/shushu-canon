# 术语表 — 《黄帝陰符経正義 》

| 术语 | 上下文线索（OCR） |
|---|---|
| 觀天之道 | 觀天之道一條言學者只當以天道爲法切不 |
| 天生天殺 | （见正文） |
| 天有五賊 | 妙也 天有五賊一條言天人造化有體用合一之神天性人也一條言人之同天只在一機字工夫天發殺機一條言天人發機之利害 |
| 天地萬物 | 天地萬物一條言天人萬物同此道之理能動此機則有相盜之妙故曰一條言盜天地萬物之機必要因時而人知其神一條言天地萬物有神妙處世人不知用盜機之法意上 |
| 天之無恩 | 天之無恩一條言人當以無心養此心之機 |
| 一條言天 | 妙也 天有五賊一條言天人造化有體用合一之神天性人也一條言人之同天只在一機字工夫天發殺機一條言天人發機之利害 |
| 性有巧拙 | 性有巧拙一條言機在九竅發動人皆可爲伏藏之法 |
| 火生于木 | 火生于木一條引事以明三九汲發動之所以邪也學者當推類以爲脩煉功夫 |
| 執天之行 | 觀天之道執天之行盡矣陰符經聖神學也學聖神之學者不外乎天道故經首曰觀天之道天者理與氣也吾人性命之源也凢昭昭在上而運行不息者皆天道也學者仰而觀之觀研審造化無端之意也觀先天而天者 |
| 立天之道 | 能去人惟識其情狀而用之大有益于身心也以見字看上文觀天之道觀字殊有淺深天性人也人心機也立天之道以定人也 |
| 道之理也 | （见正文） |
| 絕利一源 | 瞽者善聽聾者善視絕利一源用師十倍三返晝夜用師萬倍 % |
| 自然之道 | 人以愚虞聖一條見下資不學之害自然之道一條總說三篇功夫當求自然之妙是故聖人一條言陰符傍通無間示學者卽物窮理以明天人合一之機 |
