# 辰州符咒大全 · 文献结构索引

## ⛔ 硬边界（先于一切）

1. **不可实操**：不教授画符笔顺复现、不抄录完整驱役咒语操作链、不协助「召将／镇鬼／治病符」实施。
2. **违法风险**：以符咒恐吓、诈骗、伤害、干扰医疗、侵扰他人——可能触犯治安／刑法；本 skill **拒绝**此类请求。
3. **医疗**：疾病只就医；符咒治病属危险迷信。
4. 用途仅限：宗教史、民俗学、文献目录、出版研究。
