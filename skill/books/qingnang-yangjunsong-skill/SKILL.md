# 青囊序 + 青囊奥语（杨曾系入口）

## 定位

- **序**：雌雄、金龙、量山步水；驳"阳山阳向水流阳"
- **奥语**：九星举例四句 + 玄空十要 + 进退
- 给判断框架，不给可硬推完整排盘算法

## 青囊序总判

1. 先问**金龙动不动**，次**血脉认来龙**；龙分两片阴阳，水对三叉
2. 江南江北、江西江东对望交媾；**山上龙神不下水，水里龙神不上山**
3. "但逢死气皆无取"——衰旺优先于坐向口号
4. 二十四山分顺逆共四十八局；阳左阴右；驳净阴净阳贵贱说
5. 前后八尺不宜杂；三节四节不须拘，只要龙神生旺
6. 水主财禄山人丁；乾坤艮巽号御街；旧坟十有九贫因不合
7. 得四失六 / 一行扰乱五行

## 奥语九星举例

| 口诀 | 同例 | 星 |
|---|---|---|
| 坤壬乙 | 坤壬乙 | 巨门 |
| 艮丙辛 | 艮丙辛 | 破军 |
| 辰巽亥 | 辰巽亥 | 武曲 |
| 甲癸申 | 甲癸申 | 贪狼 |

是同元同气举例组，非固定星属。颠颠倒有珠宝，顺逆行有火坑。

## 玄空十要

1 龙身行止 → 2 来脉明堂不偏 → 3 功曹不高压 → 4 明堂十字 → 5 前后相照 → 6 城门锁正气 → 7 天心十道 → 8 屈曲流神 → 9 平地青云一理 → 10 **一缺非真情**

## 进退

外出入=进（财积）；内生出=退（财费）；出入克入=旺。天心既辨，向中放水看。

## 流程

金龙雌雄 → 入首清纯 → 山水龙神不错位 → 十要 → 进退 → 死气弃 → 细排转辨正/天玉

## 边界

四库削伪注；举例句勿硬套；术数非可验证因果。
