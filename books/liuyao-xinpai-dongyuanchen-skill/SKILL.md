# 六爻新派：董元辰体系

## 它是什么

这是一套与传统纳甲（野鹤一系）**方法论不兼容**的体系。差别不在细节，在底层：

| | 传统派 | 董元辰新派 |
|---|---|---|
| 旺弱来源 | 月建 + 日辰（日辰四时俱旺） | **年干合神占 50 分** + 年支月令共占 50 分；日辰不参与定旺弱 |
| 核心坐标 | 用神 | **世爻**（世爻中心论） |
| 六亲 | 按本宫五行固定 | **按世爻重排**（生世为印、克世为官杀…） |
| 吉凶判据 | 用神有无生克权 | 先定世爻旺弱 → 再分喜忌 → 忌受制主吉、喜受制主凶 |
| 空亡 | 旬空一种 | **先天旬空 + 后天轮空**两套 |
| 日辰地位 | 主宰 | 不参与定旺弱，只作时点 |

**结论：不要用传统派的"用神旺相则吉"直接套这套体系，也不要反过来。用哪一派先声明。**

## 一、干支作用论

### 五行生克的基本顺序

- 相克：金→木→土→水→火→金（顺次相克）
- 相生：金→水→木→火→土→金（顺次相生）

天干之间完全按上表。**但地支之间不完全是这样**——四土（辰丑未戌）与各行的关系有专门规定，这是本体系的第一处特色。

### 四土与火

- 辰、丑见巳午火 → 辰丑**增力**，不论晦巳午火（地支层面火不生土，土反受益）
- 辰、丑见丙丁火 → **丙丁被晦**（天干层面反被晦）
- 未、戌见巳午火 → 未戌增力，**巳火不减力**
- 午见未为合 → 午减、未增
- 未、戌见丙丁火 → 丙丁受伤

### 四土与金

- **辰、丑能生**天干地支之金
- **未、戌能脆**天干地支之金（不是生，是脆伤）

### 四土与水

- 辰、丑**不克**亥子水；但**克壬癸水**，且辰丑自身也减力
- 亥子水见辰丑 → 双方皆不减力（水不受伤，土不耗力）
- **未、戌克**亥子水

### 四土与木

- 戌卯互见 → 戌增力、卯减力
- 未卯互见 → **互绊，皆减力**
- 寅克辰丑未戌四土

### 四土彼此

- 刑：丑戌互刑、辰未互刑（皆减力）
- 冲：辰戌互冲、丑未互冲

### 刑与冲

- 刑：丑戌互刑、辰未互刑；**巳刑寅，不论寅刑巳**（寅见巳火，寅木减力、巳增力）。附带一条：雨水前的寅木力弱，不克水、不生火，遇水减力
- 冲：子午、辰戌、丑未、寅申、卯酉、巳亥。按情况分三种：
  1. 旺冲弱 → 弱者受伤
  2. 弱冲旺 → **旺者更旺**
  3. 同旺衰 → 双方皆受伤，但**动爻力大于静爻**，主静爻受伤重

### 合与半合（本体系的合是按"谁增谁减"算，不按化气算）

- 六合：子丑（双方皆减）；寅亥（**寅增亥减**）；卯戌（**卯减戌增**）；辰酉（**辰减酉增**）；巳申（双方皆减）；午未（**午减未增**）
- 半合：子辰（双方均减）；卯未（双方皆减）；丑酉（**丑减酉增**）；午戌（**午减戌增**）
- **年、月、日、时参与合绊时不减力**——因时间不减力

### 三合成局的条件（六条）

1. 卦中有三个动爻 → 可论绊
2. 卦中有二个动爻 → 可与动出的变爻论合绊
3. 卦中只有一个动爻 → **不可以合绊论**
4. 卦中无任何动爻 → 有一字**先天旬空**时，可论三合绊
5. 三合绊局中只要有一字受伤，即**不以实局论，以虚局论**（如申子辰绊局有巳火伤申，则以申子辰虚设论，过巳火日才以实论）
6. 卦中有两组以上三合绊局的**全不论**，以生克论（但须是六爻全动而构成的三合绊）

补充：合神的影响大于局部冲克。例——辛巳年起得申子辰，合神丙辛水帮子水，三字中有一字受合神影响大，即可成绊，**虽有午冲子，仍然成绊**。

## 二、卦爻作用论（十条）

这是本体系规定的"哪些爻之间才发生作用"：

1. **隔不作用**——中间隔一爻则不相作用
2. **隔空作用**——但中间隔着空爻时可以作用（空爻不阻隔）
3. 世应作用
4. 动动作用
5. 动世作用
6. 动应作用
7. 飞伏作用
8. 动变作用
9. **初爻与六爻作用**
10. 世爻本身不空，但当卦中有旬空之字或后天轮空时，**其上下之爻可隔着世爻作用**——此时世爻只是虚设，只被动接受他爻作用，而空爻不能主动与他爻作用

## 三、六亲定位论（世爻中心论）

**以世爻为中心重排六亲：**

- 生世者 → 印（母）
- 克世者 → 官杀
- 同世者 → 比劫
- 世生者 → 食伤
- 世克者 → 财

**卦中不现的六亲，皆看应爻。**

### 天然全息论：以世为中心的万物类象

**生世者（印）**
- 母亲、信件、布匹、涂料、皮肤、网站——**总之一切有覆盖含义的事物**
- 男测正印为母，女测枭为母
- 也代表担心、惊吓、害怕、恶梦
- 枭神还代表岳父

**世克者（财）**
- 一切自己所支配的事物
- 男测：正财为妻、为工资、为正当收入；偏财为父亲、为情人、为工资以外的收入
- **偏财还代表身体健康情况**——财星起好作用主身体健康，起坏作用主身体差

**克世者（官杀）**
- 一切制约自己的事物
- 女测七杀还代表生意、情人
- 正官为小领导、小干部；七杀为大官、掌实权、或武将、凶势力大，也代表地痞流氓、混子、黑社会头目或其成员
- **但主要指工作、生意、企业、自己的收入来源**

**世生者（食伤）**
- 一切自己所付出的事务
- 男测食为儿子、伤为女儿；女测食为女儿、伤为儿子
- 也代表作品、汗、排泄物、厕所地
- 也代表能力大小、口才、技能、口舌、是非。起坏作用或有口吃等
- （八字中代表食物——小孩月子里没奶吃，定是食伤起了坏作用）

**同世者（比劫）**
- 一切与自己相当的人，也代表耗财、竞争对手
- 起好作用 → 发财、有朋友相助；起坏作用 → 破财、有人争财、坏事

**一条极重的断言：**
> **食神还代表灵魂、梦；印为人的外壳。此二字皆为凶时，主人死亡。**

## 四、五行旺衰论（本体系最核心）

### 年干合神定五行旺弱

> **甲己土旺、乙庚金旺、丙辛水旺、丁壬木旺、戊癸火旺。**

判世爻旺弱**以合神为主**：合神帮扶谁，谁旺；合神克谁，谁弱。

**合神占 50 分，年支、月令两者共占 50 分。**

（注意：日辰不在这套算分体系里，与传统派"日辰为六爻之主宰"根本不同。）

### 四卦型

| 卦型 | 判据 |
|---|---|
| **一、世弱卦** | 合神克泄世爻，月令不制约世爻 |
| **二、从强卦** | 合神帮扶世爻，月令再帮扶世爻 |
| **三、从弱卦** | 合神不助世爻，年月支不助世爻 |
| **四、世旺卦** | 合神帮扶世爻，年月一个助世爻 |

### 三条前提（定旺弱前必须先查）

1. **月令旬空时** → 世爻旺弱由合神与年支决定
2. **月令两次受制时** → 世爻旺弱由合神与年支决定。（"两次受制"指月令受年支、日支的泻、晦、冲、刑、绊五种情况，**只有"耗"不算**）
3. **月令失去作用的前提下**，年支生合世爻时，以**世爻减力**论。例：世未土见年支午火，世被年支生合 → 世弱；世辰见酉、丑见酉、卯见亥、寅与亥、戌世见午，皆以世减力论。生旺、旺墓、六合绊皆如此

## 五、喜忌辩证论

### 总原则

> **喜神受制主凶，忌神受制主吉。**

操作顺序：起卦 → 先定世爻旺弱 → 区分喜忌神。**但卦中若有旬空爻，首先考虑空爻。** 关键看组合。

### 反断的两条例外

1. 当忌神根据卦中组合**起好作用**时，被制反而不吉；用神起坏作用时，逢生扶反而应凶
2. **凡合神克某爻，而年月又来克之时，此爻反断**

### 喜忌的确定

- **世弱卦、从强卦**：克泄耗世者为**忌神**，生扶世者为**喜神**
- **世旺卦、从弱卦**：克泄耗世者为**喜神**，生扶世者为**忌神**

### 空亡的反转

> **喜、忌神旬空时：喜神填实出现时变为忌神，忌神出空时变为喜神。即"喜空为忌，忌空为喜"。**

## 六、先天制约论

**卦中喜忌神受制，即为先天制约。** 当流年该喜忌神到位，或制该字的五行到位时，则应凶或应吉。

作者自评："极为重要，为断卦依据。"

## 七、合神主断论（干支分断论）

定流年吉凶的规则：

- **流年干与世爻阴阳同性** → 该年吉凶**以合神为主断**，同时干支分断
- **流年干与世爻阴阳不同性** → **干支分开断**，不再看合神

例（世爻酉金）：
- 丁丑年：丁与酉同为阴性 → 以合神为主断。以财论，丑生世为次，主改行；但丁火的事业还存在；丑冲未主后来的位置不要了；丁到位做生意
- 己卯年：同为同性 → 己为名誉、卯为财，都受制了
- 辛巳年：辛金以水来论，辛毕竟为金，也主破财不吉；辛为同事朋友骗走钱或借走
- 壬午年：壬与世不同性 → 分开断，不能再看合神
- 甲申年：申到冲寅木，**弱者冲旺者，越冲寅越旺**，但辰土受寅木克重；申绊巳也主发财；甲来了只看甲木不看合神；异性时天干地支分开断；甲申到伏神成申子辰三合绊局；申到比劫与自己单干了，朋友原来的工作不干，辰子申被制

## 八、先天旬空论与后天轮空论

### 先天旬空

卦中按**起卦日**所定的旬空字为先天旬空。

> **无论在何种情况下都为空，且该字不对其他字作用，只是被动地受其他字作用，只能被动地受他爻克冲泻耗，该字无力作用他爻。**

但**字出空却能体现事**。例：卦中申为朋友，当先天受制多次，主好换朋友、朋友工作多动多换。断其它六亲时同理。

### 后天轮空

卦中除了先天旬空字之外，全为后天轮空字。**不轮空时不空。**

两个特性：
1. **即时性**——卦中衰弱之爻轮空即失去作用
2. **延迟性（惰性）**——卦中强旺之爻轮空**尚有余力**，只有再加一个外力时此余力才失去

经验：贴近世爻的弱爻所代表的六亲，为喜为忌而后天轮空亡时，他爻再起好或坏作用时，则应轮空之爻所代表的吉事或凶事。

### 关于旬空的一段总论

> 旬空是五行阴阳交变过程中一个最显著的太极点。空为无，为太极点，是阴阳转化之终点同样也是始点。所以找旬空、断旬空是极端重要的。

几条操作规则：
- 旬空则无，逢值则填实
- **静爻逢空：如是用神则为忌，是忌神则为喜**（与传统派恰好相反的处理逻辑）
- **动空是暂时空，不为空**，出空逢值应事
- **空，则他爻可越位生克**——如三爻旬空，二爻可生克四爻，四爻也可生克二爻
- 卦中有忌神起坏作用，必待忌神旬空（轮空）或逢冲之月日时应吉
- **所有的应期都与旬空有关**

## 九、伏吟改造论

**前提：先定世爻旺弱。世旺卦伏吟主吉。**

定义：卦中**紧贴上下两爻为同一字**时为伏吟。

规则：
- 伏吟之字如出现，或由于空亡而造成伏吟组合，参与伏吟之字**皆减力**——即"越生扶越减力"
- 该伏吟之字**越受制时，力量反而转强旺了**
- 但当两紧贴的字是**先天轮空亡**时，不以伏吟论
- 断吉凶时，参与伏吟的爻所代表的六亲吉凶**反断**：当吉时以凶论，该凶时则以吉论
- 参与伏吟二字弱时，被冲则冲掉了而不再伏吟；其它情况伏吟之字旺逢制时，越制越旺

卦型与伏吟：

> **世弱卦伏吟主凶，从强卦伏吟主凶，从弱卦伏吟应吉，逢生反而应凶。**

以上仅指**参与伏吟的爻**，伏吟以外的字仍按正常断法。

## 十、进退辩证论

- 亥化子为化进，午化巳为化退
- 子化亥为化进，巳化午为化退
- 寅化卯为化进，卯化寅为化退
- 申化酉为化进，酉化申为化退
- 辰化未为化进（原文作"化时"，疑为讹字），**但不起作用**
- 未化戌为化进，戌化未为化退

一般规则：喜神化进为吉、化退为凶；忌神化进为凶、化退为吉。

⚠️ **素材内部矛盾须注意**：原文"亥化子为化进，午化巳为化退。子化亥为化进，巳化午为化退"——这两句自相矛盾（子化亥与亥化子方向相反却都称"化进"）。疑为传抄讹误，**引用前须先确定方向，不可两个都当进神用**。

## 十一、卦爻组合论（组合优先论）

> **化进化退不一定"化退忌神应吉、化退喜神应凶"，关键还得看组合。**

这是本体系的收口原则：进退、伏吟、喜忌都只是局部判据，最终由**组合**决定。

原文例：应爻为辰土化退为丑，本是忌神化退应吉；但寅木化午火化进，午火克辰土，又主吉利——两个方向叠加，须综合看。

另一条组合优先的经验：

> **凡起卦时，年支、日支、时支参与应爻且起了坏作用时，主终生婚不稳定。**

## 十二、虚实论

1. **卦中世爻只有一字时为"虚字"**，除世爻之外的字全为"实字"，其中又分实忌神、实喜神。实字包括变卦之爻及伏爻。**卦中不见的字为虚字（不包括四墓库）**
2. 当流年虚喜神到时**不应吉**，虚忌神到位时**不应凶**——"不应凶不应吉"是指**好坏程度不可确定**（吉到什么程度、凶到什么程度定不下来）
3. 当虚字与卦中字构成**克合或合绊**时，该虚字以实论。只有**生合与合生**时，该虚字才以虚论
4. **天干都是实字，不论虚字**；去掉四个墓库，剩下的虚字就不多了

## 十三、财运断法

**断所有事情都离不开食伤。**

> 测财运好坏看财星和食伤星，**二者同时起好作用时大富，起坏作用时无财、不富。**

两条经验：
- 凡是**世弱、辰丑持世时，亥水贴世主富**
- 如果**世旺、辰丑持世时，亥水贴世主穷**

## 使用流程

1. **确认用新派**：先跟用户确认要按新派（董元辰）断，不要与传统派混用
2. **定合神**：看年干 → 甲己土、乙庚金、丙辛水、丁壬木、戊癸火
3. **查前提**：月令是否旬空？月令是否两次受制（泻晦冲刑绊，耗不算）？
4. **定世爻旺弱**：合神 50 分 + 年支月令 50 分 → 判出世弱 / 世旺 / 从强 / 从弱
5. **重排六亲**：以世为中心，生世印、克世官杀、同世比劫、世生食伤、世克财
6. **分喜忌**：世弱从强 → 克泄耗为忌、生扶为喜；世旺从弱 → 反之
7. **查空亡**：先天旬空（不作用他爻）+ 后天轮空（弱爻即失，旺爻有余力）
8. **按作用论取象**：只让"隔不作用/世应/动动/动世/动应/飞伏/动变/初六爻"这些关系生效
9. **过一遍专项论**：先天制约、伏吟改造、进退辩证
10. **组合优先收口**：所有局部判据冲突时，以组合定
11. **定流年**：流年干与世爻同性 → 合神主断 + 干支分断；异性 → 干支分开断
12. **虚实校核**：虚字到位的吉凶程度不可确定，须说明
