# 医方歌括 · 蒸馏技能

**来源**：《医方歌括》，清·王泰林（旭高）
**性质**：杂病名方**韵语速记册**——一方一歌，括组成、主治与出处；不如《医方证治汇编歌诀》有长按语，也不如《增订医方歌诀》专攻水气汗下
**文本说明**：IMA 库文件为全零空文件；本技能据维基文库公域文本蒸馏
**使用边界**：古籍文献参考，不构成医疗建议。部分方含川乌草乌、麝香、雄黄等，仅作文史检索。

---

## 一、本书用法

1. **输入**：证候关键词或方名 → **输出**：歌括骨架（君臣大意 + 主治锚点 + 出处）
2. 歌中括号为嵌入注：药量别名、出处书名、《金匮》原文提示
3. 与《汤头歌诀》（汪昂）不同系：本书杂采《素问》《金匮》《千金》《局方》《宣明》至明清时方，不按二十门严格分类

## 二、按病机簇速查（精华方）

### 1. 神志睡眠 / 精神

| 方 | 歌括要点 |
|---|---|
| 半夏秫米汤（《素问》） | 和胃、泄卫通营治不寐；厥气逆、阳不交阴 |
| 防己地黄汤（《金匮》） | 独语；桂甘二防，酒渍绞汁 |
| 孔圣枕中 / 定志（互见汇编） | 善忘、远志菖蒲轴 |
| 白薇汤（《本事》） | 妇人平居忽如死——郁冒 |

### 2. 黄疸 / 肺痈 / 奔豚 / 下血下痢

| 方 | 要点 |
|---|---|
| 栀豉大黄汤+枳实 | 酒疸心中痛懊憹 |
| 茵陈蒿汤变 | 谷疸（前方去豉枳加茵陈） |
| 葶苈大枣泻肺 | 肺痈不卧喘 |
| 苇茎汤 | 不喘但咳、胸皮甲错 |
| 奔豚汤 | 四物+柴胡+桂枝意，去桂柴加生地 |
| 黄土汤 | 先便后血；术附芩甘阿胶地黄——脾虚阳陷 |
| 白头翁汤 | 热利下重；连柏秦皮坚阴 |

### 3. 肺胃津伤 / 燥 / 消渴

| 方 | 要点 |
|---|---|
| 麦门冬汤（仲景） | 火逆上气咽喉不利；从胃生津 |
| 清燥救肺汤（喻嘉言） | 补经方所未备之燥门；桑叶石膏麦冬人参胡麻阿胶杷叶杏甘 |
| 麦门冬饮（《宣明》） | 膈消；知参花粉地味等 |
| 竹叶黄芪汤等复方 | 气血两燥消渴 |
| 神效散（鲫鱼胆等） | 咸寒止渴消水 |

### 4. 中风瘫痫 / 痰瘀络

| 方 | 要点 |
|---|---|
| 侯氏黑散 | 中风；参苓姜桂术归芎细辛牡蛎等 |
| 风引汤 | 热瘫痫；多石药+龙牡——猛剂宜审 |
| 鳖甲煎丸 | 疟母；合桃核承气+小柴胡意加减 |
| 小活络丹 | 川草乌胆星地龙乳没——络痰死血 |
| 大活络丹 | 五十味；四君四物打底+风药 |
| 牵正散 | 白附僵蚕全蝎——口眼喎斜 |
| 鸡鸣散 | 脚气；木瓜姜橘茱萸槟桔苏，五更冷服 |

### 5. 救急成药（与《经验奇方》互见）

| 方 | 要点 |
|---|---|
| 玉枢丹（紫金锭） | 五倍千金子大戟山慈菇麝——却邪解毒 |
| 苏合香丸 | 寒阻灵窍；诸香+犀朱 |
| 抱龙丸（四方） | 惊风随证：辰砂抱龙等 |

### 6. 痛证 / 疟利 / 肿胀

| 方 | 要点 |
|---|---|
| 金铃散 | 热厥心痛；川楝延胡 |
| 雪羹汤 | 荸荠海蜇——肝经热厥腹痛 |
| 安胃汤 | 参椒梅枳姜连——辛酸化肝甘和胃 |
| 四兽饮 | 六君+乌梅草果——气虚痰疟 |
| 禹余粮丸 / 小温中丸 | 水邪肿胀、湿热中满 |
