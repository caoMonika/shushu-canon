# 星命古籍合参

合并四源。**星命总括 TXT 全 0xFF 损坏**；星学大成仅存「教外别意」杂诗与窦陶十问。以月波、月谈为可读主干。

## ⚠️ 边界

星命以出生时刻排十二宫推命，无实证效力；不可用于评价活人、医疗、婚配决策。

---

## 一、十二宫总框架（星学残篇 · 窦陶十问）

人事不离十二宫。问答要点：

| 问 | 答要旨 |
|---|---|
| 太岁当头 | 克我为祸；马/禄/贵当头各有劳辱象 |
| 命限空亡 | 福祸皆虚；马禄妻奴财官空各有专断 |
| 长生十二 | 马遇长生等多动；女命喜忌与男相反处须分 |
| 二十八宿立命 | 鬼、心、亢、井、箕、毕等宿度有专忌，不可例断 |
| 隔界 | 子丑兼壬癸等，须辨宫神与度之轻重 |
| 小儿关 | 三方拱夹为煞门；四季忌对宫（春忌酉等） |

**教外诗诀主题**：空亡拱夹、贴衬、用宿冲实、驾前天空／驾后蓦越、太岁填恩、流旬御史空、凶星留与交限迟速。

## 二、《月波洞中记》（相术九篇 + 八限）

九篇：仙济、九天玄微、冥度、灵岳、幽隐、河岳、心隐、贯德、玉枕。

- **五岳四渎**：额衡、颏恒、鼻嵩、左颧泰、右颧华；眼淮耳江口河鼻济。
- **八限年限**：耳15、额10、眉4、眼6、鼻10、上下唇20、颏5 等（文献数字）。
- **玉枕骨法**：车轴、仰月、覆月、方枕、一字…十八般。
- 总则：先骨法神气，次纹理黑子；相外必先试性行（目口验心）。

## 三、《月谈赋》（子平口诀体）

命主一世，运察流年。常用断语轴：

- 财父印母；财印两全椿萱并茂。
- 男：旺财为妻、正官为子；女看食官。
- 格用：财官弱须行财运；身弱忌再临财官。
- 忌：年冲月令破祖；印遭伤难守业；伤入官途休官。
- 性情：木仁水智金义火礼土信——按格局五行偏重说气质（文献义）。
