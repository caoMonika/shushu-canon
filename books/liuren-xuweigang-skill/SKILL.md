# 徐伟刚六壬技术体系

## 一、总纲：十二神将论

徐氏全部技术都挂在一个命题上：**六壬就是神将论**。

- 神不离将，将不离神；神无将不灵，将无神不应。
- 分工：**十二神行"生克权"**（六亲生克、长生十二诀、以神拟象）；**十二将行"主宰权"**（定事的性质与成败）。
- 结论：**将高于神，吉将永吉，凶将永凶**；以将统神，神随将转。传统"以神之生克定将之吉凶"是错的。
- 实操含义：断一课，先看天将定基调（吉将/凶将），再看神之生克定细节与程度，最后以象落实。

## 二、十二局天地盘面（袖里乾坤独有，最好用的速判工具）

天地盘一转，盘面形态本身即一个大格局。十二种基本盘面：

伏吟盘、退连茹盘、退间传盘、病胎盘、逆三合盘、四绝体、反吟盘、四墓覆生盘、顺三合盘、生胎盘、顺间传盘、罗网盘。

用法：起课先认盘面属于哪一局，即知大势倾向（如伏吟主静、返吟主动而反复、四绝体多凶、生胎盘主生发、罗网盘主困、四墓覆生主废而复起）。**盘面定势，三传定事，神将定成败。**

## 三、三传总汇

三传不只看三个字，要看"传布形态"：

- 进传（如午申戌）、退传（如午辰寅）：事之进退。
- 间传（跳位）、连茹（连位）：事之顺逆与缓急。
- 三合局成局：事成之象，须看局中何神当令。
- 空陷、入墓、被冲：传之"断点"，事到此处转折或终止。
- 传归何处：末传所临定结局落点。

（原书"三传总汇"为表格式逐类列举，本技能只取其判读原则，不复制表格。）

## 四、月将释论（十二将逐一）

月将＝太阳所躔之宫，**当值之将**。逐一有释论，要点在此：

- 登明亥、河魁戌、从魁酉、传送申、小吉未、胜光午、太乙巳、天罡辰、太冲卯、功曹寅、大吉丑、神后子。
- 释论体例：本位象、所主事物、加临十二宫之别象、乘十二神之别象。
- 关键象（徐氏常用）：**太冲卯主舟车**（故"神舟"取卯）、**传送申主道路行人**、**河魁戌主印绶文书**、**天罡辰主争斗罗网**、**登明亥主天门**、**小吉未主酒食婚姻**。
- 月将之理论基础另章讨论（太阳运动与人事相应），实践上记住"月将定当令之气，将吉则事有贵气"即可。

## 五、天将释解大全

十二天将各有专章（贵人、螣蛇、朱雀、六合、勾陈、青龙、天空、白虎、太常、玄武、太阴、天后），每将讲：设置原理、本象、吉凶两面的用法、加临与乘神之变。

要点：

- **将之吉凶是"恒性"**——吉将永吉，凶将永凶；凶将所临得地、有制，则凶减而不转为吉。
- **将为"主宰"**：事之成败由将定；神只是把将的性质具体化到某类人事上。
- **将随事变形**（与秦瑞生同调）：青龙占功名吉、占病则为煞；白虎占病凶、占官则主速。
- 现代象意另章（《智者乐水》"十二神将现代象意"）：古象须换成当代物象，如天吏天城不再是"骑马送公文"，而是"上级机关/批文"。

## 六、神煞：六层体系

按来源分层，用时不乱：

| 层 | 依据 | 例 |
|---|---|---|
| 岁煞 | 太岁 | 岁破、丧门、吊客、官符 |
| 季煞 | 四季 | 天喜、天赦、浴盆 |
| 月煞 | 月建 | 月厌、月破、生气、死气 |
| 旬煞 | 旬空 | 旬空、旬丁 |
| 干煞 | 日干 | 日德、日禄、羊刃、飞天 |
| 支煞 | 日支 | 支德、支破、支刑 |

徐氏的用法与伍剑虹相反：**神煞用得极重极活**，是"克应"的关键（决定课"应不应、应在何细节"）。断大事看神将，断细节、断奇象靠神煞。

## 七、六亲与长生十二诀

- 六亲：父母（生我）、子孙（我生）、官鬼（克我）、妻财（我克）、兄弟（比和）。
- 长生十二诀：长生、沐浴、冠带、临官、帝旺、衰、病、死、墓、绝、胎、养——一气之始终。
- 用法：六亲定"是什么事"，长生诀定"这事的生命力到哪一段"。官鬼临死墓绝而占病，凶；妻财临帝旺而求财，得。

## 八、判断纲要：四课—日辰—发用—三传

1. **论四课**：第一课日之阳神、第二课日之阴神、第三课辰之阳神、第四课辰之阴神。阳神表已显，阴神表内因。
2. **论日辰**（毕法集要所在，摘其常用条）：
   - 互生俱生万事宜；人宅受脱俱招盗；彼此全伤防两损；
   - 富贵干支逢禄马（干上禄支上马，或干上马支上禄；考试工作最喜，占病则宅移人动，大凶）；
   - 干支皆败势倾颓。
3. **论发用**：发用为事之机。发用空陷则事无根；发用乘凶将则凶速；发用克日则事来逼人。
4. **论三传**：初传发端、中传移易、末传归计；三传递生主顺、递克主阻。
5. **占断基本步骤**（《智者乐水》与《揭秘》共列）：定盘面 → 认四课主客 → 取发用 → 看三传 → 落年命 → 取神煞克应 → 定应期。

## 九、点将法（初学入门权宜法）

徐氏自述为"方便法门"，非根本法。四要点：

1. 强调天将最重要，将之吉凶最根本；
2. 强调四课三传这一"六壬独有的形式特征"；
3. 用将之吉凶大致断出事的最终结果（方向性判断）；
4. 强调必须真正了解每一将的意义。

作用：初学者一上手就抓住"将"，不至于在神煞与生克里迷路。学深之后自然过渡到象断与理断。

## 十、硬判据（可直接套用）

- **正象高于通象**：本命是正象，日干是通象。断具体某人，先看本命；日干只代表"今日来问的所有人"。付彪课即以本命卯木（肝）受上下申金夹克断肝癌，而非用日干。
- **年命四则**：①命重于年；②年命本身重于年命上神；③年命可直接入四课三传议论；④日干与年命是"体用"关系。
- **占病见马主"人走了"**：驿马本象主行动远行，占病逢马即"人将远行不返"，不必绕到"神气出游"。
- **虎主癌症/恶疾**：恶虎吞食一切，癌细胞亦吞食正常细胞，性能相类。
- **丁神主动摇**：占病见丁马为凶动；占事见丁主变动不安。
- **贵人克命，祷神无方**：占病而贵人（又作太岁月令）克本命，主求神无效。
- **空亡**：徐氏重"应空"，不取"填实"（与《指南》派陈公献讲填实不同，此处两说并存）。
- **现代占病最忌火神或三合火局**：时代生活变了（今人多热病、炎症、心血管），古之"凶煞"要让位于今之实况——这是"与时俱进取象"的典型例子。
- **错误起课约占一成**："错误的艺术"——起错、断错本身是系统开放性的表现，遇课象与事实完全不符时，先疑起课，不必强断。

## 十一、经典断例（取象方法示范）

- **神舟五号**（癸未年巳月己巳日巳将酉时）：干上卯＝太冲＝舟船，乘丁＝点火，乘白虎＝轰鸣冲天；中传亥＝天门且空＝射入太空；末传未＝太岁＝国家元首、又为"井泉"象＝酒泉；支上丑＝腹＝返回舱，乘青龙＝平安。应期取"合卯之月、冲卯之日"（戌月辛酉日）。
- **付彪病课**：本命卯木为肝，上下两申夹克（白虎＋贵人），虎主癌、贵人为神为太岁月令、祷神无方；卯带丁为换肝手术；中传戌空、末传巳玄，断不过次年秋。
- **一课值千金**：夫命丙午作太阳合太岁成局作生气（事业通全国），妻命丁未作贵人作月令加天门（富贵非常）——**大格之课，看年命本身格局，不看单字吉凶**。
- **相似之课**：同日两课近似，以"挂羊头卖狗肉"取象断生意性质，说明取象可以极活，但须有象可循。

## 十二、六壬与相邻术数

- **六壬与纳甲（六爻）**：六爻是"人为造一个后天之象"，六壬是"以天时定先天之象"；徐氏判六爻体系先天不足（此为其个人立场，非公论）。
- **六壬与八字**：六壬测人事、八字测天命；**课命法**＝时课与八字择器而用（有时课准而八字不准，有时反之），"课不离命，命不离课"。
- **三式关系**：太乙天元、奇门地元、六壬人元；"壬不离遁，遁不离壬"。
