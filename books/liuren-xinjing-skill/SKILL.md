# 大六壬心镜（唐·徐道符，清·程树勋/郑天民校，易仙客整理本）

拟经作歌、以经自注的六壬"教科书"，备格一百八十一篇分八卷。宋元迄今壬家奉为圭臬，邵彦和、元轸等宋人断案多直接引"心镜云"。本技能蒸自易仙客整理版（程树勋手录+郑天民校+郇应清注+《六壬入式》《兵机三十占》参校本），条文判据均出本书。

## 一、九宗门发用总诀（卷一·释课元微门）

起三传的九种法定次序，务必先审课体再断：

| 门 | 条件 | 发用取法 |
|---|---|---|
| 克贼 | 仅一上克下（或一下贼上） | 上克下名"克"取之；下克上名"贼"优先取贼；有贼则弃克 |
| 比用 | 二三四课交相克 | 取与日干比者：阳日用阳神，阴日用阴神 |
| 涉害 | 俱比俱不比 | 取受克/克害日最深者；复等则刚日取日上、柔日取辰上 |
| 遥克 | 四课上下无克 | 先取神遥克日（蒿矢），无则取日遥克神（弹射）；两贼一克时仍择比者 |
| 昴星 | 无克无遥 | 刚日取酉上神，柔日取从魁（酉）所临神；中末：刚日先辰后日，柔日先日后辰 |
| 别责 | 四课不全（仅三课）无克无遥 | 刚日取干合上神；柔日取支三合上神；中末皆归日上 |
| 伏吟 | 天地盘相同 | 有克取克；无克刚日日上、柔日辰上；迤逦刑为中末（自刑则次传并日辰再刑/冲取末） |
| 返吟 | 天地相冲 | 有克依比用涉害；中传对冲、末归初上；丁丑丁未己丑己未辛丑辛未六日无克，取辰冲（丑冲巳未冲亥）为用，对冲为传 |
| 八专 | 干支同位仅两课 | 有克比并涉害；无克刚日从日上顺数三神、柔日从二课逆数三神为用，中末重日上；数到日辰则三传飞散（独脚课不可重临） |

## 二、宗首九科卦格（吉凶基调）

- **元首**（一上克下）：臣忠子孝，事因男子起，利为客、先诉胜。
- **重审**（一下贼上兼有克）：子逆臣乖，事起女人，万事难顺，宜被告不宜先诉。
- **知一**（比用）：事因同类起，失物邻人取，逃亡不远离，讼宜和。
- **见机**（涉害）：作事羁迟多疑，盗贼邻里戚亲起。
- **蒿矢/弹射**（遥克）：蒿矢射我虽端不畏，弹射纵中无力；贵人逆转子不良。
- **虎视**（昴星）：出入关梁稽留，刚日出门身不归，柔日伏匿防不测，女多淫泆。
- **信任**（伏吟）：行人立至，失物家内盗，病喑哑，胎聋哑。
- **无依**（返吟）：逃者远寻，合者分散，官必易位，夫妻外心，占病两般侵。
- **帷簿不修/芜淫/泆女**（八专、阴阳不备）：奸私淫泆之占——初传天后末传六合为泆女（女携男奔），初末反向为狡童（男诱女）；乘元武、六合、太阴更的。

- **五合物候**（十杂卦）：甲己怀木胎果熟带青、乙庚琼花开绿林、丙辛枣赤叶落红、丁壬桑椹紫、戊癸草黄——用于射物色。

## 四、十二天将喜忌（卷四·杂将门）

12. **天空**（戊戌土）：奴婢虚诈契约；可成小事不可成大事；子小人丑三伏尸寅犯事卯守制辰主虚诈巳临户午入化未施空申鼓舌酉出户戌惊怖亥儒冠。

## 八、使用边界与素材缺陷

1. 本技能条文出自易仙客整理的程树勋手录系统（郑天民校+郇应清注+徐氏《六壬入式》参校），与郭载騋《大全》所采心镜（仅卦象神将歌、弃杂占）不同源；原书八卷一百八十一篇，兵占门系郑/程以《兵机三十占》（明·查之炜《百炼金》）补配，非徐道符原文。
2. 歌诀版本歧异多（如伏吟"先刑后冲"、返吟六阴柔日取用），郑按/伟堂按已标出异文，本技能以整理本为准。
3. 源文 OCR 有水印噪声（秘籍网）与个别错字（"大亥水"应为大海水、"初韧"应为初传），引用原句时需留意。
4. 本技能为古法歌诀判据集成；现代排盘起课教程见 liuren-jichu，课体总表见 liuren-kejing，占验实例见 liuren-duanan 与 liuren-zhinan。
