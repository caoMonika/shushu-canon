# 本地姜峦头诀（梁凿贵）

## 总流程：到地三步

1. **先观水口**——定有无结、定层级
2. **审龙**——贵贱真假、行止远近
3. **点穴**——先破五俗，再避三畏

口诀级总判：**龙真穴的，不论山谷平洋，局紧气聚则催富催贵**。地之盛败出龙身，旺弱兴衰应气运——形管结不结，运管何时发（理气另见 `dili-bianzheng-skill`）。

## 第一步：观水口定层级

| 水口形态 | 结地等级 |
|---|---|
| 城门四周关拦，内有真龙结作 | 有结 |
| 罗星、龟蛇狮象守口 | 上格之龙 |
| 华表、捍门、日月镇守 | 富贵之地 |
| 北神镇塞禁口 | 大贵之龙 |
| 狮子石柱（王侯之门） | 王侯地 |
| 破墙倒壁 | 贫贱之家 |

→ **水口不锁，不必往里看**。见罗星锁口，才跟踪寻宗问祖。

## 第二步：审龙

### 贵龙 / 贱龙

| 贵 | 贱 / 假 |
|---|---|
| 重重开帐，出脉中抽 | 拥胀，无星牵连贯顶 |
| 行度带蝉翼护带 | 枝脚直硬，脉长而僵 |
| 脉细短缩（极贵） | 鹤项鸭头、拥胀粗顽 |
| 带案带禄（贵）、带仓带库（富） | — |

### 行止与穴形（简）

- 过峡跌断必可追；送少迎多行远；来高去小结近前
- **小地多尽结，大地多缩腰（腰结）**
- 硬直不可安插；窝钳须弓脚球檐；乳突须开腮界水；骑龙须回抱
- 有人无财寻仓库之龙；有财无丁莫下孤寒之穴

## 第三步：破五俗

### 俗一：泥于尽龙
尽龙多散漫无好地。正解：**腰结多于尽结**。《疑龙经》干龙穷两砂不关是疑龙。

### 俗二：泥于龙虎钳口（俗害第一）
只认钳口不问砂水顺逆。正解：大地多**下手一边兜转**；有龙无虎等皆可。龙虎均停万人悦慕多立败。

### 俗三：泥于两水合襟
合襟前多嘴尖流直气荡。可裁：合右转左得右砂拦（或反之）。**宁居坐空也不居合水直处。**

### 俗四：泥于顶正星峰
"误葬皆因贪正面，神仙多是下偏坡"。可正下：地小顶平脉缓微突。必侧下：粗硬倾泻煞当头。剪着去水一边尤善。

### 俗五：泥于阔大明堂
明堂太阔风散气。硬条件：**一砂紧拱、内局自成**。"明堂容万马，水口不通舟。"

## 第四步：避三畏

### 畏一：到头硬直
稍硬即杀；枪头鼠尾莫下；饱腹覆钟绷面金卧梭俱死。

### 畏二：穴前倾泻
砂主人丁水主财。阴流直水更凶。真屈曲：左右互十余丈交织成横水。去水地须八分得。

### 畏三：顺砂过堂
顺逆以水来去为准。下砂/进神愈长愈福；顺砂/退神尤毒。**剪下砂莫剪上砂。** 逆局逆龙上手砂不妨。

## 分工与边界

- 专技五俗三畏；含醒心录龙虎断见 `dili-xingshi-skill`；理气见辨正/天玉
- 手抄本讹字难免，遇缺不补；形法不含元运；术数非可验证因果
